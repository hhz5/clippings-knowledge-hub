爬取网页信息

Github 作为全球最大的开源项目托管平台，不仅是程序员最爱逛的网站，也是阿虚这种软件爱好者最常访问的网站—— 我公众号上分享的软件一大半都来自 Github

而现在有了八爪鱼，我终于可以让它每天定时抓取 Github 的项目趋势排行榜，帮我及时发现最新好软件了

只需要用最直白的人话告诉它： 打开 https://github.com/trending，筛选中文的今日趋势项目榜单，提取每个项目的关键信息数据保存到Excel表格

AI 就会自动帮你梳理需求，整理成更规范化的 RPA 流程大纲，大致确认下没问题之后，就可以点击生成流程 👌

直接靠 AI 自动替你分析网页内容，对网页元素标号，精准自动化执行每一步点击、输入等操作

如果试运行有问题，可以进一步让 AI 去帮你修改（有了元素标号你去修改时描述起来也很简单）

如果没问题，那我们就可以直接点击应用，然后运行主流程啦～

由于不再需要测试的时候停下来分析每一步的网页内容，实际执行的时候速度是很快的～

以前还需要手动打开网页、点开每个项目、复制粘贴、整理成表格……麻烦死了

现在有了八爪鱼 RPA，AI 一句话就能替你实现网页自动化需求
