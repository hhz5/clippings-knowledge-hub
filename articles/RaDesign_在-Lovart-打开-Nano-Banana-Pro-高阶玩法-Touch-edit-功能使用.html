大家好，上期介绍了 Lovart 使用方法「 没看到的小伙伴请移步这里： 在 Lovart 打开 Nano Banana Pro 高阶玩法！ 」，那么今天我们来讲讲触摸编辑 “ touch edit ”这个功能。

Touch edit

上期我们用 t ouch edit 功能进行了简单的选取删除插画上的某些地方，其实他的功能远不至此，配合 Nano Banana Pro 模型，是目前最强形态「就好比克林被弗利萨干掉，触发了卡卡罗特机制变身成超1」

1. 角色修改

有些时候 Nano Banana Pro 给到我的东西不是我想要的，我想修改原本的角色但是不想换风格，那么就能解决！

提示： 一张 3D 渲染的可爱卡通 [老虎] 形象，整体为柔和的极简风格。角色拥有圆润光滑的造型、饱满简化的身体、亮黑小眼睛、短小四肢和微微红润的脸颊。画面以 Cinema4D + Redshift 级别渲染，采用柔和漫射光，没有硬阴影。背景为透明。整体使用粉柔、均衡的配色，呈现可爱、安静又俏皮的氛围。材质为哑光、毛绒般的触感，并带有轻微的阴影以增加柔和的立体感。视角为正面或 3/4 角度，仅生成一个版本。

可以看到这个风格是不错的，但是老虎完全不像，缺少威武霸气的神态，香蕉模型你该死啊！请看我下面操作：

点击左侧侧边栏第 2 个“+”图标，上传一张老虎图片

上传后再次点击侧边栏里的第 1 个图标里的“ mark ”

注意这步很关键，点击画布上生成的这个角色「不像老虎的图像」，可以看到 标记为1 ，然后点击刚刚上传的老虎图像， 变为 标记2 ，同时输入框里有相应的提示！

神奇操作来了，输入框里可以看到 标记的 地方 可以选择 ！输入提示，注意下方我的提示词格式：请保持这张标记的风格“ 标记 1 图像 ”替换成老虎“ 标记 2 图像 ”

也就是说我只需要 上传A图像的形体构成，在点击B的生成图像 ，这一点就解决了啊，不用我一直反反复复得去和模型沟通，这简直是得劲啊！！

2. 物品替换

想把产品图里的某一个物品替换掉，我需要把原图丢到PS里，用个10几分钟甚至更多的时间来调整，现在完全不需要了！！

上传一张女模特，并且上传想要换掉的产品图像，就可以替换相应的物品！

步骤和上方一样，标记人物模特的上衣，再标记替换的上衣；标记人物模特的裤子，再标记替换的裤子，然后注意输入提示词的格式： 请把该人物模特的白色运动背心“ 标记1的上衣 ”替换成外套“ 标记2的上衣 ”；再把运动裤的“ 标记3的运动裤 ”替换成“ 标记4的裤子 ”。

记得一定选好香蕉pro模型，然后回车等待生成，看看下面的效果，这简直是电商人的福音！

这个鞋有些不搭，再换个鞋！

提示： 把该模特的鞋子“ 标记1的鞋子 ”替换成“ 标记2的高跟鞋 ”。

你还真别说，我搭配的挺难看...hhhhhh...made...真难看...

3. 材质置换

利用 touch edit 换任何材质， Nano Banana Pro 的思考选项能让你画面更精美，但是不是特别稳定，就比如下面文字绒毛材质，第1次没有成功，它自己进行思考输出第2张，感觉可以，但是我还想更完美！

提示：创建一幅明亮多彩的 3D 插画，以超高品质、柔软蓬松的毛绒质感字母完整呈现单词 [RaDesign]。所有字母需在同一条水平线上排列，间距均匀，确保清晰易读。毛绒质感应表现为浓密、丝滑、细节极丰富，类似高级毛绒玩具的微距摄影效果。颜色使用 [绿色和白色] 系列，以符合该单词的情绪或能量。背景为柔和的粉彩色，与整体配色协调。光线使用柔和的棚拍灯光，搭配真实阴影与清晰锐利的渲染。整体氛围应充满奇趣、愉悦且视觉吸引力极强。

虽然毛绒质感很好，但识别性太低了，我想尝试换下 布料气泡材质 ，不会描述就找了张参考上传，利用 touch edit 的识别性，在输入框里选择这张图的 表面纹理 。

注意，标记文字的时候，我只选择了“R”字母作为测试。提示： 请把字母R“ 标记1R字母 ” 材质纹理转换成“ 标记2材质纹理 ”。

这质感转换的真不错，一些特殊的字体设计不再用 C4D 和 Blender 就可以实现了我真高兴呜呜呜 呜呜呜...

4. 品牌手册

品牌手册需要的物料比较多，可以利用 Nano Banana Pro 生成，再利用 touch edit 做意见修改，和客户快速确认！

提示：创建一幅明亮多彩的 3D 插画，以超高品质、柔软蓬松的毛绒质感字母完整呈现单词 [RaDesign]。所有字母需在同一条水平线上排列，间距均匀，确保清晰易读。毛绒质感应表现为浓密、丝滑、细节极丰富，类似高级毛绒玩具的微距摄影效果。颜色使用 [绿色和白色] 系列，以符合该单词的情绪或能量。背景为柔和的粉彩色，与整体配色协调。光线使用柔和的棚拍灯光，搭配真实阴影与清晰锐利的渲染。整体氛围应充满奇趣、愉悦且视觉吸引力极强。

这里生成的时候模型有疑问： 产品图片或品牌相关素材 （如Logo、产品照片、包装图等）有没有，这里我只上传了logo，其他的没有让他生成，现在有些问题，我们用 touch edit 修改一下。

提示：请把手机展示 “标记1手机展示 ”转换成“ 标记2工作证 ”。

可以看到替换品牌物品也是OK的，我这里只测试一小部分，其他的观众老爷们自行测试即可。
