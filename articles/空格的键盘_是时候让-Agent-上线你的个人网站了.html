是时候让 Agent 上线你的个人网站了

这两天我的个人网站再次上线了：kongge.space

做网站的过程就是在整理自己过往的经历，向外界展示自己是谁。

当然不止这些。

网站是一个灵活的载体，不同于飞书和 Notion 搭建的模块化页面。

网站可以传达你的审美，放你的摄影、设计、coding 任何作品。

一个域名就能让搜索引擎找到你，这是一个实时对外连接的窗口。

也能展示你 vibecoding 的作品。

这篇文章我想详细聊一下：

为什么你现在就该做一个自己的网站，以及怎么用 Agent 口喷实现？

01 为什么是现在？

Notion 的创始人 Ivan Zhao 讲过他做 Notion 的起点。

他在大学的时候学过艺术和计算机专业。

艺术专业的同学毕业要找工作，人人都需要一个网站来放自己的作品集，但绝大多数人不知道怎么做，也做不出来。

所以都会找他这样有计算机基础的人来帮忙。

艺术生有作品，有审美，卡在了技术上。

于是他想做一个不用写代码也能建网站的东西。

这就是Notion 诞生的萌芽。

Notion 帮助数百万人实现了零代码搭建个人网站，这是我曾经用 Notion 制作的网站/知识库。

十几年后的今天，答案已经更换了。

不再需要 Notion， WordPress，更不用买一套主题模板，往里面填内容。

Vibe Coding 就能实现，不写代码，更不花太多时间和钱。

整个制作过程就是： 收集资料+指挥 Agent 构建 。

其中收集资料最费时间。

做之前，我先是把和我相关的各种介绍、作品都收集一下，来源于自己的简历、社媒动态。

我收集到有：我做过的工具、写过的 Skill、上线过的产品，拍过的照片，我运行了三年多的一个产品星球知识库，我在各个平台的原创内容。

所有资料有了以后，我就可以构建这个网站的信息架构，可以分为 ：工具、SKII、产品、摄影、关于我、合作 ，几个模块。

每个模块在网站顶部显示菜单可以切换。跳转到对应的链接和页面。

也就是现在这个布局。

所有资料给到 Agent，让它自己根据资料和信息架构来排版这个网站。

关于网站的设计风格，可以去网上找一些自己觉得好看的站点，发送链接，让Agent 参考。

不需要写一行代码，你就在互联网上有了自己的一个坐标。

02 一个网站能给你带来什么

它可以持续记录你的成长和思考，在夜深的时候翻翻过去写过的东西，比翻朋友圈里发过的图更能认识自己。

网站可以让别人在搜索引擎找到你，甚至让你的内容能被大模型索引和引用。

你字体、颜色、留白、结构，全由你说了算，完全体现你的审美和品味。

但真正让我觉得所有人都该做一个网站的是它可以承载你的作品。

有了网站，你的每一个 demo 产品都不再是运行在 localhost，他们都有了去处。

别人看得到、用得到，才叫产品。

我的网站收敛成了四个模块

  • 我是谁：放在首页，介绍自己
  • 我做过什么：我的职业经历，我做的产品、工具、Skill
  • 我想过什么：我的沉思笔记，我创作过的内容
  • 我能提供什么：寻找商机或合作伙伴

一个实时对外展示自己的窗口，比社交媒体更能提现自己是谁

03 完整教程：全程口喷，让 Agent 帮你部署

技术栈只有两个 CLI：GitHub CLI（ gh ）和 Cloudflare 的 wrangler 。

授权一次之后，你就再也不用碰命令行了。

第 1 步：买域名

阿里云、腾讯云，哪家都行。

别在这一步纠结买什么名字。

很多人的建站热情就是耗死在选域名上的。

先买一个能接受的（.com>.cn>.net...），网站是活的，域名以后可以再换。

第 2 步：把域名添加到 Cloudflare

注册 Cloudflare，登录到控制台，点击左侧菜单域名——添加域名。

输入你域名地址，点击下一步。

选择免费套餐。

一直往下点，直到给到你两条解析地址

第 3 步：拿到 Cloudflare 给你的两条 DNS 服务器地址

复制上面图片的两个地址，到你购买域名的云厂商，打开域名解析-修改 DNS 服务器

类似下面是腾讯云的界面，选择使用非腾讯云 DNS，输入上面的两个地址。

点击提交。

这里的作用就是把域名的 DNS 解析交给 cloudflare 去处理了。

第 4 步：装 CLI，各做一次授权

复制命令给 Agent：请帮我在本地装 GitHub 和 cloudflare 相关的 CLI。

装完之后，Agent 会运行登录，浏览器打开你的账号点击授权

gh auth login
wrangler login

授权是一次性的，之后 Agent 就有了直接操作你 GitHub 和 Cloudflare 的能力。

从这一刻起，你只需要说话。

第 5 步：回域名服务商后台，改 DNS 服务器

在 DNS 记录解析配置你的域名地址。类型为 CNAME、名称是你的域名名称和 www.你的域名。

第 6 步：配解析记录

创建 pages 或 workers 来部署你的本地代码

Pages ：纯前端，适合做个人网站、作品集。

Workers ：需要后端，工具要调模型 API、要转发请求、要存数据

你经过一番 vibecoding 后，就可以一句话把本地仓库推送到 GitHub 并部署到 cloudflare 的 xx 站点。

搞定之后，你的部署流程就变成了这样：

「帮我创建一个 GitHub 仓库，把本地代码提交推上去，并连接到 cloudflare，用 Pages 部署到 Cloudflare 的 xx 站点。」

每次更新也是一句话：帮我推送仓库并部署网站。

你说完，Agent 执行，线上就变了。

非常适合你发布一些小工具。

Cloudflare 的免费额度对个人网站和轻量工具完全够用。

写在最后

如果你也用 AI 做过一些东西，也有一堆散在各处、自己都快忘了的内容。

也可以把网站搭建一起来，给 vibecoding 做一个存档点。

不用追求一步到位，先让它存在。

真正的收获可能不在网站上线的那一刻，而在你整理它的过程里。

当你被迫回答「 我做过什么、我能提供什么 」这两个问题的时候，你会比现在更清楚自己是谁。
