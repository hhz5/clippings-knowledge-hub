嗨大家好！我是阿真！

Midjourney V8 Alpha 更新了。哎嘿拖了有段时间才写，更新时间应该是上上周了。

我好像那个被杀🐷盘的用户，总觉得它会给我搞一波大的，总觉得下一个版本肯定会更好，会员也是续了又续，等到了现在。

链接👇

https://alpha.midjourney.com/imagine

注意，目前还是 Alpha 版本，后续可能还是会有变化和进步的。现在也是在这个 Alpha 的网站可以体验，其他的都还没有。

简单介绍一下它这次大版本升级的内容。

1. 生成速度更快了，真的快。 官方说法是比以往版本快 4~5 倍，实测体感也确实如此。速度变快意味着可以高频试错、快速打样、密集迭代。建议可以先用标准模式大量探索方向，找到满意的再用 --hd 或 --q 4 精修。

2. 提示词遵循更好了。 Midjourney 过去最大的槽点就是美但不听话，你写了一堆细节描述，它自顾自给你一张氛围大片，细节全没有。V8 在 prompt 理解上有明显进步，对小细节的保留更好，还可以开 --raw 模式进一步提高精确度。

3. 原生 2K 输出。 新增 --hd 参数可以直接出 2K 分辨率的图，简单说就是原来的 1M 变成现在的 5M，另外还有 --q 4 模式能获得更高的一致性和连贯性。

4. 文字终于能看了。 V8 专门针对文字生成做过调优，官方甚至在 2 月搞了一轮专门的 Rating Party。短文本、招牌、标题、画面中的英文字，成功率比 V7 高不少。

5. 之前版本的资产和参数可以继承。 好消息是 V7 的 personalization profiles、moodboards、srefs 都能直接用在 V8 上。Midjourney 终于想开了，不用每个风格代码都局限在一代版本里。

6. 网页端体验升级。 新增对话式连续生成（conversation mode）、Grid Mode 批量筛图、设置项移到侧边栏减少遮挡。Midjourney 一直在把重心从 Discord 命令行，彻底往 Web 端创作界面推。现在我也是用 Web 端更习惯了。

不过，现在还没有 Relax 模式，所以都是直接消耗 Fast 模式的。高质量模式也更贵了。 --hd、--q 4、sref、Moodboard 任务，目前都比普通任务慢 4 倍、贵 4 倍。且目前只能在 Alpha 站用。 V8 目前还没进主站和 Discord，生成的内容也不会出现在主网站上。因为还是测试性质，随时可能变。

不过吐槽的声音也不少，主要是关于像是人脸开始趋同等的问题，比如下方，在 --chaos 为15的情况下，4 张图人脸相似度比之前的版本更高了，有多高呢，请看下图👇

就我测试后的感觉是，Midjourney V8 还有一些没准备好。

很多细化的、非主流风格生成的图片，都有一种不完整的感觉。会觉得图片的渲染都没有完全到位，细节处理得很一般。哪怕2K画质细节上还是不行。就几个主流风格来说，目前的表现还可以，审美依然具有一定的优势。

好了话不多说，来看看图片效果。看热闹不嫌事大， 下方的对比图，上图是Midjourney V8，下图是Nano Banana 2，都是 2K 质量。 Nano的中文效果的不用说了指定吊打，下面主要还是对比图像细节。

目前 Midjourney V8 可能还不算完全体，加上有很大的美学加成的 --sref 值这里也没有多用，所以在这方面可能也有一些劣势。

这里做比较基础的测试，以后大家再一些场景想要去选择模型的话，可以作为参考。

文中的插图都是AI图片，注意流量朋友们，今天是超大杯（40组80张图）。
