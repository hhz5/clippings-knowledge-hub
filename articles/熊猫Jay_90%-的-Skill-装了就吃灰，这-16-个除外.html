这段时间一直在折腾 Skill 生态。

ClawHub 上万个，Skills.sh 八万多个，GitHub 上还有一堆散落的。

翻了不少，说实话大部分装了用两次就再也想不起来，要么写得粗糙，要么场景太窄。

但有十几个，装完之后确实离不开了。

我按使用频率和场景价值筛了一遍，分成五类。

每个都是我自己日常在用的，不是看介绍觉得不错，大多数都是跑进工作流里的。

此外，文末我归纳了下开发Skill的最佳实践、企业案例实战，以及配套讲解视频和PPT。

希望对你有所帮助。

一、信息抓取：先解决"喂什么"的问题

AI 再聪明，没有输入就是空转。

这类 Skill 解决的是"原材料"问题，让 Agent 能主动获取外部信息，而不是只能等你喂。

一）Agent Reach ：全网信息源一站式接入

一个 Skill 打通十几个信息源。

从 YouTube、GitHub、Reddit 到国内的 B 站、小红书、抖音、微信公众号，全部走免费开源后端，不需要逐个申请 API Key。

凭证存在本地，数据不经第三方。

还内置了 agent-reach doctor 诊断命令，环境有问题一跑就知道卡在哪。对需要跨平台采集信息的人来说，这一个 Skill 顶过去五六个工具。

●●●

https://github.com/Panniantong/Agent-Reach

适合：做竞品调研、内容聚合、跨平台信息监控的人。

二）Tavily Web Search ：专为 AI 优化的搜索引擎

和普通搜索引擎不同，Tavily 返回的不是一堆链接，而是精简过的、高相关性的结构化结果，直接就能被 Agent 理解和使用。

省去了“搜到了但还要自己筛”的步骤。

地址：

●●●

https://clawhub.ai/matthew77/liang-tavily-search

适合：需要 Agent 自主查资料、做技术选型、快速了解一个陌生话题的场景。

三）YouTube Watcher ：长视频知识提取器

快速抓取 YouTube 视频字幕，把一个小时的视频变成几分钟能读完的文字。

对于经常看英文技术分享、播客、演讲的人，这个 Skill 把"看视频"变成了"读文档"，信息吸收效率翻几倍。

地址：

●●●

https://clawhub.ai/michaelgathara/youtube-watcher

适合：学习型用户，尤其是需要大量消化英文视频内容的技术人员和内容创作者。

四）Summarize ：什么格式都能总结的万能摘要器

网页、PDF、图片、音频、YouTube 视频，不管你扔什么格式过去，它都能给你一份干净的摘要。

不用再根据不同内容类型切换不同工具，一个 Skill 统一处理所有“我没时间看全文，先给我说重点”的需求。

地址：

●●●

https://clawhub.ai/steipete/summarize

适合：信息过载的人。每天要处理大量文章、报告、视频但时间有限的场景。

二、内容创作与发布：从素材到成品的完整链路

有了输入，下一步是输出。

这类 Skill 覆盖从文字润色、图文生成到一键发布的全流程。

一）宝玉老师 Skill 合集：一个人的内容工厂

这套合集堪称自媒体从业者的军火库。

•视觉内容生成（小红书信息图、通用信息图、封面图、幻灯片、漫画）

•社交媒体发布（X、微信公众号、小红书）

•内容处理（Markdown 格式化、图片压缩、翻译、链接转 Markdown），从生产到分发一条龙。

每个子 Skill 都是针对具体场景调过的，质量稳定。

地址：

●●●

https://github.com/jimliu/baoyu-skills

适合：自媒体创作者、需要频繁产出图文内容的运营人员。

二）Frontend Slides ：用前端技术做演示文稿

不想打开 PowerPoint，想用代码控制每一个像素的人会喜欢这个。直接用前端技术栈生成演示文稿，样式、动画、交互全可编程，比传统幻灯片工具灵活得多。

安装：

●●●

https://github.com/zarazhangrui/frontend-slides

适合：技术分享、产品演示场景，尤其是需要嵌入代码示例或交互式 demo 的演讲。

三）Humanizer ：让 AI 写的东西不像 AI 写的

AI 生成的文字有一种很难形容但一眼就能认出的"套路感"。

过度使用连接词、段落结构整齐到不自然、措辞永远正确但永远没有温度。

Humanizer 专门解决这个问题，重新调整措辞和节奏，让输出读起来更像真人写的。

安装：

●●●

https://clawhub.ai/biostartechnology/humanizer

适合：所有用 AI 辅助写作的人。尤其是写公众号、写商业文案、写邮件这类需要"人味"的场景。

四）Markdown 一键发 X 长文

在本地用 Markdown 写完长文，直接推送到 X 平台作为 Articles 草稿。

格式、图片自动处理，认证一次管七天，省掉了反复登录和手动排版的麻烦。

地址：

●●●

https://github.com/joeseesun/qiaomu-x-article-publisher

适合：经常在 X 上发长文的创作者和技术博主。

五）Remotion Best Practices ：用代码做视频

做产品发布最麻烦的事情之一是录 demo 视频。

录制、剪辑、导出，整个流程和写代码完全不在一个频道上。Remotion 把视频制作变成写 React 组件：动画是状态变化，时间轴是代码逻辑，导出是一条命令。

这个 Skill 是 Remotion 官方维护的，把正确的动画曲线、音频处理、字幕生成方式都封装好了。

没有它，Agent 写 Remotion 代码会在插值、音频裁剪这些地方反复出错。

地址：

●●●

https://github.com/remotion-dev/skills/tree/main/skills/remotion

适合：需要程序化生成视频的开发者，changelog 演示、API demo、数据可视化动画。

六）Get笔记 ：用嘴记笔记

Get笔记接入了 OpenClaw Skills，意味着你可以让 Agent 直接帮你操作笔记：记笔记、查笔记、打标签、整理知识库，全部通过自然语言完成。

不用打开 App，不用复制粘贴，不用手动分类。

更有价值的是"用笔记干活"：让 Agent 根据你的会议记录生成周报，根据你的读书笔记写一篇文章，根据你过去一个月的笔记分析你在关注什么话题。

你攒的每一条笔记，都能被 Agent 调用起来。

地址：

●●●

https://clawhub.ai/iswalle/getnote

适合：重度笔记用户，尤其是希望把零散记录转化为结构化输出的人。

三、开发与设计：让代码写得更好看、更规范

Agent 会写代码，但"能跑"和"能用"之间还有一段距离。这类 Skill 解决的是代码质量和界面品质的问题。

一）Frontend Design ：告别"一眼 AI"的界面

让 Agent 写前端界面，出来的东西永远是 Inter 字体、紫色渐变、卡片布局。技术上没毛病，但一眼就知道是 AI 做的。

Frontend Design 在 Agent 动手之前先锁定视觉方向——极简、极繁、复古未来、editorial 风格——然后所有字体、配色、动效都必须服从这个方向。

它不是让界面更好看，而是让界面有立场。

安装：

●●●

https://github.com/anthropics/skills/tree/main/skills/frontend-design

适合：在意用户侧视觉体验的前端开发者和产品经理。

二）Code Review ：给代码上一道质量关卡

AI 写的代码通常是"能跑的第一稿"。

逻辑没大问题，但安全漏洞、性能隐患、可维护性差这些事，它自己很难发现。

让写代码的 AI 自己审代码，就像让学生自己批改自己的试卷，盲区是一样的。

Code Review 这个 Skill 把代码审查变成了一套系统化的流程：从安全、性能、可维护性、正确性、测试覆盖五个维度逐项检查，每个问题标注严重程度，给出结构化的反馈。

它还内置了一份常见反模式清单，专门抓那些"看起来没问题但迟早会炸"的写法。

养成一个习惯就够了：每次 Agent 写完一批代码，先让它过一遍 Review 再提交。

地址：

●●●

https://clawhub.ai/wpank/code-review

适合：所有用 AI 辅助编程的开发者。代码能跑只是及格线，Review 过了才敢合并。

三）Superpowers ：让 Claude Code 真正跑项目

很多人用 AI 写代码，其实只用到了"补全"这一层：写几个函数、改几段逻辑、跑通就完事。

但如果你想让它从头到尾跑一个完整需求，从想法到代码到测试到合并，光靠补全是搞不定的。

Superpowers 做的就是这件事。

它把一个完整的开发流程拆成了一串自动衔接的步骤：需求发散、规格确认、计划拆分、子 agent 执行、代码 review、合并。

每个环节都有专属 skill 负责，自动触发，自动接力。

三个设计让它比"直接让 AI 写代码"靠谱得多：

•多个子 Agent 各管一块，避免任务太长导致 AI 忘了前面在干嘛；

•强制先写测试再写代码，不是"能跑就行"；

•合并之前必须过 Review 关卡，不会直接把半成品推上去。

地址：

●●●

https://github.com/obra/superpowers

适合：做完整项目开发的工程师，尤其是需要从需求到交付全流程跑通的场景。

四、Skill 开发与自我进化：让 AI 自己变强

学会用 Skill 之后，自然会想自己写。再进一步，还可以让 Agent 在使用过程中自己变得更聪明。

一）Skill Creator ：Skill 的 Skill

前面介绍过，必备 Skill。

告诉 Agent 你想要什么能力，它帮你生成完整的 Skill 结构：SKILL.md、脚本文件、目录组织，全部符合规范。

省去了从零搭骨架的时间，让你把精力集中在业务逻辑上。

安装：

●●●

https://github.com/anthropics/skills/tree/main/skills/skill-creator

适合：刚开始写 Skill 的新手，或者需要快速原型化一个想法的人。

二）Skill Vetter ：装 Skill 之前先过一道安全检查

ClawHub 上万个 Skill，质量参差不齐。

2026 年初安全研究人员在 ClawHub 上发现了上千个恶意 Skill，有的偷 API Key，有的装挖矿程序，有的窃取浏览器密码。

Skill Vetter 就是你的安全门卫。它本身只是一个 4.5KB 的 SKILL.md 文件，不含任何可执行代码。

但它会教 Agent 按四步流程审查你要安装的 Skill：

检查来源信誉 → 代码审查（检测 curl 到未知 URL、读取 .ssh/.aws 等敏感路径、eval/exec、混淆代码等）→ 权限范围评估 → 风险分级（从 🟢 低风险到 ⛔ 极高风险）。

地址：

●●●

https://clawhub.ai/spclaudehome/skill-vetter

养成一个习惯：装之前先让 Skill Vetter 审一遍，审过了再装。

适合：所有 OpenClaw 用户。不是可选项，是必装项。

三）Self-Improving Agent ：让 Agent 越用越聪明

大多数 Skill 是静态的：写好了就不变。

但 Self-Improving Agent 让 Agent 主动捕获自己的执行错误和你的纠正指令，把这些反馈沉淀下来，下次遇到类似情况自动调整。

相当于给 Agent 装了一个"错题本"机制，**不是你告诉它该怎么做，而是它自己从失败里学会该怎么做。**用得越久，它越懂你的习惯和偏好。

安装：

●●●

https://clawhub.ai/xiucheng/xiucheng-self-improving-agent

适合：长期使用 Agent 处理重复性任务的用户。尤其是那些发现自己总在纠正 Agent 同一类错误的人。

八、最后

每个好的 Skill，本质上都是某个人把自己的经验浓缩成了规则。

装上它，就是站在别人的积累上往前走，不用每件事都自己从头踩一遍。

开源社区最好的地方就在这里，经验可以流通，能力可以叠加。

不过繁荣的另一面是：鱼龙混杂。

2026 年初已经有研究人员在 ClawHub 上发现上千个恶意 Skill，偷密钥、读凭证的都有。
