01 持续被颠覆的** AI 画图表工作流**

我一直在折腾画图这件事，尤其是在 AI 技术飞速发展的这几年，画图的工作流每隔几个月，就被重塑一次。

现在这些都可以交给 AI。

我们可以回顾下这两年模型进化，画图的工作方式跟着怎么变。

传统做法：打开 draw.io 或者 Figma，找模板、拖控件、对齐、配色、改字号......一个能看的架构图至少半小时起步。

24 年：模型的代码能力提升，SVG 卡片开始流传很广。为此我还做了一个文生图的产品，用户输入文字就能拿到一张 SVG 卡片。25 年：模型的 coding 能力再次提升，HTML 比 SVG 能承载更多信息，还能做交互。配图从静态卡片变成可交互页面。

26 年：Agent 的能力起来了，SVG、HTML 的产出全部 skill 化。各种垂类的画图 skill 冒出来：原型图、流程图、架构图、逻辑图......

我自己就做了好几个skill： 文图图产品、chart-craft、text-logic-diagram、image-studio、pm-image2proto......

每个 skill 各自能搞定一类图。能用，但是有几个问题：

1.样式不统一。有些是 mermaid 默认风格，有些是 SVG 拼起来，放在一起就是大杂烩。

2.生成完就是死的。想改一个字、挪一个框，都得重新跑一遍。

3.图表种类有限。我前后凑出来 30 多种，但真到要画某些奇怪的图（比如四象限叠加时间轴），还是抓瞎。

直到我用了飞书的画板 skill。

可以说它结束了这场比赛，所有图都融合到了飞书生态，便于后续修改、分享和归档。

02 画图 skill 的改变

以前我画一张需求文档配图的流程：

打开 Figma → 想布局 → 拖框 → 连线 → 配色 → 截图 → 插到文档里 → 发现要改一个字段 → 回 Figma → 改 → 截图 → 替换。

一张图来回折腾 40 分钟。

现在的流程：

我把 Agent 直接集成到了飞书里，在飞书里跟它对话。

一句话：「帮我画一个 XX 流程的泳道图，生成到飞书画板里，插入到 XX 文档。」

几十秒之后，文档生成好了，画板已经躺在里面，点一下就能预览。整个过程在飞书内部闭环，不用切窗口、不用复制粘贴、不用导出导入。

非常丝滑。

双击进入编辑态，每一个元素都是可编辑的 vector 对象。改字、改色、加节点，随手就能动。

03 看几个真实的例子

例 1：写需求文档时配一个泳道图

我在写一个埋点上报链路的需求，给 Agent 的指令是：

帮我把客户端→网关→Kafka→数仓→看板这条上报链路画成泳道图，每条泳道里列出关键动作和异常分支，生成到飞书画板，插到这篇需求文档里。

输入是一段文字描述，输出是一张结构清晰、配色协调的泳道图。

例 2：写完文章之后配几张逻辑图

文章写完，我经常想配几张图把核心观点可视化。

以前要么手画，要么找模板。现在直接把文章丢给 Agent：

根据这篇文章的核心观点，分别画几张逻辑图，风格保持一致，都生成到飞书画板。

下面就是它根据我这篇文章，Agnet 自己拆观点、自己定结构、自己配色。三张图风格统一，能直接当公众号配图用。

例 3：根据文章生成 PPT，用作演讲或者短视频录制

现在我把文章丢给 Agent：

根据这篇文章的结构，生成一份演讲用的 PPT，每一页一张飞书画板，风格统一，要适合录短视频用。

它会自动拆分章节、提炼要点、配图配色，一页一张画板生成好。

讲的时候直接全屏播放，录短视频的时候每一张就是一个分镜。

哪页讲不顺，双击进去修改再继续。

04 飞书成了为 Agent 而设计的工具

我用完之后有一个明显的感觉：飞书自从 CLI 化之后，整个产品的思路变了。

飞书里的工具，不再只是给人用的，而是给「人+Agent」一起用的。

画板有了 Agent 参与，就有了承载万物的能力。

以前我用飞书画板，最多画个流程图、架构图，而且基本都是草草两笔就收工。

我懒得在画板里精雕细琢，太费时间。

现在所有的环节交给 Agent。我只负责描述要什么，等着给我成品再修改。

我能想到的任何图：泳道图、用户旅程图、状态机、ER 图、C4 架构、价值链、SWOT、四象限、桑基图、热力图、组织架构、时间线......全部能在一个画板里实现。

而且都是可编辑的。

可以预见，因为Agent 的加持，saas 产品不会消亡，而是迎来重生，skill 可以代替 saas 的一个小功能点，但是它提供不了 saas 产品拥有的完整生态体验，飞书就是个很好的例子。

05 安装方法

最简单的方式是使用飞书原生的 Agent：飞书 aily 智能伙伴。

飞书 aily 内置了CLI，CLI 里就能调用画板的技能，不用自己额外搞 Agent。

可以在这个网站体验：https://aily.feishu.cn/，添加完之后就能在飞书里和aily 智能伙伴对话，调用飞书 CLI。

另一种方式是给你的 Agent 装上最新的飞书 CLI 就能用，不需要在指令里指定 skill 名字，Agent 会自动调用。你只要在指令里说清楚「生成飞书画板」就行。

飞书 CLI 的安装方式，在终端跑一行命令：

npx @larksuite/cli@latest install

或者让 Agent 自己装， 把下面这句话发给你的 Agent：

帮我安装飞书 CLI：https://open.feishu.cn/document/no\_class/mcp-archive/feishu-cli-installation-guide.md

它会自己读文档、自己装好。

装完之后，你就拥有了飞书 CLI 的所有能力，包含上述画任意图表的画板能力。
