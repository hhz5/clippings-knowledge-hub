我做了个万能生图 Skill，人人都可以定制设计 Agent

空格的键盘 AISkill生图设计Agent 2026-02-10

原创 空格 zephyr 2026年2月10日 08:58

上次我分享了几个生 图 Skill，它能 给 文章批量生成配图 ，也能制作故事板 、Logo 、海报，最后我还 演 示了 怎么根据自己的需求，自定义一个 Skill 来 批量出图 。

做 完这 些 以后 ，我越来越觉得 Skill 的价值被严 重低估了 。

往 小 了说，它能做 到过 去 Coze、Dify、n 8n 这 类 低代码平台做的事——用 模 块拼装各种 AI 能力 。但 它不需要你 配置节 点、连线、调参，一 个 Markdown 文件就能 搞定，真 正 让 每 个人都有手搓 AI 工具的能力。

往 大了说，我认为 Skill 正在拆解 SaaS 和 AI 应用的每一个付费模块 。那 些 S aaS 软件最 吸引你掏钱的功能点 ，一 个 Skill 就能实现 。这 也是上周美股 S aaS 板块集 体崩盘的原因 之一， 市 场已 经 闻 到 了这 个信 号。

今天我又做了个把所有图片生成场景融合在一起的 skill，一个 skill 搞定所有设计。

上篇文章 自定义 Skill 批量配图 发出去后，就有不 少朋友来 问 我这样的 Skill 怎么做 ，但 我也 发现，真 正动手用 起来的人还是很少。

其 实 Anthrop ic 官方出品的 skill-creator 就是一 个现成的元 Skill，你告诉 它你想要 什么能力，它直 接帮你生成一个 完整的 Skill 包。我做 的这个万能生 图 Skill ，就是 顺着 这个思路拆出来的。

今天我把这 个 Skill 的原理和 7 个案例展 开 讲讲，希望你看 完之后不 只 是 觉得 "效果不 错"，而 是能 理解背 后的机制，学 会自 己去做 。

原理解析

universal-image-gen skill 的 执行流程

用户说一句话 → AI 解析意图 → 引导选场景 → 引导选风格 → 确认比例/数量 → 自动构建提示词 → 调用 API 批量生成

能够制作任意风格如海报、电商、漫画、红包、UI、艺术照……

这些专业的提示词不需用户写，全部存在 references/scene_templates.md 里。AI 读取用户的意图后，从模板库里匹配最合适的模板，填入用户的具体参数，就能组装出一段专业级的生图提示词。

这就是这个 Skill 的核心机制： 用户负责说"要什么"，Skill 负责把"要什么"翻译成"怎么做"。

7 个案例

说了这么多，直接看效果。以下 7 个案例都是我今天用这个 Skill 实际生成的，每个案例告诉你：我说了什么、AI 执行什么、最后出了什么。

案例 1：冬日咖啡

输入 ：帮我生成一套冬日咖啡主题的插画海报

AI 执行 ：判定为海报设计场景，推荐手绘水彩风格。自动构建提示词：温暖色调、咖啡杯拉花（雪人图案）、壁炉、熟睡的猫咪、窗外飘雪、书籍和围巾作为场景道具。文字元素"冬日温暖拿铁"直接融入画面。

输出 ：2 张治愈系水彩插画，暖色调统一，适合冬季咖啡馆的社交媒体配图。

案例 2：机器人剪贴风

输入 ：做一组机器人主题的潮玩海报，剪贴风格

AI 执行 ：判定为海报设计场景 + 剪贴风格。自动构建提示词：黑色背景、3D 渲染的彩色机器人角色（红、蓝、黄、绿、橙多色）、贴纸质感、胶带元素、条形码装饰、斜体大字标题。文案 AI 自动生成："NEW COLLECTION"、"FUTURE IS NOW"、"TECH TOYS"、"LIMITED DROP"。

输出 ：3 张潮玩风格海报，每张构图不同但视觉语言统一，有很强的街头潮牌感。

案例 3：clawAI 网球场品牌 VI

输入 ：帮 clawAI 网球场做一套品牌周边设计

AI 执行 ：判定为 IP/周边延展场景。AI 先设计了一个机器人吉祥物（绿色 + 橙色配色，手持网球拍），然后围绕这个 IP 延展出一整套品牌物料：帆布袋、球拍套、运动 T 恤、连帽卫衣、棒球帽、遮阳帽、手提纸袋、球场地面设计。所有物料保持统一的绿橙配色和电路板纹理风格。

输出 ：4 张品牌 VI 展示图，从单品到全套一目了然，可以直接拿去跟供应商沟通打样。

案例 4：三体故障艺术

输入 ：做一组三体主题的科幻海报，故障艺术风格

AI 执行 ：判定为自定义场景 + 故障艺术（Glitch Art）风格。AI 从《三体》原著中提取了核心视觉元素：三颗恒星（蓝/紫/红）、智子量子纠缠、水滴探测器（Waterdrop Probe）、暗黑城市天际线。文字直接引用经典台词："不要回答"、"黑暗森林中每个文明都是带枪的猎人"、"弱小和无知不是生存的障碍，傲慢才是"。整体叠加了数据流、像素错位、色彩偏移等故障效果。

输出 ：3 张赛博朋克 × 故障艺术风格海报，科幻感拉满，可以直接当展览海报用。

案例 5：AI 语音聊天 App UI

输入 ：设计一款 AI 语音聊天 App 的界面

AI 执行 ：判定为信息图表场景（UI 展示类）。AI 自动规划了 4 个核心页面：语音通话界面（声波动画 + 通话控制按钮）、对话列表页（多个 AI 助手的聊天记录）、助手选择页（Luna/Max/Aria/Dr.Spark 四个角色，各有性格标签）、文字聊天界面（支持语音消息）。整体采用深紫色暗黑主题，霓虹渐变点缀。

输出 ：4 张 iPhone 机型展示图，页面逻辑完整、交互元素齐全，可以直接拿给开发看。

案例 6：PPT 制作

输入 ：制作一组带有信息图标的简约设计风格的 PPT，2025 年 AI 模型发展总结

输出 ：4 张16:9不同内容的 PPT。

案例 7：马年红包

输入 ：做一个敲键盘的小马主题的马年红包封面，要有键盘元素

AI 执行 ：判定为自定义场景。AI 构建了一个"码上暴富"的创意概念——卡通小马趴在金色机械键盘上，Space 键特别醒目。背景大红色，散落着代码符号（ </> 、 {} 、;）、金币和元宝。整体是 Q 版卡通风格，喜庆但不俗气。

输出 ：4 张马年红包封面，竖版 9:16 比例，可以直接用作微信红包封面。

最后

今天这 7 个案例，覆盖了插画、海报、品牌 VI、科幻艺术、App UI、红包封面——全部是一个 Skill 完成的。
