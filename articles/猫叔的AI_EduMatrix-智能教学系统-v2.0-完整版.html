目的是：让 AI 像资深教育专家一样思考与协作

1. 系统愿景

这是一套基于高级提示词工程构建的模块化教学设计系统，旨在解决教育工作者在备课中最耗时的痛点： 创意枯竭、结构松散、落地困难， 通过 7 个高度互锁的 System Prompts，将模糊的教学目标转化为可直接进入课堂的高质量素材。

2. 核心架构

第一阶段：深度内容构建 (The Core Layer)

这一层负责确立教学内容的骨架与灵魂，确保教学法（Pedagogy）的专业性。

Prompt 1: 沉浸式虚拟考察设计 (Immersive VFT Designer)

能力：生成带有感官细节和叙事弧线的虚拟旅程，植入具体的观察交互点。

解决痛点：告别枯燥的地点列表，创造身临其境的体验。

Prompt 2: 智能自适应路径规划 (Adaptive Pathway Architect)

能力：像算法一样思考，根据学生表现触发不同的补救或拓展路径。

解决痛点：真正实现差异化教学，而非“一刀切”。

Prompt 3: 探究式实践活动 (Inquiry-Based Activity Designer)

能力：基于 P.O.E.（预测-观察-解释）框架设计严谨的实验与手工活动。

解决痛点：确保活动不仅好玩，更能引发深度思考。

Prompt 4: 结构化微课脚本 (Structured Micro-Lecture Designer)

能力：构建基于核心隐喻的知识讲解大纲，粉碎学生常见误解。

解决痛点：将复杂概念碎片化，易于消化。

第二阶段：落地转化应用 (The Application Layer)

这一层负责将核心内容“翻译”为具体的教学物料。

Prompt 5: 学习任务单生成器 (Student Worksheet Generator)

输入：Prompt 1 & 3 的产出。

输出：直接发给学生的填空表、绘图框和反思页。

Prompt 6: 沉浸式教学编剧 (Immersive Scriptwriter)

输入：Prompt 1 & 4 的产出。

输出：极具感染力的逐字讲稿、导游解说词和翻转课堂脚本。

Prompt 7: 视觉演示架构师 (Visual Presentation Architect)

输入：Prompt 1 & 4 的产出。

输出：PPT 页面布局规划、配图建议及 AI 绘画指令（Midjourney/DALL-E）。

3. 如何使用

1. 选择起点 ：根据教学需求，运行核心层的一个 Prompt（如 Prompt 3）。

2. 获取蓝本 ：AI 输出专业的活动设计方案。

3. 一键转化 ：将该方案作为输入，发送给应用层 Prompt（如 Prompt 5）。

4. 最终交付 ：获得一份排版精美、直接可印的学生任务单。
