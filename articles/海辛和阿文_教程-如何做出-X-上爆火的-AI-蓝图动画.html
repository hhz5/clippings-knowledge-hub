先解释一下什么是 Midjourney 风格代码（Sref Code）。

这是一项类似风格滤镜的强大功能， 用户只需在提示词中加上 --sref 和对应数字，就能套用预设的视觉风格 ，无需繁琐描述，即可保持作品风格一致。

举例：在 Midjourney 里仅输入“ 一杯牛奶 ”，这是生成的图片：

如果在 “一杯牛奶” 后面加上风格代码 --sref 2007748773 ，这是生成的图片：

使用风格代码来控制生成的最大好处是： 如果你想画一系列风格完全一样的图（比如一本绘本），用同一个代码就行了，非常方便省事。

如果你想 100% 复现这种风格，在任意 prompt 的末尾加上 --sref 2007748773 的风格代码就可以了。

一些小经验：Prompt 部分可以详细一些，出来的效果会更好，毕竟风格代码只控制其中风格的部分。

到这里为止，已经非常酷了。但我们希望在视觉上再往上翻一番。

我们希望能给每个恐龙的背景加上自定义的大色块以及对应的点缀色，赋予恐龙不同的性格。但这个 sref code 会把整体配色限制得很死，甚至没办法生成纯色背景。

如果想要得到这种效果，必须魔改或者抛弃这个 sref code。

分析了一下这种风格，我们喜欢的点可以总结为： 充满技术细节的蓝图 ，以及 复古的对比配色 。所以我们在 prompt 的写作中，保留了密集的精细原理图和细节标注。

在配色上：先给背景指定一个纯色色块，同时，再选择一个相似色/对比色，作为恐龙身上的点缀色。
