内容写作统一器 - 短描述

把 AI 工具、Prompt、Skill、工作流、教程、测评、玩法盘点等主题，稳定写成适合公众号 / 小红书 / 社媒长帖发布的图文内容资产。

它会自动完成：

  • 内容类型路由
  • 风格组合选择
  • 标题与开头生成
  • 正文结构化写作
  • 模板 / Prompt / SOP 输出
  • 配图规划与图注重点设计
  • 常见失败模式自检与修正

适合场景：

  • 写公众号
  • 写小红书图文
  • 写 Prompt / Skill 分享文
  • 写教程、测评、工作流拆解
  • 把零散素材整理成高传播、高收藏、高执行欲的内容

不适合：

  • 纯短句广告
  • 纯新闻快讯
  • 单句标题或 slogan 生成
