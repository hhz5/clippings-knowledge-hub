做视频原来可以这么简单，LibTV 这次有点意思

阿慕 AppOS 2026年7月14日 10:03

LibTV 前段时间已经很火了，我之前也进去体验过。

功能确实很多，角色、场景、图片、视频和合成都能拆成独立节点。但第一次看到画布里密密麻麻的连线，我很快就不知道该从哪里开始。

这次再打开 LibTV，最大的变化是多了 Agent。

选一个 Skill，输入故事和素材，它会继续处理角色、分镜、视频、音乐和最终合成。复杂的节点依然保留，但不熟悉工作流的人，也可以先从一句话开始。

所以这次我只想验证一件事：

LibTV Agent 能不能少让我折腾节点，也把一支视频真正做完？

官网在这里： www.liblib.tv

选一个 Skill，先给项目找个“导演”

现在打开 LibTV Agent 后，我可以直接描述自己的创作需求，也可以先选择一个 Skill。

目前 Skill 商店里已经有短剧、广告、MV、动画、影视片头、自媒体等不同方向的创作方案。

这里的 Skill 和常见的风格模板有些区别。

整体使用下来，我发现模板通常只负责画面的外观，比如胶片感、赛博朋克、日系清新。Skill 还会影响剧本结构、镜头选择、转场方式、字幕、音乐和剪辑节奏。

同样一句“做一条产品广告”，选择高奢感 TVC、无厘头喜剧或者 3D 动画广告，Agent 给出的创意方向会完全不同。

官方将 LibTV 定位为专业视频 Skill Hub。目前里面已经收录了上百个专业 Skill，背后对应广告导演、MV 创作者、短剧团队和品牌创意人员沉淀下来的制作方法。

我觉得这个思路很适合我这种刚开始做 AI 视频的人。

我先让 Agent 拍了一支青春短片

我准备做一支 45 秒左右的雨季青春短片。 我选择的是 「岩井俊二电影美学」Skill 。

它主要面向青春短片、纯爱电影和日式美学广告，强调细腻、克制、有一点诗意的视听语言。

从 Skill 页面可以看到，它要求输入故事、剧本，以及视频里需要出现的三个主要元素。

“故事发生在夏日下午的公交站。

一个穿白衬衫的男生独自躲雨，旁边放着一把无人认领的透明雨伞。雨伞的伞柄上系着一张旧公交票，背面只写了一个时间。

男生一直等到雨渐渐变小，也没有人回来取伞。

公交车进站后，他隔着布满水汽的车窗，看见车里坐着一个熟悉的女生。女生似乎也看见了他，却很快随着公交车离开。

男生低头看向那张公交票，发现上面的时间，正好是他们第一次见面的那一天。

整条视频不需要对白，主要依靠雨声、公交车经过的声音、人物眼神和几个细小动作推动情绪。”

视频中的三个核心元素：透明雨伞；一张旧公交票；布满水汽的公交车窗。

我直接输入 Agent 的完整需求。

提交需求后，Agent 没有立刻开始生成所有视频，而是先整理故事结构，并生成情绪板、角色图、场景图和道具图。

情绪板确定了整条片子的颜色。

环境保留了夏天偏亮的绿色，人物服装选择简单的白衬衫，光线接近午后自然光，没有加入过多日系粉色或者过度曝光的效果。角色图则负责锁定男女主人公的外形、发型和服装。

两张角色卡都包含正面、侧面、背面和面部特写。这一步对连续镜头很重要。

如果只在每个镜头里重复写“年轻的男女主”，最后很可能出现三四张不同的脸。Agent 先将角色作为统一资产建立起来，后续各个镜头继续调用同一角色。

Agent 根据这些锚点，把故事拆成具体视频节点。我觉得这个过程比直接生成更稳。

我最终使用 LibTV 把成片被拆成 5 个分镜

镜头一：躲雨与旧雨伞，8 秒

镜头二：车票与回忆，8 秒

镜头三：隔着车窗对视，12 秒

镜头四：女生离开，8 秒

镜头五：独自走进雨中，9 秒

全部镜头生成后，Agent 继续完成最终合成。

最终版本是 45 秒、4:3 画幅 ，没有添加字幕，画面之间使用硬切。在声音上，除了背景音乐，还保留了雨声、公交车引擎声和现场环境音。

公交车进站时，音乐没有盖过车辆声音；女生离开以后，音乐逐渐减弱；最后一个镜头主要留下雨滴落在伞面和脚步声。

风格上，Agent 使用了偏柔和的逆光、轻微光晕和 35mm 胶片颗粒。这里我比较喜欢的是，它没有把所有镜头都处理成过度曝光的“日系滤镜”。

，时长00:45

让 Skill 拍一条「产品」广告

青春短片制作结束后，我又换了一个更商业化的方向。

这次选择的是 「韩系杂志风女包时尚广告」Skill ，准备制作一条时长超过 30 秒的女包广告。

我没有提前写完整脚本，只上传了产品图，再补充产品卖点、目标人群和希望呈现的使用场景。

这次测试的产品，是一只很有夏日感的女包： 蓝白格纹包身、抽褶肩带、正面带有卡通小狗和小猫刺绣图案 ，整体风格偏年轻、俏皮，也很适合日常出街、拍照和周末出行。

我给 Agent 的要求是：

“使用「韩系杂志风女装时尚广告」Skill，根据上传的产品图，制作一条 40 秒左右的女包时尚广告，成片不得低于 30 秒。

产品为一只蓝白格纹女包，带有抽褶肩带和卡通刺绣图案，整体风格清新、甜美、少女感明显。目标用户为 18 至 28 岁的年轻女性，适合周末出街、咖啡馆、逛展、拍照和日常轻搭配场景。

广告需要包含街道、咖啡馆、户外阳光场景和室内杂志拍摄等场景，重点展示包袋整体外观、格纹面料、肩带设计、刺绣细节以及上身搭配效果。

画面参考韩系时尚杂志风格，使用自然光、干净背景、低饱和色调和适度留白。减少复杂剧情，不使用夸张表演。镜头节奏可以比青春短片快一些，但不要连续快速切换。

前 5 秒内出现完整包袋，中段加入包身、肩带、刺绣和上身搭配细节，结尾保留模特背包或提包的完整造型和品牌名称。不要擅自改变包袋的颜色、图案、轮廓和肩带结构。”

上传产品图后，Agent 先识别这只包的几个核心特点： 蓝白格纹、抽褶肩带、卡通刺绣图案、甜美少女感风格 ，再根据 Skill 的广告结构安排模特、穿搭和拍摄场景。

一张产品图，也能延展出多种使用场景。

这条广告只上传了一张产品图，后续场景主要由 Agent 根据产品气质补充。

这对产品素材不多的品牌和个人卖家很有帮助。

手里可能只有一两张静态产品图，没有完整模特图，也没有预算拍大片，这时候可以让 LibTV 帮你生成产品宣传视频。

，时长00:30

创建自己的专属 Skill

用现成 Skill 做完青春短片和女包广告后，我又试了一个更贴近自己日常创作的功能： 创建自己的 Skill。

我平时写科技产品体验，已经有一套比较固定的内容习惯。

开头通常先说自己遇到的问题，产品尽早出现，中间跟着实际操作讲功能，最后再给出适合人群和个人判断。

但每次做视频，我仍然要重新告诉 AI：哪里放录屏，哪里用产品截图，字幕怎么写，开头不要绕太久，结尾不要突然喊口号。

既然这些要求会重复出现，我干脆把它们整理成一个 Skill。

我给它取名：「AppOS 科技产品体验视频」

LibTV 目前支持根据一段已经完成的 Agent 对话保存 Skill，也可以进入自定义创建页面，自己填写 Skill 描述，或者上传 Markdown 文件和文件夹。

创建完成后，我没有换一个产品测试，而是直接让这个 Skill 来介绍 LibTV 自己。

我上传了《旧车票与透明伞》的最终成片、LibTV Agent 首页、Skill 页面、工作流和素材生成过程。

Agent 将 LibTV 的成片、Skill 页面和工作流素材重新组织成一条测评体验视频，并同步输出标题、口播稿、分镜表、字幕及素材锚点清单。

，时长00:50

只用一次，自定义 Skill 看起来更像一份比较长的提示词。

我只需要更换产品素材和本期重点，之前的内容结构仍然会被继续调用。

对于固定更新某一类内容的自媒体账号，这种复用会比单次生成更有意义。
