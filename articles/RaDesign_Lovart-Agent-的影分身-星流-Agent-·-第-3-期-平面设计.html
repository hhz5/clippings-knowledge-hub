· 上传产品图像。

附上提示： 根据上传图像，请给出一款时尚哑光黑色无线耳机的高端商业产品摄影。耳机悬浮在半空中，周围环绕着飞溅的液态金和深邃的黑曜石沙。画面清晰锐利，采用影棚柔光箱照明，8K分辨率，专业调色，呈现极致纯净的视觉效果。

3.品牌宣传

宣传策划方案需要符合商业广告逻辑，风格和品牌对等，以及颜色的对等。

· 提示生成看效果。

提示： 品牌名称： 百事可乐。围绕品牌视觉识别，打造大胆的宣传活动策划方案。 品牌诠释： 分析品牌名称，推断其视觉个性、基调和美学方向。确定与品牌相符的合适色彩搭配、氛围和视觉风格。 颜色系统： 采用强烈的双色对比系统：• 背景颜色→定义了品牌氛围 • 强调色→用于字体和图形元素 • 保留皮肤、物体和材料的自然色调。 布局结构： 生成一张水平图像，并将其清晰地分割成三个垂直部分。这三个部分在视觉上必须感觉相互关联，并共享一个统一的色彩系统。最终图像中请勿显示“面板 1”、“面板 2”或“面板 3”之类的标签。

A部分——人类表情： 一幅引人注目的时尚肖像，展现了品牌的精神。自信的姿态，强烈的面部表情，极简的背景，专业的灯光。这个人必须看起来完全逼真，就像在专业摄影棚里拍摄的真人照片一样。可见的自然肌肤纹理、毛孔、细微瑕疵、逼真的发丝、自然的脸部不对称。

B 部分 — 产品英雄： 品牌的核心产品或象征性物品成为关注的焦点。画面干净利落，具有强烈的视觉冲击力，是理想的商业产品宣传片。可能会出现人手互动或微妙的人际互动，但产品本身仍然是绝对的核心元素。

C 部分——视觉冲击： 醒目的排版设计，包含简短的标语或品牌宣言。超大的字体占据画面中心，呈现出强烈的平面设计美感。

图形语言： 画面中可能会出现一些微妙的设计元素：• 重复的微文本 • 几何形状 • 极简主义图形线条 • 色块。 现实主义要求： 照片中的人物必须看起来像真正的时尚摄影师拍摄的作品，而不是人工智能生成的。照片级写实人体解剖，自然的皮肤纹理和毛孔，逼真的光影效果，精细的头发细节，电影般的景深，细腻的胶片颗粒。避免人造光滑的皮肤、塑料般的脸庞或合成的外观。 美学风格： 高端编辑广告摄影，简洁的成分，强烈的色彩对比，现代平面设计语言。 专业影棚摄影： 电影灯光，超精细纹理，8K超逼真商业广告品质。

· 这里第 2 版提示也很不错，附在下面。

提示： 品牌名称： 优食。您是一位世界级的创意总监、品牌战略家、编辑艺术总监和视觉识别设计师，专门为全球品牌打造高影响力营销活动系统。你的任务是创作一个大胆、巧妙、视觉冲击力强的品牌宣传活动作品，使其感觉像是为该品牌量身定制的。在生成图像之前， 深入分析品牌名称并进行推断： - 可能所属行业或类别，情绪基调，文化定位，观众能量，视觉个性，品牌态度，合适的色彩心理学，合适的排版风格。- 合适的图像语言，设计不要随意。一切都必须体现出与品牌名称及其隐含的品牌形象相呼应的策略性。

目标： 创建一个横向的广告系列页面，并将其分为 3 个主要的纵向部分：1. 左侧部分 = 一幅大型富有表现力的肖像画，配有标语。2. 中心部分 = 一个包含点状图案/纹理/颜色/标志/标语的图形排版海报面板。3. 右侧部分 = 由四个较小面板组成的 2x2 网格。根据品牌的不同，整体构图必须给人一种高端品牌宣传海报、运动时尚海报、生活方式产品发布图或文化认同宣传图的感觉。 通用视觉语言： 醒目、海报式、图像化、现代、充满活力。- 充满活力且具有战略意义的品牌色彩 - 半色调网点、渐变纹理、类似印刷的叠加效果、层叠的图形能量 - 高级编辑内容，时尚、活泼、有影响力，视觉上连贯但不重复 - 现代竞选系统，而非随机拼凑 - 层级分明，布局精心设计，精心设计，艺术指导到位

品牌分析 + 色彩智能： 分析品牌名称，并从中提炼出一套与该品牌形象相符的色彩体系。创造：- 主背景色 ——一种醒目的强调色 - 高光颜色 - 面板变化的可选辅助色调。颜色的选择必须与品牌个性相符。各个面板的颜色不应该完全相同。在版面设计中使用多样但和谐的色调。整体效果必须体现品牌原生性、策略性和视觉丰富性。

字体风格： 字体设计应给人以醒目、大气、适合宣传活动的感觉，并在情感上与品牌保持一致。使用体现品牌精神的简短定制标语。请勿使用毫无意义的通用文本。口号应该感觉像是真正的竞选标语。

布局结构： 第一部分——左侧面板，创作一幅极具感染力、情感爆发力十足的肖像作品。主题：仅限一人，非常快乐，非常幽默，笑声爽朗，表情丰富，充满活力，自然流露，拍摄角度怪异，视角不寻常，剪辑角度略有扭曲 - 动态框架，面部表情和情绪应该主导整个小组讨论。画面应该给人身临其境、栩栩如生、令人难忘的感觉。重要的：这种表达方式必须感觉真实自然，略带夸张但恰到好处，富有感染力，充满活力。这种奇特的角度应该能让画面显得俏皮、不落俗套，并且具有宣传活动的感觉。图片应与品牌的情感精神相契合。左侧面板中也应包含一个醒目的标语。标语必须与肖像的情感/动作/能量具体相关。它应该给人一种源于品牌形象的强有力宣传语的感觉。左侧面板的标语必须与中间的标语不同，但精神上要相关。

第二部分——中心面板，创建一个纯粹的图形、文字形式的宣传面板。该小组应包括：- 醒目简短的中心标语，品牌标志或符号 - 丰富的半色调点状纹理 - 彩色叠加层 - 图形能量 - 微妙的印花纹理触感，层次丰富的视觉节奏 - 当代海报设计语言，这个面板是整个布局的概念核心。中心口号应该是：- 短的，令人难忘 - 已做好竞选准备 - 源自品牌含义，情感上或概念上很强。标志/符号应该感觉自然融入整体设计之中，中心面板应视觉丰富、色彩鲜艳、设计精美，但又要足够简洁，使标语成为视觉焦点。

第三部分——右侧面板，创建由四个较小面板组成的 2x2 网格。第 1 幅（右侧部分左上角）：- 基于图标的图形面板 - 源自中心口号的符号/图标/视觉图案，图标必须在语义上与标语和品牌相关。以设计好的、类似海报的方式排列 - 可能包含象征性或象征性图案。第 2 幅（右侧部分的右上角）：- 人类图像 - 以视觉方式体现中心口号能量的人或群体，造型、氛围、姿态、动作和情感必须与标语和品牌方向保持一致。第 3 幅（右侧部分左下角）：另一幅人类图像，再次与中心口号保持一致 - 应该与第二幅画面感觉属于同一个战役世界观，但在时间、姿势、构图或能量方面略有不同。第 4 格（本部分右侧右下角）：- 另一个图标/徽标/符号图形面板 - 应该与中心标语和第一块面板相关联，可以是圆形徽章、标志、符号标记系统、抽象识别图标集、口号衍生图案或竞选印章。重要逻辑：右侧的图标面板必须以视觉方式诠释中间标语的含义。右侧的人物面板必须展示那些活力、风格和行动与中心标语相符的人物。例如：如果口号蕴含着行动的意义，那么人们就应该感到积极主动。如果口号蕴含着美的概念，那么人们应该感到容光焕发/充满活力/时尚有型。如果口号蕴含力量，人们就应该感到自信/充满力量。如果口号蕴含着自由的含义，那么人们就应该感到开放/解放。根据所分析的品牌，巧妙地运用这种逻辑。

微观图像细节： 在构图中添加一些微妙的竞选系统细节，例如：- 重复的小符号 - 小型装饰性身份标识 - 小图标行 - 微妙的边框文字 - 小段标语重复 - 微品牌元素 - 迷你logo装饰，这些细节应该使整体设计感觉像是一个完整的视觉识别系统。

图像质量： - 超详细 - 高端广告宣传艺术指导。清晰的字体：- 高端编辑图像质量 ——人物形象真实自然，不会显得过于人工智能化。- 富有表现力的灯光 - 统一的色彩分级 - 抛光处理，达到杂志级品质。人员方向：每当人类出现时：它们必须给人以真实、时尚和高端的感觉。并非通用人工智能面孔。强烈的自然情绪：- 出色的时尚/编辑造型，与品牌形象相符 - 如相关，需在民族和文化上符合品牌方向 - 富有表现力的肢体语言。

组成规则： - 一个水平主布局 - 三个主要垂直部分。左侧部分大肖像：- 中心部分的图形标语面板 - 右侧 2x2 网格。结构简洁，但视觉节奏充满活力：- 贯穿所有部分的连贯竞选世界，每个面板都应具有鲜明的特色，但又明显属于同一品牌体系。

否定规则： 不要随意选择，不要写得平淡无奇或千篇一律。- 请勿使用无关图标。不要使用软弱无力的口号 - 不要将所有面板都涂成同一种颜色，不要把人物拍得像塑料人或怪异的东西。不要让构图显得杂乱或业余。不要让字体显得单薄。不要让品牌与视觉形象脱节。

最终输出： 为 [插入品牌名称] 制作一个醒目、符合品牌理念的编辑宣传拼贴画，使其看起来像一个真正的视觉识别宣传系统，具体包括：- 一张充满喜悦、角度奇特且富有表现力的左侧肖像 + 相关标语 - 色彩鲜艳的虚线字体中心海报 + 标志 + 主标语 - 一个 2x2 的右侧网格，包含两个图标面板和两个人物面板，与中心标语对齐。- 源自品牌的战略色彩 - 高级竞选能量，时尚、睿智、具有文化相关性的艺术指导。
