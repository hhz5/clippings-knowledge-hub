Cowrite 上线，给 Codex 装上可视化创作工作台

我终于把 Codex 变成了一个可视化写作工作台

空格的键盘 2026年7月18日 11:33

PRODUCT NOTE · COWRITE

昨天爆肝一晚，终于把我构思的这个内置的 Codex 里的写作工具 Cowrite。

它可以在 Codex 里实现一键配图，排版，发送社媒和做 PPT。

不需要折腾乱七八糟的 Skill 和文件夹。

几乎是把我创作相关的 skill 产品化了。

选中文字后就能配图，直接插入原文，好用到爆。

使用步骤

先在Codex里安装项目：

安装成功后，直接运行 Cowrite，Codex 会返回你两个地址。

复制访问地址，可以在 Codex 浏览器打开，使用更方便，也可以用电脑自带浏览器打开地址。

此时 Codex 页面右侧加载了 Cowrite

在 Cowrite 导入文章

可以新建页面，自己输入想要写的内容的想法，写完发送给 Codex 帮你完善正篇文章。

也可以把本地 markdown 导入进来，导入后就是和大家常用的编辑器一样。

导入成功后，还可以选中内容，进行优化、配图（调用Codex 内置的 image2 配图）、转 HTML 配图。

所有和 Agent 的行为都在 Codex 内发生。并且把 Codex 输出的结果（文字、图片、代码）回写到文章中。

顶部工具栏有全文配图、排版、Slide、Cowrite。

本质上每个功能就是一个或多个 Skill，我们一个个来讲。

全文配图

可以让 Codex 根据整篇文章内容来输出配图，并插入原文。

全文排版

可以输出公众号或小红书格式的排版，生成结果，直接在 Cowrite 内预览并复制。这篇文章就是在 Cowrite 完成的排版。

生成 Slide

含 PPTX、HTML 两种格式，可以看下效果，它可以应用文章中的图片作为 PPT 的内容。

发送到飞书

最后，文章完成了，可以直接发到飞书、公众号（待完善）。

飞书这里就调用了飞书 CLI，需要自己配置自己 Key。

项目地址：SpaceZephyr/cowrite

也可以试试装在 Claude Code 、Workbuddy 等任意 Agent。

源起

这个想法源于昨天在我的社群里，突发奇想。

Skill 太多，文件夹太乱，怎么把 Skill 做成 GUI 的形式？

ChatCut 给我很大启发，结合 Codex 生态来做，很易实现。

于是我开始从自己最擅长的写作流程入手，封装了快 10 个 Skill， 使用 MCP 拆了 10 多个编辑器的功能点。

实现了文章的配图、排版、PPT 制作、和选中内容共同创作和优化。

这帮我解决了写作流程太乱，Skill 太多，每次配图还要到本地粘贴复制，到公众号排版还要手动处理的问题。

把零散 Skill 变成一个可点击的创作工作台 Cowrite 。

我还在对项目进行完善，有更大的想法想要实现，感兴趣的可以找我聊聊。
