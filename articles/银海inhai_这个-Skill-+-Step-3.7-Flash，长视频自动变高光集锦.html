视频详情

上传了一段爆款带货短视频链接，让 Agent 自主完成了视频内容分析、高光判断、自动裁剪、字幕生成，最后输出了一个可以直接分析的复盘在线页面，全程没有人工干预，一次跑通，没有返工。

这次选的模型是阶跃星辰刚发布的 Step 3.7 Flash，选它主要考虑三个点：

**快：**Flash 级模型，生成速度能到 400 TPS，视频分析这种需要多轮调用的工作流跑起来不卡。

**便宜：**实际测试下来跑完一个两小时视频的完整分析链路，总成本大概在几块钱的量级，Step 3.7 Flash 的定价是输入 ¥1.35/M tokens（缓存命中 ¥0.27），输出 ¥8.1/M tokens。

对于我这种之前已经买过 Step Plan 的用户不用愁直接用就可以，相当于是加量不加价，低至25元/月就能上车：https://platform.stepfun.com/step-plan?channel=AIchanpinyinhai

多模态 Agent 能力：原生支持多模态，视频丢进去就能理解，搜索内置在推理链路里，Agent 可以边分析边联网查资料，工具调用在多轮场景下比较稳定。

这次的 Step 3.7 Flash 是开源模型，如果有敏感信息内容可以直接部署一个本地的模型，数据不出域，本地的视频直接也能分析完成之后。

快速生成一个报告，像我之前下载在本地的跨境电商流量分析的视频，它直接分析完后给我一个相对完整的结论。

拆开来看，Agent 经历了四轮规划-执行-观察循环，我特意给它使用 CC Switch 加入到了 Claude DeskTop 里面可以更好的看清楚 Step 3.7 Flash 的整个 Agentic 的能力。

第一轮做视频理解，音频转写拿到文字骨架，逐帧分析画面内容，合并成结构化索引，每个时间段在讲什么、有没有代码演示、有没有观众互动，全部标出来。

第二轮做高光判断，它可以直接根据内容价值筛选，技术亮点、现场反应、关键结论各有权重。

第三轮对字幕理解，调用Step 3.7 Flash 中对于视频的图片文本进行OCR理解，如果深一些可以直接将文本跟时间轴进行对齐。

第四轮生成复盘页面，高光片段、字幕、摘要整合成一个网页，也就得到了我们一开头的视频的网页。

需要说清楚的是，这个工作流不是单靠模型完成的。

Step 3.7 Flash 负责理解和决策，这个版本的原生支持多模态的能力，更好的适配了像 Claude Code 这种负责编排整个 Agent loop 的 Agentic 框架层。

然后结合我自己做的视频分析 Skill 负责把拆帧、内容索引、时间戳标注、片段裁剪这些操作封装成可复用的模块。三者组合在一起才跑得通。

跑通高光剪辑之后，我把这套组合方案拿去试了几个相近的场景，发现它的泛化能力比我预期的要好。

底层逻辑是一样的，都得益于本次Step 3.7 Flash的更新，我只要关注：视频输入、多模态理解、内容判断、工具执行、结构化输出，换一下 Skill 的封装逻辑就能适配不同的任务。

通用的能力是视频内容报告的生成是这个模型+Skill里面通用的能力。

我们给 Agent 一段发布会录屏或者一场分享的完整视频，它除了剪片段，还可以输出一份结构化的内容报告：核心观点提炼、关键数据标注、演讲者的论证路径、甚至会联网搜索来验证演讲中提到的数据是否准确。

Step 3.7 Flash 天然具备搜索能力，搜索是 Agent 推理链路的一部分，它会在分析过程中自主判断哪些信息需要联网验证。

赛事、直播回放剪辑也是非常适用。

视频详情

作为学习者可以直接跳转到感兴趣的部分，不用从头看到尾。

这几个场景的共同点是：输入都是长视频，输出都是结构化的内容产品，可以看到这个产物是逐帧分析且对于每块片段的理解进行了拆解。

区别只在于 Agent 的判断逻辑和 Skill 的输出格式。

Step 3.7 Flash 在这些场景里承担的角色是一样的，理解视频内容、规划分析策略、判断哪些部分有价值、协调工具调用。

它的原生多模态能力意味着不需要额外配置视觉模块，搜索内置进推理链路意味着它能自主补充信息。

回到模型本身，Step 3.7 Flash 给我的整体印象是：它并非是那种"单项冠军"型的模型，整体看来在 Agent 工作流里综合表现比较均衡。

198B MoE 架构、约 11B 激活参数、最高 400 TPS，在 Flash 级模型里也算得上是第一梯队。

搜索不是外挂的而是内置，工具调用的稳定性在多轮场景下表现不错，开源可部署，我们就能直接它在本地也能跑。

此外这个模型也已经兼容主流的 Agent 框架，Claude Code、KiloCode、Hermes Agent、OpenClaw 这些都能直接对接，不需要为了换一个模型重写整套编排逻辑，接入成本比较低，并且比之前的 Step 3.5 Flash 版本拉升了至少5%。

这些特点组合在一起，我觉得让它成为比较适合做「需要反复调工具、需要理解多种信息、需要稳定走完全程」的 Agent 任务。

想要了解 Step 3.7 Flash 模型更多细节的朋友，可以自己阅读下这份官方技术报告，写的非常详细并且配备了不少非常不错的案例。

https://static.stepfun.com/blog/step-3.7-flash/

最后生成结构化输出，在 Step 3.7 Flash 这种又快又有多模态以及 Agentic 很不错的模型下，可以快速的降低分析时间和成本。
