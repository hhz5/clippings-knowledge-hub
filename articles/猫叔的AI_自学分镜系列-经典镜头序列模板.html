自学分镜系列 - 经典镜头序列模板

原创 猫叔的AI 2025年08月31日 16:18

下面我们来看看“怎么拍”和“具体拍什么镜头”。在影视创作中，分镜头的第一步是 拆解剧本 ；第二步则是确认 每一段剧本应以何种画面呈现 ，也就是分镜设计。

所谓分镜，本质上就是 将文字剧情转化为视觉化的过程 。通常一个剧本会被拆分为许多个不同的画面，有人会把它绘制成单张图片，也就是“故事板”。不过，很多AI视频制作者往往做到这一步就直接进入“生图”或“生视频”的阶段了。

然而，分镜之后还有更关键的一环： 镜头序列 。举例来说，当我们表现一个人说话时，如果始终只用一个正面镜头拍他，很快观众就会感到单调乏味。更好的做法是适时加入一些不同角度的画面，或者对手的反应镜头。上期的解读中，这类补充镜头被称为“B级镜头”，但从我的理解，它依旧属于“A级镜头”的范畴。

让我们来看一些 经典镜头序列模板 ，这些模板可直接用于不同类型的场景：

🎬 1. 驾驶场景（旅程开始或到达）

用于公路电影、介绍场景或地点之间的过渡。

镜头序列模板：

  1. 1. 建立广角镜头 （风景 + 道路）
  2. 2. 跟踪镜头 （车辆侧面或后部）
  3. 3. 驾驶员特写 （情绪、专注）
  4. 4. 车内中景 （展示所有乘客）
  5. 5. 插入镜头 （换挡杆、GPS、方向盘上的手）
  6. 6. 通过挡风玻璃的POV （接近城镇或特征）
  7. 7. 切换 （风景或城镇标志）
  8. 8. 广角镜头 （到达目的地）

🗣️ 2. 对话场景（两个或多个角色之间的对话）

用于戏剧、惊悚片或浪漫场景。

镜头序列模板：

  1. 1. 建立镜头 （地点 + 两个角色）
  2. 2. 过肩镜头A （聚焦于角色B）
  3. 3. 过肩镜头B （聚焦于角色A）
  4. 4. 关键台词时每个说话者的特写
  5. 5. 反应镜头 （沉默反应的特写或中景）
  6. 6. 插入 （例如，手部动作、物体、眼神）
  7. 7. 广角镜头 结束或重新连接两个角色

⚡ 3. 动作场景（打斗、追逐、逃脱）

快节奏、动态相机，视觉清晰是关键。

镜头序列模板：

  1. 1. 广角建立镜头 （地点 + 战斗者）
  2. 2. 中景跟踪镜头 （角色移动）
  3. 3. 角色间的快速切换 （特写 + 中景）
  4. 4. 一名战斗者的POV （主观动作）
  5. 5. 冲击插入 （拳打、物体击中）
  6. 6. 慢动作时刻 （增加戏剧性，不总是必要）
  7. 7. 解决方案的广角镜头 （胜利者、后果）

🧍 4. 情感揭示场景

慢节奏、特写强调、持续镜头。

镜头序列模板：

  1. 1. 广角/中景 （角色独自在空间中）
  2. 2. 缓慢推进 或推进（面部特写）
  3. 3. 过肩 显示角色所见
  4. 4. 反应特写 （情绪变化）
  5. 5. 插入 （记忆或触发物体）
  6. 6. 极端特写 （眼泪、眼睛、手）
  7. 7. 广角镜头 （显示孤立或接受）

🏠 5. 到达新地点（如城镇或家）

与您的汽车进城例子非常相似。

镜头序列模板：

  1. 1. 航拍或建立镜头 （城镇/城市概览）
  2. 2. 跟踪镜头 （进入的车辆或人）
  3. 3. POV或挡风玻璃视图 （接近地标）
  4. 4. 切换 （标志、人、建筑）
  5. 5. 内部镜头 （乘客交谈或反应）
  6. 6. 中景/特写 （引入情绪、紧张）
  7. 7. 到达确认镜头 （门打开，他们下车）

🎥 额外：YouTube风格场景（Vlog或教程）

  1. 1. 说话者中景
  2. 2. B-Roll切换
  3. 3. 屏幕插入或POV
  4. 4. 反应特写
  5. 5. 场景变化的广角镜头
  6. 6. 手持移动镜头

🧠 6. 思考/沉思场景

用于展示角色的内心状态、反思或决策过程。

镜头序列：

  1. 1. 中景 （主体坐着或站着，独自一人）
  2. 2. 缓慢推进或放大 （进入面部以表达内心聚焦）
  3. 3. 插入 （思考对象 — 信件、照片等）
  4. 4. POV镜头 （他们正在看的东西）
  5. 5. 旁白或沉默
  6. 6. 极端特写 （眼睛、微妙表情）
  7. 7. 广角镜头 （显示孤立或决定时刻）

📞 7. 电话/远程通信场景

镜头序列：

  1. 1. 中景 （拨打电话的人）
  2. 2. 插入镜头 （电话、按钮、通话屏幕）
  3. 3. 过肩(OTS) （当他们通话时）
  4. 4. 切换到接收者 （匹配构图）
  5. 5. 双方角色的反应特写
  6. 6. 分屏或交叉剪辑 （可选风格选择）
  7. 7. 广角镜头 （过渡出去）

🕵️ 8. 悬疑或调查场景

经常出现在惊悚片或悬疑片中。

镜头序列：

  1. 1. 跟踪或稳定相机镜头 （角色行走、搜索）
  2. 2. 低角度或荷兰角度 （方向混乱）
  3. 3. 插入 （证据、神秘物体）
  4. 4. 特写反应 （恐惧、好奇）
  5. 5. 剪影镜头 或 阴影
  6. 6. 带声音提示的POV
  7. 7. 惊吓/揭示镜头

🎭 9. 角色介绍场景

快速建立个性的时尚方式。

镜头序列：

  1. 1. 英雄镜头（中景或广角） （酷炫入场、剪影）
  2. 2. 跟踪镜头 （跟随他们的脚步）
  3. 3. 配饰特写 （鞋子、手、物品）
  4. 4. 他人的反应镜头
  5. 5. 慢动作入场或推进
  6. 6. 第一句对白
  7. 7. 反向镜头 （展示谁在看他们）

🎓 10. 闪回序列

通常用色彩分级或转场风格化。

镜头序列：

  1. 1. 匹配剪辑或淡入 （从物体或情绪）
  2. 2. 过去地点的广角镜头
  3. 3. 年轻自我/过去角色的特写
  4. 4. 来自现在的对话或声音重叠
  5. 5. 慢动作或柔焦特写
  6. 6. 情感反应
  7. 7. 用匹配剪辑或震动返回现在

👁️ 11. 揭示或发现场景

当角色发现重要事物时。

镜头序列：

  1. 1. POV或跟踪镜头
  2. 2. 插入 （发现的物体或关键线索）
  3. 3. 反应特写
  4. 4. 过肩（俯视物体）
  5. 5. 向上倾斜镜头 （理解的变化）
  6. 6. 匹配剪辑到相关场景 （可选）
  7. 7. 具有冲击力的广角镜头

🛏️ 12. 醒来/早晨场景

常见于内省电影或日常生活序列。

镜头序列：

  1. 1. 眼睛睁开的特写
  2. 2. 床和晨光的广角镜头
  3. 3. 插入 （闹钟、关闭它的手）
  4. 4. 俯视镜头 （静止或情绪）
  5. 5. 跟踪镜头 （角色走向水槽、镜子）
  6. 6. 反射特写
  7. 7. 带晨间例行活动的中景

✨ 13. 梦境或超现实场景

创意或实验性。通常非线性。

镜头序列：

  1. 1. 浮动相机移动 （稳定器/轨道车）
  2. 2. 不寻常角度 （倾斜、倒置、极低角度）
  3. 3. 慢动作或快速剪辑
  4. 4. 令人迷失方向的特写
  5. 5. 象征性插入 （眼睛、火焰、落下的羽毛）
  6. 6. 回响对话/过滤声音
  7. 7. 突然过渡出 （角色醒来或回神）

🕺 14. 舞蹈/表演场景

出现在音乐剧、视频、派对场景中。

镜头序列：

  1. 1. 广角主镜头 （编舞）
  2. 2. 移动轨道或摇臂镜头 （展示规模）
  3. 3. 中景表演镜头 （群体或独奏）
  4. 4. 节奏特写 （手、脚、脸）
  5. 5. 观众反应
  6. 6. 360度镜头或旋转
  7. 7. 结尾时拉远广角
