总体结构

公式条目标准格式

每个具体的“公式”条目将采用统一的格式进行呈现,确保信息清晰,方便快速理解和应用。

[公式ID] | [公式名称]

•构成: [元素A] + [元素B] → [核心效果]

•示例: [摘录原始文档中的实操示例,用以阐述公式的具体应用场景。]

关键字段说明

公式ID: 为了方便索引和交叉引用,我为每个公式设计了唯一的ID。ID由“题材缩写-类别缩写-序号”构成。

•序号: 从01开始的两位数字。

1. 核心理念

爱情浪漫题材的核心逻辑是“日常细节藏心动、现实冲突显深情、治愈结局留余温”。它擅长从平凡的生活细节中捕捉令人心动的瞬间,通过现实层面的矛盾与挑战来考验并升华情感,最终给予观众一个温暖、治愈且留有余味的情感落点。

2. 场景构建公式

LR-SC-01 (新) | 共享电量公式

  • 构成: 电量焦虑 + 共享充电设备 → 合理共处与二次见面契约
  • 示例: 在重要的线上会议前,女主角的笔记本电脑即将没电,正当她绝望时,旁边的男主角默默递过来一个大功率的移动电源。为了归还,两人自然地约了下次见面。
  • 解析: 在数字时代,“电量焦虑”是都市人的共同情感。共享充电设备不仅解决了燃眉之急,更创造了一个必须再次见面的“归还”契约,让关系的推进变得顺理成章。

LR-SC-02 (新) | 社交误操作公式

  • 构成: 私密操作 + 意外暴露给对象 → 打破社交伪装
  • 示例: 女主角想把一张加了猫耳朵特效的可爱自拍发给妈妈,结果手滑发给了平时不苟言笑的男上司。几分钟后,男上司回复了一张他自己宠物的照片,配文:“我的猫,好像比你的更可爱一点。”
  • 解析: 表情包、自拍等是现代人的“人格面具”之一。错发就像不小心掉落的面具,让对方看到了自己伪装之下的真实一面。这种“意外的坦诚”打破了常规的交往模式,是加速情感升温的催化剂。

LR-SC-03 (新) | 生活默契公式

  • 构成: 日常选择 + 惊人一致 → 天生一对的暗示
  • 示例: 新来的同事B被拉进公司外卖群。第一次点单,A和B恰好点了同一家螺蛳粉,并且都备注了“加双份酸笋,不要青菜”。取外卖时,两人看着对方的订单相视一笑,A说:“看来我们是同道中人。”
  • 解析: “吃”是人类最基本的需求,口味的契合往往暗示着性格和生活方式的合拍。“点外卖”这个场景比传统的“一起做饭”更轻量、更易于实现。通过这个小小的默契,可以含蓄地表达“我们是天生一对”的浪漫主题。

LR-SC-04 (新) | 精神共鸣公式

  • 构成: 小众品味 + 意外知己 → 灵魂伴侣的确认
  • 示例: 在一次长途飞行中,女主角因害怕而无法入睡。旁边的男主角将自己的一只降噪耳机递给她,里面正放着一首她很喜欢但非常小众的后摇。她惊讶地看着他,他也报以微笑。整个旅途,他们没有说一句话,但一起听完了男主角的整个“飞行专用”歌单。
  • 解析: 音乐是情绪的直接载体,共同的音乐品味等于拥有共同的“情绪语言”。“共享耳机”是一个极具暧昧感的动作,它意味着允许对方进入自己私密的精神世界。通过共享歌单进行交流,则是一种更含蓄、更浪漫的“赛博情书”。

LR-SC-05 (新) | 虚拟身份公式

  • 构成: 虚拟世界的默契搭档 + 现实身份的反差 → 命运的戏剧性
  • 示例: 在公司里是竞争对手的男女主角,下班后却是游戏里最默契的搭档。直到公司举办电竞比赛,他们才在赛场上发现,自己最想击败的对手,就是自己最想保护的队友。
  • 解析: 游戏世界提供了一个剥离了所有现实社会属性的“纯粹”空间。这种“先成为灵魂伴侣,再奔现”的模式,颠覆了传统的恋爱顺序,充满了现代感和不确定性,对年轻观众有很强的吸引力。

LR-SC-06 (新) | 角色扮演公式

  • 构成: 虚构的CP身份 + 高浓度情感互动 → 假戏真做的可能
  • 示例: 一直是普通朋友的A和B,在一次剧本杀中拿到了一个关于“错过”的悲情CP本。在最后环节,A的角色需要对B的角色说出一段迟到的告白。A看着B的眼睛,念着台词,却不知不觉地代入了真情实感,流下了眼泪。
  • 解析: 剧本杀提供了一个“合法的出轨”空间——情感的出轨。它给了角色一个“借口”,去试探、去表达那些在现实中不敢或不愿表达的情感。虚构与现实的边界变得模糊,为浪漫的发生提供了土壤。

LR-SC-07 (新) | 赛博陪伴公式

  • 构成: 持续的线上关注 + 关键时刻的线下介入 → 弱关系到强关系的跃迁
  • 示例: 男主角会给女主角的每一条朋友圈点赞。一天,女主角的相机坏了,她在朋友圈求助,男主角立刻私信她,发来一个修理教程,并附言:“如果搞不定,我下班过来帮你看看。”
  • 解析: 持续的、从不缺席的点赞,本身就构成了一种长情的告白,它意味着“你的所有生活,我都想参与”。这种从线上“弱关系”到线下“强关系”的转变,非常符合当代人的交友模式,真实而细腻。

LR-SC-08 (新) | 边界时空公式

  • 构成: 限定的公共空间 + 共同的疲惫属性 → 萍水相逢的温情
  • 示例: 两个刚加完班的广告人,在末班地铁上相遇。他们认出了对方是竞争公司的员工。两人相视苦笑,开始吐槽各自的甲方和老板。在短短几站路的时间里,他们从“敌人”变成了“战友”。
  • 解析: “末班车”象征着都市生活的终点和边界,坐上末班车的人,都卸下了一天的伪装。在这个临时的、流动的空间里,人与人之间的戒备心会降低,更容易产生“同是天涯沦落人”的共情。

LR-SC-09 (新) | 宠物僚机公式

  • 构成: 治愈系宠物 + 主动的互动 → 打破社交壁垒
  • 示例: 社交恐惧症的男主角只敢在猫咖里放松自己。他平时最喜欢的一只猫,叼着他刚买的猫零食,一路小跑送到了女主角面前,并对着女主角“喵喵”叫,仿佛在替他“送礼物”。女主角被逗乐了,主动过来和他聊天。
  • 解析: 宠物是极佳的社交“润滑剂”。在这个桥段里,猫咪扮演了“月老”的角色,它的一切行为都可以被解读为“天意”或“助攻”,让两个陌生人之间的互动变得合理、有趣,且毫无压力。

LR-SC-10 (新) | 潮流社交公式

  • 构成: 带有收藏属性的潮流单品 + 交换/互助需求 → 同好圈的快速连接
  • 示例: 女主角为了抽到一个限定款盲盒,天天去同一家店打卡。男主角是这家店的店员,他注意这个女孩很久了。在女孩又一次失望而归后,男主角在她离开时叫住了她,然后从柜台下拿出了自己私藏的那个限定款,说:“这个送你,就当是‘全勤奖’吧。”
  • 解析: “盲盒”的核心魅力在于“不确定性”和“稀缺性”,这使其天然具有社交货币的属性。“交换”是“娃圈”最基础的社交行为,它基于“各取所需”的公平原则,能快速建立陌生人之间的连接。

3. 情感递进公式

LR-EP-01 | 细节关怀公式

  • 构成: 不经意的照顾 + 对方的察觉 → 心动升温
  • 示例: 女主开会时咳嗽,男主默默在她桌上放了温水和润喉糖,女主看到后,偷偷在男主的笔记本上画了小太阳。
  • 解析: 真正的关怀往往体现在不为人知的细节里。一方不声张的照顾,被另一方敏锐地察觉,这种“我的用心被你看见”的互动,是心动从萌芽到升温的关键。它强调的是行动而非语言,是含蓄而真诚的情感表达。

LR-EP-02 | 试探互动公式

  • 构成: 模糊的暗示 + 试探性回应 → 情感靠近
  • 示例: 男主问女主“周末要不要一起去看画展?就当…感谢你帮我改方案”,女主犹豫后说“如果那天不下雨,就去”。
  • 解析: 在不确定对方心意时,人们往往会用一个模糊的、可进可退的理由(如“感谢”、“顺路”)来发起试探。而另一方的回应同样带有不确定性(如“看天气”、“看心情”),为彼此保留了余地。这种小心翼翼的推拉,正是暧昧期最迷人的地方。

LR-EP-03 | 共同经历公式

  • 构成: 挑战类事件 + 相互支持 → 情感深化
  • 示例: 两人一起参加公益徒步,女主体力不支,男主放慢脚步陪她,还分享自己的水和零食,最后一起冲过终点。
  • 解析: 共同经历,特别是共同克服困难的经历,是建立“革命友谊”和深化情感的捷径。在挑战面前,双方展现出的坚持、互助和担当,能让彼此看到平时不易展现的品质,从而建立起超越日常交往的深度情感连接。

LR-EP-04 | 吃醋催化公式

  • 构成: 第三方出现 + 隐性醋意 → 直面心意
  • 示例: 男二对女主表白,男主看到后,借口“还有工作没处理”提前离开,后来女主发现男主那天在办公室反复翻看她的朋友圈。
  • 解析: “吃醋”是检验心意的试金石。当一个潜在的竞争者出现时,角色会因“领地被侵犯”而产生嫉妒、占有欲等负面情绪。这种情绪的出现,以及角色为了掩饰它而做出的反常行为(如假装不在意、找借口离开),恰恰暴露了其内心真实的想法。

LR-EP-05 | 深夜倾诉公式

  • 构成: 脆弱时刻 + 坦诚分享 → 情感交心
  • 示例: 女主因家人住院情绪低落,男主陪她在天台聊天,分享自己小时候照顾生病母亲的经历。
  • 解析: 深夜和脆弱的时刻,是人们心理防线最低的时候。在这样的氛围下,角色更容易卸下伪装,分享平时不会轻易示人的过往和伤痛。通过交换彼此最柔软的部分,双方建立起的是一种深刻的、灵魂层面的信任与连接。

LR-EP-06 | 承诺萌芽公式

  • 构成: 小事约定 + 认真兑现 → 信任建立
  • 示例: 男主说“下次带你去吃我常去的那家炸酱面”,一周后,男主特意提前排队,带着热乎的炸酱面出现在女主公司楼下。
  • 解析: 信任不是靠豪言壮语,而是靠一件件小事的兑现积累起来的。一个看似随口的约定,被对方郑重其事地记在心上并认真完成,这种“言必信,行必果”的态度,会给对方带来极大的安全感和心动。

LR-EP-07 | 肢体靠近公式

  • 构成: 自然的肢体接触 + 情绪波动 → 亲密升级
  • 示例: 两人在图书馆找书,男主伸手帮女主拿高处的书,手臂不经意碰到女主的肩膀,女主耳朵瞬间变红,男主也放慢了呼吸。
  • 解析: 在非必要的情况下发生自然的、短暂的肢体接触(如并肩时手臂的触碰、递东西时指尖的相遇),是打破社交安全距离、试探对方反应的有效方式。接触瞬间双方的生理和情绪反应(如心跳加速、脸红、呼吸变化),是亲密关系升级的明确信号。

LR-EP-08 | 兴趣共鸣公式

  • 构成: 共同爱好 + 深度交流 → 灵魂契合
  • 示例: 女主喜欢老电影,男主恰好收藏了很多老胶片,两人一起在家看电影,从剧情聊到人生,发现彼此价值观高度契合。
  • 解析: 共同的兴趣爱好是建立关系的良好开端,但真正让情感深化的,是基于这个兴趣展开的深度交流。从“我们都喜欢什么”聊到“我们为什么喜欢”,再到“它让我们想到了什么”,层层递进,最终达到价值观和人生观层面的共鸣,即“灵魂契合”。

LR-EP-09 | 守护行动公式

  • 构成: 默默付出 + 偶然发现 → 情感爆发
  • 示例: 女主的项目遇到困难,男主偷偷帮她整理资料、联系合作方,女主偶然看到男主熬夜写的方案备注,瞬间红了眼眶。
  • 解析: “爱是做出来,不是说出来”。一方在背后默默地、不求回报地为另一方付出,当这种付出被偶然发现时,其带来的情感冲击力远超任何甜言蜜语。这种“原来你为我做了这么多”的感动,往往是促使情感关系产生质变的关键节点。

LR-EP-10 | 确认心意公式

  • 构成: 关键事件 + 直白表白 → 情感确定
  • 示例: 女主在暴雨中寻找丢失的重要文件,男主冒雨找到文件,浑身湿透地说“比起文件,我更怕你淋雨”,两人在雨中拥抱。
  • 解析: 在经历了长时间的暧昧和试探后,需要一个标志性的事件来终结不确定性,将关系推向明确。通常是在一个情绪达到顶点的关键时刻(如危机、感动、重大抉择),一方用最直白、最真诚的语言表达爱意,完成从“喜欢”到“爱”的最终确认。

4. 冲突发展公式

LR-CD-01 | 误会澄清公式

  • 构成: 信息偏差 + 坦诚沟通 → 关系修复
  • 示例: 女主看到男主和女二在一起吃饭,误以为两人关系亲密,男主主动拿出聊天记录,解释是帮女二解决家庭问题。误会澄清后关系更稳固。
  • 解析: 误会源于信息的不对称。解决误会的关键在于,一方能够主动、坦诚地提供缺失的信息,消除另一方的疑虑。成功的误会澄清不仅能修复裂痕,还能通过展示彼此的信任和沟通意愿,让关系变得更加牢固。

LR-CD-02 | 现实阻碍公式

  • 构成: 外部压力 + 共同面对 → 情感坚定
  • 示例: 女主父母反对她和家境普通的男主交往,两人没有逃避,一起找女主父母谈心,男主承诺会努力给女主幸福,女主也表达对男主的信任。
  • 解析: 外部的反对和压力(如家庭、阶级、疾病)是考验爱情的经典模式。关键不在于压力本身,而在于角色是选择独自承受、退缩放弃,还是选择“我们”共同面对。当两个人决定站在一起对抗全世界时,他们的情感联盟会变得前所未有的坚定。

LR-CD-03 | 过往阴影公式

  • 构成: 童年创伤 + 相互治愈 → 走出阴霾
  • 示例: 男主因童年父母离异不敢相信爱情,女主耐心陪伴,分享自己的成长经历,男主也逐渐敞开心扉,两人一起学习如何去爱。
  • 解析: 每个人都可能带着过去的创伤进入一段关系。当一方的“旧伤”因现实事件而被触发时,另一方的态度至关重要。通过耐心的陪伴、倾听和无条件的接纳,帮助对方正视并疗愈创伤,这个过程不仅是单向的拯救,更是双向的成长和情感的升华。

LR-CD-04 | 价值观冲突公式

  • 构成: 观念差异 + 理解包容 → 关系磨合
  • 示例: 女主想婚后继续追求事业,男主希望女主回归家庭,两人激烈争吵后冷静沟通,男主理解女主的事业心,女主也体谅男主的担忧,约定一起平衡家庭与事业。
  • 解析: 价值观的冲突是亲密关系中最深刻也最难调和的矛盾。解决之道不在于谁对谁错,而在于双方是否愿意跳出自己的立场,去理解对方观念背后的成长经历和深层需求,并在此基础上寻找妥协和共存之道。这个磨合过程是关系走向成熟的必经之路。

LR-CD-05 | 距离考验公式

  • 构成: 异地分离 + 坚持联系 → 感情维系
  • 示例: 男主因工作调动去外地,两人每天视频通话,分享彼此的生活,男主每个月都会偷偷回来给女主惊喜,女主也会攒假期去看男主。
  • 解析: 物理距离会削弱情感连接,因此需要通过更高频率、更高质量的沟通和定期的“仪式感”(如惊喜探望)来对抗这种削弱。异地恋考验的不是爱情的浓度,而是双方为维系关系所付出的努力和创造力。

LR-CD-06 | 前任干扰公式

  • 构成: 前任出现 + 明确态度 → 关系稳固
  • 示例: 男主的前任回来求复合,男主明确拒绝,还把聊天记录发给女主,说“我的未来里只有你”,女主更加信任男主。
  • 解析: “前任”是现有关系的一个潜在威胁。处理这个冲突的关键在于,被干扰的一方必须对前任和现任都表现出清晰、坚定且毫不含糊的态度。这种明确的边界感和对现任的忠诚,是消除伴侣不安全感、巩固信任的最有效方式。

LR-CD-07 | 自我怀疑公式

  • 构成: 自卑情绪 + 对方鼓励 → 重建自信
  • 示例: 女主觉得自己配不上优秀的男主,经常情绪低落,男主每天告诉女主她的优点,带她参加朋友聚会,让她看到自己的闪光点。
  • 解析: 在不平衡的关系中,处于“弱势”的一方容易产生自卑和自我怀疑。此时,另一方的角色就如同镜子,需要不断地、具体地映照出对方的优点和价值,通过外部的肯定来帮助其重建内在的自信。这种支持是“我爱你,也帮你爱上你自己”。

LR-CD-08 | 家庭矛盾公式

  • 构成: 家人反对 + 用行动证明 → 获得认可
  • 示例: 男主的家人嫌弃女主工作不稳定,女主没有放弃,努力提升自己,还在男主奶奶生病时悉心照顾,最终用行动赢得男主家人的认可。
  • 解析: 当冲突来自于对方家庭时,言语的辩解往往是无力的。最有效的方式是通过持之以恒的、积极的行动,来打破对方家人的刻板印象,证明自己的价值和对伴侣的真心。这是一个“农村包围城市”的长期过程,考验的是角色的韧性和智慧。

LR-CD-09 | 意外危机公式

  • 构成: 突发事故 + 不离不弃 → 情感升华
  • 示例: 男主遭遇车祸住院,女主放下工作全程照顾,每天给男主读故事、擦身,男主醒来后第一句话就是“幸好有你”。
  • 解析: 突如其来的危机(如重病、事故、破产)是对人性最直接的考验。在对方最脆弱、最无助的时候,另一方的“不离不弃”所展现出的责任感和爱,能够瞬间将情感升华到超越风花雪月的深度。这是“患难见真情”的经典演绎。

LR-CD-10 | 分手复合公式

  • 构成: 冲动分手 + 冷静反思 + 重新追求 → 破镜重圆
  • 示例: 两人因小事冲动分手,分开后都很痛苦,冷静反思后,男主主动找到女主,重新追求她,从第一次约会的地方开始,弥补之前的遗憾。
  • 解析: 破镜重圆的重点不在“破”,而在“圆”。一次分手让双方都有了冷静反思自身和关系问题的机会。复合不能只是简单的“和好”,而必须是一个“重新追求”的过程,带着反思后的成长和弥补遗憾的诚意,才能让这段关系修复得比从前更坚固。

5. 人物塑造公式

LR-CA-01 | 外冷内热人设公式

  • 构成: 冷漠外表 + 温柔内心 → 反差魅力
  • 示例: 男主是不苟言笑的医生,却会在医院门口喂流浪猫,偷偷帮贫困患者垫付医药费,女主偶然发现这些事,逐渐被他的温柔打动。
  • 解析: 通过在角色的公开行为(冷漠、毒舌、不近人情)和私下行为(善良、温柔、默默付出)之间制造巨大反差,形成一种“宝藏”般的吸引力。观众和另一位主角在“发现”其内心温柔的过程中,会获得极大的满足感和惊喜感。

LR-CA-02 | 元气治愈人设公式

  • 构成: 乐观开朗 + 共情能力 → 温暖吸引
  • 示例: 女主是咖啡店店员,每天笑容满面地迎接顾客,看到男主因工作烦恼,会给他做专属的“治愈咖啡”,还分享搞笑段子开导他。
  • 解析: 这种人设如同一个小太阳,其核心魅力在于不仅自己充满正能量,还能敏锐地感知他人的负面情绪,并用恰当的方式(而非说教)给予温暖和慰藉。她的乐观不是盲目的,而是建立在强大的共情能力之上的,因此具有真实的治愈力量。

LR-CA-03 | 成熟稳重人设公式

  • 构成: 理性克制 + 关键时刻担当 → 安全感
  • 示例: 男主是公司高管,平时理性克制,从不感情用事,但在女主遇到困难时,会第一时间挺身而出,帮她解决问题,给她足够的安全感。
  • 解析: 此人设的魅力在于“可靠”。平时情绪稳定、理性专业,展现出强大的处事能力;而在危机时刻,又能毫不犹豫地挺身而出,展现出保护伴侣的决心和担当。这种“平时靠得住,出事顶得上”的特质,能提供极强的安全感。

LR-CA-04 | 迷糊可爱人设公式

  • 构成: 偶尔笨拙 + 真诚善良 → 讨喜特质
  • 示例: 女主是实习编辑,经常犯小错,比如把文件放错地方、记错会议时间,但她真诚善良,会主动帮同事分担工作,犯错后也会认真道歉改正。
  • 解析: “迷糊”本身并不可爱,可爱的是“迷糊”背后透露出的无害感和真诚。角色的笨拙不是能力上的缺陷,而是一种不谙世事的纯粹。只要搭配上善良的本质和认真负责的态度,这种“小缺点”反而会成为激发他人保护欲和喜爱之情的萌点。

LR-CA-05 | 双向成长人设公式

  • 构成: 各自不足 + 相互激励 → 共同进步
  • 示例: 女主内向胆小,男主冲动急躁,两人在一起后,女主鼓励男主遇事冷静,男主陪伴女主克服社交恐惧,最终女主成为自信的演讲者,男主也学会沉稳处事。
  • 解析: 最好的爱情不是单方面的依赖或拯救,而是两个人成为彼此的“磨刀石”和“助推器”。他们各自的缺点,恰好能被对方的优点所弥补和引导。在相互影响、相互激励的过程中,双方都成为了更好的自己,这让爱情故事拥有了超越个人情感的成长主题。

题材二: 喜剧

1. 核心理念

喜剧的核心逻辑是“日常反差造笑点、情感内核藏温暖、反转打破套路”。它通过放大日常生活中的身份、目标、规则等方面的错位与反差来制造密集的笑点,同时在喧闹的喜剧外壳下,包裹着亲情、友情、成长等温暖的情感内核,并擅长用出人意料的反转来打破观众的预期,创造惊喜。

2. 场景构建公式

CO-SC-01 | 身份错位公式

  • 构成: 高端身份 + 低端场景 → 反差喜剧感
  • 示例: 米其林三星主厨被迫去城中村小餐馆救场,面对生锈的灶台和“要辣到喷火”的顾客要求,手忙脚乱。
  • 解析: 将一个在特定领域具有极高专业水准或社会地位的角色,置于一个完全不匹配的、充满“人间烟火”甚至混乱的环境中。角色原有的技能和行为准则在新环境中完全失效,这种“英雄无用武之地”的窘迫感,是制造反差喜剧效果的经典手法。

CO-SC-02 | 目标乌龙公式

  • 构成: 明确目标 + 阴差阳错 → 荒诞铺垫
  • 示例: 男主想给暗恋的女同事送早餐,却错把邻居家的宠物狗粮当成三明治装进餐盒,为后续送错礼物的喜剧埋下伏笔。
  • 解析: 角色有一个清晰、简单的目标,但在执行过程中,因为一系列微小的、看似不可能的巧合或失误,导致行动的初始环节就发生了根本性的错误。这个“从根上就错了”的设定,为后续一系列连锁的荒诞后果做好了铺垫。

CO-SC-03 | 规则打破公式

  • 构成: 严格规则 + 意外破局 → 喜剧张力
  • 示例: 公司规定“上班必须穿正装”,实习生因暴雨全身湿透,穿着拖鞋和睡衣冲进庄重的会议室。
  • 解析: 喜剧的张力往往来自于对秩序的破坏。通过建立一个极其严格、不容侵犯的规则或环境,然后让一个角色因不可抗力或无心之失,以一种极端的方式打破这个规则,制造出强烈的“不和谐”音符,从而引爆喜剧效果。

CO-SC-04 | 认知偏差公式

  • 构成: 自我认知 + 现实落差 → 幽默铺垫
  • 示例: 女主觉得自己“素颜超美”,出门后被小朋友喊“阿姨你的睫毛掉了”,才发现假睫毛粘反了。
  • 解析: 笑点来源于角色对自己和他人的认知与残酷现实之间的巨大鸿沟。角色活在自己美好的想象中,而观众则拥有“上帝视角”,能看到真相。当现实无情地戳破角色的自我幻想时,这种信息差就转化为了幽默感。

CO-SC-05 | 环境违和公式

  • 构成: 熟悉场景 + 异常元素 → 喜剧氛围
  • 示例: 菜市场里,一个穿西装打领带的男人蹲在摊位前,用流利的英语和大妈砍价“Can you make it cheaper?”。
  • 解析: 将一个完全不属于当前场景的元素(人、物或行为)强行植入,创造出一种视觉或听觉上的“不搭调”。这种违和感打破了观众对熟悉场景的固有预期,使其产生一种“这是什么情况?”的荒谬感和好奇心,从而营造出喜剧氛围。

CO-SC-06 | 计划失控公式

  • 构成: 完美计划 + 突发意外 → 荒诞感
  • 示例: 男主精心策划“求婚惊喜”,却被突然闯入的外卖员撞翻蛋糕,戒指还掉进了火锅里。
  • 解析: 角色制定了一个看似天衣无缝的完美计划,并对结果充满信心。然而,一系列无法预料的、来自外部的微小意外,像多米诺骨牌一样,将整个计划彻底推向失控的深渊。计划越完美,失控后的场面就越混乱,喜剧效果就越强。

CO-SC-07 | 语言错位公式

  • 构成: 外语交流 + 文化误解 → 幽默氛围
  • 示例: 外国游客用中文说“我要一份‘夫妻肺片’”,老板误以为他要“夫妻吵架调解”,掏出纸笔准备劝和。
  • 解析: 利用不同语言或文化背景下的信息不对等,制造“鸡同鸭讲”的沟通困境。一方的表达在另一方的文化语境中被完全曲解,导致双方在一个完全错误的轨道上进行着看似“正常”的交流。这种因误解而产生的驴唇不对马嘴的对话,是喜剧的常见来源。

CO-SC-08 | 道具乌龙公式

  • 构成: 关键道具 + 功能错位 → 喜剧伏笔
  • 示例: 女主把闺蜜托她保管的“减肥茶”错当成咖啡,送给需要熬夜加班的上司,导致上司不停跑厕所。
  • 解析: 一个具有特定功能的关键道具,被错误地用在了不恰当的对象或场景上,导致其原始功能被意外触发,并产生了一系列灾难性的或尴尬的后果。道具本身没有错,错的是它出现的时间和地点。

CO-SC-09 | 角色预判公式

  • 构成: 他人预判 + 角色反套路 → 喜剧感
  • 示例: 同事们都觉得“新来的经理肯定严肃古板”,结果经理第一天上班就表演了一段街舞,还和大家抢零食。
  • 解析: 通过其他角色的议论或行为,为某个即将出场的角色贴上一个刻板的标签,建立观众的心理预期。然后,让该角色以完全颠覆这个标签的方式登场,这种强烈的预期反差,能瞬间产生惊喜和幽默感。

CO-SC-10 | 节奏反差公式

  • 构成: 紧张节奏 + 突然放缓 → 喜剧缓冲
  • 示例: 警匪追逐戏中,小偷突然脚滑摔倒,警察也跟着摔成一团,两人爬起来后还互相递纸巾擦汗。
  • 解析: 在一段高速、紧张的动作序列或情节中,突然插入一个极其缓慢、日常甚至温馨的细节。这种节奏上的急刹车,打破了紧张的氛围,给观众一个意想不到的喘息之机,形成一种“画风突变”的幽默效果,起到了张弛有度的喜剧调剂作用。

3. 笑点爆发公式

CO-EP-01 | 连锁反应公式

  • 构成: 一个失误 + 连环出错 → 密集笑点
  • 示例: 男主打翻咖啡,为了擦干净爬上桌,不小心碰掉吊灯,吊灯砸中鱼缸,鱼掉进同事的键盘里。一波接一波的喜剧冲突。
  • 解析: 这是物理喜剧中的经典模式,一个微小的初始失误,像推倒第一块多米诺骨牌,引发了一系列越来越严重、越来越离谱的连锁性灾难。笑点来自于事态不断升级、主角越来越狼狈的失控过程。

CO-EP-02 | 反讽吐槽公式

  • 构成: 严肃场景 + 犀利吐槽 → 幽默爆发
  • 示例: 公司年会上,老板说“今年我们虽然没盈利,但大家精神可嘉”,实习生小声吐槽“那您的新车是用精神买的吗?”。
  • 解析: 在一个充满客套、虚伪或冠冕堂皇话语的正式场合,通过一个“局外人”或“愣头青”角色,用一句极其犀利、一针见血的吐槽,瞬间戳破所有人的“皇帝新衣”。这种对虚伪的无情嘲讽,能引发观众强烈的共鸣和爆笑。

CO-EP-03 | 肢体喜剧公式

  • 构成: 夸张肢体动作 + 意外结果 → 视觉笑点
  • 示例: 女主想优雅地跨过高台,结果裙摆被勾住,整个人倒挂在台上,露出卡通内裤。
  • 解析: 角色试图完成一个动作,但由于自身的笨拙、环境的阻碍或纯粹的坏运气,导致动作以一种极其夸张和尴尬的方式失败。笑点完全依赖于视觉冲击力,重点在于角色身体失控时所呈现的狼狈姿态和意想不到的暴露。

CO-EP-04 | 误会加深公式

  • 构成: 一个误会 + 越解释越乱 → 喜剧冲突
  • 示例: 男主帮女同事捡文件被女友看到,他想解释却把文件撒了一地,还不小心把女同事的头发扯掉一撮。
  • 解析: 误会本身只是起点,真正的笑点在于角色为了澄清误会而采取的一系列行动,反而让误会变得更加复杂、更加难以解释。每一次的“努力”都变成了“挖坑”,让角色越陷越深,观众则在上帝视角下享受着主角的窘迫。

CO-EP-05 | 反差台词公式

  • 构成: 严肃人设 + 搞笑台词 → 反差笑点
  • 示例: 高冷律师在法庭上,对方律师说“你没有证据”,他突然掏出手机说“不好意思,刚才你说这话的时候,我家猫直播录下来了”。
  • 解析: 让一个通常被认为是严肃、专业、不苟言笑的角色,在最不恰当的场合,说出一句与其身份和当前氛围完全不符的、极其现代化或无厘头的台词。这种人设与台词的巨大反差,能瞬间颠覆观众的认知,产生强烈的喜剧效果。

CO-EP-06 | 巧合撞梗公式

  • 构成: 多个巧合 + 集中爆发 → 喜剧高潮
  • 示例: 男主假装生病请假,却在游乐园遇到上司,为了躲上司钻进玩偶服,结果玩偶服没电,他穿着玩偶头在过山车轨道上跑。
  • 解析: 将多个独立的小概率巧合事件,在同一时间、同一地点集中引爆。每一个巧合都将主角逼入更深的绝境,迫使他做出更荒谬的选择,最终形成一个逻辑上说不通、但情境上又极其合理的喜剧高潮。这是对编剧技巧的极大考验。

CO-EP-07 | 自嘲自黑公式

  • 构成: 角色自我调侃 + 夸张贬低 → 幽默效果
  • 示例: 男主相亲时,女生问“你有什么优点?”,他说“我最大的优点就是——能准确找到自己的缺点,比如现在,我发现自己马上要被你拒绝了”。
  • 解析: 角色主动将自己的缺点或尴尬处境作为笑料,进行夸张的、戏剧化的自我贬低。这种“我先黑我自己,让别人无处可黑”的态度,不仅能化解尴尬,还能展现角色的豁达和高情商,是一种非常高级的幽默方式。

CO-EP-08 | 道具反转公式

  • 构成: 普通道具 + 意外用途 → 喜剧惊喜
  • 示例: 女主用高跟鞋砸门锁,结果鞋跟断掉,她捡起鞋跟当螺丝刀,反而成功开门。
  • 解析: 一个看似普通的日常道具,在特定情境下失去了其原有功能,但角色急中生智,发现了它一个意想不到的、全新的、甚至更有效的用途。这种“废物利用”式的反转,能给观众带来“原来还可以这样”的惊喜感。

CO-EP-09 | 角色模仿公式

  • 构成: 模仿他人 + 夸张变形 → 搞笑效果
  • 示例: 员工模仿老板说话的语气和动作,把老板“摸下巴思考”的动作,夸张成“抓着下巴原地转圈”。
  • 解析: 模仿的精髓不在于“像”,而在于“像”与“不像”之间。通过抓住被模仿者最核心的特征(如口头禅、标志性动作),并将其进行漫画式的夸张和变形,创造出一个既熟悉又陌生的滑稽形象,从而达到搞笑的效果。

CO-EP-10 | 意外助攻公式

  • 构成: 反派操作 + 反而帮主角 → 喜剧反转
  • 示例: 竞争对手想偷偷删除男主的项目文件,结果误删了自己电脑里的“黑料文档”,还把男主的文件备份到了云端。
  • 解析: 反派角色精心策划了一个阴谋,试图陷害或打击主角,但由于自身的愚蠢、失误或不可控的意外,其操作最终反而帮助主角达成了目标或解除了危机。这种“搬起石头砸自己的脚”的讽刺性反转,能让观众获得极大的快感。

4. 情感升华公式

CO-CD-01 | 笑点转温情公式

  • 构成: 搞笑场景 + 暖心细节 → 情感过渡
  • 示例: 男主和朋友抢最后一块炸鸡,争执中男主发现朋友脸色不好,立刻把炸鸡让给他,说“你最近加班辛苦,我减肥”。
  • 解析: 在一个看似纯粹搞笑、打闹的场景中,通过一个角色不经意间流露出的关怀和体贴的细节,瞬间将氛围从喧闹转向温暖。这个细节就像一个情感的“切换键”,让观众意识到,在所有玩笑的背后,是深厚的情感内核。

CO-CD-02 | 误会化解公式

  • 构成: 长期误会 + 真诚沟通 → 情感升温
  • 示例: 闺蜜因为“男主送错礼物”误会女主,女主拿出聊天记录和礼物收据,哭着说“我从来没想过要抢你的人”。
  • 解析: 与喜剧冲突中的“误会加深”不同,这里的重点是“化解”。一个长期存在的、造成了情感隔阂的误会,通过一次彻底的、伴随着情感爆发(如哭泣、拥抱)的真诚沟通,最终得以澄清。这个过程不仅是解开疙瘩,更是情感的修复与升华。

CO-CD-03 | 小人物高光公式

  • 构成: 平凡角色 + 关键时刻爆发 → 情感共鸣
  • 示例: 平时唯唯诺诺的实习生,在公司被客户刁难时,突然站出来说“我们产品的有问题我道歉,但你不能侮辱我的同事”。
  • 解析: 让一个一直处于边缘、被忽视、性格懦弱的“小人物”,在某个关键时刻,为了守护自己珍视的人或原则,爆发出与其日常形象完全不符的勇气和力量。这种“匹夫之怒”所带来的巨大反差,能瞬间点燃观众的情感,引发强烈的共鸣。

CO-CD-04 | 成长治愈公式

  • 构成: 搞笑经历 + 角色成长 → 情感内核
  • 示例: 男主从“只会搞砸事情的废柴”,通过帮邻居照顾老人、给同事解决麻烦等一系列搞笑经历,慢慢学会担当,最后成功策划了公司活动。
  • 解析: 喜剧的外壳下包裹着一个成长的内核。角色经历的一系列看似失败和搞笑的事件,实际上是其学习和成长的过程。当故事结尾,角色成功蜕变时,观众回看之前的种种“糗事”,会发现那都是成长的足迹,从而获得一种“笑中带泪”的治愈感。

CO-CD-05 | 亲情软化公式

  • 构成: 搞笑对抗 + 亲情细节 → 情感温暖
  • 示例: 儿子和父亲天天互怼,但父亲偷偷给儿子的行李箱塞了他最爱吃的泡菜。
  • 解析: 表面上是两代人之间充满喜感的“战争”,互相吐槽、拆台,但在这些看似不和的对抗之下,隐藏着深沉的、不善言辞的爱。通过一个微小的、温暖的细节(如塞满的冰箱、偷偷准备的礼物),将这份隐藏的亲情揭示出来,形成一种“刀子嘴豆腐心”的温暖反差。

CO-CD-06 | 友情守护公式

  • 构成: 搞笑互坑 + 关键时刻守护 → 情感深化
  • 示例: 朋友之间经常互相恶作剧,但当其中一人被欺负时,其他人立刻冲上去帮忙。
  • 解析: 真正的朋友是“能一起扛事,也能一起犯傻”。平时他们以“互坑”为乐,看似不靠谱,但在任何一个成员真正需要支持和保护的关键时刻,他们会毫不犹豫地挺身而出,展现出惊人的团结和义气。这种“平时是损友,出事是战友”的设定,是对友情最生动的诠释。

CO-CD-07 | 爱情萌芽公式

  • 构成: 搞笑互动 + 心动瞬间 → 情感升温
  • 示例: 男主和女主每次见面都吵架,但一次暴雨中,男主把伞让给女主,自己淋着雨跑开。
  • 解析: 爱情往往在“欢喜冤家”式的打闹和对抗中悄然萌芽。在一系列充满喜感的互动之后,通过一个打破常规的、充满牺牲或关怀的“心动瞬间”,让其中一方(或双方)突然意识到,自己对对方的感觉已经超越了单纯的“讨厌”,从而完成从搞笑到爱情的过渡。

CO-CD-08 | 自我接纳公式

  • 构成: 搞笑自嘲 + 自我认可 → 情感升华
  • 示例: 女主一直吐槽自己“胖、矮、笨”,但在朋友的鼓励下,她在舞台上自信地说“我虽然不完美,但我很快乐”。
  • 解析: 角色从用自嘲作为保护色,到真正从内心接纳自己的不完美,这是一个从“取悦他人”到“取悦自己”的成长过程。当角色最终能够自信地拥抱自己的全部,包括那些曾经被自己当作笑料的缺点时,故事就完成了从搞笑到深刻的情感升华。

CO-CD-09 | 社区温情公式

  • 构成: 搞笑邻里矛盾 + 集体互助 → 情感共鸣
  • 示例: 小区里的邻居因为“噪音问题”互相投诉,但当小区停电时,大家一起点蜡烛做饭、分享食物。
  • 解析: 通过展现邻里之间因生活琐事而产生的种种搞笑矛盾,塑造出一群生动、接地气的“小市民”形象。然后,通过一个共同的危机或事件,将这些平日里“各自为政”的人们团结起来,展现出“远亲不如近邻”的集体温情,引发观众对理想社区关系的向往。

CO-CD-10 | 梦想重启公式

  • 构成: 搞笑失败 + 重新出发 → 情感内核
  • 示例: 男主多次创业失败,比如开奶茶店把奶茶做成“中药味”,但他没有放弃,最后开了一家“搞笑主题咖啡馆”,吸引了很多顾客。
  • 解析: 故事的核心是关于“屡败屡战”的梦想。主角在追梦过程中的每一次失败都充满了喜剧色彩,但这些失败并没有击垮他,反而让他找到了更适合自己的方向。这传达了一个温暖而励志的主题:即使过程再搞笑,坚持梦想的人也终将闪光。

5. 人物塑造公式

CO-CA-01 | 反差萌人设公式

  • 构成: 严肃外表 + 幼稚内心 → 立体角色
  • 示例: 公司CEO私下里喜欢收集卡通贴纸,还会和女儿抢动画片看,开会时不小心把贴纸粘在西装上。
  • 解析: 与“外冷内热”相似,但更侧重于“萌”感。通过在角色的高冷、专业的社会面具之下,设置一个与其身份极不相称的、充满童趣的爱好或行为模式,制造出一种“原来你是这样的霸道总裁”的惊喜感,让角色瞬间变得可爱、接地气。

CO-CA-02 | 废柴逆袭人设公式

  • 构成: 前期搞笑失败 + 后期成长 → 角色弧光
  • 示例: 男主前期什么都做不好,比如煮泡面把锅烧糊,修水管把自己淹了,但通过学习和努力,最后成为了一名优秀的厨师。
  • 解析: 这是喜剧中最经典的角色成长弧光。前期通过一系列的失败来确立其“废柴”的人设,并承担主要的搞笑功能。后期则通过一个明确的目标和持续的努力,让其完成技能或心智上的成长,实现逆袭。这个过程让观众在欢笑中见证了角色的蜕变。

CO-CA-03 | 毒舌暖心人设公式

  • 构成: 犀利吐槽 + 默默付出 → 立体角色
  • 示例: 女主经常吐槽朋友“你脑子是不是进水了”,但朋友生病时,她会默默帮忙照顾,还帮朋友完成未完成的工作。
  • 解析: 角色的语言系统和行动系统是分离的。嘴上从不饶人,吐槽犀利精准,但行动上却总是在第一时间给予最实际的帮助。这种“嘴硬心软”的设定,让角色的关怀显得更加珍贵,也塑造了一个独立、清醒但内心温暖的立体形象。

CO-CA-04 | 迷糊靠谱人设公式

  • 构成: 日常搞笑迷糊 + 关键时刻靠谱 → 立体角色
  • 示例: 女主日常很迷糊,比如忘记带钥匙、把盐当成糖放菜里,但在项目遇到危机时,她能冷静地找出问题所在,提出解决方案。
  • 解析: 角色的“迷糊”体现在生活琐事上,为故事提供日常的笑料。但在其专业领域或面对重大危机时,她会立刻切换到“靠谱”模式,展现出惊人的专注和能力。这种反差说明她的迷糊并非愚蠢,而是一种“生活技能点没加满”的可爱特质。

CO-CA-05 | 老顽童人设公式

  • 构成: 老年身份 + 年轻心态 → 立体角色
  • 示例: 爷爷喜欢玩电竞游戏,还和年轻人组队开黑,会用网络流行语吐槽“你这操作也太菜了”,但也会在孙子遇到困难时,用人生经验开导他。
  • 解析: 打破年龄的刻板印象,让一个老年角色拥有年轻人的心态、爱好和语言体系,与年轻人打成一片,制造代际反差的笑点。同时,在关键时刻,又能利用其年龄所赋予的智慧和经验,给予年轻人指导和帮助。这种“玩起来像兄弟,正经起来像导师”的设定,非常讨喜。

题材三: 奇幻科幻

1. 核心理念

奇幻科幻题材的核心逻辑是“超现实设定造世界、科技/魔法显张力、人性探讨定深度、悬念反转引思考”。它致力于构建一个拥有独特规则的超现实世界,通过科技或魔法等超凡力量来展现戏剧张力,并在故事中融入对人性、伦理、社会等问题的深刻探讨,最后通过精巧的悬念和反转,引导观众进行思考。

2. 世界观铺垫公式

SF-SC-01 | 现实裂缝公式

  • 构成: 日常场景 + 超现实元素 → 世界观入口
  • 示例: 女主在便利店买咖啡,扫码时手机突然弹出“平行世界通道已开启,是否进入?”的弹窗,手指误触“确认”后,便利店的冰柜变成了通往星际空间站的传送门。
  • 解析: 这是将观众从熟悉、安全的现实世界,引入充满未知的奇幻/科幻世界最常用的方法。通过在一个极其日常化的场景中,植入一个完全不合逻辑的超现实元素,制造出强烈的认知冲击,从而打开通往新世界的大门。

SF-SC-02 | 规则揭示公式

  • 构成: 核心设定 + 具象化展示 → 世界观认知
  • 示例: 在“时间流速可控”的科幻世界,男主看到有人将手表调至“0.5倍速”,走路像慢动作;有人调至“2倍速”,瞬间从街头跑到巷尾,自己的手表则显示“禁止调整”。
  • 解析: 凭空解释世界观规则是枯燥的。此公式强调“Show, don't tell”(展示,而非说教)。通过一个具体的、可视化的场景,将抽象的核心设定(如时间流速、重力规则)直观地展示给观众,使其在观看故事的同时,自然而然地理解并接受这个世界的运行法则。

SF-SC-03 | 道具锚点公式

  • 构成: 关键道具 + 特殊能力 → 世界观载体
  • 示例: 奇幻世界中,女主继承外婆的“记忆镜子”,对着镜子默念名字,就能看到对方的过往记忆,但每次使用后,自己的一段记忆会随机消失。
  • 解析: 将复杂的世界观设定,浓缩到一个具有特殊能力的关键道具上。这个道具不仅是推动剧情的工具,更是世界观规则的实体化身。通过角色的使用和探索,道具的能力和限制被不断揭示,世界观也随之展开。

SF-SC-04 | 空间分层公式

  • 构成: 现实空间 + 隐藏维度 → 世界观拓展
  • 示例: 男主发现城市里的老旧电梯,在特定时间按下“-1层”,会进入“影子维度”——这里的一切都是现实的镜像,却藏着现实世界消失的人。
  • 解析: 在我们所见的物理空间之上或之下,叠加一个或多个不可见的、遵循不同法则的隐藏维度(如镜像世界、精神领域、高维空间)。这种设定极大地拓展了世界观的层次和复杂性,为故事的展开提供了更多的可能性。

SF-SC-05 | 物种设定公式

  • 构成: 特殊物种 + 生存法则 → 世界观生态
  • 示例: 科幻世界的“星蝶族”,以宇宙射线为食,白天化作人类模样生活在地球,夜晚展开透明翅膀飞向太空,一旦被人类看到真身,就会永远失去飞行能力。
  • 解析: 一个丰富的世界观必然有其独特的生态系统。通过设定具有特殊习性、能力和文化背景的非人种族,并为其规定一套独特的生存法则和限制,可以构建出一个生动、多元且逻辑自洽的世界生态,增加故事的奇观性和深度。

SF-SC-06 | 历史伏笔公式

  • 构成: 世界传说 + 现实线索 → 世界观深度
  • 示例: 奇幻世界流传“上古神树能治愈一切”的传说,男主在古籍中发现神树的插画,与自己项链上的图案完全一致,项链背面刻着“神树守护者”。
  • 解析: 为你的世界观赋予历史感。通过流传的传说、神话或预言,为世界设定一个宏大的历史背景。然后,在现实的剧情中,让主角通过某个线索(如物品、血缘、地点)与这段遥远的历史产生连接,从而赋予世界观纵深感和宿命感。

SF-SC-07 | 科技/魔法限制公式

  • 构成: 超能力 + 副作用 → 世界观平衡
  • 示例: 科幻世界的“意识传输技术”,能让人将意识转移到他人身体,但每次传输后,使用者的大脑会衰老1小时;若传输超过3次,意识会永久被困在他人身体里。
  • 解析: 无敌的超能力是无趣的。为每一种强大的科技或魔法设定明确的“代价”或“副作用”,是维持世界观平衡、保证戏剧冲突的关键。限制条件不仅让超能力显得更真实可信,也为角色的选择和牺牲创造了前提。

SF-SC-08 | 环境隐喻公式

  • 构成: 世界环境 + 人性映射 → 世界观哲思
  • 示例: 科幻世界的“污染隔离区”,富人住在无污染的“浮空城”,穷人在隔离区挣扎,隔离区的雨水是黑色的,却能治愈浮空城居民的“情感缺失症”。
  • 解析: 让世界的物理环境成为社会或人性问题的隐喻。通过创造一个具有象征意义的、充满矛盾的环境设定(如天空之城与地下废墟、纯净区与污染区),将阶级、歧视、贪婪等现实议题进行视觉化、奇观化的呈现,从而引发观众的哲学思考。

SF-SC-09 | 交互规则公式

  • 构成: 人与超现实事物 + 互动方式 → 世界观融入
  • 示例: 奇幻世界的“会说话的书本”,只有用“真心提问”才能让书本开口,若提问带有欺骗,书本会喷出墨水。
  • 解析: 设定人类与世界中的超现实事物(如魔法生物、AI、鬼魂)进行互动的具体规则。这些规则就像是游戏的“玩法说明”,它定义了角色如何在这个世界中行动、如何使用能力、如何与非人存在交流,从而帮助观众更好地代入和理解这个世界。

SF-SC-10 | 时间悖论公式

  • 构成: 时间设定 + 逻辑矛盾 → 世界观悬念
  • 示例: 科幻世界的“时间邮局”,能给过去的自己寄信,但信的内容不能改变“已发生的关键事件”,否则寄信人会从世界上消失——男主收到10年前自己寄的信,信上写着“别去参加那场实验”。
  • 解析: 时间旅行是科幻作品中的经典母题。通过设定一个与时间相关的机制,并引入一个看似无法解决的逻辑悖论(如“祖父悖论”、“命运闭环”),可以制造出极强的悬念,驱动主角和观众去探索时间的奥秘和命运的可能性。

3. 冲突构建公式

SF-CD-01 | 身份危机冲突公式

  • 构成: 主角特殊身份 + 世界对立 → 核心冲突
  • 示例: 男主从小以为自己是普通人,直到发现自己是“外星混血”,而人类与外星族群正处于战争边缘,他陷入“帮人类还是帮外星族群”的抉择。
  • 解析: 主角的身份本身就是冲突的根源。他可能是两个敌对种族的混血,或是拥有被世界所不容的能力。这种“不被任何一方完全接纳”的身份,使其必然地陷入“我是谁?”、“我该站在哪一边?”的身份认同危机和立场选择的困境中。

SF-CD-02 | 资源争夺冲突公式

  • 构成: 稀缺资源 + 多方争夺 → 利益冲突
  • 示例: “能量水晶”是维持城市运转的唯一能源,人类军队、反叛组织、外星访客都想争夺它,各自目的不同。
  • 解析: 设定一种对所有势力都至关重要的稀缺资源(如能源、水源、特定矿物、神力之源),并让多方势力为了各自的生存或利益而展开争夺。这种冲突模式结构清晰,易于展开多线叙事,展现不同群体的立场和诉求。

SF-CD-03 | 规则打破冲突公式

  • 构成: 世界规则 + 反叛者 → 秩序冲突
  • 示例: 奇幻世界规定“魔法只能用于自保”,反派为获得更强魔法,组建“黑魔法联盟”,用人类灵魂修炼,主角作为守护者必须阻止但又不能违背规则。
  • 解析: 冲突来自于对世界既定秩序的挑战。一方是现有规则的维护者,另一方则是试图打破或颠覆规则的反叛者。这种冲突的核心是“保守”与“激进”、“秩序”与“混乱”的二元对立,探讨的是规则本身是否正义、以及打破规则需要付出何种代价。

SF-CD-04 | 现实与超现实冲突公式

  • 构成: 现实生活 + 超现实干扰 → 生活冲突
  • 示例: 女主是普通上班族,某天突然能看到“幽灵”,幽灵不断向她求助,女主想回归正常生活,却发现凶手的下一个目标是自己的闺蜜。
  • 解析: 将超现实的元素强行介入一个普通人的正常生活,制造出“日常”与“异常”的碰撞。主角的核心冲突在于,是选择无视超现实的麻烦,努力维持自己平静的生活,还是被迫卷入其中,承担起自己本不该承担的责任。

SF-CD-05 | 预言危机冲突公式

  • 构成: 末日预言 + 主角使命 → 命运冲突
  • 示例: 预言说“30天后世界会被黑暗吞噬,只有‘光之子’能阻止”,主角被认定是“光之子”,却发现自己根本没有“光之力”,反而每次尝试都会加速黑暗的蔓延。
  • 解析: 冲突来自于“宿命”与“个人意志”的对抗。一个宏大的、不可避免的危机(通常以预言的形式出现)与主角个人的能力或意愿之间存在巨大矛盾。主角是被动接受命运的安排,还是奋起反抗,或者以意想不到的方式“实现”预言,是这类冲突的核心看点。

SF-CD-06 | 科技伦理冲突公式

  • 构成: 科技突破 + 道德争议 → 伦理冲突
  • 示例: “永生技术”能让人类永生,但器官来源是拥有自我意识的“人造人”。主角作为技术研发者,陷入“坚持技术造福人类”还是“解放人造人”的道德争议。
  • 解析: “我们能做到,但我们应该这样做吗?”这是科技伦理冲突的核心。当一项科技的发展触及了关于生命、意识、公平等根本性的道德底线时,冲突便产生了。它迫使角色和观众去思考科技进步的边界和代价。

SF-CD-07 | 物种对立冲突公式

  • 构成: 不同物种 + 生存矛盾 → 族群冲突
  • 示例: 人类为扩建城市砍伐森林,与视森林为家园的精灵产生冲突,身为混血的主角必须化解两族矛盾。
  • 解析: 冲突源于不同物种之间因生存空间、资源、价值观等方面的根本性矛盾。这种冲突往往没有绝对的对错之分,每一方都有其合理的立场。故事的重点在于展现这种“公说公有理,婆说婆有理”的困境,并探索共存的可能性。

SF-CD-08 | 记忆篡改冲突公式

  • 构成: 被篡改的记忆 + 真相碎片 → 认知冲突
  • 示例: 女主删除了“男友去世”的痛苦记忆,却不断梦到陌生男人,偶然发现自己的日记写着“别相信记忆公司,他还活着”。
  • 解析: “眼见不一定为实,记忆也可能骗人”。主角所认知的生活和历史是被人为篡改过的虚假现实,而真相的碎片通过梦境、闪回、或某个被遗漏的物件不断浮现。主角的核心冲突在于,要戳破美好的谎言、面对残酷的真相,还是要继续活在虚假的幸福中。

SF-CD-09 | 平行世界冲突公式

  • 构成: 平行世界的自己 + 目标对立 → 自我冲突
  • 示例: 医生男主进入平行世界,遇到杀手身份的“自己”,杀手想取代男主在现实世界的身份,因为那里有他失去的家人,男主必须对抗“另一个自己”。
  • 解析: 最大的敌人就是自己。通过引入来自平行世界的、拥有不同经历和性格的“另一个我”,并将两者置于一个零和博弈的对立目标下,可以制造出最极致的自我冲突。这探讨的是“环境如何塑造人”以及“在不同选择下,我会变成什么样”的哲学命题。

SF-CD-10 | 魔法/科技失控冲突公式

  • 构成: 超能力 + 意外失控 → 危机冲突
  • 示例: 女主一次情绪失控时,火焰魔法点燃了“封印卷轴”,释放出被封印千年的“火魔”,女主的魔法反而会增强火魔的力量。
  • 解析: 角色所依赖的强大能力,在某个意外情况下突然失控或产生反噬,从“助力”变成了“灾难之源”。主角不仅要面对失控造成的外部危机,还要克服对自己能力的恐惧和不信任,这是对英雄成长之路的经典考验。

4. 情感递进公式

SF-EP-01 | 跨物种情感公式

  • 构成: 不同物种 + 相互理解 → 情感连接
  • 示例: 人类宇航员在太空遇到没有语言、靠发光传递情绪的“外星生物”,从害怕到帮助它寻找母星,并在缺氧时被其用能量所救。
  • 解析: 在巨大的物种差异和沟通障碍之下,通过超越语言的行动和情感传递(如共同经历危险、无私的帮助),两个来自不同世界的生命体建立了深刻的情感羁绊。这种情感的纯粹性和来之不易,使其尤为动人。

SF-EP-02 | 记忆共鸣公式

  • 构成: 共享记忆 + 情感共情 → 情感深化
  • 示例: 通过“记忆共享水晶”,女主看到男主因“有魔法”被排斥的孤独过往,联想到自己“因没有魔法被嘲笑”的经历,两人因相似的孤独感互相安慰。
  • 解析: 通过科技或魔法手段,让角色能够亲身体验或看到对方的记忆。当一方在对方的记忆中看到了与自己相似的创伤、孤独或喜悦时,会产生强烈的共情,从而建立起“我懂你”的深度情感连接。

SF-EP-03 | 牺牲与救赎公式

  • 构成: 为他人牺牲 + 自我救赎 → 情感升华
  • 示例: 主角因曾经的失误导致队友牺牲而愧疚不已,最终选择牺牲自己加固“时间核心”来阻止反派,在最后一刻,队友的灵魂出现说“你已经救赎了自己”。
  • 解析: 角色背负着过去的罪孽或过失,并试图通过一次重大的、通常是为他人或世界而做出的牺牲行为,来弥补自己的过错,寻求内心的解脱。这种将个人救赎与集体利益相结合的牺牲,是英雄主义情感的最高潮。

SF-EP-04 | 信任重建公式

  • 构成: 背叛经历 + 共同面对危机 → 情感修复
  • 示例: 女主曾被最好的朋友背叛,后来两人被反派同时绑架,朋友为保护女主挡下攻击,说“我一直想弥补”,女主最终选择原谅。
  • 解析: 信任一旦被打破,很难重建。公式的核心在于,创造一个让背叛者能够用“行动”而非“言语”来证明其悔意的极端情境。在共同的危机面前,背叛者以自我牺牲的姿态保护了被背叛者,这种付出是重建信任的唯一途径。

SF-EP-05 | 亲情跨越公式

  • 构成: 时空/物种隔阂 + 亲情羁绊 → 情感传递
  • 示例: 男主通过“时间电话”联系到20年前的父亲,想告诉他未来的意外,却发现父亲早已知道,并说“我会保护好你,不管在哪个时空”。
  • 解析: 利用奇幻或科幻的设定,打破生与死、时间与空间、甚至物种的界限,让亲情得以在不可能的情境下传递。这种超越物理规则的情感连接,凸显了亲情的永恒与伟大,能带来强烈的情感冲击。

SF-EP-06 | 爱情超越公式

  • 构成: 超现实阻碍 + 坚定选择 → 情感坚守
  • 示例: 女主是“白天是人,夜晚是猫”的诅咒者,男主知道后没有离开,反而坚定地说“她是我爱的人”,并努力研发解药。
  • 解析: 爱情面临的不是现实的家庭、阶级阻碍,而是来自超现实设定的、看似无法逾越的鸿沟(如诅咒、物种差异、时空相隔)。在这种极端考验下,一方的坚定不移和无条件接纳,展现了爱情超越一切的强大力量。

SF-EP-07 | 自我接纳公式

  • 构成: 对超能力的排斥 + 认可自我价值 → 情感成长
  • 示例: 男主从小因“能看到鬼魂”被嘲笑,一直排斥自己的能力,直到用能力帮助一个小女孩找到去世的妈妈,才终于接纳自己的与众不同。
  • 解析: 主角的超能力在早期被视为一种“诅咒”或“负担”,给他带来了痛苦和排斥。通过一次关键事件,他发现自己的“诅咒”也能成为“天赋”,能够帮助他人、创造价值。这个过程是他从排斥自我到接纳自我、并最终找到自我价值的情感成长之路。

SF-EP-08 | 团队信任公式

  • 构成: 团队成员的差异 + 互补合作 → 情感凝聚
  • 示例: “拯救小队”的三名成员能力各异,初期互相质疑,在一次任务中,通过发挥各自优势、互补短板才成功脱险,从此建立起牢固的信任。
  • 解析: 一个团队由背景、性格、能力各不相同的成员组成,初期必然会因为差异而产生摩擦和不信任。通过一次或多次需要紧密合作才能完成的危机任务,让成员们认识到彼此的不可或缺,从而将“乌合之众”凝聚成一个有战斗力的集体。

SF-EP-09 | 愧疚与原谅公式

  • 构成: 过往过错 + 弥补行动 → 情感和解
  • 示例: 男主曾因嫉妒用魔法伤害了最好的朋友,导致其失去飞行能力,一直心怀愧疚。后来在朋友被抓时,他冒着生命危险修复了朋友的翅膀,最终获得原谅。
  • 解析: 角色A因过去的某个过错对角色B深感愧疚,这种愧疚成为两人关系中的一根刺。和解的唯一方式是,当B陷入危机时,A付出巨大代价(甚至生命危险)去拯救或弥补B。这种行动证明了A的悔意,也给了B一个原谅的契机。

SF-EP-10 | 使命与情感平衡公式

  • 构成: 拯救世界的使命 + 个人情感 → 情感抉择
  • 示例: 女主是“世界守护者”,必须摧毁藏有去世男友意识的“失控AI核心”。在“大爱”与“小爱”之间,男友的意识主动选择牺牲,帮助女主完成使命。
  • 解析: 这是英雄角色最经典的困境:“电车难题”。主角被迫在拯救世界的宏大使命和保护自己的挚爱(亲人、爱人、朋友)之间做出选择。无论选择哪一方,都意味着巨大的牺牲和痛苦。这种两难抉择是塑造英雄弧光、升华情感的终极考验。

5. 人物塑造公式

SF-CA-01 | 反差能力者人设公式

  • 构成: 普通外表 + 超强能力 → 反差魅力
  • 示例: 男主是沉默寡言的便利店店员,遇到抢劫时,只是轻轻抬手,劫匪的枪就悬浮在空中,事后他继续淡定地扫货,说“只是小场面”。
  • 解析: “扮猪吃老虎”的经典人设。角色拥有极其强大的、足以颠覆世界的力量,但其外在身份却极其普通、毫不起眼。这种巨大的反差制造了强烈的神秘感和期待感,当其能力爆发时,能给观众带来极大的爽感。

SF-CA-02 | 矛盾反派人设公式

  • 构成: 邪恶行为 + 悲情过往 → 立体反派
  • 示例: 反派是“毁灭世界的黑魔法师”,却有着悲惨的过往——小时候因有魔法被父母抛弃、被人类折磨,他认为“只有毁灭世界,才能让所有物种平等”。
  • 解析: 一个成功的反派不是纯粹的坏,而是“可恨之人必有可怜之处”。其极端、邪恶的行为背后,往往隐藏着一个深刻的、令人同情的悲剧性根源。这种设定让反派的行为动机变得合理,形象更加丰满、立体,甚至能引发观众的共情。

SF-CA-03 | 成长型主角人设公式

  • 构成: 能力不足 + 信念支撑 → 成长弧光
  • 示例: 女主一开始魔法能力很弱,却因“想保护被欺负的精灵族群”的信念,坚持不懈地练习,最终在关键时刻觉醒了超强的“治愈魔法”。
  • 解析: 主角在故事开始时往往是“菜鸟”,能力平平甚至低于常人。但他拥有一个坚定不移的、高尚的信念(如保护、守护、爱)。正是这个信念,支撑着他在一次次失败和挫折中不断成长,最终激发出潜能,完成从弱到强的蜕变。

SF-CA-04 | 跨物种伙伴人设公式

  • 构成: 不同物种 + 互补性格 → 伙伴魅力
  • 示例: 人类探险家男主性格冲动勇敢,他的伙伴是冷静理智的“会说话的机械狗”,一人一狗在冒险中形成绝佳搭档。
  • 解析: 为主角配备一个非人类的伙伴(如外星人、机器人、魔法生物),并在性格和能力上形成互补。这种“好搭档”的设定,不仅能在功能上帮助主角,还能通过跨物种之间的有趣互动,承担一部分喜剧或温情的功能,丰富故事的层次。

SF-CA-05 | 记忆残缺者人设公式

  • 构成: 缺失的记忆 + 寻找真相的执着 → 神秘人设
  • 示例: 男主醒来时没有任何记忆,只记得“要找到‘星核’”。他带着唯一的线索,踏上寻找真相的路,并逐渐接近“自己是‘星核守护者’”的真相。
  • 解析: 主角一登场就处于“失忆”状态,他的过去是一个巨大的谜团。故事的主线就是主角寻找“我是谁”的过程。这种设定能天然地制造悬念,让观众和主角一起,从零开始,通过不断收集线索,一步步拼凑出完整的真相,代入感极强。

题材四: 温情

1. 核心理念

温情题材的核心逻辑是“平凡日常为底、细微善意为魂、情感流动为脉、治愈力量为核”。它根植于最普通的生活场景,捕捉人与人之间不经意的、微小的善意,通过展现情感在邻里、家庭、陌生人之间的自然流动,最终达到治愈人心的目的。

2. 场景构建公式

HE-SC-01 | 日常烟火公式

  • 构成: 生活化场景 + 烟火气细节 → 温情基底
  • 示例: 清晨的老巷,早点铺冒着热气,老板熟练地揉着面团,买豆浆的老奶奶帮忘带零钱的学生垫付,学生笑着说“明天一定还您”。
  • 解析: 温情不是凭空产生的,它根植于真实、生动的生活细节。通过描绘充满“烟火气”的日常场景,如菜市场的喧闹、厨房的饭菜香,可以迅速奠定故事温暖、接地气的基调,让观众产生亲切感和代入感。

HE-SC-02 | 季节限定公式

  • 构成: 季节场景 + 应季细节 → 情感氛围
  • 示例: 冬日雪后,小区里的孩子们堆着雪人,退休爷爷拿出家里的煤炉,在楼下煮起姜茶,招呼路过的邻居“来喝杯暖暖身子”。
  • 解析: 将故事置于一个具有鲜明季节特征的场景中(如夏夜的蝉鸣、秋日的落叶、冬日的初雪),并利用与该季节相关的特定细节(如冰西瓜、烤红薯、热姜茶),可以极大地增强场景的氛围感,用季节的温度来烘托情感的温度。

HE-SC-03 | 空间记忆公式

  • 构成: 固定空间 + 情感关联细节 → 温情锚点
  • 示例: 街角的旧书店,书架上贴着老顾客留下的便签“这本书陪我度过了最难的日子”,店主在柜台后放着常给流浪猫准备的猫粮。
  • 解析: 选择一个具有情感承载能力的空间(如书店、咖啡馆、老房子),并通过与情感记忆相关联的细节,让这个空间成为一个“温情锚点”。当角色进入这个空间,与之相关的记忆和情感就会被唤醒,空间本身也成为了故事的一部分。

HE-SC-04 | 家庭日常公式

  • 构成: 家庭场景 + 互动小细节 → 亲情底色
  • 示例: 周末的厨房,妈妈在切菜,女儿踮着脚帮妈妈递盘子,爸爸在客厅修着女儿弄坏的玩具,收音机里放着老唱片。
  • 解析: 亲情往往体现在最平凡的家庭日常中。通过描绘家庭成员之间不经意的互动小细节(如一起做饭、饭后散步、为对方盖好被子),可以无声地展现家人之间的默契和关爱,为故事铺上温暖的亲情底色。

HE-SC-05 | 邻里互动公式

  • 构成: 邻里场景 + 互助小举动 → 邻里温情
  • 示例: 傍晚的楼道,张阿姨看到新搬来的小伙子抱着一堆纸箱,主动帮他开门,还递过去一瓶矿泉水“搬东西累了吧,先歇会儿”。
  • 解析: 在现代都市中,邻里关系往往是疏离的。通过捕捉邻里之间微小的、善意的互助举动(如帮忙收快递、分享自家做的饭菜、提醒对方收衣服),可以打破这种疏离感,展现“远亲不如近邻”的社区温情。

HE-SC-06 | 陌生人交集公式

  • 构成: 公共场景 + 善意小瞬间 → 陌生温情
  • 示例: 雨天的公交站,女孩没带伞,旁边的大叔默默把伞往她那边挪了挪,说“一起等吧,雨停了就好”。
  • 解析: 来自陌生人的善意往往最能触动人心。在公交、地铁、便利店等公共场景中,通过一个短暂的、不求回报的善意瞬间(如一个微笑、一次让座、一句提醒),可以展现人性中最纯粹的光辉,带来瞬间的治愈。

HE-SC-07 | 成长印记公式

  • 构成: 成长场景 + 纪念性细节 → 温情回忆
  • 示例: 小学毕业季,老师给每个学生发了自己手缝的小布偶,布偶身上绣着学生的名字,孩子们围在老师身边,把自己画的画塞到老师手里。
  • 解析: 选取成长过程中的标志性场景(如毕业典礼、第一次离家、运动会),并通过具有纪念意义的细节(如一张合影、一件礼物、一段话),将某个温暖的瞬间定格为永恒的回忆。这些“成长印记”是构成角色情感世界的重要基石。

HE-SC-08 | 治愈角落公式

  • 构成: 小众场景 + 疗愈细节 → 情感避风港
  • 示例: 社区的顶楼露台,有人在这里种满了多肉,摆着几张旧椅子,墙上挂着居民们留下的照片,累了的人会来这里坐会儿,看看远处的云。
  • 解析: 在喧嚣的城市中,创造一个不为人知的、安静的“治愈角落”。这个地方可能是一个天台、一个后院、一个秘密基地。通过充满疗愈感的细节,让它成为角色可以暂时逃离现实、安放情绪的“情感避风港”。

HE-SC-09 | 旧物关联公式

  • 构成: 旧物场景 + 回忆细节 → 情感连接
  • 示例: 女孩翻出外婆织的毛衣,毛衣袖口有外婆补过的痕迹,想起小时候外婆坐在灯下织毛衣的样子,手指轻轻摩挲着毛线。
  • 解析: 一件旧物,一段回忆。通过一件承载着情感记忆的旧物(如毛衣、钢笔、老照片),将角色的思绪拉回到过去某个温暖的瞬间。旧物成为了连接现在与过去、连接人与人之间情感的纽带。

HE-SC-10 | 深夜温情公式

  • 构成: 深夜场景 + 安静细节 → 温柔氛围
  • 示例: 深夜的便利店,店员在整理货架,加班晚归的姑娘买了一份关东煮,坐在窗边慢慢吃,店员递过来一条暖手宝“天凉,拿着暖暖手”。
  • 解析: 深夜是情绪最容易放大的时刻。通过描绘深夜中依然亮着灯的场景(如便利店、深夜食堂、医院),并捕捉其中安静而温暖的细节,可以营造出一种独特的、温柔的氛围,给孤独的都市人带来慰藉。

3. 情感递进公式

HE-EP-01 | 陌生到熟悉公式

  • 构成: 陌生交集 + 重复善意互动 → 情感靠近
  • 示例: 每天在公交站相遇的阿姨和女孩,阿姨总帮女孩占个靠窗的位置,女孩会把家里做的点心带给阿姨,慢慢的,两人从“您早”变成了“最近身体还好吗”。
  • 解析: 情感的建立需要过程。通过在固定的场景中,让两个陌生人进行多次的、微小的、善意的互动,情感关系会像“滴水穿石”一样,在不知不觉中从陌生走向熟悉,从客气走向亲近。

HE-EP-02 | 细节关怀公式

  • 构成: 他人困境 + 细微关怀举动 → 情感触动
  • 示例: 独居的爷爷不小心崴了脚,邻居小姑娘发现后,每天放学帮爷爷买菜,还帮他给花浇水,临走时会把爷爷的垃圾顺便带下楼。
  • 解析: 真正的关怀不在于豪言壮语,而在于细微之处。当一个角色陷入困境时,另一个角色通过一系列不引人注目、但极其贴心的关怀举动,展现出“润物细无声”的温暖。这些细节是打动人心最强大的力量。

HE-EP-03 | 共同经历公式

  • 构成: 共同小事 + 协作互动 → 情感加深
  • 示例: 小区停水,几户邻居凑在楼下的空地上,一起用桶装水做饭,李叔叔负责生火,王阿姨带着蔬菜,孩子们在旁边帮忙洗菜。
  • 解析: 共同的经历是拉近人与人之间距离最有效的方式。通过设定一个需要大家共同面对的小事件(如停电、暴雨、社区活动),并在其中安排协作互动的环节,可以让原本疏离的个体迅速形成一个临时的“共同体”,加深彼此的情感连接。

HE-EP-04 | 回忆唤醒公式

  • 构成: 当下场景 + 共同回忆细节 → 情感共鸣
  • 示例: 多年未见的老同学在母校重逢,走到曾经的教室门口,有人说起“当年考试前大家一起在这儿复习,你还帮我讲过数学题”。
  • 解析: 通过一个当下的场景或物件,唤醒角色之间共同的、温暖的回忆。当过去的美好瞬间与当下的情境重叠时,会产生强烈的情感共鸣,让久未联系的关系瞬间回温。

HE-EP-05 | 沉默守护公式

  • 构成: 他人需要 + 默默付出举动 → 情感沉淀
  • 示例: 备考的女孩总在深夜学习,对面楼的大爷发现后,每晚都会把自家阳台的灯多开半小时,灯光刚好照到女孩的书桌,大爷从不说什么。
  • 解析: 有一种关怀是沉默的、不求回报的。一个角色默默地为另一个角色付出,却从不言说,甚至不让对方知道。这种“深藏功与名”的守护,展现了一种深沉而厚重的情感,比直接的帮助更具力量。

HE-EP-06 | 误解破冰公式

  • 构成: 微小误解 + 真诚解释/行动 → 情感修复
  • 示例: 租客以为房东故意涨房租,后来发现房东是因为房子要修水管,怕租客不方便才想让她暂时搬走,还主动提出帮她找临时住处。
  • 解析: 在温情故事中,误解通常是微小且源于信息不对称的。通过一次真诚的解释,或是一个充满善意的行动,误解很快就能被化解。这个过程不仅是修复关系,更是让双方看到彼此善良的本意,从而加深情感。

HE-EP-07 | 代际温暖公式

  • 构成: 代际互动 + 理解包容细节 → 情感流动
  • 示例: 奶奶学不会用智能手机,孙子耐心地教她视频通话,还在手机上贴了小标签“这个是给姑姑打电话的”。
  • 解析: 展现不同代际之间的互动,并通过一方对另一方的耐心、理解和包容的细节,来体现代际之间的情感流动。重点不在于消除代沟,而在于展现即使存在代沟,爱与关怀依然可以跨越一切。

HE-EP-08 | 宠物羁绊公式

  • 构成: 人与宠物互动 + 陪伴细节 → 情感慰藉
  • 示例: 独居的年轻人养了一只猫,每天下班回家,猫都会在门口等着,他难过时猫会蹭他的手,晚上两人窝在沙发上看电影。
  • 解析: 宠物是人类最忠实的伙伴和情感慰藉。通过描绘人与宠物之间充满细节的、相互陪伴的日常,可以展现一种纯粹的、不求回报的情感羁绊,尤其能治愈现代人的孤独感。

HE-EP-09 | 善意传递公式

  • 构成: 接受善意 + 传递善意举动 → 情感扩散
  • 示例: 女孩忘带家门钥匙,邻居帮她开了门。后来看到邻居家的孩子忘带作业本,女孩主动把自己的笔记本借给孩子。
  • 解析: 善意是会传染的。当一个角色接受了他人的善意后,他会将这份温暖记在心里,并在另一个时机,将善意传递给下一个需要帮助的人。这种“善意的循环”是温情故事中最核心、最能传递正能量的主题。

HE-EP-10 | 成长温暖公式

  • 构成: 成长困境 + 他人鼓励/支持 → 情感支撑
  • 示例: 男孩第一次参加演讲比赛很紧张,老师在他上场前拍了拍他的肩膀“别怕,你准备得很充分,我相信你”,台下的妈妈比了个“加油”的手势。
  • 解析: 在成长的道路上,每个人都会遇到困境和挑战。来自他人(老师、家人、朋友)的鼓励和支持,是帮助角色克服困难、建立自信的最重要的情感支撑。这些温暖的瞬间,是成长中最宝贵的财富。

4. 冲突化解公式

HE-CD-01 | 小矛盾软化公式

  • 构成: 微小矛盾 + 共情理解行动 → 冲突化解
  • 示例: 楼上的孩子练琴声音太大,楼下的阿姨有点不满。后来看到孩子妈妈带着孩子来道歉,还递上自己做的饼干,阿姨笑着说“没事,我当年学琴也这样”。
  • 解析: 温情故事中的冲突通常是源于生活琐事的微小矛盾。化解的关键不在于讲道理,而在于“共情”。当一方能够站在对方的角度去理解其行为背后的原因时,矛盾自然就软化了。

HE-CD-02 | 误解澄清公式

  • 构成: 信息偏差误解 + 耐心解释细节 → 冲突消除
  • 示例: 同事以为女孩故意不帮她带文件,后来女孩耐心解释是因为加班忘在桌上,并马上叫了快递,还带了同事喜欢的咖啡道歉。
  • 解析: 这种冲突源于信息不对称。化解方式非常直接:通过耐心的、带有善意细节的解释,将缺失的信息补充完整。一旦信息对等,误解自然消除。

HE-CD-03 | 情绪安抚公式

  • 构成: 负面情绪爆发 + 温柔安抚举动 → 冲突缓解
  • 示例: 孩子因为玩具坏了哭闹,妈妈没有批评,而是抱着他说“我知道你很喜欢这个玩具,我们一起修好不好”。
  • 解析: 当一方(尤其是孩子)因为某件事而产生负面情绪时,另一方不应以说教或指责的方式来激化矛盾,而应首先通过温柔的、共情的安抚举动(如拥抱、倾听),来缓解对方的情绪。情绪平复了,问题才可能被解决。

HE-CD-04 | 利益小冲突妥协公式

  • 构成: 小利益冲突 + 互相让步行动 → 冲突解决
  • 示例: 两户人家争着用小区的公共晒衣绳,后来张阿姨说“我家衣服少,先给你家用吧”,李阿姨说“不用,我们一起晒,挤挤就好”。
  • 解析: 在涉及微小利益的冲突中,双方通过互相让步、各退一步的方式,达成一个“双赢”或“都能接受”的结果。这体现了人与人之间的体谅和宽容。

HE-CD-05 | 代际观念差异公式

  • 构成: 代际观念小冲突 + 包容尊重行动 → 冲突缓和
  • 示例: 妈妈觉得女孩穿的衣服太暴露,女孩没有反驳,而是给妈妈看自己和朋友的合照,解释这是现在的流行款式。妈妈虽然不理解,但还是说“只要你喜欢,注意保暖就好”。
  • 解析: 代际之间的观念差异是客观存在的。化解冲突的关键不是说服对方接受自己的观念,而是通过沟通,让对方了解自己的想法,并最终以包容和尊重的态度,允许差异的存在。

HE-CD-06 | 陌生人小摩擦公式

  • 构成: 陌生人小摩擦 + 善意让步 → 冲突化解
  • 示例: 在超市里,有人不小心撞到了女孩,牛奶洒了一地。对方连忙道歉并主动清理,女孩笑着说“没事,我自己来就好,你也不是故意的”。
  • 解析: 在公共场合与陌生人发生的小摩擦,通常是无心之失。只要一方能主动道歉,另一方能报以善意的谅解和让步,冲突就能瞬间化解,甚至可能成为一次温暖邂逅的开始。

HE-CD-07 | 朋友间小误会公式

  • 构成: 朋友间小误会 + 主动沟通行动 → 冲突消除
  • 示例: 朋友因为女孩没参加她的生日会而生气,女孩主动找朋友解释是因为奶奶突然生病,并送上准备好的礼物。朋友立刻原谅并关心奶奶的病情。
  • 解析: 朋友之间的误会,最怕的是“冷战”和“猜忌”。化解的最好方式就是主动、及时的沟通。只要把事情的原委解释清楚,并表达出对友谊的重视,再大的误会也能烟消云散。

HE-CD-08 | 家庭小分歧公式

  • 构成: 家庭小分歧 + 换位思考行动 → 冲突解决
  • 示例: 爸爸想带孩子去爬山,妈妈想让孩子在家写作业。通过换位思考,双方找到了一个两全其美的方案:早点出发爬山,下午回来写作业。
  • 解析: 家庭分歧的背后,往往是家庭成员对“为对方好”的不同理解。通过换位思考,站在对方的立场上考虑问题,找到一个能够兼顾双方诉求的解决方案,是解决家庭矛盾的最佳途径。

HE-CD-09 | 职场小矛盾公式

  • 构成: 职场小矛盾 + 专业包容行动 → 冲突缓解
  • 示例: 同事觉得男孩做的方案不够好,男孩没有生气,而是虚心请教,两人一起讨论,最终做出了更好的方案。
  • 解析: 在职场中,因工作产生的矛盾,应以专业和包容的态度来解决。不把分歧个人化,而是聚焦于工作本身,通过开放的讨论和协作,共同寻找最佳解决方案。这不仅能化解矛盾,还能提升工作成果。

HE-CD-10 | 邻里小纠纷公式

  • 构成: 邻里小纠纷 + 互相体谅行动 → 冲突化解
  • 示例: 邻居家的狗半夜叫影响了女孩休息,邻居知道后,主动采取措施,并送上安神茶表示歉意。女孩也表示理解。
  • 解析: 邻里纠纷多由生活习惯的差异引起。化解的关键在于互相体谅。当一方的行为影响到另一方时,主动采取措施改进,并表达歉意;被影响的一方也给予理解和包容。这种良性互动是和谐邻里关系的基础。

5. 人物塑造公式

HE-CA-01 | 温暖守护者人设公式

  • 构成: 平凡身份 + 持续善意行动 → 立体角色
  • 示例: 小区保安,每天早上帮居民开门,下雨时帮没带伞的人撑到单元楼,看到独居老人买东西会主动帮忙拎上楼。
  • 解析: 选取一个社会中最平凡、最不起眼的身份(如保安、清洁工、外卖员),并通过其一系列持续的、发自内心的善意行动,塑造出一个在平凡岗位上默默守护着社区的“温暖守护者”形象。这种人设真实、可信,充满力量。

HE-CA-02 | 共情倾听者人设公式

  • 构成: 温和性格 + 耐心倾听行动 → 立体角色
  • 示例: 社区社工,居民有烦心事都愿意找她聊,她从不打断别人,会认真记笔记,眼神里总是带着温柔。
  • 解析: 这个角色不一定能解决实际问题,但她拥有最宝贵的能力——倾听。她以温和、耐心的态度,成为他人情绪的“树洞”,用共情和理解,帮助他人释放压力、获得慰藉。这种人设在现代社会中具有极强的治愈价值。

HE-CA-03 | 成长治愈者人设公式

  • 构成: 曾遇困境 + 传递希望行动 → 立体角色
  • 示例: 咖啡店老板,曾经因为创业失败很消沉,后来重新开了这家小店,他会在杯子上写鼓励的话,遇到失意的顾客,会分享自己的经历“都会好起来的”。
  • 解析: 角色本身也曾是“被治愈者”,他经历过困境,并从中走了出来。因此,他更能理解他人的痛苦,并以自己的经历为蓝本,通过实际行动(如一杯免费的咖啡、一句鼓励的话),向他人传递希望和力量。他既是治愈者,也是希望的象征。

HE-CA-04 | 代际桥梁人设公式

  • 构成: 理解包容性格 + 连接代际行动 → 立体角色
  • 示例: 社区里的大学生,周末会教老人用智能手机,还会听老人讲过去的故事,再把这些故事讲给小区的孩子们听。
  • 解析: 这个角色通常是年轻人,他既能理解老年人的固守与孤独,也能接纳年轻人的新潮与活力。他通过自己的行动(如组织活动、翻译代际语言),成为连接不同代际之间的桥梁,促进彼此的理解和融合。

HE-CA-05 | 善意传递者人设公式

  • 构成: 感恩之心 + 持续传递善意行动 → 立体角色
  • 示例: 普通上班族,曾经在困难时得到过陌生人的帮助,现在他会每天给流浪猫喂食,帮邻居代收快递,看到路上的垃圾会随手捡起。
  • 解析: 这个角色的核心驱动力是“感恩”。因为自己曾被善意照亮,所以立志成为新的光源。他通过一系列微小但持续的善意行动,将自己收到的温暖不断地传递出去,形成一个善意的闭环。他是温情故事中最理想的“普通英雄”。

题材五: 校园

1. 核心理念

校园题材的核心逻辑是“青春成长为线、校园生活为景、情感羁绊为核、现实议题为魂”。它聚焦于学生在特定校园环境中的成长与蜕变,故事围绕学业竞争、师生关系、同学情谊、青春懵懂及自我探索等核心议题展开,通过描绘真实可感的校园场景和细腻的情感互动,旨在传递青春的活力、迷茫与温暖。

2. 校园场景构建公式

CA-SC-01 | 课堂日常公式

  • 构成: 课堂场景 + 互动细节 → 校园氛围
  • 示例: 高中数学课上,老师在黑板上推导复杂的函数公式,后排男生偷偷传纸条讨论周末的篮球赛,前排女生举手提问时紧张得声音发颤。
  • 解析: 课堂是校园生活最核心的场景。通过捕捉老师与学生、学生与学生之间生动、真实的互动细节,可以快速还原出不同学龄段特有的课堂氛围,是构建校园故事真实感的基础。

CA-SC-02 | 课间百态公式

  • 构成: 课间场景 + 鲜活细节 → 青春活力
  • 示例: 初中课间10分钟,走廊里挤满打闹的男生,女生围在一起分享零食和八卦,课代表抱着作业本穿梭在教室,上课铃响时大家匆忙跑回座位。
  • 解析: 课间是学生最放松、最能展现真实个性的时刻。通过描绘课间十分钟的众生百态——打闹、八卦、补觉、赶作业——可以集中展现青春的活力与校园生活的丰富多彩。

CA-SC-03 | 操场记忆公式

  • 构成: 操场场景 + 运动细节 → 热血青春
  • 示例: 高中运动会800米赛跑,女生跑到最后一圈时体力不支,全班同学在跑道边为她呐喊加油,她咬牙冲刺越过终点线,同学立刻冲上去递水、扶着她慢走。
  • 解析: 操场是承载热血、汗水和集体荣誉感的经典场景。通过描绘运动会、体育课、篮球赛等场景中的拼搏、竞争与互助细节,可以有效地传递青春的激情与团队精神。

CA-SC-04 | 图书馆时光公式

  • 构成: 图书馆场景 + 安静细节 → 专注氛围
  • 示例: 大学期末周,同学们在图书馆埋头刷题,只有笔尖在纸上沙沙作响和轻轻翻动书页的声音,阳光透过玻璃窗落在摊开的笔记本上。
  • 解析: 图书馆是校园里“安静的战场”。通过描绘学生们在其中专注学习的细节,如奋笔疾书、小声讨论、阳光下的侧影,可以营造出一种紧张而宁静的奋斗氛围,展现学业压力下的共同努力。

CA-SC-05 | 社团活动公式

  • 构成: 社团场景 + 协作细节 → 兴趣成长
  • 示例: 高中话剧社排练,成员们围在一起讨论剧本台词,有人负责改剧本,有人练习走位,道具组的同学用纸箱制作舞台布景,大家齐心协力让排练顺利推进。
  • 解析: 社团是学生因兴趣而聚集、发展个性的地方。通过描绘社团活动的协作过程,包括成员间的讨论、分歧、合作与最终的成果,可以展现由兴趣驱动的成长和团队合作的重要性。

CA-SC-06 | 食堂烟火公式

  • 构成: 食堂场景 + 饮食细节 → 校园烟火气
  • 示例: 中学午餐时间,学生们排着队打饭,窗口阿姨笑着问“要多加点菜吗”,有人端着餐盘找同学拼桌,边吃边聊当天的课程。
  • 解析: 食堂是校园里最具“烟火气”的场所。通过描绘打饭、拼桌、分享食物等日常饮食细节,可以展现学生之间轻松、自然的生活状态,为故事增添浓厚的生活气息。

CA-SC-07 | 毕业季场景公式

  • 构成: 毕业场景 + 纪念细节 → 青春告别
  • 示例: 大学毕业典礼,同学们穿着学士服在校园里拍照,互相在毕业册上签名留言,校长致辞时有人悄悄抹眼泪,散场后大家拥抱告别。
  • 解析: 毕业是校园故事中一个重要的情感节点。通过描绘拍毕业照、写留言、吃散伙饭、拥抱告别等具有仪式感的纪念细节,可以集中渲染离别的伤感、对未来的憧憬以及对同窗情谊的珍视。

CA-SC-08 | 晚自习时光公式

  • 构成: 晚自习场景 + 学习细节 → 共同奋斗
  • 示例: 初三晚自习,教室里只有台灯的光亮,同学们在错题本上整理知识点,遇到难题时小声讨论,老师在过道里巡视,偶尔停下来给学生讲题。
  • 解析: 晚自习是体现“共同奋斗”精神的典型场景。通过描绘安静教室里的学习细节,如整理错题、小声讨论、老师的巡视辅导,可以展现学生们为了共同目标而并肩作战的集体感和奋斗精神。

CA-SC-09 | 校园角落公式

  • 构成: 小众角落场景 + 私密细节 → 青春心事
  • 示例: 高中校园的紫藤花架下,女生坐在长椅上翻看日记,男生躲在角落练习吉他,还有同学在这里偷偷给喜欢的人递情书。
  • 解析: 每个校园都有一些不为人知的角落,它们是承载青春秘密和私密心事的场所。通过描绘在这些角落里发生的、不为人知的细节,可以展现角色细腻的内心世界和青春期特有的敏感与情愫。

CA-SC-10 | 考试季场景公式

  • 构成: 考试场景 + 紧张细节 → 学业压力
  • 示例: 高中月考,监考老师分发试卷,学生们紧张地填写姓名考号,拿到试卷后有人快速浏览,有人深吸一口气开始答题,交卷铃响时,有人匆忙检查,有人露出放松的表情。
  • 解析: 考试是校园生活中压力最大的时刻。通过描绘考场内外的紧张细节,如考前的准备、考中的状态、考后的反应,可以直观地展现学业压力给学生带来的影响,是构建学业冲突线的重要场景。

3. 核心冲突设计公式

CA-CD-01 | 学业竞争冲突公式

  • 构成: 学业目标 + 竞争压力 → 成长挑战
  • 示例: 高二女生想考上重点高校,每次考试都和班级第一的男生竞争,看到对方成绩比自己好时会焦虑失眠,后来在老师引导下,她明白竞争的意义在于成为更好的自己。
  • 解析: 学业竞争是校园题材最核心的冲突之一。通过设定一个明确的学业目标(如考第一、进重点班),并描绘主角在与对手的竞争中所感受到的压力、焦虑以及采取的行动,来探讨竞争的本质,展现主角在压力下的成长与蜕变。

CA-CD-02 | 师生矛盾冲突公式

  • 构成: 学生行为 + 老师管教 → 观念碰撞
  • 示例: 初中男生上课总爱睡觉、玩手机,班主任多次找他谈话、没收手机,他觉得老师“多管闲事”,后来偶然发现老师在放学后帮他补课,才逐渐理解老师的用心。
  • 解析: 冲突源于师生之间因立场、观念不同而产生的矛盾。通过展现学生的“叛逆”行为与老师的“管教”措施之间的碰撞,并最终通过某个契机让双方达成理解,可以深入探讨师生关系,塑造立体的师生形象。

CA-CD-03 | 同学矛盾冲突公式

  • 构成: 同学互动 + 误解/利益分歧 → 关系危机
  • 示例: 高中女生和闺蜜竞选班长,闺蜜为了当选私下拉票,女生得知后很生气,两人冷战。后来在一次小组合作中,闺蜜主动道歉,两人重归于好。
  • 解析: 友情是校园生活的重要组成部分,而友情的危机往往源于误解或利益分歧。通过设计一个导致好友关系破裂的事件,并描绘双方从冷战到和解的过程,可以探讨友谊的脆弱与坚韧。

CA-CD-04 | 青春懵懂冲突公式

  • 构成: 暗恋情感 + 现实顾虑 → 情感纠结
  • 示例: 高中男生暗恋同班女生,想表白又怕被拒绝后连朋友都做不成,看到女生和其他男生讨论问题时会吃醋,只能偷偷在笔记本上写女生的名字。
  • 解析: 青春期的爱恋是朦胧而纠结的。冲突的核心在于“想靠近”的冲动与“怕被拒”的现实顾虑之间的矛盾。通过描绘主角在暗恋中的种种内心戏和试探行为,可以细腻地展现青春期情感的酸甜与苦涩。

CA-CD-05 | 自我认同冲突公式

  • 构成: 个人特质 + 校园评价 → 自我怀疑
  • 示例: 初中女生喜欢画画,却被同学嘲笑“不务正业”,她开始不敢再画画,后来美术老师发现她的天赋,鼓励她参加比赛,她才重新找回自信。
  • 解析: “我是谁?”、“我应该成为什么样的人?”是青春期的核心命题。当主角的个人特质或兴趣爱好不被主流的校园评价体系所认同时,会产生自我怀疑。通过描绘主角在外界评价与自我认知之间的挣扎与最终选择,可以探讨自我认同与成长的议题。

CA-CD-06 | 社团矛盾冲突公式

  • 构成: 社团目标 + 成员分歧 → 团队挑战
  • 示例: 大学摄影社计划举办摄影展,成员们在主题选择上产生分歧,争执不下,甚至有人提出退出。最终通过民主投票和分工合作,展览大获成功。
  • 解析: 社团是校园里的小社会。当团队为了一个共同目标而努力时,成员之间因理念、性格、能力等方面的差异而产生的冲突,是对团队协作能力的考验。解决冲突的过程,也是团队凝聚力形成的过程。

CA-CD-07 | 家庭与校园冲突公式

  • 构成: 家庭期望 + 校园选择 → 两难抉择
  • 示例: 高中女生想加入街舞社,父母却觉得“跳舞影响学习”,要求她去补课。她偷偷参加排练,在与父母爆发争吵后,最终通过约定达成平衡。
  • 解析: 冲突来自于家庭对子女的期望与学生个人在校园中的追求之间的矛盾。主角被迫在“听父母的话”和“追随自己的内心”之间做出选择。这个过程探讨的是两代人的观念差异以及沟通和解的可能性。

CA-CD-08 | 校园霸凌冲突公式

  • 构成: 霸凌行为 + 受害者应对 → 正义守护
  • 示例: 初中男生因身材瘦小被同学欺负,他一开始不敢反抗。后来班长发现后,联合其他同学制止霸凌,并陪他一起找老师反映情况,最终霸凌者受到惩罚。
  • 解析: 校园霸凌是现实且沉重的话题。冲突的核心在于展现霸凌行为的恶劣、受害者的恐惧与无助,以及旁观者或正义方(同学、老师)的介入和反抗。故事旨在探讨勇气、友谊和正义的重要性。

CA-CD-09 | 兴趣与学业冲突公式

  • 构成: 兴趣追求 + 学业压力 → 平衡挑战
  • 示例: 高中女生热爱弹钢琴,想参加比赛,但高三学业紧张,家人和老师都劝她放弃。她陷入纠结,最终通过制定严密的计划,实现了兴趣与学业的平衡。
  • 解析: “应试教育”背景下,学生的个人兴趣与繁重的学业压力之间的矛盾是普遍存在的冲突。主角需要在“追求梦想”和“面对现实”之间寻找平衡点。这个过程考验的是主角的时间管理能力、决心和毅力。

CA-CD-10 | 转学生融入冲突公式

  • 构成: 转学生身份 + 环境适应 → 融入挑战
  • 示例: 高一女生转学到新学校,面对陌生的环境,她不敢主动说话,感到孤独。后来同桌主动和她聊天,邀请她加入小组讨论,她才慢慢适应新环境,交到了朋友。
  • 解析: 转学生是校园里的“闯入者”。冲突来自于新环境带来的陌生感、孤独感以及与原有小团体之间的隔阂。通过描绘转学生如何通过自身努力或他人帮助,一步步融入新集体的过程,可以探讨适应、沟通和友谊建立的主题。

4. 情感递进脉络公式

CA-EP-01 | 同学情谊递进公式

  • 构成: 陌生同学 + 共同经历 → 深厚友谊
  • 示例: 初中开学时,男女生成为同桌,从陌生到熟悉,通过一起做项目、互相鼓励,最终成为形影不离的好朋友。
  • 解析: 友谊的建立源于共同的经历。通过设计一系列需要角色共同完成的任务或面对的困境(如小组作业、运动会、考试),让原本陌生的同学在协作和互助中加深了解,最终建立起深厚的友谊。

CA-EP-02 | 师生情感递进公式

  • 构成: 误解师生 + 暖心互动 → 信任建立
  • 示例: 高中男生觉得数学老师“严厉、偏心”,直到一次生病缺课,老师主动帮他补课、关心他的身体,他才逐渐改变看法,建立起对老师的信任。
  • 解析: 师生关系往往从误解开始。通过一个或多个暖心的互动细节,让学生看到老师在严厉外表下的关怀和付出,从而打破误解,建立起超越师生身份的信任和依赖。

CA-EP-03 | 青春暗恋递进公式

  • 构成: 默默关注 + 细节互动 → 情感升温
  • 示例: 高中女生默默关注篮球社男生,会偷偷递水、帮他整理书本。男生察觉后,会在下雨天和她共撑一把伞。两人虽未言明,但情感在细节互动中慢慢升温。
  • 解析: 暗恋的情感递进是“非语言”的。它通过一系列微小的、充满暗示的细节互动来完成。一方的默默关注和付出,被另一方察觉并给予积极的回应,这种心照不宣的默契是推动情感升温的关键。

CA-EP-04 | 同桌情谊递进公式

  • 构成: 陌生同桌 + 日常互助 → 亲密关系
  • 示例: 高一刚开学,男女生成为同桌,从一开始的很少说话,到后来互相借笔、讲题、分享早餐,最终约定“一起考上同一所大学”。
  • 解析: 同桌是校园里最特殊的一种关系。通过描绘大量的、琐碎的日常互助细节,可以展现两人在朝夕相处中建立起来的、超越普通同学的亲密感和默契,这种情谊往往会成为青春最难忘的记忆。

CA-EP-05 | 社团伙伴情感递进公式

  • 构成: 兴趣伙伴 + 协作挑战 → 团队羁绊
  • 示例: 大学动漫社成员在筹备漫展时,遇到资金不足、场地变更等问题,大家一起想办法解决,经历挑战后,团队成员之间的羁绊更加深厚。
  • 解析: 因共同兴趣而聚集的伙伴,其情感的升华来自于共同迎接挑战。通过设计一个具有相当难度的团队任务,让成员们在协作、争吵、和解、奋斗的过程中,建立起“战友”般的深厚羁绊。

CA-EP-06 | 毕业生情感递进公式

  • 构成: 同窗好友 + 毕业告别 → 不舍情谊
  • 示例: 大学四年的室友们,在毕业前一起拍毕业照、吃散伙饭,聊起四年的点点滴滴,哭着约定“每年都要聚一次”。
  • 解析: 毕业的仪式感和即将分离的紧迫感,是催化情感的利器。通过集中描绘毕业前的各种告别场景,将多年同窗积累的情感进行一次集中抒发,从而将这份情谊升华、定格。

CA-EP-07 | 问题学生与老师情感递进公式

  • 构成: 叛逆学生 + 老师引导 → 信任依赖
  • 示例: 叛逆的初中男生经常逃课,班主任没有放弃他,通过谈心了解到其家庭变故,在学习和生活上给予关心,最终男生开始信任并依赖老师。
  • 解析: 对于“问题学生”,情感的建立始于“被理解”。老师需要首先放下权威,通过耐心的引导和真诚的关怀,找到学生叛逆行为背后的根源,并给予其真正需要的帮助。这种“拯救者”与“被拯救者”的关系,容易建立起极强的信任和依赖。

CA-EP-08 | 跨年级情感递进公式

  • 构成: 学长/学姐 + 新生帮扶 → 温暖情谊
  • 示例: 大学新生入学时,学姐主动帮她搬行李、介绍校园、分享经验,在学姐的帮助下,新生很快适应了大学生活,两人也建立了深厚的友谊。
  • 解析: 这种情感模式类似于“引导者”和“追随者”。通过学长学姐对新生的主动帮扶,传递校园的温暖和传承。新生产生的感激和崇拜,与学长学姐的责任感和关爱相结合,形成一种独特的、跨越年级的温暖情谊。

CA-EP-09 | 小组合作情感递进公式

  • 构成: 陌生小组 + 任务协作 → 默契配合
  • 示例: 高中语文小组合作,从一开始的意见不统一、互相争吵,到后来分工合作、互相补位,最终在协作中形成默契,圆满完成任务。
  • 解析: 这是“从敌人到战友”的经典模式。将一群互不熟悉甚至互有偏见的同学组成一个小组,让他们在完成一个必须合作才能完成的任务的过程中,通过磨合、理解、协作,最终建立起对彼此能力的认可和团队的默契。

CA-EP-10 | 校园情侣情感递进公式

  • 构成: 暧昧关系 + 共同成长 → 稳定恋情
  • 示例: 高中男女生从暧昧走向恋爱,他们一起制定学习计划,互相监督,在考试失利时互相安慰,在共同成长中,恋情变得更加稳定。
  • 解析: 校园恋情最美好的部分,不是花前月下,而是“共同成长”。将两人的情感发展与学业进步、个人成长紧密绑定,让他们成为彼此变得更好的动力。这种“战友式”的爱情,比单纯的风花雪月更加坚固和动人。

5. 校园人设塑造公式

CA-CA-01 | 学霸人设公式

  • 构成: 优异成绩 + 独特学习方法 + 性格特质 → 立体学霸
  • 示例: 高中女生每次考试都是年级第一,她的学习方法是“整理错题本、制定每日计划”。但她不是“书呆子”,性格温和耐心,还经常帮同学讲题。
  • 解析: 塑造学霸,不能仅仅停留在“成绩好”的标签上。需要为其赋予独特的、可供模仿的学习方法,以及区别于“书呆子”刻板印象的性格特质(如乐于助人、有反差萌的爱好),使其形象更加立体、可信、甚至可爱。

CA-CA-02 | 文艺青年人设公式

  • 构成: 兴趣爱好 + 细腻情感 + 校园表现 → 立体文艺生
  • 示例: 大学男生喜欢写诗、弹吉他,笔记本里写满了细腻的诗句,他会关注校园里的花草树木,性格安静内敛,但和志同道合的朋友在一起时会变得健谈。
  • 解析: 文艺青年的核心是“敏感”和“表达”。通过赋予其明确的文艺类兴趣爱好(如文学、音乐、绘画),并描绘其细腻善感的情感世界,以及在校园中的具体表现(如在草坪弹唱、在社团发表作品),可以塑造出一个有内涵、有灵魂的文艺形象。

CA-CA-03 | 体育生人设公式

  • 构成: 运动特长 + 热血性格 + 反差细节 → 立体体育生
  • 示例: 高中男生是篮球社社长,在球场上热血拼搏,性格开朗外向。看似大大咧咧,却会在女生生病时主动帮忙搬书,考试前还会认真复习,怕拖班级后腿。
  • 解析: 体育生不能只有“四肢发达”。在赋予其运动特长和热血性格的同时,必须加入“反差细节”(如内心细腻、讲义气、有责任感),打破“头脑简单”的刻板印象,塑造出一个既有力量又有温度的立体形象。

CA-CA-04 | 班主任人设公式

  • 构成: 教学风格 + 管理方式 + 暖心细节 → 立体班主任
  • 示例: 初中班主任教学严谨,但管理班级时很民主。她记得每个学生的生日,会在生日当天送上小礼物,学生生病时会亲自去家里探望,被学生称为“妈妈一样的老师”。
  • 解析: 一个成功的班主任形象,必然是“严”与“慈”的结合体。需要明确其教学和管理的风格,更重要的是,通过一系列具体的、持之以恒的暖心细节,展现其对学生发自内心的关爱,塑造出一个“亦师亦友”甚至“如母如父”的理想教师形象。

CA-CA-05 | 转学生人设公式

  • 构成: 适应过程 + 个人特质 + 融入表现 → 立体转学生
  • 示例: 高中转学生女生一开始内向害羞,但她擅长画画。通过在班级黑板报上展现才华,她逐渐被同学接纳,并最终成功融入新集体。
  • 解析: 转学生人设的看点在于“变化”。故事需要完整地展现其从“局外人”到“局内人”的适应过程。同时,必须赋予其一个鲜明的个人特质或技能,这既是其区别于其他人的标签,也是其打破僵局、融入集体的关键“敲门砖”。

题材六: 治愈

1. 核心理念

治愈题材的核心逻辑是“创伤为起点、疗愈为脉络、和解为终点、温暖为底色”。它聚焦于个体在经历挫折、伤痛后的心灵重建过程,通过场景、情感、行动的层层递进,传递“创伤可修复、生活有希望”的核心信念。

2. 疗愈场景构建公式

HE-SC-01 | 自然疗愈公式

  • 构成: 自然场景 + 感官细节 → 心灵舒缓
  • 示例: 失恋后的女孩来到湖边小屋,清晨听着鸟鸣醒来,午后坐在藤椅上看湖面波光,伸手触摸微风里带着的青草香。
  • 解析: 将角色置于开阔、宁静的自然环境中(如森林、海边、山野),并通过调动角色的五感(视觉、听觉、嗅觉、触觉),描绘其与自然元素的互动细节。大自然固有的生命力和秩序感,能够有效地舒缓角色的内在焦虑和创伤。

HE-SC-02 | 静谧空间公式

  • 构成: 安静场景 + 治愈细节 → 心灵避风港
  • 示例: 失业后的男孩在旧书店打工,每天用软布擦拭泛黄的书页,在书里夹上带有干花的书签,累了就坐在窗边的旧沙发上,听着留声机里的轻音乐。
  • 解析: 创造一个与外界喧嚣隔绝的、充满安全感的安静空间(如书店、咖啡馆、阁楼)。通过描绘角色在这个空间里进行的、富有仪式感的、缓慢而专注的活动,让这个空间成为角色可以暂时躲避现实压力、安放情绪的“心灵避风港”。

HE-SC-03 | 手工疗愈公式

  • 构成: 手工场景 + 专注细节 → 情绪沉淀
  • 示例: 丧母后的女孩跟着奶奶学陶艺,揉泥时感受泥土在掌心的厚重,拉坯时专注于转盘的转速,最后在杯底刻上母亲的名字。
  • 解析: 通过让角色进行一项需要高度专注的手工活动(如陶艺、编织、木工、烹饪),将其注意力从内心的痛苦中暂时转移出来。手工制作过程中的专注、重复和创造性,能够帮助角色沉淀纷乱的情绪,获得掌控感和成就感。

HE-SC-04 | 田园疗愈公式

  • 构成: 田园场景 + 劳作细节 → 心灵重建
  • 示例: 遭遇职场PUA的女人回到乡下老家,清晨跟着爷爷去菜园摘青菜,正午在院子里晒稻谷,双手沾满泥土时,看着满园的绿意,突然觉得“生活还有很多实在的美好”。
  • 解析: 回归土地,回归最质朴的生活方式。通过描绘角色在田园中的日常劳作细节(如播种、浇水、收获),展现生命从无到有的过程。这种与土地的连接和收获的喜悦,能够帮助角色重建生活的信心和价值感。

HE-SC-05 | 宠物陪伴场景公式

  • 构成: 人与宠物互动场景 + 陪伴细节 → 情感慰藉
  • 示例: 独居且抑郁的老人收养了一只流浪狗,每天早上给狗梳毛,傍晚带着狗在小区散步,狗会在老人发呆时用头蹭他的手,难过时趴在他脚边。
  • 解析: 宠物提供的是一种无条件的、非批判性的陪伴。通过描绘人与宠物之间充满细节的、相互依赖的日常互动,可以展现一种纯粹的情感慰藉。对于孤独、封闭的创伤者而言,宠物是打破隔绝、重建情感连接的重要桥梁。

HE-SC-06 | 旧地重游公式

  • 构成: 有回忆的场景 + 今昔对比细节 → 创伤释怀
  • 示例: 与好友闹掰多年的女人回到母校,走到曾经一起坐过的操场台阶,摸了摸当年一起刻下名字的老槐树,想起那时的欢声笑语,突然明白“当年的矛盾不过是青春里的小插曲”。
  • 解析: 让角色回到与创伤或美好回忆相关的旧地。通过今昔场景的对比,以及角色心态的变化,展现时间的流逝对创伤的冲刷和对记忆的滤镜效果。这是一种通过直面过去来与过去和解的疗愈方式。

HE-SC-07 | 深夜疗愈公式

  • 构成: 深夜场景 + 温柔细节 → 情绪释放
  • 示例: 加班到深夜的女孩回到出租屋,泡一杯热牛奶,打开小台灯,翻出日记本写下当天的委屈,写完后抱着暖水袋躺在沙发上,看着窗外的星星慢慢平静下来。
  • 解析: 深夜是人最脆弱、也最真实的时刻。通过创造一个安静、温暖、只属于角色自己的深夜场景,并描绘其进行自我关怀的温柔细节(如一杯热饮、一盏暖灯、写日记),为角色提供一个安全释放负面情绪的出口。

HE-SC-08 | 艺术疗愈公式

  • 构成: 艺术创作场景 + 表达细节 → 情感宣泄
  • 示例: 经历校园霸凌的男孩开始学画画,把内心的恐惧画成黑色的影子,把渴望的温暖画成发光的太阳,墙上的画从“黑色为主”慢慢变成“彩色居多”。
  • 解析: 当创伤无法用语言表达时,艺术成为最好的出口。通过让角色进行绘画、音乐、写作等艺术创作,将其内在的、压抑的情感进行视觉化或符号化的表达。创作的过程,就是情感宣泄和自我梳理的过程。

HE-SC-09 | 社区疗愈公式

  • 构成: 社区互动场景 + 互助细节 → 归属感重建
  • 示例: 刚搬到新社区的独居女孩,在社区手工课上,邻居阿姨教她织围巾,孩子们把自己画的画送给她,冬至时大家还邀请她一起包饺子。
  • 解析: 创伤往往伴随着与社会的隔绝感。通过描绘角色在社区(或任何互助团体)中,与其他成员的互动和互助细节,让其重新感受到人与人之间的连接和温暖,从而打破孤立,重建归属感。

HE-SC-10 | 季节疗愈公式

  • 构成: 季节变化场景 + 成长细节 → 创伤修复
  • 示例: 失去孩子的母亲在春天种下一棵樱花树,看着树苗发芽、长叶、开花,一年后看着盛开的樱花,母亲轻声说“你看,春天又回来了”。
  • 解析: 将角色的创伤修复过程与自然界的季节更替、植物的生长周期相结合。通过描绘角色在不同季节对同一对象的持续关注和照料,用外在景物的生命循环来隐喻内在心灵的枯萎与重生,充满诗意和希望。

3. 情感疗愈递进公式

HE-EP-01 | 创伤触发公式

  • 构成: 创伤相关场景 + 情绪波动细节 → 疗愈起点
  • 示例: 车祸幸存的男孩路过曾经出事的路口,突然想起当时的撞击声,双手开始发抖,呼吸变得急促,他赶紧走到路边的长椅坐下,慢慢平复。
  • 解析: 疗愈的开始,必须是直面创伤。通过一个与创伤记忆高度相关的场景、物品或声音,触发角色的应激反应(PTSD)。通过细腻地描绘其生理和情绪上的剧烈波动,来展现创伤的深度,并以此作为整个疗愈故事的起点。

HE-EP-02 | 微小疗愈公式

  • 构成: 日常小事 + 温暖细节 → 情绪缓解
  • 示例: 因自我否定而焦虑的女孩,某天在便利店买早餐时,店员笑着对她说“今天的阳光很适合你”,路上遇到小朋友对她挥手,回到家发现窗台的多肉长出了新叶。
  • 解析: 疗愈不是一蹴而就的,它开始于日常生活中微小的、积极的反馈。通过一系列来自外界的、不经意的温暖细节,像微光一样,一点点照亮角色灰暗的内心世界,帮助其暂时缓解负面情绪,是推动疗愈进程的第一步。

HE-EP-03 | 陪伴疗愈公式

  • 构成: 他人陪伴 + 倾听细节 → 情感疏导
  • 示例: 失恋后的女孩找闺蜜倾诉,闺蜜没有打断她的哭诉,只是递上纸巾,轻轻拍她的背,等她哭完后,才说“我知道你很难过,但你值得更好的人”。
  • 解析: 在角色最脆弱的时候,一个“在场”的、不加评判的陪伴者至关重要。疗愈的关键不在于给出建议,而在于耐心的倾听。通过描绘陪伴者“少说多做”的细节(如递纸巾、拥抱、安静地坐着),来疏导创伤者的情绪,为其提供情感支持。

HE-EP-04 | 自我接纳公式

  • 构成: 自我反思 + 肯定细节 → 自我和解
  • 示例: 因身材自卑的女孩,某天看着镜子里的自己,想起自己擅长做饭、喜欢看书,她开始在日记本上每天写“3件自己做得好的事”,慢慢从“讨厌自己”变成“接受自己的不完美”。
  • 解析: 许多创伤的根源在于自我否定。疗愈的核心一步是“自我和解”。通过角色主动的自我反思,从负面评价中剥离出来,寻找并肯定自身的优点和价值。这个从“挑剔自己”到“拥抱自己”的转变过程,是角色内心强大的开始。

HE-EP-05 | 希望唤醒公式

  • 构成: 困境场景 + 转机细节 → 生活信心
  • 示例: 创业失败负债的男人,在最绝望时,收到曾经帮助过的客户的消息,说“愿意投资你的新项目”。看到消息时,男人手里的泡面差点掉在地上,眼里重新有了光。
  • 解析: 在角色陷入最低谷、即将放弃希望的时刻,给予其一个意想不到的“转机”。这个转机不必是惊天动地的大事,可能只是一条信息、一个机会、一句鼓励。它的作用是重新点燃角色对生活的信心,将其从绝望的泥潭中拉出来。

HE-EP-06 | 仪式感疗愈公式

  • 构成: 疗愈仪式 + 情感投入细节 → 创伤告别
  • 示例: 丧父后的女孩,在父亲忌日那天,准备了父亲喜欢的酒和菜,坐在桌前和父亲“聊天”,把想对父亲说的话写在纸上烧掉,最后对着父亲的照片鞠躬说“爸爸,我会好好生活的”。
  • 解析: 为创伤的告别设计一个充满仪式感的行为。这个仪式是角色主观构建的,通过具体的、象征性的行动(如写信、烧纸、埋葬旧物),将内在的情感外化,并赋予其一个明确的“结束”标志,帮助角色完成与过去的切割。

HE-EP-07 | 能力重建公式

  • 构成: 尝试新事物 + 进步细节 → 自我认同
  • 示例: 因失业而自我怀疑的男人,开始学做咖啡,从一开始的手忙脚乱,到慢慢能做出拉花。第一次成功做出爱心拉花时,他拍了照片发给朋友,收到了夸赞。
  • 解析: 创伤往往伴随着能力的丧失感。通过让角色学习一项全新的技能,并描绘其从笨拙到熟练的进步过程,可以帮助其重建“我能行”的自我认同感。每一次微小的进步,都是对自我价值的一次肯定。

HE-EP-08 | 共情疗愈公式

  • 构成: 看到他人相似经历 + 共鸣细节 → 创伤缓解
  • 示例: 因校园霸凌而封闭自己的女孩,在网上看到有人分享“被霸凌后走出阴影”的故事,故事里的感受和自己一模一样,她在评论区留言,收到很多人的鼓励。
  • 解析: “原来不止我一个人这样”——这种被理解的感觉本身就是一种强大的疗愈。通过让角色接触到与自己有相似创伤经历的他人(或故事),产生强烈的共鸣,可以极大地缓解其孤独感和病耻感,获得群体支持的力量。

HE-EP-09 | 自然疗愈递进公式

  • 构成: 长期自然接触 + 变化细节 → 心灵修复
  • 示例: 焦虑症患者每周去公园散步,第一周只是低着头走,第二周开始注意到路边的野花,第三周会停下来听鸟叫,三个月后,他的焦虑发作次数明显减少。
  • 解析: 这是“自然疗愈”的动态过程。通过描绘角色在长期与自然接触的过程中,其观察视角、心境和行为的细微变化,来展现自然对心灵潜移默化的修复作用。重点在于展现这个“渐进式”的修复过程。

HE-EP-10 | 传递疗愈公式

  • 构成: 帮助他人 + 反馈细节 → 自我价值认同
  • 示例: 曾被帮助过的抑郁症女孩,开始在公益平台做志愿者,陪孤独老人聊天。老人握着她的手说“谢谢你陪我,我今天很开心”,女孩突然觉得“自己也能给别人带来温暖”。
  • 解析: 疗愈的最高境界,是从“被疗愈者”转变为“疗愈者”。当角色有能力去帮助与自己有相似困境的他人时,他不仅传递了善意,更在“被需要”和积极的反馈中,获得了最强大的自我价值认同,完成了疗愈的闭环。

4. 创伤冲突疗愈公式

HE-CD-01 | 创伤复发冲突公式

  • 构成: 创伤复发场景 + 积极应对行动 → 疗愈强化
  • 示例: 地震幸存者在下雨天突然想起地震场景,情绪崩溃。他赶紧按照心理医生教的方法,打开窗户感受雨水的气息,播放舒缓的音乐,慢慢平复下来。
  • 解析: 疗愈过程并非一帆风顺,创伤的复发是常见的冲突。关键在于展现角色在创伤复发时,不再像过去一样被动承受,而是能够主动运用已经习得的疗愈技巧(如深呼吸、正念、求助)进行自我调节。每一次成功的应对,都是对疗愈效果的一次强化。

HE-CD-02 | 自我否定冲突公式

  • 构成: 自我否定想法 + 反驳行动 → 自我和解
  • 示例: 因考试失利而自我否定的学生,觉得“自己永远考不好”。他的老师让他写下自己之前的成功事例,看着这些,学生慢慢反驳“我不是一直失败”。
  • 解析: 内心的冲突来自于根深蒂固的自我否定想法。冲突的化解,需要一个“反驳”的行动。通过收集与自我否定想法相悖的“证据”(如过去的成功经历、他人的积极评价),来挑战和动摇不合理的负面认知,最终实现自我和解。

HE-CD-03 | 人际关系创伤公式

  • 构成: 人际触发场景 + 边界建立行动 → 创伤修复
  • 示例: 曾被朋友背叛的女孩,在新友谊中,对方想翻看她的手机。她想起之前的背叛,但还是勇敢地说“我希望我们能有各自的隐私”,对方表示理解。
  • 解析: 曾受过人际关系创伤的人,往往难以建立新的信任。当类似的情景再次出现时,冲突便产生了。疗愈的关键在于,角色能否吸取教训,勇敢地为新的关系设定健康的“边界”。当边界被尊重时,创伤就开始被修复。

HE-CD-04 | 丧亲之痛冲突公式

  • 构成: 丧亲触发场景 + 纪念行动 → 创伤释怀
  • 示例: 母亲在整理父亲的旧外套时,突然崩溃大哭。她抱着外套,想起父亲喜欢钓鱼,于是把父亲的钓鱼竿整理好,放在客厅的角落,每天擦拭,慢慢从“不敢面对”变成“能平静回忆”。
  • 解析: 丧亲之痛的冲突在于“睹物思人”的无尽悲伤。化解方式不是“丢掉”或“忘记”,而是将对逝者的思念,转化为一种积极的、持续的“纪念行动”。通过这种方式,逝者以另一种形式活在生者的生活中,悲伤也逐渐转化为平静的怀念。

HE-CD-05 | 职场创伤冲突公式

  • 构成: 职场触发场景 + 应对策略行动 → 创伤修复
  • 示例: 曾遭遇职场霸凌的女人,在新公司遇到同事故意刁难。她没有像以前一样沉默,而是冷静地说“你的要求超出了我的工作范围,我们可以找领导确认”。
  • 解析: 职场创伤的复现,是对角色是否真正成长起来的考验。冲突的化解,在于角色能否运用新的、更成熟的应对策略(如冷静对峙、寻求第三方支持、保留证据),来保护自己,打破过去“受害者”的循环。每一次成功的反抗,都是一次疗愈。

HE-CD-06 | 自我怀疑冲突公式

  • 构成: 怀疑触发场景 + 证据收集行动 → 自我认同
  • 示例: 因项目失败而自我怀疑的设计师,在客户说“你的设计不够好”时,开始怀疑自己的能力。后来他翻出之前客户好评的邮件、获奖的设计作品,慢慢意识到“一次失败不代表全部”。
  • 解析: 与“自我否定”类似,但更侧重于对“能力”的怀疑。当怀疑被触发时,角色需要主动地去“收集证据”,寻找能够证明自己能力的客观事实。这个过程就像律师在法庭上为自己辩护,通过有力的证据来驳斥内心那个“我不行”的声音。

HE-CD-07 | 童年创伤冲突公式

  • 构成: 童年触发场景 + 疗愈对话行动 → 创伤修复
  • 示例: 因童年被忽视的男人,在看到侄子被父母忽视时,想起自己的童年。他找到心理医生,进行“与童年自己对话”的疗愈,他对“童年的自己”说“对不起,让你受委屈了,现在我会好好照顾你”。
  • 解析: 童年创伤的冲突,是“现在的我”与“内在的小孩”之间的冲突。当创伤被现实场景触发时,角色需要通过一种象征性的“疗愈对话”,去看见、安抚、并承诺照顾那个曾经受伤的“内在小孩”。这是一种深度自我关怀的疗愈方式。

HE-CD-08 | 失恋创伤冲突公式

  • 构成: 失恋触发场景 + 断舍离行动 → 创伤释怀
  • 示例: 失恋后的女孩,在看到前男友送的礼物时,又开始难过。她决定进行“断舍离”,把礼物分类,有用的捐赠,有纪念意义的封存。看着空出来的抽屉,觉得心里也轻松了很多。
  • 解析: 失恋的痛苦,往往与过去的回忆和物品纠缠在一起。冲突的化解,需要一个果断的“断舍离”行动。通过整理、舍弃、封存与过去相关的物品,在物理空间上与过去告别,从而在心理空间上也为新的生活腾出位置。

HE-CD-09 | 健康创伤冲突公式

  • 构成: 健康触发场景 + 积极治疗行动 → 创伤修复
  • 示例: 患重病的老人,在看到病友放弃治疗时,也有些动摇。但医生给她看了成功案例,家人每天陪她锻炼,她开始积极配合治疗,从“害怕死亡”变成“相信能康复”。
  • 解析: 面对重病,内心的冲突往往是“求生欲”与“恐惧绝望”的斗争。当负面情绪被触发时,来自外部的积极信息(如成功案例)和持续的社会支持(如家人陪伴),是帮助角色坚定治疗信念、战胜内心恐惧的关键。

HE-CD-10 | 群体性创伤冲突公式

  • 构成: 群体触发场景 + 共同疗愈行动 → 创伤修复
  • 示例: 经历自然灾害的社区居民,在灾后重建时,大家一起成立“互助小组”,分享各自的经历,互相鼓励,一起参与社区重建。
  • 解析: 对于群体性创伤(如灾难、战争),个体的疗愈离不开群体的支持。当创伤被集体回忆触发时,通过组织共同的疗愈行动(如互助小组、集体哀悼、社区重建),让个体在群体中找到归属感和力量感,是修复群体创伤的有效途径。

5. 治愈型人设塑造公式

HE-CA-01 | 自我疗愈者人设公式

  • 构成: 经历创伤 + 自我救赎行动 → 立体角色
  • 示例: 曾患抑郁症的女孩,通过写日记、学瑜伽、做志愿者慢慢走出阴影,后来她成立“情绪树洞”公众号,分享自己的疗愈经历,帮助他人。
  • 解析: 这是最经典的治愈型主角。他/她自己就是创伤的亲历者,整个故事就是其自我救赎的过程。在完成自我疗愈后,他/她进一步将自己的经验升华,去帮助更多的人。其口号是:“我曾在黑暗里行走,所以想为别人点亮一盏灯”。

HE-CA-02 | 陪伴疗愈者人设公式

  • 构成: 温柔性格 + 持续陪伴行动 → 立体角色
  • 示例: 社区心理辅导员,在居民遭遇创伤时,会耐心倾听,每周定期回访,从不催促“快点好起来”,只是说“我会一直陪着你”。
  • 解析: 这个角色是“疗愈天使”。他/她本身可能没有经历过深刻的创伤,但拥有极强的共情能力和耐心。他/她的核心功能是“陪伴”和“倾听”。通过持续的、无条件的、温暖的陪伴,为创伤者提供一个安全的情感依靠。

HE-CA-03 | 自然疗愈者人设公式

  • 构成: 热爱自然 + 引导他人接触自然行动 → 立体角色
  • 示例: 退休的林业工人,组织“自然疗愈营”,带都市焦虑人群去山林里徒步、认植物、听自然声音,引导他们通过自然来修复内心。
  • 解析: 这个角色是大自然的“代言人”。他/她深谙自然之道,并相信自然拥有疗愈人心的力量。通过引导他人去接触、观察、融入自然,帮助他们从都市的喧嚣和内心的焦虑中解脱出来。

HE-CA-04 | 艺术疗愈者人设公式

  • 构成: 擅长艺术 + 用艺术疏导行动 → 立体角色
  • 示例: 美术老师,在学校开设“艺术疗愈课”,教孩子们用画画表达情绪,通过“画树测试”了解其内心,并用艺术创作帮他们疏导困扰。
  • 解析: 这个角色是“灵魂的画师”。他/她擅长某种艺术形式,并将其作为一种疗愈工具。通过引导他人进行艺术创作,帮助他们表达无法言说的创伤,并从创作中获得力量和解脱。

HE-CA-05 | 创伤共鸣者人设公式

  • 构成: 相似创伤经历 + 共情支持行动 → 立体角色
  • 示例: 曾经历校园霸凌的心理咨询师,在面对被霸凌的孩子时,会分享自己的经历,让孩子觉得被理解,再教他们应对方法。
  • 解析: 这个角色的疗愈力量来自于“我懂你”。因为拥有相似的创伤经历,他/她能够与创伤者产生最深度的共情。通过分享自己的故事和经验,他/她不仅能给予对方情感上的支持,还能提供最实用的应对策略,是“过来人”和“引路人”的结合体。
