用 Skywork 打造你的 AI 生产力系统

昆仑天工 Skywork 桌面版发布了，用它来打造一个你的个人 AI 生产力系统

原创 空格 zephyr 2026年2月4日 10:58

大家好，我是空格。

最近发现昆仑天工 Skywork 桌面版发布了，支持 Windows，多模型路由，操作比 Claude Code 简单不少。

我目前用 Claude Code 搭了一套个人生产力系统。它能自动抓 YouTube、X、Newsletter 热点，筛选题，评估爆文指数，结合我的写作风格和读者画像给出建议，直接创作文章。

靠这套系统，我做到了每天更新质量稳定的文章。

我叫这个系统「 个人 AI 生产力系统 」（AI Productive System）。

你的文件就是 AI 系统的上下文，上下文诞生 Skills，Skill 组合为 Agent，Agent 运行于系统中。系统是最大的容器，Agent 是执行特定任务的组合体，Skill 是最小的能力单元。

今天借 Skywork 这个工具，给大家演示一下：拿到一款 AI 神器，怎么把它和自己的生产环境结合，让 AI 源源不断为你创造价值。

选择 Skywork 的原因很简单，它的门槛比 Claude Code 低多了，在 windows 桌面端下载就能使用，而且支持顶级模型 opus4.5 和 Gemini 3pro，复杂代码、写作任务都可以放心交给它。

产品下载地址： https://skywork.ai/desktop

什么是 AI 生产力系统

简单的说，这就是一个文件夹结构。它 是根据你自己的上下文、业务线、创作特点构成的。

整个系统生长在你的文件夹体系里。

你收藏的内容，你阅读的知识，你对文章的数据分析和反思，你对标大V的拆解和学习，都在这里。

参考我现在的文件夹结构：

这个结构是完全个人定制的。每个人的业务不同，结构也不同。

有了这个结构后，就可以导入你创作过的文章、收藏过的内容、读过的金句。

梳理好内容的时候，你自然就会构建属于这个系统的 skills，比如因为你读过的金句都是在 X 上保存的，你就可以做一个 X 收藏内容同步到本地 Skill，因为这些金句可以加到你创作中，你就可以做一个，写作时为我引用我收藏过的金句的 skill。

如果把多个 Skills 串起来，比如「生成选题 Skill」+「评估选题质量 Skill」+「生成文章草稿S kill」，就形成了一个「内容创作 Agent」

文件越多，Skill 越多，业务线越多，Agent 越多。

下面我们就用 Skywork 桌面版，从一个空文件夹开始，一步步搭建完整系统。

第1步：创建文件夹结构

打开 Skywork，输入指令，让 AI 帮你生成文件夹结构。

根据你的需求，改写下面指令，让 AI 给你推荐 Skills：

我是一个内容创作者，主要在小红书和公众号发布文章。
信息源是 X、YouTube、微信读书。我喜欢的作者，我的写作风格偏好。
我需要保存：历史文章、金句收藏、月度/年度计划、微信聊天记录。

请根据我的情况，设计一个 Obsidian 文件夹结构，用于搭建个人内容生产系统。参考目录结构：
\`\`\`
00 收件箱/00 笔记/01 动态
01 内容创作/
02 选题管理/
03 素材管理/
04 历史文章/
05 内容数据/
06 计划/
07 系统方法/

最后 Skywork 给我生成的效果，如果这个结构不合适，可以根据自己的业务调整。

文件夹命名用的是杜威十进制法。 这是图书馆给书籍分类的方法，用数字编号00/01/02让内容有序排列。

好处是：文件夹自动按数字顺序排列，一眼就能找到，而且预留了扩展空间。

系统生长在你的文件夹体系里。 这个结构就是你系统的骨架。

第2步：试用 Skills

Skills 能让 AI 根据描述调用特定文件、工具来完成任务。

比如「播客转录 Skill」能自动把 YouTube 视频转成文字，「选题生成 Skill」能根据热点给你推荐选题。 播客处理 skills

Skill 是最小单元的 vibe coding 作品。

不需要写代码，不需要懂编程。你只需要用自然语言描述你想要的能力，AI 就能帮你创建。

可以根据自己的特点修改下面提示词，让 AI 给你推荐适合你的 skills。

我的痛点：
1. 每次创作都从零开始，效率低
2. 找不到以前的优质素材和金句
3. 不知道什么选题好，缺乏选题灵感
4. 选题执行周期不可控，经常拖延
5. 播客内容处理流程繁琐

请根据我的痛点，推荐可以安装的 Skills，并下载到项目文件夹。

第3步：导入你的上下文

这一步最重要。AI 的能力上限，取决于你喂给它多少上下文。

可以导入的内容：

  • 你本地保存的文件
  • 你历史创作的内容
  • 你在微信中的聊天记录
  • 在 flomo、Notion、飞书里的笔记

格式可以是 Markdown、PDF、Word，这些 AI 都能读。

把这些内容分类放进第1步创建的文件夹里。

文件越多，Skill 越多，业务线越多，Agent 越多。

当你的素材库有 100 篇金句，AI 就能「引用你收藏过的金句」， 历史文章有 50 篇，AI 就能「模仿你的写作风格」，选 题库有 200 个，AI 就能「根据你的偏好推荐选题」。

上下文是系统的燃料。没有上下文，再强的 AI 也只能给你通用答案。

本地的文件可以直接拖到到你第一步构建的系统里，但是SaaS、社交平台的内容就需要自己做工具，这个我们后面可以展开讲。

第4步：根据上下文创建 Skills

当上下文梳理的足够清晰，你自然就清楚你需要什么 Skills 了。

比如可以 「根据我历史创作的内容00/01 下的内容，以我的风格来输出一篇文章」 这句话本身就是一个 Prompt，发给 AI 就能创建一个 Skill。

再比如 ：「根据我提供的 Notion API，把创作的内容导入到 Notion，每次我说『导入 Notion』就触发」

Skill 就是把你重复做的事情固化成指令， Skill 为系统所服务，可以自迭代，现在我做到的效果是，在这个系统里，在任何一个终端都可以调用你的 Skill 。

你不需要写代码，只需要用自然语言描述：

  • 这个 Skill 要做什么，参考文件和脚本是什么
  • 什么时候触发
  • 输入是什么，输出是什么

AI 会帮你把它格式化成标准的 Skill 文件。

当你有了 5 个 Skill、10 个 Skill、20 个 Skill，它们就可以组合成不同的 Agent，完成复杂的工作流。

第5步： Skills 常用推荐

Skywork 官方提供了很多 Skills 可以下载，我看了一下，都是一些办公常用的，可以下载体验。

你也可以从 GitHub 上找，比如：

  • https:// github.com/anthropics/skills（官方）
  • https://github.com/ComposioHQ/awesome-claude-skills
  • https://skillsmp.com/zh

只需要输入链接地址，告诉 AI 我要安装这个 Skill，AI 会自动帮你下载安装到指定目录。

安装完成后，你就可以在 Skywork 里调用他们工作了。使用次数越来越多，就可以把多个 skill 进行串联制作成工作流。

写在最后

使用这套系统，我做到了日更公众号、小红书，每天剪视频、写文章，甚至我在工作中的原型图和需求文档，我创作的产品项目文件也都迁移到了这里，每天工作都离不开它了。

这个系统的搭建的逻辑很简单，用的好，不只是个人效率倍增，系统本身也能自我成长和迭代。整体逻辑：

1.先有系统 ：你的文件夹结构、你的上下文、你的业务流程

2.再有 Skill ：把重复的操作固化成一个个小能力

3.最后有 Agent ：把多个 Skill 串联起来，完成复杂任务

在搭建这个系统过程中，必然会有很多难点，比如，怎么管理自己的文件夹系统、如何实现 Skills 在不同设备上都可以调用，如何根据自己的业务抽象 Skills 和 Agents？

如果你具备产品和开发的思维，就可以抓取不同源头的数据，创作内容，生产图片、视频，做成网站、小程序、APP，潜力无限。
