视频详情

哩布哩布本来就是图片赛道里的国内应用独角兽，2026 年切到视频赛道后，LibTV 的势头很猛。

现在它已经不只是一个新工具，更像国内 AI 视频制作的第一选择，里面已经跑出不少高质量作品，抖音上破百万播放的 AI 视频也不少。

我今天这里说的「复刻」，不是把原视频照搬一遍，而是拆它的结构，如果自己做就比较容易卡住了，不知道那些专业镜头词怎么写，以前我会直接写“高级感、电影感、科技感”，质量就那样。

现在，像我对于哪一个爆款视频的制作比较感兴趣，我可以直接上传到 LibTV 的画布里面，然后让它直接帮我拆解出来脚本，我输入的提示词是：帮我拆解视频脚本，并优化成像素风格的画面。

在这里直接就是「教科书级」的使用：开头怎么抓人，镜头怎么推进，转场怎么接，音效怎么配置、有没有对白、分镜脚本怎么写、最后怎么收情绪，给我们写的清清楚楚。

然后我们直接点击「生成分镜」就可以生成图片了。

我们等待 2 分钟左右的时间就可以得到这样一个完整的分镜图，每个画面遵循了我想要的风格。

从图片分镜到视频，也是直接点击「批量生产视频」就可以。

我们仅需一路点点点，在生成视频模型里面我们都可以使用很多类似 Seedance 2.0 这类目前最新视频效果最好的模型，基本上都可以承包我们的所有视频制作需求了。

等待视频制作完成之后，我们可以直接在线剪辑合并，也可以导入专业的剪辑工具里面进行二次加工，这个方法不只适合广告，短剧开头、MV 片段、产品种草视频都能用。

不过上面应该是很多纯图像视频模型、画布就能够解决的事情，我自己觉得 LibTV 现在比较新的一点，也在这里：它不是只给创作者一个画布，还给 Agent 一个入口，不让 AI 直接出片，先让 Agent 看懂原片。

视频详情

比如我们想要直接让 Agent 来复刻我们开头的视频，咱们只需要负责判断这个视频是否值得学习，Agent 负责拆解和执行，这个「Creator + Agent」 的双入口在行业里挺新的。

如果你想走 Agent 这条路，先去 Skill 地址安装 LibTV Skill，装好后就可以在支持 Skill 的 Agent 里直接对话。

Agent Skill 在这里可以下载：https://github.com/libtv-labs/libtv-skills 

我直接把这个地址给到了我的 Codex，让它直接帮我去安装完成。

然后去 LibTV 获取自己的 Access Key 填入即可。

接下来最简单的说法就是：上传参考视频和产品图，然后告诉它「参考这个视频，帮我的产品生成一支同风格广告」。

它会自己拆脚本、规划分镜，再把节点和提示词配出来，然后最后会把生成的结果放到画布里面。

当然了，如果要做好复刻爆款视频这件事，把参考视频上传到 LibTV 画布里，选中「脚本」节点，然后在写脚本的时候可以指定更换的人物或者环境。

我同样拿了一个爆款视频素材来做参考，通过脚本拆解和分镜、人物风格描绘后，生成出来的质感就完全不一样了。
