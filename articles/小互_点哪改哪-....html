那么什么是 Touch Edit 触控编辑呢？

先说下大家都懂的几个AI图像编辑的真实痛点，当AI图像生成后，我们想：

❶ 改一个局部，要重跑整张图

换光、换背景、换脸、换字，只要动一点，
模型就会给你一张“完全不认识的图”。

❷ 参考图永远是摆设

你丢十张 moodboard 给模型，它更像在“吸风格”，
根本不理解你真正想借用的是哪一部分。

❸ 多轮修改基本都是“越改越坏”

尤其是做多页长图、封面、竖版信息流的时候。
第一版很好看，第二版就开始跑偏，第三版直接崩掉。

你我都知道这是模型的问题：
它没办法知道你真正想改哪里，也记不住你已经改过什么。

那么Touch Edit 到底是什么？

就让我演示下给你看，给你展示下，一开始我那张图是怎么生成的

首先我们上传三张照片：分别是小互我、马斯克和特朗普

然后你们会看到图像上有 1、2、3、4、5 几个数字编号↑

在lovart 里面

在任意图片上 cmd+click（Mac）/ ctrl+click（Windows）

就可以选中图片上的任意部分，作为参考

它会自动识别你选择的区域是什么

它会 自动识别画面结构、物体关系、布局，可以精准定位（自动选择是“女头发”还是“头部”

如果元素过多，你可以通过下拉选择相应的元素

像这样

选择你需要的元素后，下面就是见证奇迹的时刻了

你只需要按照你想要的任意组合即可随意组装你的要的图像了

就像排列组合一样

比如这样↓

就会生成我一开始的图像

然后我们换个组合

它就会是新的组合 哈哈哈哈

Touch Edit 它能精准理解你点的“是什么部分”

你点人物的头发，它知道是“头发”，

你点人物脸，它知道是“头部”，

你点背景灯，它知道是“光源”。

不是那个“糊出一坨”的传统 inpaint，

是完全理解画布里每一个元素关系的那种工具。

是不是有点神奇...

所以 Touch Edit 其实 一个能“理解整个画布”的智能编辑系统，支持：

  • 精准选区
  • 多图融合
  • 复杂场景改动
  • 文本识别与改字
  • 参考图风格、构图、姿势的点选式抽取
  • 不破坏整体布局的局部修改

其根本意义：
你不再需要想 prompt 怎么写 → 直接点画面即可。

总结一下

优点与不足：

优点

✔ 局部修改不破坏整体，体验很丝滑，自由度很高
✔ 不满意依旧可以进行多轮修改，仍然保持一致性
✔ 参考图真正变成“零件库”，你可以随意从任意图像中取零件
✔ Touch Edit 触控 编辑 + 之前的分层编辑大幅提高了图像编辑可控性
✔ 与 NB Pro 的结合非常丝滑

不足

✘ 初次使用需要适应下，有时候选不中识别不了，但其实是选中的
✘ 存在一定的失败率，但是在可接受范围，基本一轮对话即修正
✘ 极端复杂的文字排版有时候不好识别，比如大字母或者分很开的标题
✘ 多人脸一致性虽好，但不是 100%

以前我们是在对着一个模型说话，
它努力理解，但永远隔着一层“误会”。

现在有了 Touch Edit，
我们终于能在一张图上
像正常人一样
指哪里，就是哪里。
想怎么改，就怎么改。
