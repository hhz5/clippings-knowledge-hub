视频详情

但是一开始让我感兴趣这个开源项目的，是做这个产品的人，OpenClacky 产品创始人是李亚飞，2014 年开始创业，十年连续创业者。

早期他是 Ruby 深圳社区发起人，后来创办 ShowMeBug，做技术面试和编程测评平台，拿到红杉中国、高瓴等机构近亿元 A 轮融资。

到了 AI 这一轮，他和团队是国内较早进入 AI 编程赛道的一批人，从第一代试 RAG，到第二代做云端多 Agent，再到第三代回到单 Agent 用 Ruby 从零重构。

谁能想到经过两年三代架构迭代，最后把「省 Token」做成了产品的**第一性原理。**

所以在我刚刚构建的这个项目过程中，发现它在整个交互过程中很明显的透出了关于 Tokens 用量的表达。

在这个开源项目里面，站在业务视角看的几个核心能力，像 Token 的消耗、是否开源、模型自由切换、技能和自我迭代能力、以及 IM 通信工具的集成接入，在整体上它都胜于其他几个框架。

对于 OpenClacky 这个项目的他说的一句话我是真的感受到满满的实干家感：

"Clacky 来自敲键盘的声音，就是一个在电脑上帮你自动敲键盘的 Agent。"

没有画超级智能的饼，很实在的就是帮我能够多干点活。

我尝试去下载的时候，在它的网页中直接装的过程让我有点意外，直接下载双击安装包，完事，没有 Docker，没有 Gateway，没有配置指南，安装完成就可以直接运行了。

之前像 OpenClaw 折腾别的 Agent 光环境就能劝退一半人，我自己的很深的感触就是：用别的产品天天在折腾怎么装，现在是用 OpenClacky 直接安装就能开始把 AI Agent 养起来。

但是为什么说这个 OpenClacky 会被投资人看中呢，它的核心就是咱们刚刚提到的，它是真的比其他 AI Agent 框架会更省 Token。

官方自己公布过一组 Benchmark 数据，用三个真实工作场景任务做横评，同 Prompt、同模型、同 Skill、同时间段，测了四家 Agent，同样的任务做出来效果差不多，但是成本差距还是挺大的。

OpenClacky 总成本 $5.10，Claude Code $5.49，OpenClaw $15.70，Hermes Agent $30.14。

请求数分别是 51、70、81、218，核心工具数分别是 16、40+、23、52。Cache 命中率分别是 90.6%、95.2%、88.7%、60.3%。

总账单是 Hermes 的 1/6、OpenClaw 的 1/3，比 Claude Code 还低。

到底真的能够省 Token 吗？看到这组数据后带着这个疑惑，我就直接自己也去实测了下。

我按照官方提供的这个 Prompt 模板，然后按照官方一模一样去直接输入整个提示词，最终得到了下面的这个效果。

在这个官方提示词里面也是这个是用到了 @歸藏 老师的PPT Skill，能够做出在 PPT 上视觉呈现相当美观的结果。

视频详情

我自己实际测试下来，甚至比官方给的数据里面还要更省一些，49个步骤总共花费了我 $0.9373。

在数据测试下来 OpenClacky 官方也承认，确实 Claude Code 这种在部分任务上的 Cache 命中率更高，OpenClaw 在某些场景请求数更少，但对于用户最终看的是总账单能省下来，靠的是几个具体的工程选择。

所以我就更好奇它是怎么省下来这些 Tokens 的呢？

我仔细的研究了一下官方提供的技术报告，OpenClacky 把核心工具压到 16 个，像我们也知道，之前OpenClaw一上来默认就给你装了一大堆的核心工具，工具越多，每次请求都要带更重的 schema，没用到的工具也在上下文里消耗 Token。

OpenClacky 这种设计方式，就把很多长尾能力交给 Skill 按需调用，并且两个自进化的钩子，能够在需要的时候去沉淀成合适的Skill。

它在空闲期自动压缩上下文，我去喝杯咖啡回来，它不会把之前的长对话原封不动塞回去让我买单，甚至还有 BYOK 模型路由，复杂任务用强模型，简单任务用便宜模型。

单次便宜是一回事，更大的变化是，我现在敢全天开着它了，并且不断的给它分派一些定时任务，比如早上让它去搜索一些来自 X 的情报数据，因为它内置了浏览器，它会自动的唤起浏览器来干活。

再比如中午的时候，直接让它从网页里抓一些我关心的数据整理成表格，然后直接发送到我已经绑定好的飞书里面，当然它也支持像微信、钉钉、Discord等通信工具的快速接入。

每次开口之前，我不再下意识想这次会不会又烧掉一大笔Token呢？。

同时如果我再集成像阿里云百炼大模型平台这种 CLI for AI Agent 框架的能力，一键安装完成后，一样能快速兼容。

在 OpenClacky 里面可以直接一键调用全模态的模型能力，我让 OpenClacky 帮我去生成一张3:4的猫咪图，然后再改风格，再改成海报，再加海报文本等等一系列操作，让我随时随地都可以办公或者整活。

甚至在 OpenClacky 里面用一句话：“让这只猫咪动起来”。

我们就能直接得到下面这只猫咪的视频。

视频详情

OpenClacky 就真的越来越好用，非常方便实用。

李亚飞有句话说得挺准：“如果每次让它干活之前你都要先想一遍会不会烧钱，那它就不是个人助理，只是一个昂贵的临时工。”

用了两个月之后，我开始琢磨一个问题：为什么这个拿了近亿融资的团队，还是会愿意选择去做一个「帮人省钱」的工具？

李亚飞的判断很直接：AI Agent 的下半场，谁能让人用得起，谁就赢了。

“中国程序员再多也不过千万级别，真正的行业工作者是几亿人。”

顺着这个判断，OpenClacky 做了一件有意思的事：把 Skill 放在产品核心位置。

比如可以把审查合同的经验封装成 Skill，财税顾问可以把报税流程做成 Skill，HR 可以把面试评估方法变成 Skill，然后通过 OpenClacky 分发、更新、售卖。

他们已经有一个真实案例，一位创作者做了「青狮龙虾」，把 16 个 Skill 打包在一

起，卖了很多单。

李亚飞说他们想做创作者的「技术合伙人」。

创作者提供行业经验，OpenClacky 提供技术底座，三七分成。

“创业就是不断寻找自己的位置。我不需要把品牌打得全球都知道，我更希望默默成为更多伙伴背后的力量。”

这话让我想到身边不少专业人士，律师、医生、财务顾问、培训师，积累了十年二十年的经验，但这些经验一直锁在脑子里，然后可以直接在 OpenClacky 里面去推广售卖自己的「经验 Skill」。

视频详情

如果 Skill 真的能成为新一代软件的形态，那每一个有行业认知、愿意折腾、敢站出来的人，都可能成为一个微型 SaaS 的创始人，而这些人不用会写代码，不用融资，不用组建团队。

我相信红杉和高瓴投的，应该是在押这个方向：未来每个专业人士都可以沉淀经验，Agent 负责执行，用户按场景购买一个更懂自己行业的 AI 助理。

回到我自己，用了一段时间后，最大的感受是它改变了我对 AI 工具的使用心态。

以前叫 Agent 干活总有一种「用完赶紧关」的心理，现在是开着就开着，有事就让它干。

我现在已经把它当成了日常工具，如果你也有类似的「AI Agent 焦虑」，确实可以体验试试看。

官网 openclacky.com，GitHub 搜 clacky-ai/openclacky，一键安装，macOS、Windows、Linux 都支持。

省下来的 Token 钱是小事。

我真正高兴的是，终于不用每次都小心翼翼的算账了。
