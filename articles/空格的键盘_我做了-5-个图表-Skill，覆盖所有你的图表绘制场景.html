1. text-logic-diagram：文字转为逻辑图

这个 Skill 解决的问题是配图。我经常写完一篇文章，想用图表把逻辑关系可视化。但架构图 Skill 只能画系统组件，画不了概念之间的递进、循环、对比这种抽象关系。

所以我就做了这个。

它支持 6 种逻辑关系：递进、流程、循环、层次、对比、矩阵。

你丢一段文字给它，它先分析文本的逻辑结构，然后判断每一段适合用哪种关系图来表达，生成多张 SVG 图。

**案例：**上周分析 Anthropic 那篇 "Building Effective Agents" 博客，我把五种 Agent 工作流模式的文字描述丢进去，它自动拆出了三张图——一张递进关系图（从提示链到自主 Agent 的复杂度阶梯），一张对比图（工作流 vs Agent），一张循环图（Agent 的 OODA 执行循环）。

地址：github.com/zephyrwang6/draw-skill/tree/main/text-logic-diagram

2. architecture-diagram：系统架构图

这个参考了一个 GitHub 开源项目：github.com/Cocoon-AI/architecture-diagram-generator

我把它的样式进行了优化，并改成了中文。

现在支持 8 种组件类型的语义化配色。双主题切换。深色模式科技感拉满。

点一下右上角按钮切到浅色模式，贴到文档里一点不突兀。

调用时候说：画一个 AI 客服平台的微服务架构图

然后它会问你几个问题，确认后生成一个独立 HTML 文件，浏览器直接打开，截图就能用。

**案例：**同样是 Agent 那篇文章，我说「画一个 AI Agent 工作流架构图」。

它把五种模式（提示链、路由、并行化、编排-工作者、评估-优化）全部画在一张图里，底层是增强型 LLM，顶层是自主 Agent 循环。

3. mermaid-generator：Obsidian 里直接画

有时候我不需要精美的 HTML，只需要一段 Mermaid 代码。

在 Obsidian 里、飞书里就能直接渲染，不用打开浏览器，不用截图。轻量、快速、够用。

这个 Skill 支持三种 Mermaid 图表：流程图、序列图、类图。

只需要说：把这个转为流程图：用户打开页面、浏览商品、加入购物车、结算支付

4 . chart-craft ：35 个通用图表

这两个是通用的图表生成器。

chart-craft 是基础版，支持 10 种图表类型，覆盖最常见的场景：流程图、架构图、ER 图、商业模式画布、用户旅程图、思维导图、竞品分析、SWOT、产品路线图、组织架构图。

chart-craft-plus 是增强版，直接扩展到 35 种图表，5 大类别：技术架构、流程逻辑、业务战略、数据可视化、信息展示。

新增了桑基图、漏斗图、热力矩阵、OKR 对齐树、甘特图、C4 模型、威胁建模图、BPMN 图等等。

两者的共同特点：

三种内置风格：黑白简约（Notion 风）、深色暗调（科技感）、Claude 暖色（默认）。

还支持品牌风格扩展，说一句「Stripe 风格」，它会自动去拉设计规范，应用到图表里。

全部输出为独立 HTML 文件，无外部依赖。截图清晰，打印友好。

**案例：**用 chart-craft-plus 的 Claude 暖色风格，给 Anthropic 那篇 "Effective Harnesses" 做了一张「四种失败模式」对照图。

无限循环、发散偏移、环境破坏、上下文丢失，每种失败模式左边写症状、右边写 Harness 对策。暖色卡片式布局，贴到文章里信息密度高，看着也不累。

地址：github.com/zephyrwang6/draw-skill/tree/main/chart-craft-plus
