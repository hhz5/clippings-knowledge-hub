AI 工具怎么选？看这一篇就够了

原创 空格 zephyr 2026年1月7日 14:07

我在 AI 行业三年多了，每天都泡在各种 AI 工具里。

但说实话， 我自己也经常懵 。

上周有个朋友问我：「我想做个小程序原型，该用什么工具？」我脱口而出说 Claude Code，结果他折腾了两天装环境、配 Node，最后跑来骂我。

其实他应该用 V0，10 分钟就能看到效果。

还有就是最近因为 claude code 用的比较多，一些普通简单的对话，也会在 CC 里进行

但是这效果不如 Gemini、chatgpt、豆包好，至少它们是可以长久记忆你发的所有内容的。

这些事让我意识到：工具太多了，连我这种每天用的人都不知道怎么用了；

所以我决定写这篇文章，把我试过的工具、总结出来的经验，一次性说清楚。

一方面梳理自己在用什么，另一方面给大家做一个AI 工具的科普和推荐。

我把工具分为下面几大类型：

但要先说个前提：你不需要那么多工具

打开 公众号、X、小红书，每天都有人喊「又出神器了！」「不用就落后了！」

我的工作台上常驻的 AI 工具就那么几个。

工具焦虑是假的，解决问题是真的。

这九大类工具，你可以看看分别是什么，

每个类型下的主流产品是什么，技术逻辑是啥。

不需要真的去用，就当是理解这个行业也足够了。

一、AI Chatbot

如果你只能用一个 AI 工具，那就是它。

ChatGPT、Claude、Gemini、Kimi……这些都属于「对话式 AI」。你问它问题，它给你答案。简单粗暴。

我个人的使用习惯是， 日常问答用 Gemini（因为手机 App 最顺手），写长文章或者分析复杂问题用 Claude（它写东西真的更「像人」），查实时信息用 豆包（自带搜索，不用担心信息过时）。

国内的话，Kimi 读长文档很强，豆包的语音对话体验不错。

这类工具是一个 AI 全家桶， 能多模态输入和输出 ， 想到什么就问什么。

Poe/monica 聚合多个模型，一个入口用所有 AI

二、Research Agent

当你需要的不是「一个答案」，而是「一份深度报告」时，普通 Chatbot 就不够用了。

Research Agent 会自己去网上搜索信息、阅读多个网页、整理和分析内容，最后生成一份结构化的报告。它不是「回答问题」，而是「帮你做调研」。

以前你要花几小时甚至几天搜索、阅读、整理资料。现在 AI 可以帮你完成 80% 的工作。

Manus 是「全自主 AI Agent」的代表，能自己打开浏览器、执行代码、操作文件，但还在邀请测试阶段，普通人用不上。

Genspark 我用得最多，它同时调用好几个 AI 模型来做研究，能生成视频、网站、PPT，甚至能帮你打电话。免费额度也够用。

ChatGPT Pro 用户有个 Deep Research 功能，会花几十分钟深度研究一个问题，生成带引用的长篇报告。但 200 刀一个月，太贵了，我没订。

国内平替可以用 秘塔 AI 搜索做得不错，搜索结果干净，来源标注清楚，没有广告。

当你要了解一个新行业、研究竞争对手、整理某个话题的资料——总之，任何需要「大量搜索+阅读+整理」的工作，都可以先让 AI 跑一遍。

可选产品

产品 特点
Manus 适合复杂的数据分析和深度研究任务
Genspark 「混合多 Agent」架构，同时调用多个 AI 模型
OpenAI Deep Research ChatGPT Pro 用户专属功能
Gemini Deep Research Google 的深度研究功能，和 Google 搜索结合
Perplexity Pro 带搜索的深度问答，来源标注清晰
秘塔AI搜索 专注搜索+总结，无广告，来源清晰
Kimi 探索版 能阅读网页和文档，做深度分析

三、CLI Agent

这是我用得最多的一类工具，也是对我工作改变最大的一类。

以前我写代码，是打开编辑器，一行一行敲。现在我用 Claude Code，是打开终端，用自然语言描述需求，然后看 AI 自己写、自己测、自己改。

目前最强的是 Claude Code 。Google 刚出了 Gemini CLI，免费额度多，但能力还差点意思。OpenAI 的 Codex CLI 也不错。

但这类工具门槛最高 ——你得会用命令行终端，得理解基本的编程概念。如果你是纯小白，这类工具暂时用不了。

官方文档在这：https://docs.anthropic.com/en/docs/claude-code

可选产品

产品 特点
Claude Code 目前最强的 Coding Agent
Gemini CLI Google 出品，免费额度多，开源
Codex CLI OpenAI 出品，开源，可用 o3 模型
Aider 开源工具，支持多种模型
智谱 GLM-CLI 智谱出品，中文代码理解好
通义灵码 CLI 阿里出品，和阿里云集成

使用场景

- 从零写新项目 ：描述需求，AI 帮你搭建项目结构和代码

- 写文章/文档 ：Claude Code 也能帮你写文章、整理笔记

- 批量修改代码 ：重构、重命名、格式调整

- 自动化任务 ：写脚本处理文件、数据

四、AI-IDE

如果说 Claude Code 是「你说需求，AI 全权负责」，那 Cursor 就是「你和 AI 一起写代码」。

Cursor 是一个代码编辑器，内置了 AI 能力的 VS code。你写代码时，AI 实时给建议；你选中一段代码，可以让 AI 帮你改；你遇到报错，可以直接问 AI 怎么修。

我的使用习惯是 ：写新项目用 Claude Code（从零开始让 AI 搭架子更快），维护老项目用 Cursor（改 bug、加小功能更方便）。

Cursor 现在是最火的 AI 编辑器，$20/月。Windsurf 便宜点，$15/月，界面更干净。GitHub Copilot 是老牌选手，$10/月起，和 GitHub 集成好。

国内有通义灵码和 CodeGeeX ，都是免费的 VS Code 插件，中文支持友好，可以先试试。

这类工具的门槛比 Claude Code 低一点——你需要会写代码，但不需要会命令行。

- 学习新技术 ：写代码时 AI 解释语法和概念

- 日常开发 ：写任何代码时的效率工具

五、Prototyping Agent

开头那个故事：我朋友想做原型，我让他用 claude code，结果他折腾了两天。

其实他需要的是 V0。

V0 是 Vercel 做的，你用自然语言描述「我想要一个 xxx 界面」，它直接生成可以运行的网页。不需要装任何环境，不需要懂任何框架，在浏览器里就能完成。

类似的工具还有 Bolt.new（能做全栈应用，带数据库）、Replit Agent（在线 IDE，支持各种语言）。

这类工具特别适合 ：

  • 有个想法想快速验证
  • 给客户/投资人演示产品概念
  • 非程序员想做个简单网站

可选产品

产品 特点
V0 专注前端 UI 生成，效果最好
Bolt.new 全栈应用生成，前后端+数据库一起搞定
Youware 代码开发、托管和部署
Replit Agent 在线 IDE + AI，支持 50+ 编程语言
Lovable 对话式生成完整应用
Create.xyz 文字描述生成网页应用
Google AIstudio 谷歌生态集成，体验友好

使用场景

- 验证想法 ：快速做一个原型看看效果

- 做 Demo ：给客户或投资人演示产品概念

- 学习开发 ：通过 AI 生成的代码学习前端技术

- 个人项目 ：做一些简单的个人工具或网站

学习难度低，不需要部署，但理解代码会帮助你更好地调整结果。

六、Design Agent

我经常需要做设计——产品原型图、公众号封面、社交媒体海报。

以前我用 Figma 慢慢拖，或者找设计师帮忙。现在我会先让 AI 出一版，再自己调。

Lovart 是我最近在玩的 ，号称「第一个 AI 设计 Agent」。你给它一个需求，它能生成一整套品牌视觉——logo、社交媒体图、海报，而且风格统一。还在 Beta 阶段，但已经很惊艳了。

Figma 自己也加了 AI 功能，能生成布局、自动写文案、搜索素材。如果你本来就用 Figma，直接用它的 AI 功能就行。

其他选择 ：Galileo AI（被 Google 收购了，改名叫 Stitch）、Canva Magic Studio（适合非设计师）、Midjourney 和 DALL-E 3（做设计素材）。

国内有即时 AI ，和即时设计集成，中文友好。

可选产品

产品 特点
Lovart 号称「第一个 AI 设计 Agent」
Figma AI 内置在 Figma 里的 AI 功能
Galileo AI (Google Stitch) 文字生成 UI 设计，已被 Google 收购
Canva Magic Studio 适合非设计师，操作简单
Midjourney 图像生成，适合做设计素材

使用场景

- UI/UX 设计 ：快速生成 App 或网页界面

- 营销物料 ：海报、banner、社交媒体图

- 品牌设计 ：logo、视觉系统

- 设计灵感 ：不知道怎么设计时，让 AI 给你几个方向

上手难度不高，关键是学会描述设计需求——颜色、风格、情绪、用途。

七、Video Agent

这是最「科幻」的一类工具。

你输入一句话，制作真的视频，有运动、有光影、有镜头切换。

Sora 是目前画质最好的 ，OpenAI 出品，但只对 ChatGPT Plus/Pro 用户开放。Runway 是老牌玩家，生成速度快，质量稳定，适合内容创作者日常用。

可灵（Kling）是国产之光 ，快手出品，全球领先水平，运动效果特别好，能生成 2 分钟的视频。字节的即梦和剪映集成，用起来也方便。

我的体验是，目前 AI 生成的视频还不能直接商用（细节经不起推敲），但做创意 demo、社交媒体内容、产品演示已经够用了。

再给它一两年，影视行业会被颠覆。

可选产品

产品 特点
Sora（OpenAI） 目前画质和真实感最好
Runway 生成速度快，质量稳定
Kling（可灵） 字节跳动出品，运动效果好，能生成 2 分钟视频
Veo（Google） 画质极高，但还在测试阶段
Pika 社区活跃，迭代快
Hailuo AI 免费额度多，适合入门
可灵 (Kling) 快手出品，全球领先水平

使用场景

- 社交媒体内容 ：短视频、创意广告

- 产品演示 ：展示产品功能和效果

- 故事讲述 ：把文字故事变成视觉内容

- 创意探索 ：验证视频创意，制作 demo

上手难度不高，主要是学会写好「视频提示词」——描述画面内容、运动方式、镜头角度、风格。

八、Music Agent

用文字描述你想要的音乐风格和内容，AI 直接生成歌曲——包括旋律、编曲、人声。

AI 学习了大量的音乐数据，理解不同风格的特征、歌曲的结构、和声的规律。

Suno 是目前最容易上手的 AI 音乐工具。你输入「一首轻快的电子音乐，适合科技类播客开场」，它能生成带旋律、带编曲、甚至带人声的完整歌曲。

相信大家也刷到不少AI 唱歌的视频了吧。

Udio 这款做的也不错，音质更专业，适合追求高品质的用户。

这类工具特别适合：视频配乐、播客片头、广告背景音乐、甚至「我就是想听听 AI 怎么唱我写的歌词」。

可选产品

产品 特点
Suno 最容易上手的 AI 音乐工具
Udio 音质更专业，适合追求高品质的用户
Stable Audio 适合做背景音乐和音效
MusicGen（Meta） 开源免费，适合开发者

使用场景

- 视频配乐 ：给短视频、vlog 做背景音乐

- 播客片头 ：制作个性化的开场音乐

- 创意表达 ：把想法变成歌曲

- 商业用途 ：广告配乐、品牌音乐

第九类：语音/音频助手

最后一类是语音相关的工具。

ElevenLabs 是这个领域的王者 。你可以用它生成各种语音——播客旁白、有声书、视频配音，音色自然到分不出真假。更厉害的是，你可以用几秒钟的音频「克隆」一个人的声音，然后让 AI 用这个声音说任何话。

其他选择 ：OpenAI 的语音 API 也很强，Google 的 TTS 免费额度多。国内讯飞语音是老牌玩家，中文效果不错。还有橘子老师做的 lisenhub 也值得用。

使用场景 ：做有声内容、给视频配音、做播客、开发语音助手产品。

ElevenLabs 官网：https://elevenlabs.io

最后

每周都有新工具出来，但核心能力差别不大。与其什么都试一遍，不如把一个工具用熟。

AI 能放大你的能力，但它不能替你思考。得知道自己要什么，AI 才能帮你更快地得到它。

用了 AI 工具，无非是效率高一点。这不是必需品，是增强剂。
