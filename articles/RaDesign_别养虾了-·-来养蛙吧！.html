大家好，今天介绍一款无需部署，打开即用的 Ribbi 产品，运行在浏览器环境中，不需要获取系统级权限，也不会访问用户本地文件或敏感数据，用户只需要打开网页即可开始使用。

Token 消耗

自从安装完 “🦞” 用户最关心的无非两项，一是是否安全，二是这玩应倒地要消耗多少 token ，在实际使用 AI Agent 处理任务时，模型通常要来回调用多次，token 消耗也就随之增加。

在同等类型的任务下，Ribbi 的 token 消耗比 “🦞” 减少了大约 73%，因此在长时间运行任务时，用户的整体成本会显著下降。

地址：https://ribbi.ai/home

究竟能做什么

有很多人一直在问 “🦞” 倒底能做什么，同样这个问题也适用 Ribbi，它本质是替你执行事情、串联流程，也就是取决于你工作中的 工作流程 是什么样的。

比如：写内容找 ChatGPT 、做稳定的图像找 Nano Banana Pro、生视频找 Seedance 2.0 、配音翻译找 ElevenLabs、做设计找参考图等等...

在 Ribbi 输入框里使用 “@” 选择工具组合你的工作流程，使用 “/” 选择适合的技能。

1.设计风格提取

作为设计师来说，每天都会看大量的参考，现在更是唾手可得，像最老牌的设计社区比如：behance、dribbble、站酷、UI中国等行业内的设计发源地，前辈们/大厂的设计交互总结与审美各有千秋「我悄悄的用 behance 以外的参考链接，只要在这个模式下也是可以的」。

看到好的创意我们可以用 Ribbi 丢个参考链接进行 IP参考 直接出图。

· 进入首页，选择上方 “Generate” 在输入框输入 “@” 选择 Nano Banana pro 模型，并上传一张 IP 参考图进行风格统一生成「左侧 + 添加图像」。 

· 生成想要的图像后，将鼠标移动生成图像右下角显示 “ 引号，为引用该图像。

· 在输入框里输入 “/” 找到 behance 链接转设计 并选择上，附上你所找的链接参考和提示回车等待即可。

提示：「生成的图像」「behance 链接转设计」「链接」分析 Behance 作品链接，提取设计风格、配色、版式等关键元素，结合生成的大熊猫IP形象，帮我做一套完整的IP方案。

Ribbi 回复的倒是挺幽默... 觉得没问题让他按上方的规划生成，等待中...

确实屌，就是我记得熊猫是毛茸茸的，我让他重新生成。

还有些文字上的瑕疵，这个后期修改掉即可「注意：我这里只作为演示，请勿抄袭」。

2.电商产品图

· 左侧选择 + 新建对话，在输入框里 “/” 选择 亚马逊产品图片集，上传产品图。

可以看到我并没有输入提示，让 Ribbi 根据分析，我进行选择就行了。

· 高级、够用，很强，我甚至让 Ribbi 把图像里的英文改成中文。

3.海报 Skill 制作

· 继续新建对话，“/” 选择 生成高审美的海报，上传参考图像「上传多张，我这里上传 3 张」，提示附上要求。

提示：「生成高审美的海报」「上传参考的海报」根据我上传的三张海报，请给我设计出一张相同风格有关 W 透明字母在海报中心的海报。

还算满意，但是 W 字母后面的文字需要修改一些。

W 字母也有些端正了，让它有些透视倾斜感会更好，跟它对话就好了。

· 感觉有些意思，我们在输入 “/” 选择 增强图片，引用最终图像，进行高清优化。

· 以上算是一个简单的海报流程，在输入框里输入 “帮我把以上流程做成skill”，方便以后直接输出。

我们实验一下，输入提示：现在生成一张有 R 字母的海报。

通过 @ 指令和 “/” 指令自由组合工具，即可创建出无数种可能性，保存后的Skill可以被重复使用、编辑和优化。

4.短视频复刻

· 我们可以回到首页，也就是 “Skills”  上方栏，在这里可以选择 复刻短视频 或者在输入框里 “/” 选择 复刻短视频 都可以。

· 这里依旧用 “/” 来测试，进行短视频复刻。复制参考视频 + 上传同类型图像「同类型图像还原更为准确」并附上提示。

提示：「复刻短视频」「视频链接」把这个视频的主题改成我上传图像 🎧，然后制作一个类似的视频。「上传的图像」

到这里我调整优化了两个版本，最终拾取两版最好的片段结合出视频。

觉得视频还可以，就继续在生成动感的音乐进行融合。
