实现原理

这里应用了 getdesign.md。感谢 Skill 开源氛围，让我不用自己去逐个拆解这些品牌的设计规范，DESIGN.md 已经把 62 个顶级品牌的设计语言整理成了标准化的 ：颜色、字体、字号层级、字间距、圆角、阴影，全部是精确数值。

我是怎么用的

最简单的用法，一句话：这篇文章做成 PPT

它会先问你两件事：要什么风格（给你 5+1 的推荐）、要什么格式（HTML / PPTX / 都要）。

如果你很明确，可以一步到位：

用 Stripe 风格把这份 BP 做成 PPTX，10 页

它就直接开工，跳过所有询问。看下我做的 PPT 效果。

整体运作是这样的：内容分析 → 风格匹配 → 拉设计规范 → 生成大纲（会给你过目一次）→ 逐页渲染 → 交付。

最早仅支持 HTML。但在职场上用得最多的还是 PPTX，并且 PPTX 支持修改。PPTX而是用 python-pptx 原生构建的，每一页都是真实的文本框和形状，你拿到手可以直接在 PowerPoint 里改字、换色。

如果你想给这个 Skill 换上自己公司的设计系统，也很简单。安装后直接说：

给这套 PPT Skill 加一个风格，参考我发的 PPT 文件（或截图）

它会把你公司的设计语言拆解成 token，加进风格库。

思维比方法重要

比 Skill 更重要的：让思维适应 Agent 式的 PPT 制作以前我做 PPT，要花大半天、甚至一周的时间去磨，比如各种季度、年度汇报。我自己是个完美主义者，会把样式、字词磨得很美观、顺畅。

但这忽略了 PPT 最大的作用：传达自己的思维。

它是在汇报演讲的时候，用视觉化的内容抓住听众注意力的工具。

所以最重要的是先做好表达的内容，其次才是 PPT。

我把 PPT 的制作分两种：一种是观点式的，一种是汇报式的。

对于观点式

制作最快的方式，就是口语化输入文字。既然想要表达，那你一定足够清楚自己要表达的观点。

先写个大纲，然后用语音输入法把观点说出来，语音输入是打字速度的 4-6 倍。

输入的内容磕磕绊绊也无所谓，都可以交给 AI 润色。

最后把这些内容做成你喜欢的风格的 PPT。整个过程，从想法到成品，快的时候半小时。

对于汇报式

汇报要汇总大量素材。拿年度汇报来说，通常要整理过去一年的产出、项目背景、项目结果、反思。去各种系统里拿数据是少不了的，这是最耗时间的部分。

整理好数据后，定义 PPT 的制作大纲。大纲就是每页的标题 + 结构化小标题。

把这些标题整理成一个表格。

然后让 Agent 结合你整理的数据，按表格的内容来输出——这时候你就有了汇报内容的结构化表达。

最后自己优化一遍这个表格，把它发给 AI，让它按你选的 PPT 风格输出成品。

人负责的是判断：讲什么、按什么顺序讲、哪个数据放大；

Agent 负责的是执行：排版、配色、格式。

用习惯了就再也回不去了。
