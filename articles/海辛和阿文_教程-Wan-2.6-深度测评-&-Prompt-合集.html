Hi 这里是海辛和阿文~

受通义实验室邀请，我们作为创作者参加了今天 Wan 2.6 模型发布直播。我们整理了直播中展示的所有案例和提示词，希望对大家有帮助！

总体而言，感受最深的两点：

1. 视频角色（starring）是个被严重低估的功能。

2. Wan2.6 对影视级分镜提示词的响应又进化了！

#1. 视频角色 Starring

视频角色是这次更新的重点功能，用户只需要上传一段5秒钟的视频参考（可以是人物/动物/虚拟角色/甚至是物品），就可以直接在视频生成中调用，生成质量不仅高清，连音色都能保留！

![[Pasted image 20251218153523.png]]

  人物角色  

我们以阿文本人为例，测试了人物角色。上传过程十分简单，对着镜头念一两句对白即可完成角色创建。

接下来我们就可以在 Wan 2.6 中召唤角色了：

Prompt: @Simon阿文 作为迅猛龙饲养员的日常，年度精彩时刻混剪

Prompt: @Simon阿文 在和平饭店喝可乐

Prompt: @Simon阿文 @SantaCyber 坐在一辆满载礼物的雪橇车中，被堵在车阵中央。四周汽车静止，雪持续落下。礼物箱轻微晃动，彩纸边缘沾着雪粒。@SantaCyber 猛地一甩鞭子，皮鞭在空中划出清晰弧线。驯鹿同时发力，雪橇前端抬起，车身脱离地面，飞跃静止的车流。

  动物角色  

除了创建人物角色，你甚至可以创建 动物角色。我们上传了一段我们家小猫尼卡的视频，虽然光线很暗，清晰度也有点低，但一点都不影响角色的创建。

毫不夸张地说，这是亲主人认证的生成质量：

Prompt:  和一群狮子一起长大的 @nika 的非洲生活日常

Prompt:  和一群迅猛龙一起长大的 @nika 的非洲生活日常

Prompt:  迅猛龙跳进人类的家中，解救被人类绑架的 @nika ，逃跑。

  物品角色  

最让我惊喜的是，你甚至可以创建一个物品角色。我们随手拍了朋友酒吧里的一杯酒，上传到 Wan。

然后直接让这杯酒出现在了爱因斯坦的手中：

可以想象，这个功能将会大大降低产品宣传片的生成难度，而且，还是1080P。

顺带一提，视频角色功能已开放 1080P 的 API，相信很快就能在各个优秀的第三方平台上用上。

#2. 电影级分镜

从 Wan 2.2 开始，Wan 系列就一直保持着对专业影视术语的高度响应，而这次升级，分镜能力又进化了。我们发现，模型原生分镜能力搭配专业的镜头脚本，可以让生成结果有质的提升。

下面这些案例建议搭配 Prompt 一起观看。

Prompt:

风格： 极暗背景 / 轮廓光 / 4K微距 / 极度丝滑

镜头脚本：

[极特写] 黑色背景中，大块可可豆被金属磨盘碾碎，粉尘飞舞。

[慢动作特写] 浓稠的黑巧克力浆像丝绸一样倒入搅拌碗。

[特写] 搅拌器高速旋转，带起巧克力漩涡。

[中景加速] 蛋糕在烤箱中快速膨胀（Time-lapse 延时摄影感）。

[特写] 刚出炉的蛋糕表面撒上一层细密的糖粉。

[极特写] 银色勺子挖开蛋糕，内部热气腾腾的巧克力岩浆流出，填满画面。

Prompt:

风格：古典油画质感 / 超现实幻想 / 细节丰富且奇异

镜头脚本：

[手持过肩跟随] 镜头紧跟在主角身后（过肩视角），伴随着轻微的呼吸感和晃动。他正跌跌撞撞地穿过黑暗潮湿的隧道，手扶着长满青苔的墙壁。 冲出洞口，镜头瞬间变稳并拉开。眼前是博斯画作般的超现实平原，粉色和蓝色的半透明玻璃塔高耸入云，色彩诡异而鲜艳。

[特写A] （快速切）一只巨大的、眼神深邃的猫头鹰栖息在扭曲的枯木上，头转过来直勾勾地盯着镜头。

[特写B] （快速切）一个巨大的红色草莓长着人类的双腿，正从画面左侧走到右侧，背上背着一个透明的玻璃球。

[特写C] （快速切）一条长着蝴蝶翅膀的蓝色怪鱼在低空滑翔，几乎擦过镜头，留下一串水珠。

[正面反打] 镜头切回主角正面（Reverse Shot）。背景是刚才那个奇异的世界。主角摘下兜帽，眼神失焦，嘴巴微张，彻底被眼前的景象震撼（保持轴线一致）。

Prompt:

风格：赛博朋克、机甲、特工 

镜头脚本： 

[特写] 一只手戴上充满了机械细节的战术手套，拉紧。 

[特写] 脚踏入一只重型机械靴子，地面尘土飞扬。 

[特写] 武器/道具（如光剑柄或手枪）卡入腰带的卡槽，发出咔嚓声。 

[极特写] 眼睛突然睁开，瞳孔中有数据流光闪过。 

[中景/全景] 主体摆出帅气的战斗姿态，背景是霓虹城市。

Prompt:

风格：伪纪录片 (Found Footage) / 噪点 / 蓝调 / 压抑 

镜头脚本： 

[固定镜头] 深夜的客厅，空无一人。一把摇椅突然自己剧烈地摇晃起来。 

[特写] 走廊尽头的灯泡发出滋滋声，忽明忽暗，然后猛然爆裂，玻璃飞溅。 

[中景] 电视机屏幕全是雪花噪点（Static noise），突然映出一个模糊的人影。 

[特写] 一只苍白的手猛地拍在玻璃窗上（从外向里）。 

[切黑 + 字幕] 画面瞬间切黑，屏幕中央出现鲜红的文字 "COMING SOON" 或 "RUN"。

Prompt:

风格：像 Nike 广告 / 高对比度 / 汗水与肌肉 

镜头脚本： 

[特写] 篮球鞋在木地板上急停，发出摩擦声。 

[极特写] 满是汗水的额头，眼神死死盯着上方。 

[慢动作] 球员起跳，手腕在最高点柔和地拨球出手。 

[追踪镜头] 篮球在空中划出一道完美的抛物线，背景是虚化的观众。 

[特写] 球刷网入框，网花翻起。 

[全景] 整个球馆的观众瞬间起立欢呼，彩带喷射。

Prompt:

风格： 波普点阵、RGB色差、强烈的漫画拟声词 

镜头脚本： 

[2.5秒] 孙悟空： 金甲红披风，挥棒瞬间定格，画面炸裂，金色字体 "WUKONG" 弹出。 

[2.5秒] 猪八戒： 赛博朋克风的壮汉（带猪鼻特征），扛着发光的九齿钉耙，背景是绿色波普圆点，字体 "BAJIE" 带着涂鸦感出现。 

[2.5秒] 沙和尚： 脖子上挂着巨大的骷髅念珠，水墨风格的蓝色流体围绕着他，铲子挥下，字体 "WUJING" 像水流一样凝固。 

[2.5秒] 唐僧： 圣洁的白衣僧人，身后有漫画线条组成的“佛光”，手持锡杖，神圣庄严，字体 "MASTER" 以极简几何风格出现。 

[5秒] 英雄合影： 四人背对背站立，仰视镜头，背景是绚丽的多元宇宙漩涡。
