核心交互设计为一个圆形的高亮光标，它会随着鼠标平滑移动并带有轻微的延迟感。这个圆形聚光灯充当揭示遮罩的角色，实时显现出底层隐藏的第二张人像照片 \[图片二\]。当用户移动光标时，感觉就像是在扫描照片的另一个维度。

如果你对六爻有任何不懂的地方，请主动追问我。

  

首先非常有仪式感，你算的也是对的，但我这里有几个修改意见：

1. 1\. 功能双语化：我希望现在所有的功能都是中英文双语的。比如“老阴”、“老阳”，不光要有英文，还要有中文。卦象最终的结果也要以中英双文呈现。

第四个案例，我们来挑战一下3D互动领域。

有了之前Claude Code和各种Skills的经验，我们已经知道AI已经能做一些简单的3D场景了。

但我想看看GLM5能不能做更复杂的粒子系统。这个系统能展示一个由几百个微小立方体组成的3D模型，并且能够通过点击按钮，让这个模型瞬间粉碎，变成受物理引擎影响的独立方块散落一地，然后再点击另一个按钮，让这些散落的方块平滑地飞回原位，重新组装成模型。

以后做3D就不需要做3D模拟宇宙了，在Claude Code里plan模式下，我roll了二十轮就能做出来这样的效果。

你是一位精通 Three.js、React 和 WebGL 的高级前端开发工程师。我要你做一个名为“Voxel Toy Box”的 3D 粒子交互系统。

  

场景与视觉描述： 这是一个基于 Web 的 3D 场景，背景干净整洁（类似于淡色渐变或白色），地面有一个接收阴影的平面。场景中心展示了一个由数百个微小立方体（Voxel 像素块）组成的 3D 模型（例如视频中的老鹰）。UI 界面漂浮在 3D 画布之上，左上角显示当前粒子数量（例如 923），右上角有暂停和分享按钮，正下方有一个醒目的交互主按钮。

  

核心数据结构： 模型数据基于 JSON 格式，每个粒子包含 {x, y, z, color} 属性。系统应该支持通过 JSON 导入导出模型布局。

  

核心交互逻辑（物理与动画）：

1. 构建状态 (Build Mode)： 初始状态下，所有立方体根据 JSON 数据静止在目标位置（一只鹰），组成完整的物体。
2. 粉碎效果 (Break Mode)： 当点击底部的粉红色“BREAK”按钮时，应用物理引擎（建议使用 Cannon.js 或 Rapier）。此时，原本静止的体素方块瞬间变成受重力和碰撞影响的独立刚体，并施加一个随机的爆炸力，让它们散落在地面上，模拟乐高积木倒塌的效果。
3. 重构效果 (Rebuild Mode)： 当粒子散落后，按钮变为绿色的“REBUILD”。点击后，禁用物理模拟，所有粒子应忽略重力，通过插值动画（Lerp）平滑地从当前的散落位置飞行回到它们原始的初始坐标 (x, y, z)，重新组装成原来的形状。
4. 多模型切换： 系统应具备菜单功能，允许用户在不同模型（如老鹰、猫、兔子）之间切换，或者重新利用地上的散落粒子组装成全新的形状（例如“Eagle x2”变成两个老鹰）。

技术栈要求： 请使用 React 配合 React Three Fiber (R3F) 进行开发。为了保证性能（处理 1000+ 粒子），请务必使用 InstancedMesh 来渲染立方体，并配合 use-cannon 或 @react-three/rapier 处理物理效果。请输出完整的、可运行的代码结构。
