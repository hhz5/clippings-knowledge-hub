二、Logo 批量生成 Skill

文章配图只是开始，同样的逻辑，换个场景就是 Logo 生成器。

这个 Skill 支持两种入口：

入口 A：文字描述， 帮我设计一个 AI 生产力系统的 Logo，科技感，紫色系

入口 B：上传参考图

丢一张喜欢的 Logo 给它，要求根据图片制作 logo，Skill 自动拆解：

  • 图形元素（什么形状、什么符号）
  • 色彩方案（主色、辅色）
  • 排版风格（字体类型、排列方式）
  • 情感调性（专业？温暖？前卫？）

然后问我："想要类似风格？还是保留某些元素改进？"

工作流：

  • 收集品牌信息 → 展示 7 种风格（极简扁平 / 线条艺术 / 渐变现代 / 徽章印章 / 吉祥物 / 字母标志 / 手写书法）
  • 根据描述推荐最适合的风格，我选择确认
  • 生成 10 个 Logo 变体的提示词：不同构图、不同配色、不同图标
  • 批量出图，保存到指定目录
  • 不满意的话，可以指定修改某一张重新生成

三、故事板 Skill：8 帧漫画

最近看着豆包、千问、元宝开始发红包，抢用户了，最受益的还是用户，紧跟热点，来制作一个拟人化的故事。

描述故事：豆包、千问、元宝三个 AI 产品拟人化，春节争抢用户，。元宝在微信发 10 亿红包，千问在淘宝送 30 亿奶茶，豆包认认真真给用户打电话。

发送描述后，Skill 做了这些事：

  • 润色故事线 — 补充叙事细节，梳理情感弧线
  • 拆分分镜 — 8 个关键帧，每帧标注镜头类型（远景/近景/特写）、画面描述、情绪基调
  • 选择风格 — 提供 8 种风格，根据故事推荐，我选了"黑白漫画卡通风"
  • 批量出图 — 8 帧全部生成，角色在每帧中保持一致

四、零门槛，创建你自己的生图 Skill

上面三个 Skill 都是我自己搭的。 但你完全不需要从零开始写。

我做了一个「生图 Skill 创建助手」—— 你只需要回答几个问题，它帮你自动生成一个完整可用的 Skill。

流程是这样的，输入和输出：

🤵 帮我创建一个生图 Skill

🤖 Q1：你想做什么类型的配图？→ 文章配图 / Logo / 分镜故事 / 社交媒体图 / 海报 / 数据可视化 / 角色设计

Q2：图片主要用在哪？→ 文章插图 / 社交平台 / 品牌用途 / 教学演示

Q3：每次大约生成多少张？→ 1-3 张 / 5-10 张 / 10+ 张

Q4：喜欢什么风格？→ 展示 5-8 个相关风格选项，带一句话描述

Q5：有参考图吗？→ 上传一张，助手自动拆解风格元素

Q6：色彩偏好？图片比例？文字规则？→ 快速确认

Q7：APIkey 和 API url 是什么

回答完这几个问题，助手自动生成：

  • SKILL.md（Skill 主文件，包含完整工作流）
  • references/style-guide.md（你选定的风格模板）
  • scripts/generate_image.py（图片生成脚本）

生成完毕，你说"帮我用这个 Skill 给批量出图"，它就开始干活了。这个 skill 真的无敌，输入一张图就能复刻成 skill，批量无限出图，token 上限就是创作上限。我做完之后就觉得很多产品可以退订了，我可以按自己需求自定义 skill，比如在 dribble 看到好看的原型图，仿照做 skill。

skill 下载： https://github.com/zephyrwang6/image-create-skills/tree/main/image-skill-builder

五、Skill 再多，不如一个系统

文章配图、Logo 生成、故事板、社交媒体图……这些 Skill 各自独立，但它们背后是同一套逻辑：

提示词 + API + 自动化流程 = 批量出图

单独用一个 Skill，解决了一个问题。把多个 Skill 串起来，结合你的上下文，就拥有了一个系统。

我现在的内容生产流程： 自动推热点→ 选题 评估 → 和 AI 协同写作 → 自动配图 → 自动排版 → 推送到草稿箱

这是我系统中的一个环节，Skill 是零件，系统是机器。

有了这个系统，知识管理、项目管理的理念在这里运行的更加顺畅了。

我收藏保存的文件可以自动同步到系统中引用在其他文章里，而不是在收藏夹吃灰，我拆解的项目任务，AI 会自动提醒，有些可以自主执行，给我降低行动的门槛。
