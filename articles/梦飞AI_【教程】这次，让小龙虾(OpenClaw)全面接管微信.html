以下为全流程部署龙虾微信 AI 机器人：OpenClaw + bot 全流程指南

不需要公网服务器，在自己电脑上就能跑起来一个能聊天、能回群消息的🦞小龙虾微信机器人。

这套方案能做：

私聊自动回复：好友发消息，AI 自动回复

群聊自动响应：AI 自行决定是否回复

支持多种大模型：火山引擎、OpenAI、Claude 等主流模型均可接入

无需公网IP：通过 WebSocket 长连接主动接收消息，整体架构如下：

微信用户发消息    
↓
云端虚拟设备（你的微信账号在云上登录）    
↓ 
OpenClaw 网关（本地运行）    
↓
大模型（火山引擎 / OpenAI 等）    
↓
回复消息 → 微信用户

三个核心组件：

准备工作

  1. 准备大模型 API Key

本文以火山引擎为例（也支持 OpenAI、DeepSeek 等）。

前往 火山引擎方舟控制台 创建 API Key，记录下来备用。

  1. 安装 Node.js

前往 nodejs.org 下载并安装 Node.js v18 或更高版本（推荐 v22/v24 LTS）。

安装完成后验证：

node --version  # 应显示 v18.x 或更高
npm --version

第一步：安装 OpenClaw  

打开终端（Windows 用 Git Bash 或 PowerShell），执行：  

bash npm install -g openclaw --ignore-scripts

必须加 --ignore-scripts，否则会因为 node-llama-cpp 的安装脚本报错

验证安装成功：

openclaw --version

第二步：注册账号

前往 openclaw-juhe 注册并订阅服务，具体见GitHub。

登录后台后：

1、进入「设备管理」→「设备列表」

2、点击「初始化设备」，选择登录类型（建议使用ipad不影响你手机正常使用微信）

4、下载「本地代理.exe」，运行后点击「启动代理」，复制客户端 ID

5、在后台粘贴客户端 ID，点击「设置代理并登录」

6、扫码完成微信登录

登录成功后，在设备详情里记录三个凭证：

appKey、appSecret、guid（设备 ID）

第三步：下载 openclaw-juhe 插件

git clone https://github.com/Hanson/openclaw-juhe.git
cd openclaw-juhe``
npm install --ignore-scripts --legacy-peer-deps`

记录下这个目录的完整路径，后面配置会用到（例如 D:\projects\openclaw-juhe）。

因为这里有一些限制操作，所以我更改了一部分代码：

第四步：修改插件代码

改动 1：允许所有好友私聊

打开 openclaw-juhe/src/bot.ts，找到私聊过滤的代码段：

改之前：

if (!isGroupMsg) {
if (!isContact(senderId, account)) {
log(`juhe: ignoring DM from non-admin user ${senderId}`);
return;
}
}

改之后：

// contacts 为空时允许所有人，否则按白名单过滤
if (!isGroupMsg) {
const hasContactList = account.config.contacts && account.config.contacts.length > 0;
if (hasContactList && !isContact(senderId, account)) {
log(juhe: ignoring DM from non-contact user ${senderId});
return;
}
}

改动 2：允许所有群消息

同样在 src/bot.ts，找到群消息过滤代码：

if (!isRoomAvailable(chatId, senderId, account.rooms)) {
log(`juhe: ignoring message from unconfigured room ${chatId}`);
return;
}

改之后：

// rooms 为空时允许所有群
const hasRoomList = account.rooms && account.rooms.length > 0;
if (hasRoomList && !isRoomAvailable(chatId, senderId, account.rooms)) {
log(juhe: ignoring message from unconfigured room ${chatId});
return;
}

改动 3：添加 WebSocket 心跳

打开 openclaw-juhe/src/monitor.ts，在文件顶部的常量处添加一行：

const WS_RECONNECT_INTERVAL = 5000;
const WS_MAX_RECONNECT_ATTEMPTS = 10;
const WS_PING_INTERVAL = 20000; // 新增：每20秒发一次心跳

在 ws.onopen 回调里，认证消息发送后添加心跳逻辑：

ws.onopen = () => {
// ... 原有的 auth 消息发送代码 ...
// 新增：启动心跳，防止服务器 45 秒后断开连接let pingTimer: ReturnType<typeof setInterval> | null = null;
pingTimer = setInterval(() => {
if (ws?.readyState === WebSocket.OPEN) {
ws.send(JSON.stringify({ type: "ping" }));
}
}, WS_PING_INTERVAL);
};

在 ws.onclose 回调开头清除心跳：

ws.onclose = () => {
// 新增：清除心跳
if (pingTimer) {
clearInterval(pingTimer);
pingTimer = null;
}
// ... 原有的重连逻辑 ...
};

juhebot 服务器大约 45 秒没有收到任何数据就会断开连接，加了心跳之后连接才能保持稳定。

第五步：配置 OpenClaw

首次运行 OpenClaw 会自动生成配置文件，位置在：

  • Windows：C:\Users\你的用户名\.openclaw\openclaw.json

  • macOS/Linux：~/.openclaw/openclaw.json

先运行一次让它生成配置文件：

openclaw gateway run

看到启动日志后按 Ctrl+C 退出

然后编辑 openclaw.json，添加以下配置（在现有内容基础上合并）：

添加火山引擎模型

在 models.providers 下添加：

"volcengine": {
"baseUrl": "https://ark.cn-beijing.volces.com/api/v3",
"apiKey": "你的火山引擎API Key",
"api": "openai-completions",
"models": [
{
"id": "ark-code-latest",
"name": "ark-code-latest",
"api": "openai-completions",
"reasoning": false,`      `"input": ["text", "image"],
"contextWindow": 128000,
"maxTokens": 4096
}
]
}

添加微信通道

在 channels 下添加：

"juhe": {
"enabled": true,
"type": "wechat",
"baseUrl": "https://chat-api.juhebot.com",
"appKey": "你的appKey",
"appSecret": "你的appSecret",
"guid": "你的guid",
"contacts": [],
"rooms": []
}

type：个人微信填 "wechat"，企业微信填 "wework"

contacts：留空数组 = 所有好友均可私聊；填入 wxid 列表 = 白名单模式

rooms：留空数组 = 所有群均可响应注册插件路径

在 plugins 下添加：

"plugins": {
"load": {
"paths": ["D:\\projects\\openclaw-juhe"]
},
"entries": {
"juhe": { "enabled": true }
}
}

设置默认模型

在 agents.defaults.model 下修改：

"agents": {
"defaults": {
"model": {
"primary": "volcengine/doubao-seed-2.0-code"
}
}
}

第六步：启动服务

openclaw gateway run

看到以下日志说明启动成功：

[juhe] juhe[default]: WebSocket connected
[juhe] juhe[default]: auth message sent
[juhe] juhe[default]: authentication success

用你自己的微信给机器人账号发一条消息，机器人应该会在几秒内回复。

在群里发消息，机器人会自行判断是否回复（可以通过 system prompt 设定回复规则）

常见问题

Q：安装时报错 "Invalid Version" 或程序崩溃

A：加上 --ignore-scripts 参数：

npm install -g openclaw --ignore-scripts

Q：WebSocket 每隔几分钟就断开

A：按照第三步改动 ，给 monitor.ts 添加心跳机制。

Q：私聊发消息机器人不回复

A：检查日志，如果出现 ignoring DM from non-admin user，说明 contacts 白名单限制了，按改动 1 修改代码。

Q：群消息不回复

A：检查日志，如果出现 ignoring message from unconfigured room，说明 rooms 配置限制了，按改动 2 修改代码，并确保 openclaw.json 里 rooms: []。

Q：发消息返回"协议不在线"

A：微信账号在 juhebot 云端掉线了，去 juhebot 后台重新登录。

Q：日志显示回复成功但微信里没有收到

A：检查日志里 to_username 字段，确认发送目标地址格式是否正确（个微群应该是 xxxxxxx@chatroom，不能有额外前缀）。进阶配置指定群和权限控制

如果只想让机器人在特定群里响应，在 rooms 里配置：

"rooms": [
 {
"id": "xxxxxxxxx@chatroom",
"requireMention": true,
"scope": "everyone"
}
]

群 ID 可以从日志里看到：received message from ... in group xxxxxxxxx@chatroom

配置项说明：

requireMention: true

需要 @ 机器人才回复

requireMention: false

所有消息都处理

scope: "everyone"

所有群成员

scope: "whitelist"

仅白名单用户自定义 AI 人设

在 openclaw.json 的 agents.defaults 里添加 system prompt，告诉 AI 它的角色和行为规则：

"agents": {
"defaults": {
"systemPrompt": "你是一个友善的助手，名字叫小助手。在群聊中，只有当有人直接向你提问时才回复，不要回复闲聊内容。"
}
}
