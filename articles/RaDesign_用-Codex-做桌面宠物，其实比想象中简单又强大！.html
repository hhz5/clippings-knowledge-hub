每次都是放假期间更新！！！五一那会 Codex 更新了一个特别有意思的小功能：Pets 桌面宠物。刚开始看到的时候，我其实没太在意。因为第一眼看上去，它就像是一个普通桌面小彩蛋。

不过我刚用 Codex 的时候，第二个项目就是想做一个桌面宠物，因为我也看不懂代码，AI中间在写的过程我也不想看，要是有个小窗口实时汇报进度，那就真的太棒了。现在我的项目又被暂停了🫣，因为 Codex 这波更新，分分钟就把我搞了快一周的进度碾压了...

开启宠物路径一：设置 — 外观 — 宠物 — 唤醒宠物

开启宠物路径二：直接在 Codex 的输入框打/，选择宠物即可唤醒或者收起宠物。

唤起宠物，可以与宠物进行互动，默认会在桌面右下角会出现一个小像素角色，可以拖动到桌面任意位置，鼠标拖住或者点击都会触发各种状态，挺有意思的。Codex 工作的时候它也会动，空闲的时候就待在那里挂机，有点像小时候电脑里的电子宠物、QQ宠物。

有了宠物后，你发起任务，就可以去干别的了，它会跟着 Codex 的任务状态一起变化，实时给你汇报进度和状态，也可以在宠物处和它对话来解决，如果你没时间立即处理，它会在宠物右上角将多条消息折叠起来，想看的时候直接点击展开就行。

如图，当 Codex 有正在跑的任务的时候，它会进入忙碌状态；任务完成之后会有动作反馈；空闲的时候则会进入安静待着。

这次更新的只是一个小功能，但是感觉总比之前一直看 Generating... Running...等结果要好的多。这种感觉就像这个AI助手开始 “存在” 了一样，就是那种不再是面对对话框，而是有个小东西在那里 “陪你干活” ，这个体验还挺微妙的。

等我额度恢复后，我第一时间就想去做一只体验一下，我也去看了大家都生成了哪些可爱的宠物，看看能生成什么风格的，然后发现大家脑洞真的很大，什么机械狗、像素猫、企鹅、幽灵、动漫主角……不过风格大体都是差不多的。

下面我们也来看看怎么简单快速的做一个自己的宠物，给还没有体验的小伙伴看下大体流程，以及能做到什么程度。

下图是目前官方已经给了几个默认角色，如果不满意就自己创建。

可以直接点击 创建自己的宠物，回到对话框，你会发现Codex 自动给你调用了一个技能，是 OpenAI 专门做的一个生成宠物的 Skill：

Hatch-pet

如果没有安装，在 Codex 输入框执行：$skill-installer hatch-pet 。

安装完成之后，Codex 就具备了生成宠物资源的能力。

到这里很多人第一反应基本都是：“那我直接一句话生成不就行了？”理论上确实可以。比如你直接输入：

帮我生成一个像素风小猫宠物

目前 Codex 宠物生成技能是自带一组状态动画的，包含：

  • idle：空闲中 / 待机状态
  • running-right：向右奔跑
  • running-left：向左奔跑
  • waving：挥手
  • jumping：跳跃
  • failed：失败 / 执行失败
  • waiting：等待中
  • running：运行中 / 执行中
  • review：审查中 / 复查中 / 代码审核中

如果不满意已有的，可以自己再补充，让 Codex 补充对应的状态。

这样简单描述生成出来的东西，还是多少有点“AI”味。很像那种素材网站会出现的角色。或者手游广告里常见的小 mascot。看上去没问题，但就是没有“角色感”。然后我也试过好几种描述词，后面发现，这样描述只是在描述形式，不是生成角色啊，换句话说，你这样生成，在Codex 看来就是：

“给你一个最常见、最保险的猫咪形象。” 起码不会出错，因为你描述的太模糊了，生成的宠物只能是特别普通的。

但如果你换一种方式。

比如：

生成一只长期陪伴程序员工作的像素小猫，平时安静挂机，
Codex 工作时开始敲代码，
任务完成后会挥手，
整体风格参考独立游戏角色，不要太二次元，颜色控制在低饱和范围。

结果会一下好很多。因为你这样描述，它会包含：

  • 世界观
  • 使用场景
  • 性格
  • 工作状态
  • 动作逻辑
  • 审美方向

总之就是，能描述的越详细越好，生成宠物最重要的是：设定。

我现在最常用的 Prompt 写法

  • 角色身份
  • 使用场景
  • 工作状态
  • 风格方向
  • 动画要求
  • 审美限制
帮我生成一个适合 Codex 的桌面宠物。

角色是一只长期陪伴开发者工作的像素风小猫。
平时安静待机，在 Codex 执行任务时进入工作状态，
任务完成后会有轻微庆祝动作。

整体风格参考独立游戏角色，
避免过度二次元，
不要手游素材感，
颜色保持低饱和，
轮廓清晰，
适合长期桌面陪伴。

需要包含：
idle 状态
工作状态
完成状态
思考状态

背景透明

这种写法也不会很复杂，好处就是最后生成出来的东西，会稳定一些，稳定在宠物的状态和动作会更完善，比如你生成的是小人，但是默认可能只有往左跑的东西，但是如果完善一点，它会具备更全面的动画状态。但是换个角度，说白了差别也不会特别大，想要完全定制化最好就是自己先去Image2 生成对应的系列图，然后再拿过来生成，因为直接在Codex 里面生成的效果还是大体风格都是这样的。

生成完成后就会在自定义宠物里面出现，直接选择即可。

这个功能最强的不止在这，关键是这个功能可以用来做很多事情，你看下面这张图就懂了！！！

这些动作、表情、一致性、连贯性、太强了，说实话我自己做我都做不出来......最后做出来的宠物效果也符合预期。

但是我对这个像素风格不是很满意，能不能做成那种IP感觉的？于是我再让 codex 去生成，但是效果依旧不是很好，还是用了Image2 生成后，效果更接近三维IP的效果，如下图

搞笑的是，生成过程中，给我生成了一组崩坏风，还挺可爱。

这里生成的不完整，不过没影响，重要的事情还是交给 codex 做，这里只需要找到自己想要的效果，后面就让 codex 来按照这个效果补全就行，也不需要什么特殊的办法和提示词，直接扔过去，让它按照生成的效果，重新生成角色宠物即可。

不过有时间和想做的细致的一点的建议还是 image2 生成，不然这玩意消耗额度，而且跑这种三维质感的时间和额度都更多，看个人选择吧，现在过程是没有任何难度的。

最后

这个宠物其实 Codex 不是先做的，而且也不是啥重要的更新，为什么我会觉得这个功能特别有意思呢？因为我前端时间基本算是沉迷AI Coding，有了这个宠物会感觉AI 开始从“工具”变成“角色”了。以前的软件，本质上只是功能。用了 Codex Pets 后，并且自己生成一个后，感觉就是把我自己长期合作的助手第一次把它“实体化”了。

虽然现在它还只是一个小功能。但我觉得未来很可能会出现：真正长期存在于系统里的 AI Companion。

甚至以后每个人可能都会有：自己的 AI Mascot、自己的工作流人格、自己的 Prompt 风格、自己的视觉角色。

而这可能会成为下一代 AI 产品体验的一部分。
