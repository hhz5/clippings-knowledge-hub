Lovart 重磅更新 · 多视角 + 矢量化

RaDesign 2026-03-14

大家好，如你所见 Lovart 更新了，主要更新的功能为 图像多视角 + 图像矢量化，该两项功能大大增强了 A

原创 RaDesign 2026年3月12日 18:14

大家好，如你所见 Lovart 更新了，主要更新的功能为 图像多视角 + 图像矢量化，该两项功能大大增强了 AI 出图后的优化修改的能力。并且从其它小功能更新也能看出它们野心极大，比如 扩展 里增加了 1倍 图到 4倍 图，这完全是C端和B端适配的尺寸、调整 功能里的饱和度锐化等调节、自由画布 里出现了 A4 纸张的尺寸等...

主要更新功能

通过昨天的一天测试用下来做个简单的总结，方便大家快速理解。后面我用案例为大家解析怎么使用，以及有哪些注意的小细节。

图像多视角：用户通过鼠标拖拽的交互形式「不用提示词，傻瓜式操作」，切换图像里角色视角角度「以前有个梗把大象P正，这回可以把大象从侧面P成正面了😊」。

图像矢量化：用户可以把.png 和.jpg 图像一键转换为矢量格式「即SVG格式」，可用于印刷、或导入 Illustrator / Figma 设计软件里「对于设计师来说更好用了」。

1.3D角色多视角 · 主体

· 用 Nano Banana pro 模型生成 3D 角色，后进行鼠标拖拽改变角色对镜头的视角。

提示：创建一个可爱的 [小绵羊] 打扮成 [教师装扮] 的3d渲染数字插图。人物应该有一个柔软的，圆润的身体，最小的细节，点或线的眼睛，和小玫瑰色的脸颊。风格参考：柔和柔和的调色板，哑光纹理，干净的照明，极简主义，中性的背景（浅灰色或软米色）。角色应该佩戴适合其工作的简单、迷人的配饰（如飞行员头盔、宇航员服、探险家帽、教师服饰等）。使角色富有表现力，俏皮，视觉平衡，仔细注意比例，就像一个可收集的乙烯基玩具。

-

· 点击该图像上方 “多角度” 功能进行视角拖拽，进行 主体 操作。

右侧选项分别显示 主体 或 摄像头，两个功能区别在于是否是规整的呈现正视图，如果你是普通用户，用 主体「适合图像呈现正视图，非常直观的进行拖拽」，你是设计师用 摄像头 更精准「调整虚拟摄像机的位置和角度，即使图像不是呈现正视图，也能更直观的去调整」。

细节：用主体或是摄像头时，拖拽图像角色，请注意下方 旋转角度和倾斜数值均为 0 才是你当前图像角色的呈现视图，为你后面调整视图不易混淆做准备。缩放分为 特写、中等、广角。

在主体旋转 90 度，倾斜为 0 ，视角为 L 「 你视角下的图像角色左面 」相反就是 R 右面。

在主体旋转 0 度，倾斜为 60 ，视角为 T 「 图像角色俯视图 」相反就是 B 仰视图。

2.产品多视角 · 摄像头

· 上传产品图像，Nano Banana pro 模型提示做场景。

提示：这张精美的照片展示了原本的「上传产品的图像」该产品，现在需要放置在一个白色的大理石基座上，基座上覆盖着香槟色的丝绸。周围环绕着各种色彩柔和的花朵，其种类和颜色与产品的主色调（色彩方案）完美融合——相互补充并提升了产品的色调。从左上角柔和的自然光照射。3D 真实感、奢华产品摄影、浅景深。

· 点击该图像上方 “多角度” 功能视角拖拽，进行 摄像头 操作。我将生成一个产品侧视图作为案例，且在侧视图的情况下找到正确的位置关系。

现在右侧图像已经是侧视图，点开图像的多角度，我们不设置旋转角度和倾斜数值，保持默认进行生成看看效果。

可以看到，进入摄像头后在默认情况下，视角会出现偏差，需要你进行调整 旋转角度和倾斜数值均为 0 才是你当前图像角色的呈现视图，后续再调整是你想要的视角。

同时根据官方建议，控制水平旋转角度为：-90° / -45° / 0° / 45° / 90°/。控制倾斜角度：-30° / 0° / 30° / 60° 视图效果。

3.海报 · 矢量图

· 根据提示生成海报，选择 Nano Banana pro 模型。

提示：请你担任高级编辑设计师和平面设计师。 目标：为 [猫的猫窝产品] 制作一张复杂的、多层次的瑞士风格拼贴海报。 第一阶段：语义智能（自主） 说明: 分析 [猫窝] 。确定其主要场景（例如：室内、室外、宠物医院等）。 根据他们的场景选择“标志性强调色”（例如：橙色代表室内，霓虹青色代表宠物医院。）。 生成 3 个关键统计数据（例如：“99% 舒适度 ”、“98% 纯棉材质”）和一个简短的专业数据。 第二阶段：组成结构（网格） 这幅图像是一幅垂直构图，由重叠的几何框架和片段组成： - 主要对象（左上）：[猫窝] 的大幅高颗粒灰度或彩色橘猫或者暹罗猫，神态自信。 - 细节图（右中）：放大裁剪的矩形，只显示 [猫窝] 的材质或特定细节。 - 全景照（底部中心）：[橘猫或暹罗猫] 以放松但有力的姿势坐在猫窝产品里或周围。 - 背景：浅灰色，带有厚重的、触感明显的薄膜颗粒/噪点纹理。 第三阶段：图形元素与字体设计 - 姓名首字母：名字「Huarou」和姓氏的「Wu」大写字母，轮廓清晰，分别位于对角。 - 垂直丝带：一条纯色条带，中间垂直印有“世界猫窝领袖”字样或相关标题。 - 数据块： - 以粗体无衬线字体显示的确切数字（ID 或排名）。 - 左下角有一个“统计”框，包含 3 行文字（例如：“两次舒适度冠军/四次材质大奖/三次登上领奖台”）。 - 点缀：在网格中散布橙色和黑色方块、虚线圆圈和小星号，以增加视觉复杂性。 第四阶段：光照和纹理 - 质感：高对比度、粗糙、颗粒感强。整体图像应看起来像印刷精美的杂志或复古海报。 - 灯光：对拍摄对象使用专业影棚灯光，但后期处理呈现出“丝网印刷”或“半色调”的感觉。 第五阶段：技术规格 8K分辨率。瑞士现代主义美学。扁平化矢量图形与超写实摄影相结合。

5.真人图像 · 调色 · 多角度
