视频详情

整个实现过程就三步：

装 skill

描述需求

拿成片，成片可以直接在浏览器剪辑

整个 skill 的实现流程是

  • 它先把官网抓了一遍(20 张滚动截图、99 个素材、3 套字体、17 个色值)
  • 写了DESIGN.md、SCRIPT.md、STORYBOARD.md
  • 跑 Kokoro TTS 出旁白，跑 Whisper 出 word-level 时间戳
  • 做六个分镜的 HTML
  • 调浏览器逐帧抓出 MP4
  • 最后，它还在本地搭了一个剪辑页面。 直接起一个 Studio，浏览器里就能拖时间轴、调单镜头、改 prompt 重跑。

每个环节对于"AI 出片但人要把控细节"的工作流特别关键。

HyperFrames 本质上是把视频当代码写。每个场景是一段 HTML，文字是<h1>****、卡片是**<div>、动画是 GSAP 时间线、音轨是<audio>****，最后用浏览器逐帧抓帧、ffmpeg 编码成 MP4。**

Agent 最擅长写 HTML/CSS/JS，这比让它学一个剪辑软件简单太多。

再加上lint / inspect / render全都是 CLI、返回结构化结果(报浮点冲突自己改、报对比度低自己调色)，整个迭代回路对 Coding Agent 来说就是日常的"写代码—跑检查—改 bug"。

视频详情

做完之后的感觉很明确：HyperFrames 不只是给 AI 加了一个"出图能力"，它已经能让 Coding Agent 生产一类新的内容形态——PPT 式解释视频。

视频可以用来产品做宣传、塞进文章开头当 hero，或者单独投到即刻、小红书、视频号、X。

把"写完一篇文章顺手做一条视频"的成本，从"找外包/自己学剪辑/录屏"压到"花几千个 token、等几分钟"。这是一次真正意义上的产线压缩。

03 有了这个能力，实现视频创作自由

我在 HeyGen 官方和自己跑下来的实践里挑了几个最稳的场景，给大家举个例：

1 网站 / PPT 转产品宣传片

以前需要顾一个外包团队、给 brief、等三周、改十轮的活，现在一句"把这个官网做成 30 秒宣传片"就完事。

提示词框架："30 秒、16：9、保留品牌色、结尾 CTA、目标平台 LinkedIn"

2 文章配视频

写完一篇公众号或博客，顺手让 Claude Code 做一条 30 秒动态摘要，塞进文章开头当 hero，或者单独发即刻、小红书、视频号。

3 产品发布片

开源项目刚发版、SaaS 上新功能、Skill 仓库新增组件，需要一条短发布片。给 Claude Code 一个 README 或 CHANGELOG，加上品牌风格，十几秒到一分钟的 promo 直接出。

4 知识科普切片

一篇技术长文不是所有人愿意读，提炼成 3-5 个知识点，做成 20 秒一条的卡片视频，适合连续投放小红书、视频号、X。

5 brief 转方案展示

商单 / 甲方 brief 来了之后，Claude Code 先把 brief 拆成结构，再生成一条提案风格的视频(品牌色、产品镜头、CTA)，给客户看比 keynote 更有制作感。提案命中率会肉眼可见地提升。

6 教程演示视频

新工具、新 skill、新工作流，用 macOS Notification 组件加终端截图组件，做一条"输入命令 → 看到结果"的演示片，比录屏稳定也比录屏好排版，出错可以一键重渲。

这些场景的共同点是：**内容已经在文档里、流程已经跑通，缺的只是一层视觉包装。**HyperFrames 来补上这一层，Coding Agent 来把内容翻译成时间轴，人只负责给方向和判断。

05 写在最后

HeyGen 把这件事做成开源 + skill 生态，而不是把它锁在自家产品里。

这家公司对未来视频的判断已经很清楚了，未来不全是 prompt 直接生成画面，也会有大量"代码结构化的视频"。

有了这个 skill， 独立创作者也拥有了和小团队同等的视觉生产能力。

一家创业公司发布会需要的所有视频物料，可以在 Codex 里跑一晚上全出。

Coding Agent 负责组织内容，HyperFrames 负责稳定渲染。

内容的"分发形态"和"生产成本"被同时改写。

产品介绍、知识解释、数据报告、课程卡片、社交短片，这些不需要电影级生成，需要的是稳定排版、准确文字、可复用模板、可自动化渲染。

装好 Agent+ HyperFrames 之后，就实现了任意内容转视频的自由。
