在小说阅读器中沉浸阅读

去年上半年在网页对话框里和 AI 对话，把自己的需求扔给他，然后给你一份文档，这就是用 AI。到了下半年 Claude Code 在非程序员圈子开始流行，接着 skill 横空出世，Agent(智能体)越来越强，春节又来个OpenClaw，装龙虾，养龙虾，这些新事物，这个还没学会下个又出来了。

用好 AI 似乎变得越来越有门槛，作为每天都被事务缠身的打工牛马，哪有时间研究这些层出不穷的新工具，新技术啊。

Claude Code 打开就是一个黑乎乎的终端，想要调整一个功能都不知道打字说什么。OpenClaw 更狠，要装环境、申请 API、接机器人、配一大堆东西，装好了还要设人格、装 skill、一口一口喂大。Cowork 我们用不了，用的了费用也非常高，额度可怜的说几句话就没了。

这些工具的底层能力其实都差不多：读写文件，能跑代码，能上网查东西，能生成图片，能一步一步帮你把复杂任务做完。

真正的差别在于：谁能让普通人，用最快最简单的方式用到这些新玩意。

哈哈，想着想着它就来了

字节跳动旗下的 AI 编程工具 TRAE 新发布了一个叫 SOLO 的独立产品  

这个不是原来TRAE 里面那个给程序员用的SOLO模式

它是一个独立的桌面程序，当然也有网页版

我研究了一下，觉得这个东西的定位很有意思：

它是将给程序员用的 AI 编程工具，进行了极度的简化，打造成了给所有职场人用的 AI 工作搭子。

SOLO 独立客户端是什么

先用最简单的话说清楚：SOLO 是一个你打开就能用的 AI 助手，能做的事情很多，读你的文件、帮你写文档做表格做 PPT、帮你上网查资料、帮你写代码跑脚本、帮你处理数据生成图表——但这些你完全不需要知道。

你只要用人话告诉它：你想干嘛。

它有两个模式：MTC模式和 Code 模式。

Work 模式就是日常办公，处理文件、写材料、做分析；

Code 模式可以写代码、搭网页、做工具。两个模式无缝切换，一个界面搞定。

跟 Claude Code 比，SOLO 没有终端恐惧症。跟 OpenClaw 比，SOLO 不用养不用调不用配。跟 Cowork 比，SOLO 是中文原生，便宜又好用。

打开网页端：https://solo.trae.ai/   这里就可以下载桌面端，下好了就跟着我一起来认识这个工作搭子吧。

好了不废话了，直接上实测。

让 SOLO 介绍自己

第一次打开 SOLO，说实话我也不知道它能干嘛。一般有交互功能的产品我都会让他自己介绍自己，这就是最好的说明书。

他先问我什么格式，又问我需要什么版本的需要多长，再问我这个给谁看。我去，这个工作搭子会来事，想的这么周到的吗？

然后他就咔咔开始干活，给了我一份非常完整的使用手册：问答写作、Word 文档、Excel 表格、PPT 演示、PDF 处理、写代码、跑命令、上网搜索、生图、多步骤任务管理……有哪些能力以及怎么用。

这么多字我怎么会有耐心看完呢？于是我就跟他说："我没有耐心看完你写的说明书，你把他做成一个交互式网页，我需要查看的时候，打开这个网页就可以查询你的功能"

2 分零 3 秒后，这个网页就做好了，点击链接直接就能打开。

还贴心的加了搜索和分类，每个功能都有案例可以展开，这个网页也保存在你的电脑上了，需要的时候随时可以打开，或者想要他加点什么进去都行。

你不需要懂智能体，不需要懂代码，甚至都不需要懂他能做什么。你只需要懂"我想要什么"。

如果你是第一次用 SOLO，我建议你也这样开始——让它介绍自己。 一来你能了解它的能力边界，二来这个交互过程本身就能让你感受到它的工作方式。

奶茶店老板的三个月流水

好，热身完了，来点真实的工作场景。

假设你是一个奶茶店老板（或者任何做小生意的人），每天忙着出单、进货、盯店，根本没时间分析数据。但你心里一直有几个问题：到底哪几个产品是真的赚钱？哪个时间段最忙，排班该怎么排？外卖平台和门店的比例健不健康？该不该砍掉几个卖不动的品？

问题是，你的数据散在各种地方：美团后台导出来一个表格，饿了么又是一个格式，门店的手记 Excel 列名都对不上，有的日期写的"1月5号"，有的写的"2026/1/5"，有的干脆空着。

让一个不会 Excel 公式的人来整理这些？至少一天。让一个会的人来？也得半天。

我给 SOLO 丢了 4 个文件：

  • 美团1-3月订单导出.csv（美团后台导出的风格，有些字段是空的，有重复行）
  • 饿了么销售记录.xlsx（列名和美团完全不一样，日期格式也不同）
  • 门店手记1月.xlsx（手工记录，有错别字，有的行只写了品名没写金额）
  • 门店手记2-3月.xlsx（换了一个人记，列的顺序变了）

然后我说：

"这是我奶茶店过去三个月的销售数据，来自不同平台和门店手记，格式很乱。帮我做这几件事：1. 把所有数据清洗合并成一张标准的总表 2. 分析哪些产品利润最高、哪些该砍掉 3. 分析每天不同时段的订单分布，给我排班建议 4. 外卖vs门店的占比和利润对比 5. 做成一份图表丰富的分析报告，我要给合伙人看"

SOLO 开始干活了。

像不像请了一个专业的会计？不是上来就自己想当然的干，先问清楚你想要什么，这就很贴心了！

他不是把这些表格都读下来硬算，一个表就几千行数据，这么大的数据量什么模型能自己硬算啊。观察了一下他的工作方式，先是读取表格，了解表格的数据结构后，他开始自己写分析脚本，不同的表格他写了不同的分析脚本，然后把输出的数据整合在一起再做 ppt。

我记得多年前 python 脚本做数据分析，是一门课，要专门学。现在你甚至都不需要知道他用了 python 脚本做分析，只要告诉他你要什么，然后他给你一个结果就可以了。

20 分钟后他给了我一个数据清洗合并后3643 行的 excel总表和一份 ppt

关键是什么呢？你完全不需要知道它背后用了 pandas 还是 openpyxl，用了什么公式什么图表库。我只需要知道"我想搞清楚我的店到底赚不赚钱"，剩下的它来。

这就是我一开始说的：让普通人，用最快最简单的方式用到这些新玩意

行政小张的杂乱文件噩梦

每到月末，行政最怕的事来了——整理文件。

公司上个月的合同、发票、报销单、入职材料、各种证明文件，全部混在一个文件夹里。PDF 和 Word ,Excel，Txt 各种文件混在一起，文件名有的规范有的不规范，有的甚至就叫"文档1.pdf"。领导说下班前要整理好，汇总给他，列出每份合同的甲乙方、金额、签署日期，每份发票的金额和开票日期。

头皮麻不麻？想不想砸键盘？

我模拟了这个场景，在一个文件夹里塞了一堆混在一起的文件：有采购合同、销售合同、增值税发票、费用报销单、员工入职登记表、资质证明——文件名有规范的也有不规范的。

然后我跟 SOLO 说：

"这个文件夹里有很多文件，全是混在一起的。帮我做三件事：1. 按类型自动分类到不同的子文件夹（合同、发票、报销单、人事材料、其他）2. 从所有合同里提取甲方、乙方、合同金额、签署日期 3. 从所有发票里提取发票号、金额、开票日期 4. 把提取的信息汇总成一张 Excel 表"

5 分钟后，他就搞定了，所有的文件分门别类放到文件夹里，并且把所有的合同都汇总好了

这只是小试牛刀，如果你有大量的文件需要整理，但又不放心，那就先复制一份备份一下，然后把这个文件夹放心交给 SOLO，不会让你失望的。（重要文件操作前备份是一个好习惯！！）

老板突然要的调研报告

周五下午四点，老板在群里 @ 你："咱们看看现在市面上主流的项目管理工具都有哪些，各自什么特点优劣势，下周一开会讨论用哪个。你整理一份报告。"

你一看，什么飞书、钉钉、Notion、Teambition、ONES、Jira、Monday、Asana……光听名字就一堆。你对其中大部分可能只是听过没深入用过。要把这些都调研清楚、做个对比矩阵、写个结论建议——你周末大概率得搭进去。

我跟 SOLO 说：

"帮我做一份项目管理工具的竞品调研报告，要求：1. 覆盖国内外主流的项目管理工具至少8个 2. 每个工具整理出核心功能、价格体系、适用团队规模、优缺点 3. 做一个横向对比表 4. 给出适合20人左右互联网团队的推荐建议 5. 输出一份 Word 格式的报告，要专业，能直接发给老板"

SOLO 先联网搜了一圈，抓取了各个产品的官网介绍、定价页、功能对比页，还搜了一些第三方的评测文章。然后开始整理。

word 文档怎么看，老规矩，上网页，早知道我开始就让他做一个网页了。

这才对嘛，这样的网页交给领导，还不夸我会做事？

周五下午四点接到任务，SOLO 半小时交稿。 周一交上漂亮的网页，周末该去哪玩就去哪。而且因为它是联网实时搜的，价格和功能信息都是最新的，参考价值很高。

技能市场：让你的 SOLO 学会新技能

看完这几个案例你可能会想：如果某个工作流我以后还会反复用，每次都要重新说一遍吗？

4 月 2 号 SOLO 上线了一个新功能——技能市场（Skills Marketplace）。

简单说，每一个 Skill 就是一个"可插拔的技能包"，封装了某类任务的工作流、专业知识和工具调用。安装之后，SOLO 在需要的时候会自动调用，你不用每次都解释该怎么做。

比如你经常需要处理 Excel 数据生成可视化报告，装一个数据分析相关的 Skill，以后丢文件给它就行了，它知道该怎么处理。你经常要做 PPT，装一个 Slides Skill。你经常要做 SEO 分析，也有对应的 Skill。

技能市场里有 TRAE 官方精选的 Skill，覆盖开发工具、数据分析、界面设计、内容创作、效率提升这些高频场景。也支持用户自己制作和上传 Skill。

写在最后

说回开头的问题。

Claude Code、OpenClaw、SOLO，它们底层能做的事其实差不多。但 SOLO 做对了一件事，它不要求你先成为一个懂技术的，才能享受 AI 的能力。

SOLO 是一个已经培训好的同事——你不需要教它，你只需要告诉它"帮我把这件事搞定"。

它的 slogan 是"More Than Coding"。我觉得这句话的意思不是说它比编程工具更强，而是AI 真的能帮你做的事，远不止写代码。 每一个打工人的日常工作里，那些重复的、繁琐的、耗时间但没技术含量的事情，现在都可以交给 SOLO。

你不需要知道 SOLO 可以做什么，关键你想做什么，只要是你想的，不用考虑他能不能，直接告诉他，能做的他会立即做，做不了的他会自己写代码去做，那些烦人的怎么实现的过程交给 SOLO，你不需要懂技术，不需要学提示词，不需要折腾任何东西。

打开 SOLO，告诉它你今天想搞定什么。

然后去倒杯咖啡。
