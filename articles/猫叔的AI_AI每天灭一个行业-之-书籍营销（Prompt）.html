第二层：渠道物种生成器

2.1 小红书图文生成器

【资产包】
{粘贴第一层输出的JSON}

【输出格式】每条笔记包含：
1. 标题（带emoji，20字内，含数字或反问）
2. 封面文案（大字压图的那行字）
3. 正文（300-500字，口语化，分段清晰，结尾带互动提问）
4. 标签组合（8-10个，含流量词+精准词）
5. 评论区预埋（3条自己评论引导互动）

【风格锁定】
- 人设：资深编辑/读书博主/行业insider
- 语气：有信息量但不端着，像朋友分享发现
- 禁止：假大空、鸡汤味、过度营销感

2.2 抖音/视频号短视频脚本生成器

你是短视频爆款编导。基于以下书籍资产包，生成5条短视频脚本。

【资产包】
{粘贴第一层输出的JSON}

【输出格式】每条脚本包含：
1. 选题角度（为什么用户要看这条）
2. 黄金3秒（开场钩子，必须制造冲突/悬念/反常识）
3. 分镜脚本（按5-8个镜头拆解，每个镜头标注：画面描述+字幕文案+时长）
4. 口播逐字稿（可直接对着念，控制在45秒-90秒）
5. 结尾钩子（引导关注/评论/转发的那句话）
6. 文案区（发布时的文案，含话题标签）

【风格锁定】
- 节奏：信息密度高，不废话，每句话都有存在意义
- 情绪：前5秒抓焦虑或好奇，中间给干货，结尾给希望
- 禁止：朗读式口播、PPT式讲解、假装震惊

2.3 公众号深度长文生成器

你是公众号头部账号主编。基于以下书籍资产包，生成1篇深度推文框架。

【资产包】
{粘贴第一层输出的JSON}

【输出格式】
1. 标题（主标题+副标题，共2套方案）
2. 开篇钩子（前3行必须让人想读下去，200字内）
3. 文章结构大纲（按"观点-论据-故事-金句"节奏设计，标注每部分字数）
4. 转折点设计（文章中间必须有一个"原来如此"的顿悟时刻）
5. 情绪曲线（标注读者在每个段落的情绪状态）
6. 结尾行动号召（不是硬广，是价值观共鸣后的自然邀请）
7. 次条预告（如果要做成系列，下一篇切什么角度）

【风格锁定】
- 信息密度：不注水，每段都有增量
- 叙事：观点锐利但不偏激，有思辨厚度
- 禁止：标题党后正文拉跨、全文复述书本内容

2.4 播客/音频提纲生成器

【输出格式】
1. 单期主题（吸引点击的那个切口）
2. 时长规划（建议30-45分钟）
3. 开场白（如何在前60秒建立期待）
4. 段落结构（每段标注：核心议题、关键问题、预计时长、需要的案例/故事）
5. 金句植入点（哪些时刻适合放重磅金句）
6. 互动埋点（适合让听众截图/分享的那几句话）
7. 结尾收束（如何让听众觉得"这期值了"）

【风格锁定】
- 像两个聪明人的深夜对谈
- 有观点交锋，不是单向输出
- 信息量和故事性兼具

2.5 电商详情页/直播话术生成器

3. 详情页长图文案框架（按屏拆解，每屏一个说服点）
4. 问大家预埋（5个常见问题+最佳回答）

1. 开场过款话术（30秒内讲清楚这是什么书、为什么要买）
2. 痛点戳穿话术（制造"不买会后悔"的紧迫感）
3. 价值塑造话术（让用户觉得物超所值）
4. 逼单话术（最后30秒促成下单）
5. 弹幕预判（用户可能问什么，怎么回）

【风格锁定】
- 电商详情页：扫一眼就知道买不买
- 直播话术：口语化、有感染力、不油腻
