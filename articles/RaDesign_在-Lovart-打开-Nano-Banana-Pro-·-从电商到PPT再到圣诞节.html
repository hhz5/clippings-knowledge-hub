1.电商详情页

电商页面大家非常的熟悉， 在一个页面内，用清晰信息、强卖点和信任背书，解决用户所有疑虑并促成下单的转化工具。

在 X 上看到非常好的电商详情提示词，来自 @沐阳 佬，拆解一下流程且附上提示词：

-

· 品牌 logo 生成

创建自己的品牌，logo 很重要，让用户第一眼甚至很长一段时间记住你就是成功。

提示词： 极简高端时尚品牌logo，矢量风格，干净几何形。品牌名：["WUHUAROU"]。图标：细线圆形徽章，内含肉类肉块（负空间，现代，优雅）。配色：深苔灰绿色(#2F3A33)搭配温暖米白背景(#F3EFE6)或透明背景。字体：高端衬线体"WUHUAROU"，字母间距宽松，下方小字"五花肉"。无渐变、无阴影、无3D、无样机、无水印。

这里 Nano Banana Pro 还是很有意思的，一口气生成 4 张让我选择，我挑了第 2 张 logo 更符合我做服饰品牌。

这个很有意思，忍不住扩展一下，我们上传一个装衣服的纸袋「或者生成」，利用 Lovart 里的 mockup 功能「样机功能」，把刚做的 logo 放上去。

首先利用“ 编辑元素 ”把 logo 分层「如果下方文字也要用，请变成图片即可移动」，回到 纸袋 点击 mockup 功能等待片刻，再把 logo 拖进去即可。

-

· 产品头图展示

产品主要的图像展示，也就是主视觉，产品名称清晰且快速的浏览是什么产品。

提示词： [产品·丝滑睡裙] 主KV（Hero） 9:16竖版高端极简时尚海报。柔和摄影棚日光，温暖米白渐变背景（奶油/燕麦色），超干净。精致亚洲美女模特(25-30岁)，精致五官，自然裸妆，长发慵懒随意，放松优雅姿态，全身照，一只手轻轻抚摸裙摆。

服装必须与上传的产品参考图匹配：香槟色/奶油色缎面短款吊带睡裙，细吊带，V领，裙长至大腿中部，丝滑光泽面料，保持服装设计与参考图完全一致。

排版布局：左上角放置 WUHUAROU logo(小号)。顶部居中巨大衬线标题(2行)："SILK SLIP DRESS" / "丝滑睡裙"(中英堆叠，干净)。左侧中部玻璃拟态信息卡(3个要点，双语)：仿真丝触感 / Silk-like touch；修身不紧绷 / Flattering fit；居家也优雅 / Elegant at home。右下角【圆角药丸CTA】："立即选购 → / SHOP NOW →"。

负面词：cluttered, busy, multiple patterns, gradients, shadows, watermark, logo repeated, messy text, low quality, blurry, plain face, unattractive

· 产品场景展示

展示该产品在特定环境下细节。

提示词： 9:16竖版，电影质感干净时尚摄影。背景：柔和晨光透过白色纱帘的卧室，奶白色床品，极简北欧风格，温暖氛围。精致亚洲美女模特全身侧身站立，长发披肩，回眸微笑，一只手撩起发丝。使用上传的产品参考图保持香槟色短款吊带睡裙的形状、长度、面料光泽完全一致。

文字：左上角小号 WUHUAROU logo。左上小号优雅字体："晨光私语 / Morning Whisper"。左下大标题："慵懒得刚刚好"。标题下副标题(双语)："丝滑触肤，开启美好一天 / Silky touch, beautiful day begins."。右下角CTA药丸："了解更多 → / LEARN MORE →"。

负面词：cluttered, busy, dark, messy room, shadows, watermark, messy text, low quality, blurry, plain face

有点小问题，标题字体太黑了，我们这里用 Lovart 的 “ 编辑元素 ” 功能修改下颜色。

点击吸管吸取下方颜色，并且使用“ 编辑元素 ”分层后更方便其他元素的修改，比如下方的模特位置调整「同时注意在点击下载前，记得全选来合并图层毕竟分层了」。

这里有个小技巧：分层后再合并，人物角色边缘带一点阴影，这里就要重新利用 Nano Banana Pro 优化一下。

其实还可以在优化一些细节的，比如右下角了解更多这里..

2.蛋壳里的世界

这是一个很有意思的创意，放在这篇教程文章里原因是起到缓解视觉疲劳的。

提示词： 一个开放或破裂的 [球体物体] 的超现实微距镜头，转换为微型 [环境类型] 立体模型。球体内是一个以 [环境细节] 为特色的微小、高度详细的世界。在中央，矗立着一个高度细致、逼真的微型模型，由 [主角]、[衣物/外观]、[姿势/动作] 组成。

[次要元素-可选，最多1-2项] 在背景中可见。球体的外壳有一个逼真的 [材料/纹理/品牌]。

场景位于模糊的 [背景/表面] 上，强调规模和深度。风格：微距摄影，倾斜移位效果，浅景深，体积照明，逼真，电影，超详细，8k渲染，虚幻引擎5，辛烷值渲染，光线追踪。

4.PPT生成

依靠 Lovart 平台生成 PPT 并编辑，既可以用 Text Edit 修改优化文字，又可以用 Touch Edit 不破坏画面的情况下元素修改。

提示词： 请生成10页PPT，英语有关，比例6:9，大纲：设定学习目标，介绍发音，提供示例词（cat、hat、mat），加入图片匹配、故事、练习句子、互动游戏、单词搜寻、拼写练习和家庭作业。

这里我做了一些简单的测试，当生成第 1 次的时候，风格我个人不是很喜欢，上传了一张极简风格的图像作为风格参考，还别说，根据风格参考出来的效果就是不一样，很令我欢喜。

提示词： 请简约，有空白，我给你上传一张风格参考， 上传参考。

我附上几张，大家可以看看效果..

整体看到很不错，唯一有些问题的地方是 2004 年，需要小小的修改一下，点击“ 编辑文字 ”

非常的丝滑「 怀疑吃了德芙巧克力了」,我甚至做了一套圣诞节风格的 ppt，但是细节太多地方要调整，这里不放了，这篇文章阅读时间又超纲了，同时做完的 ppt 可以下载或者在线预览。

扣题了，在 Lovart 生成编辑 PPT 的能力更加 完整，大家可以去试试。

5.圣诞节海报

年年大厂 app 首屏欢迎圣诞节页面都会有很多，我找了一些参考，利用 Touch edit 功能快速出，「不知道 Touch edit 功能的小伙伴请移步“ 高阶使用方法 ”文章前去查看 」。

大致流程思路还是要说的，上传大量的参考，利用 Touch edit 功能 替换圣诞树或者风格 ，在利用 Text Edit 功能 修改文字， 我相信前几期跟着学的小伙伴应该能快速掌握。这里放下截图。

觉得 1 和 2 非常好，我利用1图像里的圣诞树替换图像 2 里的圣诞树 ，利用 Text Edit 功能 进行标记附上提示词： 请把这里的圣诞树 「标记1的圣诞树」 转换成这里的 「标记2的圣诞树」。

在生成的图像里，把下方的额礼物换成图上的，重复上面的标记替换得到下的图像。

有瑕疵，文字需要修改，利用 Text Edit 功能 编辑文字，再次等待生成即可。

到这步我想换个圣诞树，上传一棵圣诞树，用 touch edit 功能把圣诞树标记出来，再 输入提示词： 请把这张圣诞树 「标记1的圣诞树」 风格，转化成这里的圣诞树 「标记2的圣诞树」 风格。
