视频起号有卡点？这 9 个 Skill 帮你搞定视频创作

空格丶 空格的键盘 2026年8月4日 17:09

上次分享小红书起号的 Skill，评论区问得最多的一句是： 能不能来一套视频创作的 Skill？

我花了一周，边搭边测，又攒出了一套，9 个 Skill。

把做视频拆成选题、脚本、动效、剪辑、字幕、声音、封面 几个环节。

一个环节一到两个 Skill，再加一个总控把它们串起来，一共 9 个。

跟小红书那套一样，单个都能用，但真正的价值是 串成一条流水线 。

下面逐个讲功能、实现和产出效果。

一、总控：space-video

和小红书那套的思路一样，Skill 一多，你和模型都会选择困难。

所以我先给这套配了个 导演 。

你跟它说一句「帮我做条视频」，它先问清楚：口播还是录屏？发竖屏还是横屏？有没有参考？然后判断你现在卡在哪一步，路由到对的子 Skill，按对的顺序串起来，成片后还帮你复盘。

Skill 再多，也不用自己去记名字。

二、选题：space-video-topic

一条视频动手前，先解决四件事：参考哪条、讲什么、叫什么、说什么。

这一个 Skill 全包了：

- 下载参考 ：给一个抖音 / YouTube / B站链接，去水印下载。

抖音这条我实测，先在浏览器打开一次页面刷新签名，再用 yt-dlp 脚本下载。下载内容包括：

- 逐字稿 ：把参考视频转成带时间的逐字稿，方便拆解。

- 选题 + 标题 + 正文 ：从爆款里拆出可复用的选题结构，再起标题、写口播正文。

我给一个我的抖音视频链接，它就给我下载了下面几个内容。

三、脚本：space-video-script

这个 Skill 干两件事：

一是 去 AI 味 。AI 写的稿子念出来会「假」：长句一口气接不上、书面连接词、工整排比。它把这些改成能对着镜头念的口语。

二是 精确到秒的分镜 。每一秒都有安排：这几秒讲什么、画面是什么、怎么切。

四、剪辑：space-video-edit

这是最硬的一个 Skill，专治口播失误。

它先帮你 剪口播 ：转写 → 识别口误、语气词、静音、重复、卡顿、残句 → 生成审核页让你确认删哪里 → 剪出干净视频 → 再重新转写做字幕。

这里参考了博主 chengfeng 制作的剪辑 skill。

- 删前保后 ：后说的通常更完整，所以删前面的口误，保后面完整的。

剪完再走成片：分镜、时间轴对齐、导出。

五、画面 B-roll：space-video-broll

我自己剪口播最头疼的就是画面，一张脸从头说到尾，观众很容易走神。

这个 Skill 是个 动效导演 ：先给内容找一个能动起来的视觉隐喻（河流、网络、流水线、坍缩……），再排成一条 30 秒以上的连续动效。

可以把动效加到原视频轨道里。

这个 Skill 使用 haperfram 的 Skill 做基础，用纯 HTML/CSS 写画面，逐帧确定性渲染成 MP4，

六 B-roll（手绘图解）：space-video-broll-sketch

上一个是代码渲染，这个是 调真实视频模型 。

给它一篇公众号文章，它优先抽原文配图，把逻辑拆成 6 到 10 帧手绘白板图解：白底、黑色单线、每帧只有一处蓝，像一支看不见的笔一笔一笔画出来。

出片这一步接了两条模型通道：火山引擎的 Seedance ，或者 libtv 的 Agent ，二选一，配好 key 就能逐帧生成再拼成片。

七、字幕：space-video-subtitle

这个 Skill 走四步：转写 → 口播式断句 （按呼吸和语义断，不按标点）→ AI 校对 （专名、同音字、标点，中文 ASR 高发的「在/再」「的/得」都会盯）

输出 SRT/ASS，可以用剪映导入。

剪过的视频，字幕会基于剪后视频重新转写，不沿用原字幕。

八、配音配乐：space-video-audio

声音这块也补上了，这个 Skill 处理三件事：

- 配音 ：把口播稿用 TTS 生成旁白，使用 edge-tts 免费模型。

- 找 BGM ：按视频调性去免版权曲库找，我实测跑通了 Pixabay 免登录取直链的方法（免费免署名）。

- 混音 ：BGM + 旁白压进视频，自动做 压音 （人声一响 BGM 自动下沉）、响度归一到 -14 LUFS、淡入淡出，画面不重编码。

九、封面：space-video-cover

封面决定点击率。

它出的封面要满足两点：这一条足够抓人，且放进主页一排能看出是同一个账号

固定的主色、字体、标题位，每条只换具体排版和强调色。

支持视频号、B站、小红书、YouTube 各自的比例。

这篇文章的封面就是用这个 Skill 做的。

怎么用

告诉你的 Agent（Qoder / Claude Code / Codex）：

帮我安装这几个 Skill：github.com/SpaceZephyr/creator-buddy/tree/main/video-Skills

装完，说一句「帮我做条视频」会自动路由到总控，也可以直接点名某一环，比如「帮我剪一下这条口播」。

单个能用，但价值在串成工作流，三条标准工作流：

链路 A · 完整口播成片

topic 选题脚本→ script → 录制 → edit → broll → subtitle → audio → cover → 发布

链路 B · 拆解一条爆款参考

topic 下载参考 + 逐字稿 → 拆选题结构 → 复用到自己的脚本

链路 C · 把一篇文章变成视频

broll-sketch（文章转手绘图解）→ audio 配乐 → cover → 发布

除了下载和视频模型生成需要对应的 key，其余 Skill 都不需要第三方 API。

最后

很多人问我，怎么做的这么快，我想了想大概是这些 Skill 大多 依赖我最早做的那几个最底层的 Skill。

还有参考了一些开源的 Skill，比如B-roll 的渲染路线参考了 HyperFrames （HTML 转视频），剪辑的方法论来自博主 chengfeng 的剪口播 Skill 。

大家可以创建自己的 Skill 基因。

我的 Skill 大多源自于我的 写作风格和设计风格 。

去 AI 味那一步，用的是我的写作风格；B-roll 和封面的视觉，用的是我的设计风格。

这就是我的 Skill 基因。

你也可以试试：把自己的写作习惯、审美偏好，落成几份文字，当成你所有 Skill 的底座。

再去制作其他 Skill 会快很多。
