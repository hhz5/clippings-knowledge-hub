# 技能名称：竖屏短剧镜头节奏优化大师 v1.0 
## 📝 技能描述 
针对2025-2026年爆款竖屏短剧（完播率≥40%）数据提炼的标准化镜头节奏优化模块，可直接对接「微短剧AI辅助编剧体系」和Seedance/可灵/即梦等AI视频生成工具，平均提升作品完播率30%以上。 
## 🚀 核心能力 
| 能力模块 | 功能说明 | 
| --- | --- | 
| 基础适配层 | 自动适配9:16竖屏画幅所有通用镜头准则，自动规避画幅/信息安全区/时长等基础问题 | 
| 时长模板层 | 支持1分钟爽剧/3分钟标准剧/10分钟中长剧三类主流时长的标准化镜头拆分 | 
| 品类调优层 | 支持甜宠/战神/悬疑/搞笑等主流品类的差异化节奏适配 | 
| 完播率优化层 | 内置3秒钩子/15秒注意力唤醒/结尾5秒留客等行业验证的防划走设计 | 
| AI工具适配层 | 内置Seedance/可灵/即梦等主流AI视频生成工具的专用提示词后缀 | 
| 质量质检层 | 可量化的节奏验收清单，自动校验所有节奏指标是否达标 | 
## 🎮 使用方法 
### 输入参数 
| 参数 | 必填 | 可选值 | 说明 | 
| --- | --- | --- | --- | 
| video_duration | 是 | \`1min\`/\`3min\`/\`10min\` | 单集时长 | 
| video_category | 是 | \`sweet\`/\`god_of_war\`/\`suspense\`/\`comedy\`/\`other\` | 剧集品类：甜宠/战神赘婿/悬疑/搞笑/其他 | 
| ai_tool | 否 | \`seedance\`/\`keling\`/\`jimeng\`/\`none\` | 对接的AI视频生成工具 | 
| export_format | 否 | \`plan\`/\`prompt\`/\`both\` | 导出格式：仅优化方案/仅提示词/两者都有 |

# 竖屏短剧镜头节奏优化提示词模板库 
##  通用基础模板（所有场景通用） 
【通用版】
竖屏9:16画幅，平均单镜头时长1.8秒，特写占比85%，所有核心信息（人脸/台词/重要道具）放在画面上2/3区域，避开底部字幕遮挡区，80%镜头带轻微运动（推/拉/摇/跟），硬切转场占比90%以上，节奏明快，前3秒用强冲突钩子镜头，每15秒插入一个注意力唤醒点，结尾5秒停在冲突最高点做下集钩子
【高爽点版本】
竖屏9:16画幅，平均单镜头时长1.5秒，特写占比90%，所有核心信息在画面上半部分，冲突点镜头切换速度提升20%，爽点镜头配合突然拉近动效，前3秒强冲突钩子，全程高密度节奏，无冗余镜头，结尾5秒强悬念钩子
##  分品类专属模板
### 1. 甜宠/情感类
竖屏9:16画幅，平均单镜头时长2秒，特写占比90%，情侣同框优先肩以上景别，情感戏镜头可放宽至3-4秒，配合轻微柔光动效，节奏舒缓但无拖沓，前3秒用高甜/高虐反差钩子，每20秒一个情感爆点，结尾5秒停在最心动/最虐的瞬间
### 2. 战神/赘婿/逆袭类
竖屏9:16画幅，平均单镜头时长1.5秒，特写占比90%，冲突镜头切换速度提升20%（单镜头≤1.2秒），爽点镜头配合突然拉近的动效强化爽感，前3秒放打脸/被看不起的强冲突钩子，每10秒一个小爽点，每30秒一个大爽点，结尾5秒停在最解气的瞬间
### 3. 悬疑/恐怖类
竖屏9:16画幅，前半段平均单镜头时长2-3秒营造氛围，后半段揭秘/反转时节奏提升30%，用快速跳切制造紧张感，前3秒用诡异画面/悬念钩子，每15秒一个小反转，结尾5秒停在最惊悚/最出乎意料的瞬间
### 4. 搞笑/段子类
竖屏9:16画幅，平均单镜头时长1.8秒，包袱点前1秒用固定镜头铺垫，抖包袱瞬间用快速切换/特写放大笑点，前3秒用反差感搞笑画面钩子，每20秒一个大包袱，结尾5秒停在最搞笑的表情/动作瞬间
##  分时长后缀模板
### 1分钟爽剧
（拼接对应品类模板后加）总镜头数30-40个，3秒钩子→17秒铺垫→25秒冲突→10秒反转→5秒钩子，全程无尿点
### 3分钟标准剧
（拼接对应品类模板后加）总镜头数80-100个，3秒钩子→37秒铺垫→80秒主冲突+2个小爽点→40秒大爽点→15秒反转→5秒钩子，每2分钟一个大节点
### 10分钟中长剧
（拼接对应品类模板后加）总镜头数200-250个，每2分钟一个大节点，每个节点内置1个小爽点+1个钩子，全程保持高密度节奏
##  对接AI工具专属后缀
### Seedance2.0
适配Seedance2.0生成，运动参数适中，转场用硬切，画幅严格9:16，输出无黑边
### 可灵
适配可灵AI生成，镜头运动自然，避免过度晃动，画幅9:16安全区适配
### 即梦
适配即梦AI生成，节奏匹配生成速度，特写镜头优先清晰对焦人脸

## 🔴 强制必过项（缺一项直接不合格） 
| 检查项 | 合格标准 | 完成打勾 | 
| --- | --- | --- | 
| 画幅适配 | 严格9:16竖屏，无黑边、无变形 | ▢ | 
| 信息安全区 | 所有核心信息（人脸/台词/重要道具）在画面上2/3区域，避开底部字幕/UI遮挡 | ▢ | 
| 前3秒钩子 | 前3秒有明确强冲突/反差/结果前置钩子，能留住用户 | ▢ | 
| 单镜头时长 | 平均单镜头时长≤2秒，普通叙事镜头≤2秒，冲突/爽点镜头≤1.5秒，情感特写最长不超过4秒 | ▢ | 
| 特写占比 | 近景+特写镜头占比≥80%，中景≤15%，大远景≤5%（特殊需求除外） | ▢ | 
| 动态要求 | 80%以上镜头带轻微运动（推/拉/摇/跟），完全静止镜头≤20% | ▢ | 
| 转场要求 | 硬切转场占比≥90%，软转场（淡化/闪黑等）≤10% | ▢ | 
| 结尾钩子 | 最后5秒有明确下集钩子，停在冲突最高点，配引导看下集的文案/音效 | ▢ | 
## 🟠 完播率优化项（直接影响完播率，建议全部达标） 
| 检查项 | 合格标准 | 完成打勾 | 
| --- | --- | --- | 
| 注意力唤醒点 | 每15秒有一个注意力唤醒点（镜头震动/音效/字幕弹窗） | ▢ | 
| 冲突密度 | 1分钟剧至少2个冲突点，3分钟剧至少5个冲突点，10分钟剧每2分钟至少1个大冲突点 | ▢ | 
| 爽点密度 | 1分钟剧至少1个爽点，3分钟剧至少3个爽点，10分钟剧每3分钟至少1个大爽点 | ▢ | 
| 无冗余镜头 | 没有无意义的空镜头、拖节奏的长镜头 | ▢ |
