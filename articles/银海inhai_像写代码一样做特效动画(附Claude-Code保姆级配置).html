这几天在刷 X 的时候，刷到一个挺离谱的视频案例。

作者说自己几乎没剪视频，全程是在和 AI 对话，通过写代码的方式直接做动画，这事一下子把我勾住了。

画面是那种很规整的数据可视化动画，节奏、字幕、讲解都很到位，看第一眼你会以为是哪个剪辑师做出来的，结果点进去一看，全是代码生成的...

顺着线索往下看，才发现是在 Claude Code 用的 Remotion 的 Agent Skills，简单说，就是把 Remotion 这种“用代码做视频”的能力，直接交给 Claude Code 来调度。

我们就不再关心组件怎么写、时间轴怎么对齐，而是用提示词描述你要什么样的视频。

本文内容就会手把手带你在国内用自己喜欢的模型用上 Claude code （ 文末赠送免费使用的Token ） ，然后可以结合着不同的 Skills 做出更有趣的内容。

我干脆照着思路，自己模仿着跑了一次完整流程，目标也定得很明确，做一条 科普解说类的视频 ，不是炫技，就是那种日常内容创作者真的会用到的东西，也经常刷到类似的。

正好小红书上刷到一个灵感，说是做 Space X 的火箭发射故事，而这一些Claude本身就很擅长，所以我提给他的第一个需求就是：

根据这个skill信息，使用这个remotion，帮我制作一个介绍马斯克SPace X的火星发射动画，需要按照时间周期来设计，并且需要有火箭发射到天空上的动画，然后同时呢你需要根据时间周期配备对应的文本解说

我拆的时候，没有只盯着 Remotion 本身，而是把整个视频拆成了三件事：讲什么、怎么说、画面怎么配。

第一步是内容，先让模型帮我生成一段偏口语的科普解说稿，结构清楚一点，有起有落，适合直接念出来。

这里我用到的就是 remotion-dev/skills 这个 skill，它更像一个“视频执行器”。

Remotion Skill 的地址是：https://github.com/remotion-dev/skills

我把文案结构、解说音频的信息一股脑丢给它，让它去负责画面、字幕和简单动画的组合。

真正跑起来之后，我最大的感受是： 已经不太像在“剪视频”了，更像是在描述一个视频应该怎么长。

哪里是标题，哪里是重点句，哪里该停一拍，哪里该换画面，这些事情从操作层，退回到了表达层。

上面这个动画视频， 就是用 Claude code + Remotion Skill 全自动生成的。

这套 Claude code + Skills 的组合跑下来，我只是在改提示词，改文案，改节奏描述，视频本身的生成反而成了一个相对确定的结果，让我很难想象精细化的视频剪辑会长成什么样。

比如说，我第二个需求就是：

帮我设计一个关于 AI产品银海的 视觉动画，需要大概有20秒，然后我喜欢的风格是黑色+高斯模糊毛玻璃等高级一些的视觉效果，你可以使用一些失焦，缩放的效果，然后可以用旁白配音，给我生成最终的这个结果。

有了上面的这些Skill学习基础以及Claude的使用，我们可以更轻松的拿到一个比较好的效果。

这个视频里面，我还加入了文本语音合成能力的 Skill ，它也能自动给你合并成一个音视频文件，如果我们在对于画面细节再进行进一步打磨，它一定会做的更好，核心底层是前端层面。

当然，我也不是想把它吹成“随便一句话就能出大片”，它依然有门槛，比如你得先把 Remotion 和 Claude Code 在本地跑起来，还要要找到合适的 Skill ，才能真的开始玩。

那么，下面就逐步教大家如何使用安装 Claude code。

这篇会提供保姆级的第三方模型在 Claude Code 中使用的一个实际可用配置方案，用起来更灵活，成本也更友好。

先说安装。Claude Code 官方推荐用 npm 全局安装，直接一行命令就可以：

# 通过 npm 全局安装（官方推荐）npm install-g @anthropic-ai/claude-code

装完之后，可以在终端里跑一下 claude --version，如果能看到版本号，说明环境没问题。

claude --version

到这里，其实 Claude Code 已经可以直接用了，默认会走 Claude 自家的模型，但大多数同学不太好搞定Claude API，并且容易封且贵。

Claude Code 实际上本身支持通过环境变量的方式接入第三方推理服务，比如 Kimi、DeepSeek、Minimax 这些模型，都可以统一接进来用。

我这里用的是七牛云的 AI 大模型推理服务，新用户可以直接领一个 1000 万 token 的免费额度，而且是全模型通用的， 地址是：https://s.qiniu.com/26fa2a。

领完之后，在模型广场里选一个你觉得合适的模型就行了，这次演示我选的是 Minimax M2.1，整体体验和响应速度都还不错。

模型选好之后，接下来就是配置 API Key 和模型信息。

直接在本地创建 Claude Code 的配置文件，用下面这条命令：

vim ~/.claude/settings.json

如果之前没有这个文件，直接新建就行，然后把下面这段配置完整贴进去：

{  "env": {    "ANTHROPIC_AUTH_TOKEN": "sk-your-api-key-here",    "ANTHROPIC_BASE_URL": "https://api.qnaigc.com",    "ANTHROPIC_MODEL": "minimax/minimax-m2.1",    "ANTHROPIC_DEFAULT_SONNET_MODEL": "minimax/minimax-m2.1",    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "minimax/minimax-m2.1",    "ANTHROPIC_SMALL_FAST_MODEL": "minimax/minimax-m2.1"  },  "permissions": {    "deny": [      "Read(./.env)",      "Read(./.env.*)",      "Read(./secrets/**)"    ]  },  "companyAnnouncements": [    "您正在使用七牛云 AI 大模型推理服务 🚀"  ]}

其中最关键的就是 ANTHROPIC_AUTH_TOKEN，这里需要替换成你自己的 API Key。

API Key 可以在七牛云控制台里获取，访问 https://portal.qiniu.com/ai-inference/api-key。

登录后创建一个新的 Key 或直接复制已有的就行，填好之后，保存文件并退出即可。

如果你后面想换模型，也很简单。直接在七牛云的模型广场里点开目标模型。

把对应的模型 ID 拿过来，替换配置里的 minimax/minimax-m2.1，保存后重新启动 Claude Code 就可以生效。

配置完成之后，可以简单验证一下。终端里直接输入 claude 启动 Claude Code，然后用 /status 命令查看当前状态。

如果 Base URL 显示的是 https://api.qnaigc.com，API Key 是已设置状态，模型名称也对得上，基本就说明一切正常了。

到这一步，其实已经可以放心用了。

如果你对费用比较敏感，也可以顺手去七牛云控制台的订单管理和资源包管理里看看消耗明细，整体会比较清楚，不太容易踩坑。

到此为止，恭喜你，已经大功告成了。

接下来就很简单了，你可以直接在 Claude Code 里输入各种需求，不管是写代码、改脚本、做工程辅助，还是当一个本地超级助手，用起来都很顺手。

然后你可以直接把 Skill 放到你的新项目文件目录下面，然后直接对它提出你的需求即可。

模型在本地工具里的那种“随叫随到”的感觉，确实会让人效率提升得很明显。
