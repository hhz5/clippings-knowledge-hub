01 

先分清订阅、Codex Credits 和 API

免费用户也可以体验 Codex，但不同套餐的用量、可用模型、Cloud Tasks、Code Review、Credits 和团队能力不同。免费账号更适合体验轻量任务，不适合作为高频开发主力。

  • 订阅：Free / Go / Plus / Pro ，使用 ChatGPT 和套餐内 Codex 能力，适合个人
  • Codex Credits：套餐内 Codex 用量不足后继续使用，符合条件的 Plus / Pro 用户
  • API Key 与 API 余额：按 API Token 计费，适合自动化、CLI、IDE、CI/CD，适合开发者、团队

目前的这几种使用方式的区别，别搞混：

  • 订阅 Plus，不等于自动获得 API 余额；
  • 给 API 账户充值，不等于 GPT 账号变成 Plus；
  • API Key 登录 Codex 时，走标准 API 计费，不走 GPT 套餐内额度；
  • Codex Cloud 需要使用 GPT 账号登录。

普通用户怎么选？目前最合适的还是 Plus，综合性价比最高。

Free $0/月 体验快速、轻量编码任务 第一次了解 Codex
Go $8/月 轻量编码任务 用量较少的个人用户
Plus $20/月 每周完成若干集中开发任务 大多数个人开发者
Pro 5x $100/月起 比 Plus 更高的用量 高频个人开发者
Pro 20x 更高档 Pro 高强度、多任务工作流 重度用户
Business 按团队方案 团队工作区、权限、管理能力 小团队与公司
Enterprise / Edu 联系销售 企业级安全、权限和治理 大型组织与教育机构

如果你只是想体验 Codex：

  • 先用自己的 Free 账号登录。
  • 选择一个小项目。
  • 尝试读取代码、解释文件、修改 README 或修复一个局部问题。
  • 确认工作流适合自己后，再考虑 Plus。

如果你准备把 Codex 用在日常开发：

  • 个人用户优先推荐从 Plus 开始。
  • 用量不足时，先检查任务是否过大、MCP 是否过多、上下文是否过长。
  • 再根据 Codex 用量页决定购买 Credits 或升级 Pro，不要盲目升级。

如果你是团队用户：

  • 优先评估 Business、Enterprise 或 Edu。
  • 团队账号需要考虑权限、日志、数据控制、SSO 和成员管理。

02

Codex 用量和额度怎么理解

官方说明，Codex 用量会受到多种因素影响：

  • 使用的模型；
  • 代码库大小；
  • 任务复杂度；
  • 本地任务还是 Cloud Task；
  • 是否需要保留更长上下文；
  • 是否启用了更多 MCP；
  • 是否使用图片生成；
  • 是否开启更快但更耗用量的模式。

同样是一条消息：

  • 修改一个小函数，消耗可能较低；
  • 扫描大型仓库、执行长任务、加载多个 MCP，消耗会更高；
  • 图片生成平均会更快消耗套餐内用量。

Codex 额度是按照 API Token 用量计费，以每百万输入 Token、缓存输入 Token、输出 Token 对应的额度为计算标准。

「5 小时」 和 「1 周」 两个额度怎么理解？

5 小时额度，相当于短期限流器。防止你短时间内疯狂使用 Codex。用了会减少，5 小时后自动恢复。

周额度，相当于本周总预算，只要使用 Codex 就会持续消耗。不会因为 5 小时到了而恢复，必须等到下一周重置。

两者是什么关系？每次使用 Codex：会消耗 5 小时额度，也会消耗周额度不是二选一，而是同时扣减。

Codex 使用步骤

推荐方式

在受支持地区，打开官网，选择一种长期使用的登录方式：

注册方式 以后怎么登录 注意事项
邮箱和密码 使用同一邮箱和密码 建议开启 MFA
Google 每次继续使用 Google 登录 不要改用普通密码入口
Microsoft 每次继续使用 Microsoft 登录 不要混用其他入口
Apple 每次继续使用 Apple 登录 注意“隐藏我的邮箱”

登录成功后建议设置好密码和密钥等信息，能有效避免后续风控触发手机号二验，但核心还得是你的魔法根基稳定，如果触发二验，就等几天再登录，目前应该都可以绕过，实在绕不过就只能接码验证，这里不展开说明。

05

触发二验是为什么？

这是目前大部分人最需要知道的新问题之一：

  1. 先确认 GPT 网页是否仍能正常登录。
  2. 截图保存完整报错，包括错误代码和发生时间。
  3. 不要连续点击重发短信，避免触发临时频控。
  4. 等待一段时间后再试。
  5. 使用无痕窗口、不同浏览器和干净设备再试一次。
  6. 发工单中明确写明：这是已有账号登录 Codex 时触发的二次验证，不是注册新号。
  7. 以上都无法解决，如果账号之前没有绑定过，可以临时绑定一个通过即可，但是要确保临时绑定的稳定性，否则下次验证就无法进行了。

06

异常与风控排查

1. 报错后的操作，千万不要硬刷和重复高频操作

  • 清理缓存和 Cookie。
  • 切换/更换网络。
  • 等待最多 1 小时再尝试。
  • 避免短时间连续失败登录。
  • 换浏览器、设备或无痕窗口。

 2. 被删除、停用或封禁怎么办

常见原因包括：

  • 违反使用政策；
  • 违反服务条款；
  • 规避安全或访问限制；
  • 不当共享账号或 API Key；
  • 可疑活动或未授权访问；
  • 多次收到警告后仍继续违规；
  • 未完成要求的验证。

3. 正确申诉路径

  • 先检查收件箱和垃圾邮件。
  • 使用停用通知邮件中的申诉入口。
  • 如果无法访问邮件，使用：https://openai.com/form/appeal/
  • 如果没有收到邮件但无法访问，Help Center 右下角聊天入口联系支持。
