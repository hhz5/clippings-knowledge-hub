嗨大家好！我是阿真！

真是薛定谔的懒人，一边不想努力，一边总想写点什么。我一个鹞子翻身起来就是猛猛写！

最近我弟要找工作，我看了一眼他的简历，这都什么玩意，排版能丑成这样？实在忍不了了，搓了个工具给他做简历。

可能很多人都有同感，把简历内容整理出来并不难，但是排版就很头疼。

当一份 Word 简历放在模板里以后，要调整字号，要裁头像，要调整模块顺序，还要保证内容压缩到同一页。改完导出 PDF，发现格式又好像不对。经常是已经有了简历的内容，但是离能够正式投递的简历成品，还有一段很烦的距离。

正好也到毕业季了，有求职需要的朋友们可能也多起来了，我用做了一个 AI 可视化简历生成器。目前是 1.0 版本，效果还不错的。

请注意：下面的各项简历信息均为虚拟内容。

可视化简历生成器

界面长这样👇

先放一些输出版式效果👇

如果你已经准备好了简历内容，但是对排版头疼，对怎么针对心仪岗位改简历头疼，那么可以试试这个哎嘿。

功能很简单但也方便，你可以导入你的简历文档，然后通过接入DeepSeek API 优化简历，还可以导入心仪公司的招聘详情文案，让 AI 基于岗位需求优化文案。文案优化好之后，通过风格预设和布局进行排版，再在右边精修元素块大小、文字效果、间距等，最终在右上角导出。

它把导入、编辑、排版、AI 优化、保存、导出放在同一个页面里，让用户可以从已有 Word、Markdown、TXT 简历出发，快速整理成一份能投递、能打印、能分享的正式简历。

使用路径

它的使用路径很简单，我用一句话来概括：左边选风格，上方选布局，中间直接改内容，右边调细节，顶部负责导入和导出。

下面是简单的使用流程介绍。

导入文档

打开网页，导入文档。这里支持 TXT、DOCX、Markdown 文档。👇

顶部导入文档的右边有【AI 优化】，可以保持原意整理表达，也可以基于岗位需求进行优化。举个例子，比如说你的个人简介，就是那种非常简单的自然语言的个人简介要做成简历，就需要将内容进行结构化，否则在中央的空间里面显示不出来。这时可以点击右边的【AI 优化】功能进行优化。

建议使用【AI优化】，因为它还可以基于版式调整字数，更匹配版式的效果。比如下面的内容直接导入的话，到界面里只有一段话👇

在【导入文档】右边点击【AI 优化】以后，会出来下面这个界面，填入API，然后把目标岗位 JD 也填进去，它就会按照版式去调整和控制内容。

记得去 API 平台新建一个 API 复制到 API Key 的框里👇

这个 API 消耗非常低的大家不要担心，这类任务做100个简历也用不了 1 块钱。除了这一步以外，其他的版式修改是完全不收费的。

简历档案会自动保存，如果你要新建档案，用于不同岗位，就点击【新建档案】👇

内容修改

简历的初版式出来以后，可以开始调整内容细节，Ctrl + 鼠标滚轮可以调整版式显示的大小，右上角也可以通过加减符号调整。

鼠标移动到指定内容的时候就可以点击直接修改，也可以在下方点击添加，比如教育背景这个，点击【添加一条】以后可以添加一个新的教育背景。👇

头像也可以修改，点击头像修改头像；鼠标滑动到头像可以看到滑块，可以修改大小；右键可以修改头像的形状，或者不显示头像。👇

想要添加模块，可以从这里添加👇

想要拖拽和删除模块，把鼠标移动到模块的中间，会出现一个手掌图标，就可以拖拽了。模块右上角会有红色的删除图标，点击即可删除。每一个小的模块也可以添加删除内容。2列的也可以通过拖拽变成1列的版式哦。👇

改完这些以后，就可以进入到排版和精细排版了。

简历排版

对于不想细调的朋友，右边有 8 个一键样式，一键选择，点击就修改完了。👇

想继续找个更好看样式的朋友们，可以把风格预设和布局结合起来匹配出最喜欢的样式。

风格预设这块有 34 套风格预设，可以让大家快速切换简历气质。上方有 14 种布局，覆盖顶栏、左右栏、紧凑、杂志、卡片、时间轴、外框等场景。👇

我尝试几个匹配的效果。商务正式 + 卡片👇

简洁蓝轴 + 时间轴效果👇

柔和奶油 + 左栏，文字比较多的简历优先使用顶栏、左栏、右栏布局。👇

整点杂志感的👇

终端+名片👇

极简留白👇

16 组配色、12 种章节标题样式、字体、标签、头像形状，都可以继续微调。同一份简历内容，可以快速变成商务版、紧凑版、创意版、双栏版、杂志版。

排版微调

上一节分享的是它的风格与版式结合，大家可能会从上面的版式中感觉到一些问题，比如说名字太大、留白太多，或者顶部空间不足之类的。那么右边的微调这一块就派上用场了。

首先是字号与间距，最简单的调整就是在这块调整，字体大小和段落行距还有姓名大小是最重要的，调整后效果会很明显。👇

可以简单调整，也可以逐项微调。很多内容是基于调整后的内容自动调整的，所以改的时候不用太担心。👇

技能标签可以调整不同样式，如果需要强调就用强调效果。这一块也可以调整头像形状，或者你在上一个版式把头像关闭以后，从这里可以再次找到并打开。👇

如果你一切都很满意但是就是不喜欢这个配色，那么可以在右边选择整套配色，或者自己自定义颜色。👇

不同配色效果👇

顶部空间不够的时候，就调整头像的大小，它会自动调整整体的排版👇

最后，还可以调整版面的整体的字体。虽然这里给了很多字体，而且用的都是开源授权的字体，但我建议大家在简历里最好还是优先使用黑体和宋体，不要过于花哨，看起来更加严肃正经一些。字体生效会需要 5-10 秒左右，要稍微等待一下才能看到效果。👇

导出

最后要说的就是右上角的导出了。

首先当然是 PDF 格式，这个在很多场景是最方便。另外，同样支持 PNG 和 JPG 图片格式的导出。

HTML是单文件网页的形式，但是排版还是按 A4 的版式的。最后有Word 和 Markdown 的格式，是考虑大家也可以把基于原始口语化文档优化后的结构化的简历内容，大家也可以把这个内容同步到招聘平台上，或者是保留好内容源，下次导入更方便。👇
