第一步：准备你的「个人原料」

想要创建一个属于你自己的网页，首先需要准备一份最基础的资料。包括：

  • 你希望展示哪些信息；
  • 你能提供的服务或价值；
  • 你希望对方如何与你联系；
  • 你希望突出的个性、标签或技能。

这些内容的本质，是你希望别人如何认识你。

它既是一张「名片」，也是你在数字世界里的「门面」。

你可以准备一个word文档或者用 Markdown 结构的文档都可以，差不多可以长成这个样子：

Markdown文件格式我的个人基础信息

第二步：借助大模型进行内容润色

有了基础信息之后，我使用大模型对资料进行了润色和结构化处理。

我告诉大模型：“ 请帮我把这份资料整理得更清晰、有条理。 ”

结果就得到了一份逻辑清晰、表达自然的文档，然后你可以再局部修改修改让它看起来更靠谱。

使用大模型辅助优化

在这里我还推荐一个小技巧：你可以使用语音笔记的方式快速记录灵感，再借助大模型转写润色，这样能大大提高效率。我曾在另一篇文章中分享过语音笔记的方法，也可以参考： 我是怎么“口喷”就能写出文章的

第三步：进入创作流程，用AI生成网页

接下来，我把整理好的文档投入到「个人博客创作流程」中。这个流程其实非常简单：

我打开了我的 AI 编程工具 Cursor 编辑器，当然也可以咱们之前分享给大家的方法 吩咐 AI 帮我一键运行万星 Github 项目 使用“阿里云百炼 + Clien” 的方式，然后告诉它：

“请读取我的个人资料信息，按照我的风格要求生成网页。”

大概三到五分钟，整个网页就自动生成完毕了。效果真的很不错，页面结构主要由 HTML、CSS 和 Javascript 三部分构成，搭建过程非常高效。
