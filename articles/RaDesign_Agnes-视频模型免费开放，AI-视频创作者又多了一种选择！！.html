2.Agent应用

Pavo Agent 基于自研 Harness 框架运行。用户可以通过一句自然语言描述图片、视频或短片创作需求，由 Agent 理解任务并组织相应的创作步骤。

· 在首页选择 Agent 功能，在输入框上传产品图像，以及附上提示词，等待它默默的跑完并生成。

· 可以看到下方 Agent 围绕该需求完成创意理解、素材生成、图片制作、分镜制作和视频生成。

提示：请根据我上传的产品图像，帮我为一款背包制作一张商业海报和一条15秒广告视频。
