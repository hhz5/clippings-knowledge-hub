大家好，如你所见 LiblibAI 推出的 LibTV AI 视频工具，创作者可以根据需求，利用大语言模型自由组合图像模型与视频模型，并快速搭建工作流。

LibTV 是什么

一款面向视频创作者的工具，已经上线 20+ 的高频视频创作功能，比如：多机位 9 宫格镜头设计、模拟真实影视机位调度、角色三视图生成、快速建立稳定角色设定等「 我下面会讲到 」。

地址：https://www.liblib.tv

Github地址：https://github.com/libtv-labs/libtv-skills

如何使用

· 点击首页 “开始创作” 按钮进入画布创作。

可以看到有 4 个快捷方式，分别为 “故事脚本生成”、“角色三视图”、“首帧图生视频”、“音频生视频”。

左侧工具栏分别为 “添加节点”、“工具箱”、“我的素材”、“历史素材”、“常见问题”。

-

这里最为重要的，也是常用的 “添加节点” 功能，你可以看到在 4 个快捷方式上方一行小字 “双击画布自由生成节点”，里面包含了 5 大节点，“文本”、“图片”、“视频”、“音频”、“脚本” 和 “上传”、“从图库上传”。

· 测试生图模型，我选择 Midjourney niji 7「 MJ审美依旧夯 」模型，LibTV 支持风格参数 “sref” ，太牛逼了！

对比我发在 X 上的原始风格参数，完美呈现「这一刻我的小心脏已经被拿捏住了」。

· 做个简单的图像转换视频节点看看。

点击右侧图像的 “+” 加号，选择 “视频” 生成。

模型选择 “可灵O3” + 提示：图像里的女角色缓缓走向屏幕。

简单的测试甚是满意~

节点流程

基于已有的“文本”、“图片”、“视频”、“音频”、“脚本” 5 类节点，我们可以通过连线的方式，自由搭建出所需要的「任务工作流」，方便之后快速进行复杂任务。

1.角色三视图

· 双击/或者左侧工具栏选择 “+” 进入到 “图片节点” 里输入 “/” ，看看快捷功能。里面包含 “多机位 9 宫格”、“剧情推演 4 宫格”、“25宫格连贯分镜”、“电影级光影校正”、“角色 3 视图生成”、“画面推演 3 秒后”、“画面推演 5秒前”。

注意：只有 “图片节点” 里输入 “/” 才有以上功能，且使用此功能必须有一张图片，可连入“文本节点” 加强控制。

-

· 我们继续用 Midjourney niji 7 模型 + sref 风格代码「选择一个之前生成的」，输出图像。

点击图片右侧 “+” ，选择 “图片节点”，进行 “/” 里的 “角色三视图生成”。

这里注意：换成 Lib Nano pro 模型，比例为 16:9，关掉摄像机「 换模型是因为 Lib Nano pro 生成三视图更稳定，比例 16:9 横向可观看三视图，关掉摄像机是因为还用不到 」。

点击 “角色三视图生成” 后等待即可。

2.脚本生成器

· 根据上方生成的三视图，点击 “脚本节点” ，在脚本生成器里，选择 “角色生成分镜脚本”。

点击图片上方的图标，进行上传图像三视图，一共 2 个 角色节点，我们在生成一个。

添加提示后点击生成等待片刻，生成后点击箭头图标放大看看内容。

觉得没问题就回到画布，点击上方生成分镜。

确认模型、比例、摄像头等没问题继续生成，这里我们把摄像头打开，用默认的即可「专业人士可以自行调整」。

可调节的摄像功能好全啊，我都得私下多学一学，太夯了也「学不完，根本学不完 ！」！

继续等待...

故事情节还原能接受，点击生成视频看看效果。

3.电影级光影校正

· 双击选择 “图片节点”，继续使用 Midjourney v7 模型，进行真实人物测试。

目前颜色单一且偏向暖色，点击右侧 “+” ，拉出一个节点 “图片节点”。

在输入框里输入 “/” 选择 “电影级光影校正”，模型记得换成 Lib Nano 2 快速看看效果。

效果确实优秀，如果觉得还需调整，可以点击上方工具栏里的 “打光” 进行调整。

在 “打光效果” 里调节的角度，颜色都可以调整，我试着把光调整到左上角点击生成。

4.完整工作流流程

· 双击创建 “图片节点” 上传图像 作为参考。

点击图片节点里的 “图生图” ，根据上传参考图，右侧会自动产生节点，同时参考图会自动至新节点的生成器中「这个后面会用到」。

-

· 将准备好的 角色设定 信息填入一个 “文本节点”，然后等待其连接新节点，表示该信息会作为生成器提示词的一部分。

提示：1.风格，请保持上传参考图像的风格不变。2.外貌设定，女性，约18～34岁左右，身材苗条，黑色短发，有些卷毛。饰品金色手镯。气质优雅。3.服饰设计，主色：白色+透明薄纱，类似一体旗袍，但没有袖子，苗条。4.动态设觉，手拿酒杯，在品酒杯里的葡萄酒。5.背景，在高端酒会。

-

· 点击上传的参考图，上方工具栏里 “多角度”，全部生成一遍。

· 生成多角度后，用鼠标框选多个视角的图像和刚才编辑的 角色设定 “文本节点”进行打组，右侧会有一个 ”+“ ，点击 ”视频节点“ 进行生成。

模型选择 可灵O3 ，比例可以改成 智能 ，提示：请根据多角度，生成高端酒会，镜头旋转。

添加 LibTV skill

注意事项写在开头：

· 不同的龙虾由于部署环境差异大，可能出现不同的情况，推荐大家尽量使用本地部署官方 openclaw，或者飞书的 clawbot，或其他稳定的平台

· 不同龙虾吃的语言模型不同，对 skill 的理解会有偏差，推荐大家使用 GPT5.4、Claude 4.6、Gemini3.1、GLM5、Kimi2.5 等模型，不支持多模态理解的模型无法使用此skills。

· 一般 1 分钟视频生成时长在 15-30 分钟，如遇高峰时间，视频生成时间可能更长（比如1小时），建议尽量控制视频在 3 分钟内，因此请大家发出任务后，确认已经回答了基础问题，就可以后台等待了，待 30 分钟后回来验收成果。

-

安装步骤

步骤 1: 你需要先拥有以下任意一个工具：OpenClaw  / 飞书插件 / KimiClaw 。

· OpenClaw 官方教程：https://docs.openclaw.ai/zh-CN/start/getting-started

· 飞书安装教程：https://www.feishu.cn/content/article/7613711414611463386

以上 2 种方法，任意 1 个工具的安装，就可以进入下一步的 LibTV Skill配置！

-

步骤 2: 获取 libtv-skills，这里也有 2 种超便捷的安装方式

· GitHub 直达 ：官方仓库  「 https://github.com/libtv-labs/libtv-skills 」，里面的 README 文件有详细的 npx skills add 一键安装和手动安装教程，小白轻松上手。

· ClawHub 平台一键安装 ：打开 ClawHub Skill页 「 https://clawhub.ai/haofanwang/libtv-skill 」，跟着页面提示点一点，就能把 Skill 直接安装到你的 OpenClaw 环境里，很方便！

-

步骤 3：安装 libtv-skill，拿到 skill 文件后，请解压到对应的 ~/.openclaw/skills/ 目录，即可调用！

-

步骤 4：授权登录 LibTV，要让 libtv-skill正 常工作，还需要神秘密码 access_key，跟着下面的步骤操作，轻松完成配置！

获取 access_key

直接去 Liblib.TV 官网登录账号，把鼠标移到右上角头像，在 账户 / 设置区域 就能找到并复制你的 access_key 啦！

配置 access_key

拿到密钥后，有两种简单的配置方式任你选，配置完成则是🦞完成了 LibTV 的登录。

· 对话式授权 ：直接把你的 access_key 发给 OpenClaw（比如在和 OpenClaw 的对话里按照提示操作），收到「key 已添加」的确认消息，就说明你已经完成 LibTV 登录授权。

· 环境变量设置：直接设置环境变量，然后重启相关进程，libtv-skill 就会自动用这个密钥访问 LibTV 。 输入指令 ： export LIBTV_ACCESS_KEY="your-access-key"

注意：创作过程使用的算力均为你的 access_key 对应的账号算力， 请为 skill 准备充足的“口粮” ！！

-

步骤 5：开始创作！

1. 说出你的创作想法 ：在 OpenClaw 里直接发消息，比如：帮我做一个《凡人修仙传》的漫剧！OpenClaw 会立刻调用 LibTV 创建会话，把你的创作指令传达出去！

2. 坐等成果出炉 ：LibTV 收到指令后就会开始生成图片 / 视频，完成后在对话中返回：

· 可以直接播放的成片视频链接

· 对应的 LibTV project 链接 点击可查看整个创作过程「整个工作流过程需要在结果完成后进行返回 」

3. 提供参考图片/视频

· 如果是本地的 openclaw，请把需要参考的视频/图片的路径发给 openclaw

· 如果是飞书的 clawbot，请打开你的飞书🦞对应的应用设置，开发上传权限后，发送参考图片/视频即可。

4. 随时追踪创作进度 ：想知道任务做到哪一步了？可以直接在对话里问：现在进度怎么样啦？或用具体的 sessionId/project ID 精准查询。

5. 开启新的创作画布 ：默认情况下，所有任务都会在同一个 LibTV 画布项目里进行。可以直接说 “开启新任务”，或者输入指令 create_session ，新开项目将不会保留之前项目的上下文。
