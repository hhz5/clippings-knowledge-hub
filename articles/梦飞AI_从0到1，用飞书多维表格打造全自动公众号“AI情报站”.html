从0到1，用飞书多维表格打造全自动公众号“AI情报站”

梦飞AI AI飞书多维表格公众号运营自动化插件开发 2025-11-10

使用飞书多维表格+智能体，自动获取内容，推送飞书通知，以及总结内容，写作思路，直接生成选题参考的AI情报站教程

原创 张梦飞i 梦飞 AI 2025年11月7日 18:04

之前一直想汇总一下我关注的博主，一旦更新了就自动给我推送文章总结，来掌握资讯。但是一直没有什么好的能抓取公众号文章的方案。

最近看到了一个技术分享，发现还挺好用， 于是专门做了一个飞书多维表格插件。

现在我用这个插件自动帮我抓取博主发布的内容，然后利用飞书多维表格的公式，设置数据好坏的判断标准。如此一来， 某篇文章数据好质量高，这个插件就会自动给我推送飞书通知，以及帮我总结好文章内容，写作思路，甚至直接帮我生成一个选题参考。

「 插件开发思路 」

1、利用公众号后台的「超链接」功能，以此可以获取到任何公众号的文章标题+封面+链接。

2、利用「飞书多维表格」的强大表格和插件的能力，调用「超链接」功能完成提取和录入。

3、利用「飞书多维表格」的字段捷径和AI能力，对文章链接进行内容提取，进而完成分析和总结

4、利用「飞书多维表格」自动化流程能力，将消息推送给我自己。

不得不说，飞书多维表格在这类的 工作流/复盘/AI功能 场景提效使用非常方便，我们在做这些任务的时候，第一反应都是使用它， 而且现在飞书多维表格无需下载飞书，在 base.feishu.cn 上就可以直接使用，很方便。

「 第三步，部署并使用插件 」

如果你自己写了一个插件，要安装到飞书多维表格使用，参考以下方式部署。

以我们写好的代码包和windows系统为例：

首先我们先确保有nodejs和python，去以下地址下载和安装。

python：https://www.python.org/downloads/node.js：https://nodejs.org/zh-cn/download/

下载完成后一路点击“Next”进行安装即可。

然后把下载的代码文件，解压后，进入文件夹，在文件夹地址栏输入CMD，回车，打开终端。

在终端内输入：（服务器与winodws方法一致）：

启动前端项目：

npm installnpm run dev

再新建一个终端，输入以下代码启动后端项目：

pip install -r requirements.txtpython server.py

项目启动后，就可以在飞书多维表格进行使用了：

新建一个飞书多维表格，点击右上角的插件，点击自定义插件

点击新增插件，输入插件名称和服务地址：

服务地址，如果你是windows本地启动的，则输入http://localhost:9000

如果是服务器使用的，则输入服务器IP:9000

输入完成后，在表格创建相应的字段：【封面图、标题、文章链接、更新时间、公众号名称】

然后输入刚刚获取到的两个公众号的参数，以及你想获取的公众号的名称，就可以开始获取数据：

现在我们已经可以提取到文章的标题、封面和地址了。

接下来我们需要把网址里的内容直接提取出来，网址提取文本内容大家应该已经司空见惯，直接拿扣子上的插件「微信公众号内容提取」来用，发布成多维表格的字段捷径就好了。

然后这个字段捷径，在飞书多维表格中，引用文章链接作为输入url，这样就可以获取到文章内容了。

有了文章内容之后，那我们想如何对文章进行分析和处理，都可以非常自由的在飞书多维表格中操作了。

比如使用【总结】这个字段捷径，将【文章内容】以及【标题】给到AI，还可以在【自定义总结要求】中写自己的提示词。让AI按你想要的方式进行总结，后续我们就可以根据总结的内容做相应的推送了。

这些都是在飞书多维表格里完成的。如果你还没有体验过，可以使用 专属邀请码 New2H4g6L3v9B2l 免费获得3个月专业版体验。

如果你用了飞书多维表格，不仅以上功能可以实现，我们刚才获取到的封面图，只能获取到URL，这时候我们用【链接转附件】的字段捷径，可以直接把封面url转为图片。

现在我们的整个表格就完成了，但是只有这些还不够，如果这些文章数据放在那，它就只是个死数据。我根据我内容的评价标准，为AI制定了一个打分标准，这样AI就可以对这些数据进行加工和打分。

然后制定一个「自动化流程」：当近期有多个AI博主都发了某个主题内容时或者有某个文章得分高于8.5时，就会给我发送飞书通知。

到了这一步，我的目的就达到了。但其实利用飞书多维表格的能力，我们甚至可以直接把内容比较好的文章的相关信息同步到我的素材库里去，然后把我的写作风格配置上，让AI按照我标题、内容、封面图风格，帮我生成新的标题、内容、封面图。

不过，我还是喜欢自己探索，以上的功能已经够我用了。
