视频详情

这个案例来自于豆包官方案例视频，跟着这篇教程你可以完整的复刻这个流程。

以此案例，能够让小白对使用龙虾做任务，让AI融入业务，有一个直接的体感。你会体验到AI在业务中的便利性、同时也能体会到AI在长链路任务中存在的不稳定性、甚至幻觉。

但，重要的是，你能够完全切身的体验到AI是如何嵌入业务流中的，这是十分有价值的收获。

这次实验里，为了不把重点放在“怎么分别接模型、接搜索、接视频能力”上，而是直接体验 Agent 在业务链路里怎么工作，我们会用到火山方舟的 Agent Plan：

https://v2mg.cn/2X0dhMlEuk0/

如果在以往方式下，我们要搭一个想这个文章中完整的Agent，需要分别配置大模型、联网搜索、视频处理、向量化、工具调用等能力。

每个能力背后都可能是不同平台、不同 API Key、不同计费方式。

这对开发者来说只是麻烦，对小白来说就是门槛。

Agent Plan 的作用，就是把这些 Agent 常用能力统一到一个套餐里，让你用一个相对简单的方式，把完整工作流跑起来。它把模型、联网搜索、图片/视频、向量化等能力放到一个统一的调用和计费体系里。

所以，我们就不再用为了跑一个 Agent 流程，到处找模型、配 API Key、算不同平台的费用，目前Agent Plan还支持了Seedance 2.0模型的使用。

这对于小白来说，极大的降低了跑通完整 Agent 工作流的门槛。

Agent Plan可以无缝接入到你的任意IDE或者AI工具中，以下是为了跑通这个Case的功能，我们选用Arkclaw来完成。

因此，如果你想要完成这个流程，建议直接上200的套餐，足够一次性跑完全程，下面我们直接进入实操。

完整流程约需要45分钟，以下操作，你可以在「火山动手实验室」完成整个流程：https://developer.volcengine.com/handsonlab/7

实操结果

以下是我们在实验室完成配置后，跑通的效果和过程，一起看看如何走完直播电商全链路的，大家也可以直接在「火山动手实验室」完成整个流程。

整个流程由 ArkClaw 调度，底层核心模型是 豆包大模型2.0。

在此次Case中，我们将以一个服饰类目直播间的春季换新专场为例，通过运营的身份，展示从选品到复盘的完整闭环。

智能选品：结合热点与历史数据，AI挑品

我们只需要在对话框中输入：

帮我结合近期的春季换新热点，以及我们的历史销量和利润率，筛选一下本周直播的潜力商品。https://tokenmap.feishu.cn/base/U7mTb3OtwawUhws9C87c4uZsnjh?from=from_copylink

AI会自动执行：查询品类库获取在售商品数据 → 调用联网搜索分析春季消费热点 → 综合销量、利润率、热度进行多维度选品 → 然后将筛选结果写入飞书多维表格并返回链接。

资质排雷：自动核验供应商

只需要输入提问：

这批品可以直接用吗？帮我评估一下表格里这些供应商的资质。

ArkClaw 会自动执行：读取上一步生成的多维表格，逐一调用供应商资质评估 Skill，核验工商信息、经营状态等关键指标，并主动标记异常供应商。

脚本生成：一句话出完整直播脚本

继续回复：

收到，去掉未检索到有效工商信息的供应商，针对剩下的商品，提取表格里的卖点，帮我生成一份直播的结构化脚本。

ArkClaw 自动执行：先从多维表格中剔除资质异常的商品，然后提取各商品卖点信息，自动生成包含各时段憋单话术和展示动作的结构化直播脚本，并更新到多维表格的新视图中。

这条指令包含三个串联操作：过滤（去掉异常供应商）→ 提取（读取卖点字段）→ 生成（输出结构化脚本）

切片制作：直播高光时刻自动提取

直播结束后，我们可以直接把直播的视频发送给Arkclaw： 

昨晚直播了，录像我刚传上去。请提取昨晚互动率最高的3个高光时刻，自动完成切片处理。

ArkClaw 会自动分析直播录像，识别互动率峰值对应的时间段，自动完成视频切片，并为每个切片预拟短视频文案，全部归档至多维表格。

自动化分发：一句话发布到抖音

输入：

帮我在抖音上发布表格中的第一个切片视频。

ArkClaw 自动执行：从多维表格中获取对应的切片视频和预拟文案，调用抖音视频分发 Skill，自动完成发布并返回视频链接。而且是全程操作浏览器完成。

他会自动打开浏览器发布视频：

数据复盘：自动分析并生成可视化报告

最后，输入要求，AI会根据完整的数据表格进行复盘：

对直播数据进行复盘分析，并给我一个可以公网访问的链接。https://tokenmap.feishu.cn/base/SIhfbEScJaI6Gjs7seycHmZunOf

ArkClaw 自动执行：汇总本场直播的全部数据（GMV、转化率、各品表现等），进行多维度分析，生成带图表的可视化复盘报告，并返回一个可直接访问的预览链接。

**至此，整个操作完成，跑完整个流程之后，你会发现：

Agent Plan 帮我们省掉了很多原本很麻烦的底层配置。如果没有它，你可能需要分别接大模型、联网搜索、视频处理、向量化、工具调用，还要分别处理 API Key、额度、计费和稳定性。

但他把这些底层能力先打包好，让我们不用一上来就纠结模型怎么接、搜索怎么配、视频能力怎么调，而是可以先完整跑一遍：选品、排雷、脚本、切片、分发、复盘。

这是 Agent Plan 在这个Case里的真正价值。

如果你想复刻以上流程，可以直接在「火山动手实验室」完成，这里已经整理好了完整的教程：https://developer.volcengine.com/handsonlab/7

**

如果你在操作过程中，遇到了走不通，或者与预期不符的情况，可以尝试多次对话或者清空上下文。

毕竟，这个任务不是一个简单的、1是1、2是2的固定任务，中间会经过模型多链路的自动处理，尤其是20多分钟的长视频也给模型带来了极大的上下文挑战。

因此，即使你中间有问题也无需气馁，多试几次，长任务的智能体搭建，与普通的AI一问一答不同，工具调用失败、视频处理等待、搜索结果偏差、上下文过长、平台授权中断等等。出现这些问题非常正常。

因为真实的 Agent 工作流，本来就不是一个“输入一句话，立刻得到完美答案”的过程。

难以掌控的环节和错误，也是Agent开发体验的重要部分。
