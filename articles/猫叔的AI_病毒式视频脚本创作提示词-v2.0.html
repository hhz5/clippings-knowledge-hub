# 🎬 三幕式脚本结构

## 第一幕：开场钩子 (前15-30秒)

### 黄金法则：
**标题承诺 = 开场内容 = 结尾兑现**

### 必须包含的4个元素：

1. **视觉冲击** (0-3秒)
   - ✅ 好例子："[展示最震撼的画面] 你看到的这个，花了我3万块"
   - ❌ 坏例子："嘿大家好，今天我要..."

2. **价值承诺** (3-8秒)
   - 明确告诉观众看完能获得什么
   - ✅ "今天我要告诉你如何用50块做出餐厅级别的牛排"
   - ✅ "这个产品的致命缺陷，厂商绝对不想让你知道"

3. **制造悬念** (8-15秒)
   - 提出问题或展示冲突
   - ✅ "但在此之前，我先犯了3个几乎毁掉一切的错误"
   - ✅ "结果完全出乎我的意料"

4. **快速入题** (15-30秒)
   - 不要自我介绍（除非你是新频道）
   - 不要"废话三连"（记得订阅+点赞+开启小铃铛）
   - 直接开始正文第一个要点

### 检查清单：
- [ ] 前3秒有视觉/听觉冲击吗？
- [ ] 观众知道看完能得到什么吗？
- [ ] 有让人想继续看的理由吗？
- [ ] 15秒内进入实质内容了吗？

---

## 第二幕：主体内容 (70-80%时长)

### A. 内容类型适配

#### 如果是【挑战/实验类】：
\`\`\`
结构：设定规则 → 过程展示 → 遇到困难 → 克服/失败 → 结果
节奏：每2-3分钟一个小高潮
技巧：展示真实反应，不要过度表演
\`\`\`

#### 如果是【教程/讲解类】：
\`\`\`
结构：问题引入 → 解决方案 → 分步演示 → 常见错误 → 总结
节奏：每个步骤1-2分钟，用转场词连接
技巧：用类比和例子，避免术语堆砌
\`\`\`

#### 如果是【评测/对比类】：
\`\`\`
结构：产品背景 → 测试维度 → 逐项对比 → 优缺点 → 推荐建议
节奏：每个测试点30秒-1分钟
技巧：用数据说话，保持客观
\`\`\`

#### 如果是【榜单/盘点类】：
\`\`\`
结构：主题引入 → 逐个介绍 → 排名揭晓 → 意外之选
节奏：每项30-90秒，越往后越精彩
技巧：倒序排列（最好的放最后）
\`\`\`

#### 如果是【故事/Vlog类】：
\`\`\`
结构：背景铺垫 → 事件发展 → 转折点 → 高潮 → 感悟
节奏：随情绪自然起伏
技巧：真实细节 > 华丽辞藻
\`\`\`

### B. 留存率维护技巧

**每隔2-3分钟使用以下技巧之一：**

1. **进度提示**
   - "我们已经完成了一半，接下来是最关键的部分"
   - "还记得开头我说的那个问题吗？答案马上揭晓"

2. **制造小高潮**
   - 意外结果
   - 搞笑失误
   - 惊喜发现

3. **视觉变化**
   - 更换场景
   - 切换视角
   - 插入B-roll（提示剪辑师）

4. **互动元素**
   - "评论区告诉我你会选哪个"
   - "暂停视频，猜猜接下来会发生什么"

### C. 内容质量检查

**每写完一段，自问：**
- [ ] 这段话删掉会影响理解吗？（如果不会，就删）
- [ ] 这个信息和主题直接相关吗？
- [ ] 这里会让观众觉得无聊想跳过吗？
- [ ] 有没有用行话/术语需要解释的？

---

## 第三幕：强力收尾 (最后10-20%)

### 结构设计：

#### 1. 兑现承诺 (80-90%位置)
\`\`\`
揭示答案 / 展示成果 / 给出结论

✅ "所以答案是：[清晰明确的答案]"
✅ "最终成品看起来是这样的：[展示]"
✅ "经过测试，我的推荐是：[具体建议]"

⚠️ 不要：模糊其辞、故意绕弯、答非所问
\`\`\`

#### 2. 意外加成 (90-95%位置)
\`\`\`
给观众"超预期"的东西：
- 额外技巧
- 幕后花絮
- 失败片段
- 彩蛋内容

示例："还有一件事我必须告诉你..."
\`\`\`

#### 3. 行动号召 (95-100%位置)
\`\`\`
根据视频目标选择1-2个CTA：

如果要涨粉：
"如果你想看更多[相关内容]，记得订阅"

如果要互动：
"在评论区告诉我[具体问题]，我会回复"

如果有系列：
"下一期我们会[预告]，点这里提前看"

⚠️ 不要贪心要太多（订阅+点赞+分享+评论+...）
⚠️ 给观众一个具体的、容易完成的行动
\`\`\`

#### 4. 结尾画面 (最后3-5秒)
\`\`\`
- 简洁有力的结束语
- 可以重复核心观点
- 或者幽默收尾

✅ "就这么简单"
✅ "感谢观看，下期见"
✅ "我是[名字]，记住这个方法，它真的有效"
\`\`\`

# 🎨 风格与语气指南

## 通用原则：
- **对话式写作**：像和朋友聊天，不是念论文
- **主动语态**：用"我测试了"而不是"测试被进行"
- **具体胜过抽象**："节省30%时间"优于"更高效"
- **真实胜过完美**：承认失败和不足，更真实可信

## 不同风格示例：

### 🔥 激情风格
\`\`\`
"这太疯狂了！当我看到结果的时候我简直不敢相信！"
"听着，这可能是我做过最愚蠢/最聪明的决定..."
\`\`\`

### 🧊 冷静专业
\`\`\`
"让我们看看数据怎么说。第一个测试显示..."
"有三个关键因素需要考虑。首先是..."
\`\`\`

### 😄 轻松幽默
\`\`\`
"好消息是它成功了。坏消息是我的钱包哭了。"
"如果你和我一样[搞笑的缺点]，那你一定需要这个..."
\`\`\`

# 📚 附录：常见问题

**Q：脚本字数和视频时长怎么换算？**
A：
- 正常语速：150-180字/分钟（中文）
- 快速语速：200-250字/分钟
- 加上停顿、画面展示时间，按130-150字/分钟预估更准确

**Q：如何判断一个开场好不好？**
A：
- 给5个陌生人看前15秒，至少3个想继续看

**Q：多长的视频最合适？**
A：
- TikTok/短视频：30秒-3分钟
- YouTube：8-15分钟（广告友好）
- 深度内容：15-30分钟
- **最重要的是：说完你要说的就停，不要为了时长硬撑**

**Q：如果我的内容就是很硬核/小众怎么办？**
A：
- 硬核≠无聊
- 用类比、故事、案例包装专业内容
- 目标是"让外行也能听懂大概，让内行觉得有深度"

【总原则（必须遵守）】
- 全程禁止“水内容”。每一句必须满足至少一项：
  1) 推进目标/剧情；2) 增加期待/悬念；3) 提供新信息/反转；4) 回扣前面埋下的钩子；5) 情绪价值（好笑/爽感/共鸣/惊讶）。
- 开头必须兑现“标题&封面承诺”，否则会掉人。
- 叙事节奏：每 30–45 秒至少出现 1 次“新鲜刺激点”（反转/升级/意外障碍/关键新信息/情绪瞬间/更接近真相）。

3) SEO：
   - 10–15 个“标签关键词”（用逗号分隔）
   - 至少 10 个“话题 Hashtag”（每个以 # 开头）

【脚本结构（必须严格执行）】

A) 片头 Intro（占全文 10–15%）
- 第一句：直接抛出承诺/结果/反差（让观众立刻知道“我会看到什么”）
- 复述标题&封面承诺（用更口语的方式）
- 说明回报（观众看完能获得什么：答案/方法/爽点/真相/情绪）
- 埋 1 个“开放式悬念”（后文必须回收）
- 立刻进入正题（禁止长背景、禁止寒暄）

B) 主线 Storyline（占全文 70–80%）
- 目标必须简单、好理解（用一句话写清楚）
- 4–6 个“里程碑节点”（每个节点都要更接近结果，并带来新的期待）
- 每个节点必须包含至少 1 个：
  - 新信息（观众之前不知道的）
  - 升级（ stakes 变大/代价更高/更接近真相）
  - 反转（预期被打破）
  - 障碍（出现阻力并解决）

- 禁止跑题：所有段落必须能回答“这段对最终兑现有什么作用？”

- 强力收尾：一句有力的 closing line（可带轻微下集钩子，但不强行）
