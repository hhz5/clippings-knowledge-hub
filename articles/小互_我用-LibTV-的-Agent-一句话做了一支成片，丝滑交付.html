实操全程

1打开 Skill 页面

进入首页后，在输入框的下方点击这个全部 Skill就可以打开 Skill 页面

2选择并使用

根据类别，选择喜欢的 Skill，点击使用，就进入这个 Skill 的工作流了。如果你有喜欢的 Skill 就点击收藏，然后还有一种方式可以使用。

3对话框里调用

新建一个项目，对话框里点击这个图标，就会弹出 Skill 菜单，可以选择官方预设的和你刚刚收藏的，或者你自己创建的 Skill，至于自己怎么创建 Skill 一会再说。

4启发式问答

如果你从 Skill 页面直接点击使用 Skill 进入画布，就能感受到工作流的好处了，哪怕你一点想法都没有，通过启发式问答，一步一步了解你的需求，你只要回答，剩下的事情 Libtv 一次性搞定。

聊聊我的整体感受

用下来我最大的感受是，它把上手快和能做深这两件一直打架的事，捏到一块儿了。

但真正让我觉得这个 Agent 模式值钱的，是另一点。

画布时代

一条片子要一个节点一个节点盯出来，跑完一个审一个，没问题才接下一步，人得从头守到尾。

现在

把自己那套成熟工作流做成 Skill 接进去，Agent 就能照着同样稳定的风格和流程，把整条片子自动跑完，出来还是熟悉的那个水准，不用再一个节点一个节点地盯着。

而 AI 生成里那些不可控的小毛病，某个镜头没对上、某个细节穿帮，LibTV 又有画布和故事板兜底，哪儿不满意就在哪儿做局部修正，比推倒重来方便太多。再加上生图、生视频的主流模型它基本都包圆了，一个地方就能调，不用在好几个工具之间来回倒腾。

1Skill 把风格和质量稳住

2Agent 把整条片子自动跑完

3想修哪儿随时在画布里修

4模型还全都在一处

这几样凑到一块儿，才是我觉得它比别家强的地方。

写给新手

对新手当然也友好：

不用学节点

不用懂运镜

挑个 Skill 把想法说清楚，它带着你走完，最后交到手里是一条能直接发的片子。
