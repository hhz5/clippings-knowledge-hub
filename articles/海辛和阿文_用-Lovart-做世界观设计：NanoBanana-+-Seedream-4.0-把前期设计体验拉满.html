用 Lovart 做世界观设计：NanoBanana + Seedream 4.0 把前期设计体验拉满

海辛和阿文 AI世界观设计LovartNano BananaSeedream 4.0 2025-09-15

如果你也在做世界观设计，不妨把你的碎片放上 Lovart 的画布，从第一张草图开始，你的世界，已经在回应你了。

原创 海辛 海辛和阿文 2025年09月12日 20:56

创作虚构作品非常重要的一步是 决定世界观（worldbuilding） 。它决定角色能经历什么、读者会体验什么。

这种前期设计，体验上很像头脑风暴。在我的经验里，画布是最好的承载形式。因为在画布里你可以尽情的在不同的概念之间建立联系和发散，贴上不同的参考图给自己启发。

如今有了 NanoBanana / Seedream 4.0 以后，在画布里进行前期世界观设计体验简直拉满了。以前只能看着画布上的参考图想象，现在能直接根据需求让 AI 生成准确的设计，并轻松 AI 改图。

一、地理设计

我尝试在 Lovart 中构建一个虚构的黑猫都市。不同的世界观会各有侧重，我会从 “地理” 开始设计起。我想设计一个形态像黑猫猫眼的城市。

Prompt：一座坐落在一个巨大圆形盆地中的城市，这个盆地的形状完美地模拟了猫眼的轮廓。城市的地理布局呈现出独特的同心圆结构，从外围到中心分为七个环带，每个环带都有着截然不同的特色和功能。最外围的环带被称为"睫毛区"，这里生长着高耸入云的黑色水晶树，它们像巨大的睫毛一样保护着整座城市。

我想给外围的睫毛水晶树画更明确的示意图，这个水晶树我希望不仅是在形态上模拟睫毛的质感，也有功能的作用，他们能够吸收月光将其转化为城市运行所需的资源。于是我 使用 nanobanana / seedream 4.0，基于已有的城市图进行 remix.

Prompt：请生成这张图上圆圈外围高耸入云的黑色水晶树的设计三视图。

接下来我想基于此画一个城市的俯视图，展示城市不同区域的时间流速不同，瞳孔区 1 天 = 1 天，睫毛区 1 天 = 1 周，越靠近瞳孔，时间流速越快。

Prompt：参考这张图片的内容和风格，画一张这个城市的俯视图的草稿示意图，展示城市不同区域的时间流速是不同的，在最外围的睫毛区，时间流动最慢，一天相当于外界的一周；越靠近瞳孔，时间流动的越快。

有了 Nanobanana 和 Seedream 4.0 的能力，用 AI 细化设计变得容易了许多，生成的图像一下准确多了，而不是凭空瞎想出完全其他画风和内容的东西。

Nanobanana 和 Seedream 4.0 这样有精准修图能力的 AI，给了我们不停进一步修改设计的空间， 同时 Lovart 这样的画布承载形式让想象力能一直自由流淌。

一会儿的时间就得到了一些互相呼应补充的地理设计。

二、文化与传统

对于一些比较模糊的想法，我可以直接调用 Lovart 的 design agent 来帮我头脑风暴。

比如，在我的脑海里，夜瞳城的社会结构采用了一种被称为"梦境议会"的独特制度。城市的重大决策不是通过传统的投票或辩论来决定，而是通过集体梦境来达成共识。

一时间我想不到比较好的可视化这个设定的思路，就可以让 Lovart 来帮我头脑风暴，这是他直接画出来的一组图。

这种模式虽然常常还会有大量需要调整的内容，但会很给我灵感。这一块儿可以延展的内容非常多，这次篇幅有限，就不展示啦。

三、角色设计

在上一部分，Lovart 给我生成的“梦境引导师”的概念图里，我觉得这个角色很有意思。

于是我可以通过 nanobanana, seedream 4.0 提取这个人物，获得三视图，用于下一步的角色细化设计中作为标准。

Prompt：请将图中的这个主角抽离出来，画其角色设计图三视图，维持画风不变。背景为牛皮纸。画幅比16:9

获得这个角色的三视图了以后，我就可以画这个角色在各个场景的图片。

还能生成其不同的角色状态

Prompt：生成这个角色面部特写，在线稿草稿风格的不同的神色状态：羞涩的开心、抬头思考、扶额皱眉、抱着小猫很惬意。白色背景。

结语

当灵感不再只是“想得到”，而是“看得见、改得动、落得下”，世界观设计的难点就从取舍焦虑， 转化为有节奏的判断与取样。

Lovart 让思考被可视化并可回溯，NanoBanana 与 Seedream 4.0 让假设快速长出形态，我们可以在“想—见—改—定”的循环中，把一棵睫毛水晶树，生长为一座按月相呼吸的城市，再从制度与材质里，雕刻出有灵魂的角色。

如果你也在做世界观设计，不妨把你的碎片放上 Lovart 的画布，从第一张草图开始，你的世界，已经在回应你了。
