OpenClaw 是什么？一句话说清楚

OpenClaw 概念图：你的 AI 私人助手

OpenClaw 是一个装在你自己电脑上的 AI 私人助手 。

跟 ChatGPT 最大的区别是：ChatGPT 只能跟你聊天，而 OpenClaw 能 真的帮你干活 ：发邮件、管日程、整理文件、抓取网页数据、控制智能家居…

而且它是开源免费的（但需要自己付 AI 模型的 API 费用，后面会讲怎么选最省钱的方案）。

装好之后，你可以通过QQ、飞书、钉钉、Telegram 或者网页跟它对话，让它帮你做事。

它有多火？ OpenClaw 在 GitHub 上的星标登顶，超越了 React（全球最流行的前端框架）排名第一，只用了一个多月时间，是目前最受关注的开源 AI 项目之一。

开始之前：你需要什么

你需要准备的 说明
一台电脑 Mac 或 Windows 都行（Mac 体验更好，Windows 需要多装一个东西，后面会教）
网络连接 可能有时候需要能访问国际网络（安装过程中要从 GitHub 下载东西）
大概 30 分钟的时间 第一次装会慢一点，后面熟了就很快

不需要的： 不需要会编程、不需要懂代码。虽然要用到"终端"（一个输入命令的窗口），但所有命令都是复制粘贴的，你不需要自己写任何代码。

什么是"终端"？ 终端就是一个跟电脑对话的窗口。平时你用鼠标点击图标来操作电脑，终端是用打字的方式来操作电脑。比如你在终端里输入"打开浏览器"，电脑就会打开浏览器。听起来很高级，其实就是复制粘贴命令而已。

重要提醒：Mac 和 Windows 的安装路线不一样

因为 Mac 和 Windows 的操作差别比较大，下面分成两条路线讲。 请根据你的电脑类型，只看对应的部分。

• Mac 用户 → 往下看「Mac 安装全流程」

• Windows 用户 → 跳到「Windows 安装全流程」

配置向导部分（选 AI 模型、输入密钥等）两个系统是一样的，合并在后面统一讲。

🍎 Mac 安装全流程 （Win用户跳过）

Mac 第一步：打开终端

1 按键盘上的 Command + 空格键 （同时按这两个键），会弹出一个搜索框（叫 Spotlight）

2 在搜索框里输入 Terminal （或者输入中文"终端"）

3 按回车键，或者点击搜索结果里的"终端"

4 会弹出一个窗口，里面有一行文字和一个闪烁的光标， 这就是终端

终端长什么样？ 它就是一个白色（或黑色）背景的窗口，上面可能显示你的电脑名字和用户名，最后有一个 $ 或 % 符号和一个闪烁的光标。你在这里输入命令，按回车，电脑就会执行。

怎么在终端里粘贴命令？ 先在网页上复制命令（选中文字后按 Command + C ），然后切到终端窗口，按 Command + V 粘贴，最后按回车执行。

Mac 第二步：检查有没有 Homebrew

⚠️ 注意：通常情况下， OpenClaw 会自动安装Homebrew 和Node.js ，当你安装 OpenClaw的时候，它顺带就会帮你安装。

所以这里我们先跳到 第五步 ，如果没有安装，再跳回到这一步开始！

Homebrew 是 Mac 上的一个"软件管家"，用来安装各种开发工具。安装 OpenClaw 需要先有它。

在终端里输入下面这行命令，按回车：

brew --version

看结果：

• 如果显示类似 Homebrew 4.x.x 的版本号 → 说明你已经有了， 跳过下一步，直接去"Mac 第四步"

• 如果显示 command not found: brew 或者报错 → 说明没装，继续下一步

Mac 第三步：安装 Homebrew

这一步大概需要 3-10 分钟 ，取决于你的网速。安装过程中会让你输入电脑密码（开机密码）。

如果你的电脑里有，可以直接跳过！

在终端里复制粘贴下面这行命令，按回车：

/bin/bash-c"$(curl-fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

安装过程中你会遇到的情况：

1 要求你按回车确认 → 直接按回车

2 要求输入密码 → 输入你的 Mac 开机密码（注意：输入密码时屏幕上不会显示任何字符，这是正常的！不是卡住了，而是为了保护隐私。盲打输入完密码后直接按回车）

3 屏幕上滚动一堆英文 → 正常现象，等它跑完就行

4 最后出现 "Installation successful!" → 恭喜，安装成功！

如果你是 Apple Silicon（M1/M2/M3/M4 芯片的 Mac）：

安装完 Homebrew 后，它可能会提示你运行两行命令来配置路径。通常是类似这样的：

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile eval "$(/opt/homebrew/bin/brew shellenv)"

请把终端里提示的那两行命令原样复制粘贴执行 （不要用我上面写的，以你终端里实际显示的为准）。

怎么判断自己是不是 Apple Silicon？ 点击屏幕左上角的苹果图标 → "关于本机"，如果芯片那里写的是"Apple M1"、"Apple M2"之类的，就是。

验证 Homebrew 是否装好了：

brew --version

看到版本号就说明成功了。

Mac 第四步：安装 Node.js

Node.js 是 OpenClaw 运行需要的一个环境（你不需要了解它是什么，装上就行）。

注意：OpenClaw 要求 Node.js 版本 >= 22。 如果你以前装过旧版本的 Node.js，可能需要升级。

先检查你电脑上有没有 Node.js：

node --version

看结果：

• 如果显示 v22.x.x 或更高版本（比如 v22.5.0、v24.13.0）→ 版本够了，跳过这一步，直接去"Mac 第五步"

• 如果显示的版本号低于 v22（比如 v18.x.x、v20.x.x）→ 需要升级，继续往下看

• 如果显示 command not found → 没装过，继续往下看

安装（或升级）Node.js：

brew install node

安装完成后验证：

node --version

看到 v22 或更高的版本号就对了。

如果 brew install node 装出来的版本还是低于 22 怎么办？

试试这个命令强制安装最新版：
brew install node@22
然后按照终端里的提示把它链接到系统路径。

Mac 第五步：一键安装 OpenClaw

终于到了安装 OpenClaw 本体的时候了！在终端里复制粘贴下面这行命令，按回车：

curl -fsSL https://openclaw.ai/install.sh | bash

这行命令做了什么？ 它会从 OpenClaw 的官网下载一个安装脚本，然后自动执行。脚本会帮你：
1. 下载 OpenClaw 的程序文件，包括 Homebrew 和 Node.js （如果没有跳回第二步开始）
2. 把它安装到正确的位置
3. 自动启动配置向导

整个过程大概 5-10 分钟 ，等它跑完就行，中间不要关掉终端窗口。

安装完成后，它会自动进入配置向导。→ 跳到下面的 「配置向导（Mac 和 Windows 通用）」 部分继续。

🪟 Windows 安装全流程（Mac用户跳过）

重要：Windows 需要先装 WSL

什么是 WSL？ WSL（Windows Subsystem for Linux）是微软官方提供的一个工具，让你在 Windows 上运行 Linux 系统。OpenClaw 不能直接在 Windows 上运行，需要通过 WSL 来运行。放心，装 WSL 很简单，一行命令就行。

Windows 第一步：以管理员身份打开 PowerShell

1 按键盘上的 Win 键 （键盘左下角那个 Windows 标志）

2 搜索 PowerShell

3 右键点击 "Windows PowerShell"

4 选择" 以管理员身份运行 "

5 如果弹出提示"你要允许此应用对你的设备进行更改吗？"，点" 是 "

6 弹出一个蓝色窗口，这就是 PowerShell

为什么要"以管理员身份运行"？ 因为安装 WSL 需要修改系统设置，只有管理员权限才能做。

Windows 第二步：安装 WSL

在 PowerShell 里输入下面这行命令，按回车：

wsl --install

安装过程中你会遇到的情况：

1 系统会自动下载和安装 WSL2 和 Ubuntu（一个 Linux 系统）， 需要几分钟到十几分钟

2 安装完成后需要重启电脑 → 保存好你正在做的事情，然后重启

3 重启后，电脑可能会自动弹出一个 Ubuntu 的窗口，让你设置用户名和密码

4 用户名 ：随便起一个英文名字（比如 user ），不要有空格和中文

5 密码 ：设置一个你能记住的密码（输入时同样不会显示字符，盲打后按回车）

6 确认密码 ：再输入一次相同的密码

如果重启后没有自动弹出 Ubuntu 窗口： 在开始菜单搜索 Ubuntu ，点击打开它，然后按照提示设置用户名和密码。

Windows 第三步：打开 WSL 终端

以后每次操作 OpenClaw，都在这个 WSL 终端里进行（不是 PowerShell）。

打开方式：

1 在开始菜单搜索 Ubuntu ，点击打开

2 或者在 PowerShell 里输入 wsl 按回车

你会看到一个类似 Linux 终端的窗口，显示类似 user@你的电脑名:~$ 的提示符。

怎么在 WSL 终端里粘贴命令？ 在网页上复制命令后，在 WSL 终端窗口里 右键点击 就是粘贴。或者用 Ctrl + Shift + V （注意：是 Ctrl + Shift + V，不是 Ctrl + V）。

Windows 第四步：安装 Node.js

在 WSL 终端里依次输入下面的命令（一行一行来，每行输入后按回车等它执行完再输入下一行）：

第一行：更新系统软件包列表

sudo apt update

如果要求输入密码，输入你刚才设置的 WSL 密码，按回车。

第二行：安装 Node.js 版本管理工具

curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -

第三行：安装 Node.js

sudo apt install -y nodejs

第四行：验证安装

node --version

看到 v22.x.x 或更高版本号就说明成功了。

Windows 第五步：一键安装 OpenClaw

在 WSL 终端里复制粘贴下面这行命令，按回车：

curl -fsSL https://openclaw.ai/install.sh | bash

整个过程大概 2-5 分钟 ，等它跑完就行，中间不要关掉窗口。

安装完成后，它会自动进入配置向导。→ 继续看下面的「配置向导」部分。

⚙️ 配置向导（Mac 和 Windows 通用）

安装完成后，会自动进入一个交互式的配置向导。它会一步一步问你问题，你按提示选择就好。

安全确认和快速开始选择

如果安装后没有自动进入配置向导 ，手动输入这个命令启动：
openclaw onboard --install-daemon
（ --install-daemon 会让 OpenClaw 注册为系统服务，开机自动启动）

第一步：安全提醒

第一个画面会提醒你 OpenClaw 是实验性软件，会访问你的文件和网络，问你是否了解风险。

操作： 用键盘 左箭头 ← 选择 Yes ，按回车继续。

关于安全： OpenClaw 会读取你电脑上的文件来帮你干活，这也意味着它能看到你的私人文件。建议不要在存有敏感文件（银行信息、密码文档等）的电脑上使用，或者在使用时注意限制它的访问范围。

第二步：选择安装模式

会问你要 QuickStart（快速开始）还是自定义安装。

操作： 选 QuickStart ，按回车。

选 QuickStart 就对了，它会帮你设置好最基本的东西。等你熟悉了以后，随时可以用 openclaw onboard 重新配置。

选择 AI 提供商：四个选项一目了然

这一步是选"AI 的大脑"用谁家的。会列出几个选项，用键盘上下箭头选择，按回车确认。

提供商 推荐度 说明 价格参考

第四步：连接 AI 模型（两种方式）

API Key vs OAuth：两种连接方式对比

选完提供商后，你需要让 OpenClaw 连接上 AI 服务。有两种方式：

方式一：API Key（推荐，更稳定）

API Key 是一串类似密码的文字，用来连接 AI 服务。

以 Anthropic（Claude）为例，获取 API Key 的步骤：

1 打开浏览器，访问 https://console.anthropic.com/

2 注册一个账号（需要邮箱）

3 登录后，点击左侧菜单的 API Keys

4 点击 Create Key （创建密钥）

5 给密钥取个名字（随便写，比如 openclaw ），点创建

6 复制生成的那串密钥

⚠️ 这串密钥只会显示一次！ 一定要复制好保存下来。如果忘了复制，就需要删掉重新创建一个。

其他提供商获取 API Key 的地方：

提供商 注册地址 备注
OpenAI https://platform.openai.com/api-keys 需要绑定信用卡
Google Gemini https://aistudio.google.com/apikey 有免费额度
MiniMax https://platform.minimaxi.com/ 注册送 ¥15 额度
DeepSeek https://platform.deepseek.com/api\_keys 注册送额度，国内直连
KIMI（月之暗面） https://platform.moonshot.cn/console/api-keys 注册送 ¥15 额度

提醒： 第三方服务商可能更便宜，可以多问问，或者问问小互！嘿嘿

API Key 概念：用钥匙连接 AI 大脑

方式二：OAuth 授权登录（更方便，但有风险）

如果你已经有 ChatGPT Plus 或 Claude Pro 的 付费订阅账号 ，OpenClaw 支持直接用你的订阅账号登录，不需要单独购买 API。

操作方法： 在配置向导中选择对应的 OAuth 选项，它会自动打开浏览器让你登录你的账号，授权完成后自动连接。

⚠️ 重要警告：OAuth 方式有封号风险！

2026 年 2 月，有多位用户报告使用 Claude Pro/Max 和 Google 的 OAuth 账户接入 OpenClaw 后 账号被封禁 。PCWorld、SecurityWeek 等多家媒体都报道了这个问题。

建议： 用独立的 API Key，不要用你的个人付费订阅账户的 OAuth 登录。如果你一定要用 OAuth，建议用一个不重要的账号。

第六步：配置聊天渠道（可以跳过，后续通过聊天让龙虾帮你）

这一步决定你以后怎么跟 OpenClaw 说话。可以选：

• Telegram ：推荐海外用户，设置最简单

• WhatsApp ：扫个二维码就行

第七步：技能（Skills）等其他配置

会问你要不要启用一些预装技能（比如网页浏览、文件管理、日程管理等）。

操作： 选 Yes 全部启用。以后用不到的随时可以关掉。也可以选择跳过，后续通过聊天方式安装， 我建议是跳过》

它可能会问你是否要打开网页面板（Web UI），选 "Open the web UI" 就会自动在浏览器里打开。

验证安装成功

装完了，我们来确认一切正常。

检查运行状态

在终端里输入：

openclaw status

如果看到显示 Running （运行中），就对了。

如果显示没在运行 ，输入 openclaw gateway start 启动它。

打开网页面板

在终端里输入：

openclaw dashboard

或者直接在浏览器地址栏输入：

http://127.0.0.1:18789/

什么是 127.0.0.1？ 这是一个特殊的网址，表示"你自己的电脑"。因为 OpenClaw 是装在你自己电脑上的，所以通过这个地址访问。18789 是 OpenClaw 使用的端口号。

如果看到 OpenClaw 的网页面板，恭喜你，安装成功！

发一条消息测试

在面板的聊天框里发一条消息试试，比如输入：

你好，介绍一下你自己

如果收到正常回复，说明 AI 大脑也连接正常！

健康检查（可选）

如果你想更全面地检查有没有问题，输入：

openclaw doctor

它会自动检查各项配置是否正常，有问题会给出修复建议。

常用命令速查表

装好之后，这几个命令你可能会用到，都是在终端里输入的：

命令 作用 什么时候用
openclaw gateway start 启动 OpenClaw 电脑重启后，OpenClaw 没有自动启动时
openclaw gateway stop 停止 OpenClaw 不用了想关掉时
openclaw gateway restart 重启 OpenClaw 改了配置之后
openclaw status 查看运行状态 想看看它是不是在运行
openclaw dashboard 打开网页面板 想用网页跟它聊天
openclaw doctor 自动检查配置问题 出了问题不知道怎么回事时
openclaw update 更新到最新版本 想体验新功能时
openclaw onboard 重新运行配置向导 想换 AI 模型或重新配置时
openclaw logs 查看运行日志 出了问题想看详细错误信息

小技巧： 如果你在安装时加了 --install-daemon ，OpenClaw 会在开机时自动启动，你不需要每次手动输入 openclaw gateway start 。

如果没有，下次打开终端，输入： openclaw tui 即可

常见问题排查

❓ 输入 openclaw 后提示 "command not found"

原因： 终端找不到 OpenClaw 程序，通常是环境变量没配好。

解决办法：

1 先试试关掉终端，重新打开 ，再输入 openclaw status

2 如果还是不行，可能是 npm 全局路径没配好。输入以下命令：
npm config get prefix
看看输出的路径是什么。然后把那个路径加到你的 PATH 里：
echo 'export PATH=$(npm config get prefix)/bin:$PATH' >> ~/.zshrc    source ~/.zshrc

3 如果以上都不行， 重新运行一次安装命令

❓ 网页面板打不开

1 先确认 OpenClaw 在运行： openclaw status

2 如果没在运行： openclaw gateway start

3 再试一次访问 http://127.0.0.1:18789/

4 如果端口被其他程序占用了，可以换一个端口：
openclaw gateway --port 18790
然后访问 http://127.0.0.1:18790/

❓ AI 不回复消息

1 检查 API Key 是否正确： 运行 openclaw doctor ，它会告诉你哪里有问题

2 检查 API 账户是否有余额： 去对应提供商的网站查看

3 检查网络： 如果你用的是国外的 AI 服务（如 Claude、GPT），需要确保网络能访问这些服务

4 检查模型名称： 确保配置文件里的模型名称跟提供商的一致（比如 DeepSeek 的模型名必须是 deepseek-chat ）

❓ Mac 上 Homebrew 安装失败

可能原因： 网络问题，下载超时。

解决办法： 换国内镜像源安装：

/bin/bash -c "$(curl -fsSL https://gitee.com/cunkai/HomebrewCN/raw/master/Homebrew.sh)"

这是一个中国大陆用户维护的 Homebrew 安装脚本，下载速度会快很多。

❓ Node.js 安装失败或版本太低

解决办法 1： 直接从官网下载安装包：
- 访问 https://nodejs.org/zh-cn/download
- Mac 用户下载 .pkg 安装包，双击安装
- 安装完关掉终端重新打开，再输入 node --version 检查

解决办法 2（Mac）： 用 npm 的版本管理工具升级：

npm install -g n sudo n 22

❓ Windows 上 WSL 安装失败

1 确保 Windows 版本够新： WSL2 需要 Windows 10 2004 版本以上，或 Windows 11

2 检查虚拟化是否开启： 打开任务管理器 → 性能 → CPU，看"虚拟化"是否显示"已启用"。如果没有，需要在 BIOS 里开启（具体方法因电脑品牌不同，可以搜索"你的电脑品牌 + 开启虚拟化"）

3 如果提示需要更新 WSL 内核：
wsl --update

❓ 想重新配置

如果之前配置选错了，不用重新安装，直接运行：

openclaw onboard

会重新进入配置向导，重新选择 AI 模型、输入密钥等。

❓ 想完全卸载重装

openclaw gateway stop npm uninstall -g openclaw rm -rf ~/.openclaw

然后重新从安装命令开始。

装好之后可以做什么？

OpenClaw 装好只是第一步。它真正强大的地方在于你可以给它装"技能"，让它会做更多事情：

• 邮件管理： "帮我查看今天的未读邮件，重要的做个摘要"

• 日程管理： "明天下午 3 点提醒我开会"

• 网页抓取： "帮我查一下 XXX 产品的最新价格"

• 文件整理： "把下载文件夹里的图片按日期归类"

• 写作辅助： "帮我起草一封回复客户的邮件"

更多技能可以在 ClawHub（https://clawhub.ai/）上浏览和安装。目前 ClawHub 上已经有超过 13,000 个社区技能，但刚上手不要贪多， 先装几个最实用的就够了 。

但如果你只是装好就用，它就只是一个普通的 AI 聊天机器人——和 ChatGPT 没什么区别。真正让 OpenClaw 变得不一样的，是它的 人设配置系统 。

进阶：给你的 AI 助手塑造灵魂

OpenClaw 的工作目录（默认在 ~/clawd/ ）里有一组 .md 文件，它们就像 AI 的"性格档案"。每次 AI 醒来，第一件事就是读这些文件，搞清楚自己是谁、在帮谁、该怎么做。

你不需要一次全配好， 从 SOUL.md 和 USER.md 开始就够了 ，其他的用到再加。

SOUL.md：它是谁

这是最核心的一个文件，决定了你的 AI 助手的 性格、说话方式和行为准则 。

打开终端，创建这个文件：

nano ~/clawd/SOUL.md

往里面写什么？举个例子：

# SOUL.md - 你是谁  你是小白，一个温柔、直接、有主见的 AI 助手。  核心信条： - 要提供真正的帮助，不是表演式的客套 - 跳过"这是一个好问题！"这类废话，直接解决问题 - 可以有不同意见，有偏好，甚至觉得某些事情无聊 - 提问前先自己想办法，真的卡住了再问 - 做一个你自己都想与之交谈的助手  边界： - 隐私就是隐私，没得商量 - 对外操作（发邮件、发推文）先问再做 - 对内操作（读文件、整理笔记）大胆做

写完按 Ctrl + X ，然后按 Y 保存，按回车退出。

重点： 这个文件你可以随时改。用了几天觉得它太啰嗦？改。觉得它不够主动？改。它会按照你最新写的来。

IDENTITY.md：它叫什么

比 SOUL.md 更简单，就是给 AI 一张"名片"：

# IDENTITY.md  - 名字：小白 - 身份：你的 AI 私人助手 - 风格：温柔、俏皮、支持感拉满 - Emoji：💫

名字随便起，叫"贾维斯"、"星期五"、"小爱"都行。

USER.md：你是谁

这个文件是告诉 AI"你在帮谁"，让它了解你的习惯和偏好：

# USER.md  - 名字：小互 - 时区：Asia/Shanghai - 偏好：沟通直接、步骤清晰、可以直接帮我执行 - 当前重点：做自媒体内容、学习编程 - 互动风格：可以轻松，但执行要稳

写了这个之后，AI 不会每次都问"你好，请问有什么可以帮你的？"，而是直接进入状态，知道你是谁、你在做什么。

AGENTS.md：工作守则

这个文件定义了 AI 的 工作流程和规矩 ，比如：

• 每次醒来先读哪些文件

• 什么操作可以自己做，什么必须先问你

• 群聊里该怎么表现（不要什么都回，像个正常人一样）

• 怎么管理记忆文件

你可以简单写，也可以写得很详细。OpenClaw 安装时会自动生成一个默认版本，后面慢慢按自己的需求改就好。

HEARTBEAT.md：定时巡逻

这个文件让 AI 主动帮你干活 ，而不是等你发消息才动。

# HEARTBEAT.md  1. 检查有没有新邮件，重要的通知我 2. 看看日历，提前 2 小时提醒我有会议 3. 检查系统运行状态  如果什么都没有，回复 HEARTBEAT_OK（别打扰我）。

配合 OpenClaw 的心跳机制（默认每 30 分钟执行一次），它就会像一个尽职的助理一样定时巡查，有事才叫你。

MEMORY.md：长期记忆

AI 每次启动都是"失忆"的，但 MEMORY.md 让它能记住重要的事：

• 你做过的重要决策

• 你的偏好和习惯

• 之前踩过的坑

它会自动维护这个文件——把每天的对话日志（ memory/YYYY-MM-DD.md ）里值得记住的内容提炼进来，就像一个人整理日记、更新自己的认知一样。

六个文件一张表

文件 一句话说明 必须配吗
SOUL.md AI 的性格和行为准则 强烈建议
IDENTITY.md AI 的名字和身份 建议
USER.md 你的个人信息和偏好 强烈建议
AGENTS.md 工作流程和安全规矩 可选（有默认值）
HEARTBEAT.md 定时自动执行的任务 可选
MEMORY.md AI 的长期记忆 自动生成

最低配置： 只写 SOUL.md + USER.md，花 5 分钟，你的 AI 助手就能从"通用聊天机器人"变成"了解你的私人助手"。
