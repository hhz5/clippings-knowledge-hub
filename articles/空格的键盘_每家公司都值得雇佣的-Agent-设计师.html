每一样都要走一遍生图流程。这件事在 codex 用 Skill 制作风格单调、制作低效。

我要实现配图、封面图制作的“高效率”“活人感”和“多样性”。

这就需要能够对接不同的出图模型，能够将多种出图方式融合。

不得不借用一些设计工具来实现，用了一圈设计 Agent 产品，只有 Lovart让我快速沉淀了这套工作流。

去年我就有使用过一段时间 lovart，这是一个原生的 AI 设计产品。

一年过去，Agent、生图模型的能力到了一个新的顶峰，lovart 给我的体验也是如此。

从文章配图到公众号封面，再到虚拟 IP，最后到带 IP 的视频和小红书封面，整套跑了一遍，我就沉淀了 4 个 Skill，收获了 20 多张可以用于生产的精美图片，而整个过程花的时间一小时都不到。

下面是我使用 lovart 完整过程，一起来看看我的使用思路，以及 Lovart 能力如何。

1 文章配图：顺便给视频剪辑攒一批素材

写完文章第一步是配图。技术类长文每隔几段就要一张概念图来续节奏，纯文字读者撑不住。

提示词：

基于这篇文章的内容（粘贴要配图的文章），为我自动拆解段落结构，
给关键段落各生成一张配图。不超过 10 张。
风格：简约手绘 + 建筑蓝图编辑风混搭，参考 Notion / Linear 配图调性。
内容覆盖：
比例 16:9，配色克制，整体能直接插进公众号正文。

一共产出了 8 张配图，下面是我节选的效果，整体很不错

这一批图有两个用途。一是直接插进公众号文章正文，二是后面做视频时当 Broll 素材用，也就是录制视频的时候我可以边讲边用上面图作为视频的画面。一举两得。

我让它用上面同样的风格制作了一张公众号封面图，并在跑完一句话存成 Skill："请帮我总结此对话并生成一个设计 Skill"。

lovart 让我高效低成本的把文字内容的价值榨干。

下次文章只需把 Markdown 丢进去，选择 Skill 就能出图。

这个 Skill 还能用于文章配图，或制作公众号封面，比如这篇文章我就让它制作了一个封面图。

这张封面没怎么改就直接用了。它把文章里 几个核心概念图标化，远看是封面，近看是一张可视化目录。

2 视频封面

文字版的活儿到这就告一段落。下一步是把同一篇内容录成视频，发到 B 站、小红书、视频号。

我去调研了下小红书的视频封面，我发现数据好的视频封面做的都很精致，有创意。

比如下面这些，字体的设计、人物的表情、动作、插入元素，一下就能吸引用户点击。

视频内容的成败有一半在封面 。

文章封面用户先扫到标题，封面差一点点还能挽救；视频封面是用户决定点不点开的唯一判断依据。封面差一口气，内容做得再好也白搭。

公众号的白底简约风搬到视频上完全不够看。

视频封面要的是钩子、是活人感、是辨识度。

我决定先把自己的"虚拟 IP"做出来，再用 IP 出视频封面。

这就实现了我一开头提到的封面创作的多样性和活人感。

4 多主题封面

IP 资产做完之后不能直接上正式封面，要先测试。我挑了 4 个真实可能要写的技术主题，让每种 IP 风格各跑一张 16:9 横版封面，看哪一套风格在不同主题下都稳：

每张封面要求：
- 比例 16:9、3:4
- 左右布局，文字占左侧 60%，IP 在右侧 40%
- 人物动作与标题内容呼应
- 背景加飘浮的 产品 logo、技术元素（代码片段、终端窗口、流程图等）

【效果图：4 张主题封面，各两种尺寸配图】

跑出来 4 张封面风格各异，人物始终是同一个虚拟 IP。

这一轮目的是 用一组对比找到自己的封面公式

封面=设计风格+IP 表情动作+内容标题+内容元素

风格、内容元素都是从内容中提炼出来的，IP 的表情和动作则要和内容标题有关联。

公式定下来，下面就能总结成方法或 Skill。

在下一次使用时调用方法就能生成封面图了。

有了这个流程，我又给自己上面做的封面图加上了虚拟 IP，一下子档次就上来了。

5 Mockup 和字体设计

做完这一套，我突然意识到一件事：我手里这堆规整的 IP 人像，太适合拿去做周边产品了。

我用 Lovart 的 Mockup，就能制作周边的杯子、微章等效果图。

以后真要卖周边、做物料图，这套素材直接拿出来用，省得找设计出图了。

整套工作流跑下来，我手里多了 4 个 Lovart Skill、5 套 IP 风格、十几张可直接发布的封面和配图，外加一组 Mockup 周边素材。从一篇 Markdown 到完整视觉资产，用了不到一个一个小时。
