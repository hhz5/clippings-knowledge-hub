怎么不直接生成肖像照？

很多人做 AI 肖像照，第一步就是上传一张自拍，然后输入一句“帮我生成一张高级职业头像”。

也不是不可以，但是可能容易出现一些问题。比如脸不像本人；风格特别模板感，千篇一律，一看就是 AI 套出来的；皮肤像塑料，毛孔细纹一律抹平；妆容、服装跟自己的气质完全不搭等等。

我分享一个相对更稳的做法，把这个流程拆成两步。

核心流程

准备参考图

    ↓ 

让 AI 基于参考图反推出"男版 + 女版"两组肖像照提示词

    ↓ 

挑自己那组提示词

    ↓ 

上传自己的照片，用自己的照片 + 提示词生成个人肖像照

参考图负责光线、构图、镜头、背景、色调、氛围、摄影质感；自己的照片负责脸型、五官比例、年龄感、发型基础、皮肤质感、自然神态；男女两版服装、妆容、姿态、气质的适配边界，由 AI 一次性给出两套，用户自己挑。

其实就是让 AI 先学会参考图的摄影语言，再将这样的摄影语言迁移到人物身上。

考虑男女两版不是同一段反推内容 + 末尾贴一句性别适配。如果只是在最后加一句“避免裙装浓妆”，模型大概率还是会把参考图里的女性元素照搬给男性组。所以我让它反推出的描述本身，从服装到妆容到发型到姿态到配饰到肤质处理，全部从源头按男女分别写两套。

也有共享的部分，构图、光线、镜头、背景、色调、整体摄影质感。这些是“摄影语言”，跟性别无关，两版完全一致。

这样就不会出现男版提示词用户拿去用，却出现AI 给他穿了真丝吊带之类的灾难现场。

具体操作

其实我在后面放了一个一步调用的 Skill ，但是这个也不一定要使用 Skill，任何能识图的对话 AI 也都能完成任务，所以也可以先按照这个步骤来。

第一步不要直接出图，先让 AI 看图、拆解、写提示词。

下面这套模板可以直接复制给（Kimi、豆包、千问、元宝、ChatGPT、Gemini……）👇

请基于这张参考肖像图，帮我反推出可用于 AI 生图的肖像照提示词，
同时输出男版 + 女版两组，分开代码块，共享的和共同的内容两组提示词都要有。只要用户不做要求，提示词必须默认为中文。

要求：
1. 不要描述图中具体人物身份。
2. 不要复刻图中人物的脸。
3. 男女两版的服装 / 妆容 / 发型 / 姿态 / 配饰 / 肤质 / 表情这七项
   必须从源头分别重写，不是同一段描述加一句性别适配。
   - 男版：服装写西装 / 衬衫 / polo / 大衣，妆容不写或写"自然无妆"，
     发型短或中长，姿态沉稳，配饰极简，肤质哑光真实，
     禁裙装 / 蕾丝 / 长发披肩 / 红唇 / 珍珠 / 柔美姿态。
   - 女版：服装写连衣裙 / 衬衫 / 套裙 / 真丝 / 针织，
     妆容写自然妆感 / 淡眉 / 卧蚕 / 玫瑰唇或裸唇，
     发型可长可卷，配饰珍珠 / 细项链等克制不堆砌，姿态温柔自信。
4. 共享部分：构图 / 光线 / 镜头 / 背景 / 色调 / 整体摄影质感
   按参考图原样提取，男女版一致。
5. 输出的提示词要适合后续配合我的个人照片使用。默认借鉴参考图人物动作，除非用户要求不借鉴。
6. 在每组输出提示词最后加上下列内容：
```使用上传照片作为唯一人物参考。
保留我的脸型、五官比例、骨相、年龄感、发型基础、皮肤质感、身体比例和自然神态。
不要换脸，不要把我美化成另一个人，不要过度磨皮，不要生成通用 AI 网红脸。
只借鉴提示词中的摄影风格、光线、构图、背景、服装气质和整体氛围。
保留毛孔、细纹和自然肤色不均，不要做塑料感磨皮。
背景简洁不喧宾夺主。
不要改变年龄感和身体比例。```

请注意，如果是将输出提示词用在即梦这类生图工具中的时候，提示词多了效果可能时好时坏，这部分提示词可以尝试去掉，作为对比👇

拿到男女两套提示词后，挑自己性别那套，进入下一步。

把第一步反推出来的完整的提示词选择男女任意一版，加上自己的原照片做参考图，给到 AI 工具去生图，就能拿到一张既保留了本人长相、又借鉴了参考图摄影质感的肖像照了。

将提供的肖像编辑成正式的 ID 照片。保留人物原有的面部特征、脸型、骨骼结构、肤色和自然友好的表情。创建一个居中、正面的护照风格的头部和肩部肖像，头部正直，眼睛看向镜头，肩部水平，姿势自然。将随意的背景替换为干净的纯色浅蓝色 ID 照片背景。整理头发，抚平额头和耳朵周围的乱发，同时保持逼真的头发质感。进行微妙的自然修饰，均匀肤色，减少轻微的阴影和瑕疵，保留自然的毛孔和面部细节，不过度平滑。将服装换成整洁的专业深蓝色西装外套搭配干净的白色衬衫，从最终裁剪中去除其他装饰元素。使用柔和均匀的摄影棚灯光，无强烈阴影，面部清晰可见，符合官方文件照片构图，高分辨率，逼真的摄影风格。

小结

参考图管风格，本人照片管身份，就是这么简单。本人照片最好是越清晰越好，细节越好输出的也越像，这点注意一下。

另外，如果希望照片在原基础上进一步优化细节，让照片更有质感，推荐一个工具，叫 Magnific 。
