Gamma 是一款 AI 驱动的在线 PPT 创作平台，只需输入一句提示，就能自动生成结构清晰、视觉精美的专业演示文稿。

Gamma Prompt Library（Gamma 提示库） 是由 Gamma.app 官方推出的 AI 提示模板与自动化工作流程平台。

它汇集了 100+ 个精心设计的 Prompt（提示词模板） ，帮助用户快速创建高质量的简报（deck）、企划案、教学内容、商业计划、销售提案等。

这些 Prompt 专为不同职业与场景优化，涵盖：

  • 顾问（Consultants）
  • 行销人员（Marketers）
  • 教育工作者（Educators）
  • 销售专业（Sales Professionals）
  • 一般用户（General）
  • 开发与运营团队（Operations / Productivity）

除此之外，Gamma 还整合了多个 AI 工具（如 Claude、OpenAI、Zapier、Make、n8n、ElevenLabs、Synthesia 等 ），支持 自动化生成内容与可视化简报 ，形成一个完整的「AI 内容生产生态系统」。

🌟 1. 顾问类（For Consultants）

这类 Prompt 主要用于商业策略、投资分析、市场研究与高层简报：

  • 医疗系统扩张计划：包含人口热力分析、选址打分、资本预算、盈亏预测。
  • 生物科技临床试验优化：病患招募策略、数字化工具节省成本方案。
  • 不动产投资信托（REIT）资产组合优化：保留/出售策略、五年价值增长规划。
  • 保险业数字转型路线图：当前成熟度评估、三年时间表与ROI。
  • 金融科技并购尽职调查报告：业务模型、财务状况、技术栈、风险评估。

👉 适用对象 ：顾问、战略部门、研究分析师。

💼 2. 行销类（For Marketers）

专为品牌经理与市场企划人员设计的 Prompt：

  • 品牌视觉指南：故事、标志规范、配色表（含Hex代码）、语调、影像风格。
  • 可持续鞋履营销活动：Z世代目标族群、预售目标、网红合作、广告预算。
  • DTC家具品牌预算计划：50万美元预算分配、ROI分析、三种情境模拟。
  • 内容策略：B2B网络安全公司内容支柱（合规、情报）、SEO集群、排程表。
  • 社群行销活动：地球月可持续品牌宣传，4周日程，跨平台策略（Instagram/TikTok/LinkedIn）。

👉 适用对象 ：行销经理、公关人员、品牌主理人、自媒体经营者。

🎓 3. 教育类（For Educators）

这些 Prompt 为教师和培训师打造，帮助快速生成课程与教学计划：

  • 《了不起的盖茨比》文学分析：作者背景、象征主义、讨论问题、论文题目。
  • 小学语音课（-at 字族）：学习目标、单词例句、小游戏与家庭作业。
  • 巴黎气候协定课程：NDC、气候融资、政策辩论与模拟活动。
  • 数学教学示例：分数教学（用披萨模型讲解），含视觉步骤与动手练习。
  • 情绪管理课：辨识挫折、身体信号、应对策略、角色扮演。

👉 适用对象 ：中小学教师、大学讲师、教育科技工作者。

💰 4. 销售类（For Sales Professionals）

专注销售提案、客户沟通与产品演示：

  • AI客服工具试点方案：30天实验、成功指标（响应快30%）、实施计划。
  • HR软件需求探索电话结构：识别问题、定量痛点、ROI场景。
  • 财务管理平台商业案例：人工流程痛点 vs 自动化解决方案。
  • CRM竞争分析：与Salesforce对比、差异化价值、成本节省分析。
  • 客户续约简报：展示自动报表节省工时、下季度新功能预告。

👉 适用对象 ：销售经理、B2B客户代表、解决方案顾问。

🧩 5. 一般用途（General Prompts）

用于企业运营、创业、非营利项目等：

  • 四天工作制提案：生产力研究、试点计划、成功指标。
  • 家族五金店品牌重塑：保留传统精神、现代化体验、电商策略。
  • 青少年编程非营利计划募资书：预算与影响力分析。
  • 团队愿景演示：2030年书店蓝图、社区活动空间。
  • 设计思维工作坊议程：同理图、快速原型、反馈回合。

👉 适用对象 ：创业者、非营利组织、团队负责人。

使用方式说明（如何使用 Gamma Prompt Library）

  1. 访问网址 → https://gamma.app/zh-tw/prompts
  2. 选择分类 → 选择「顾问」「行销」「教育」等主题。
  3. 点开具体Prompt → 查看示例说明与内容结构。
  4. 点击“View Prompt” → 自动打开 Gamma 编辑器，AI 会生成对应简报。
  5. 自定义调整 → 修改文本、图像或排版即可导出。
  6. 可结合API自动化 → 若企业用户可连接 Zapier / n8n 实现全流程自动内容生成。
