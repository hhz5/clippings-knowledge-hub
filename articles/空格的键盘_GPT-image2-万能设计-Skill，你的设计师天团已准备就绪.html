这几天一直没发 GPT-image-2 的内容。

看到很多测评文章，毫无疑问它是图片生成的最高水平，文字毫无瑕疵，风格多变，没有 AI 味。

那我该怎么把它用起来呢？

过去的几天，我一直在围绕 GPT-image2 来设计 Skill，终于有了一个稳定的 Skill。

它可以帮我产出 PPT、文章配图、封面图、逻辑图、架构图、流程图等等等。

就像这篇文章的封面图，我一次召唤它产出了 5 张，每张效果都巨巨好看啊🤩！

所以这篇文章我不止介绍下我的这个 Skill 可以做什么，还要拆解我制作它的思路。

01 我的作图场景有哪些？

对个人用户来说，我不是设计师，但我日常工作也经常会用到配图的场景。

最常用的作图场景就这几个：

1封面图。小红书、公众号、视频号，一天可能要好几张。

2文章配图。写完文章要插图，总不能全用 。3 PPT 图。演讲、分享、汇报，每页都要设计。 4 流程图、架构图、数据可视化。产品方案、技术分享、工作汇报。

5原型图。产品设计、验证、需求沟通。

刚好这几个场景之前都做过对应的 Skill。

只是之前用的是让 AI 生成 HTML 的方式，画出来是网页，截图当图用。

我只需要把 HTML 换成GPT-image-2 模型出图就好了。

放在以前，我要说 html 出的 PPT、配图和图片模型出的各有优势

现在可以说 GPT-image-2 的出图完胜 html。

想清楚了，就开干。

02 让 AI 自己改自己的 Skill

我的做法很直接：把需求扔给 Claude Code，让它参考之前做过的 Skill，复刻一个新的出来。

我跟它说的大致是：

🌰参考 PPT 制作那个 Skill，做一个用 GPT-image-2 出图的 Skill。流程是用户输入内容，先问要什么类型，确认信息齐全后问选哪种风格，再问是自动生成提示词还是审核后再生成，最后出图。

Agent 就开始干了。

它读了我之前 slide-deck 的结构，理解了风格定义的方式，然后把整个流程重新设计了一遍。

连着做了好几 Skill，做完就开始测。

这一测就是好几天。提示词太长会被 API 拒，4:3 大图会超时，PPT 风格出来字太少太单调，每个问题都是一轮迭代。

最后稳定下来的版本，就是下面几个 Skill。

03 先做单个 Skill

1 文章配图 Skill。

给一篇文章，自动分析每段核心内容，批量生成配图，再插回 markdown。一篇文章 6 张图，10 分钟搞定。

下面是根据 DeepSeek v4 发布文章出的配图。

2 PPT 制作 Skill。

给一个主题和大纲，逐页生成幻灯片设计图，最后能导出 PPTX 和 PDF。

3 小红书封面：

给一个你的封面描述，选择风格就开始制作封面图。

4 各种图表

流程图、架构图、热力图、四象限图、数据可视化，都可以一句话制作。

04  合成 image-studio Skill

几个 Skill 各自能用，用起来得不对劲。

每次换类型就得切 Skill，风格定义各管各的，维护起来麻烦。

花叔做的 huashu-design 给了我启发，他把多种设计能力整合进一个 Skill，用一套统一的品牌资产协议贯穿所有输出。

于是我让 Agent 把上面三个合成一个，顺手把风格从原来的几种扩到 12 种：

每种风格是一份完整的设计规范：底色 hex、标题字体和字重、5-8 个颜色的色板、视觉元素清单、该做什么和绝对不做什么。

测稳定后，一个统一的space-image-studio Skill就成型了。

用户只要说一句话，（但是不建议一句话，最好是描述的越详细效果越好）

画张小红书封面：标题"我用AI每天读100篇文章"，xhs-vibrant 风格做张PPT配图：核心观点 Context not Prompts，minimal 风格画个产品路线图，dark-atmospheric 风格

打字。回车。一张能直接发的图。

已开源：

https://github.com/zephyrwang6/space-GPT-image2-design

05 怎么调 GPT-image-2

有两个方法我都在用。

一是用 Codex。开 ChatGPT Plus 会员就能在 Codex 里调 GPT-image-2。Codex 天然和 Skill 配合，在 Claude Code 里配好 Skill，让 Skill 调 Codex 的 API 出图。Plus 一个月 20 美金，不光是聊天，Codex 算力也包在里面。把 Plus 的价值榨干。

二是买 API。OpenAI 官方的、中转站的都行。成本一毛多一张图。具体哪家不推荐了，市面上很多，自己搜搜比比价。

我两种都在用。日常写文章配图走 Codex，批量生成走 API，速度更快。

06 最后

虽然内置了 12 种风格，但更建议拿过去之后自己再改改。

按自己常用的场景和审美修改风格定义，这才是真把它用起来的方式。

每个人的设计品味不一样，我定义的 不一定是你喜欢的。把色板换成自己的品牌色，把字体换成顺手的，把"该做什么"改成自己的设计偏好。

有了 Skill 和模型 API，各种 AI 产品提供的画图能力可以自己 DIY。

相当于自己拥有了一个设计师团队，没必要再花几十美刀订阅费了。
