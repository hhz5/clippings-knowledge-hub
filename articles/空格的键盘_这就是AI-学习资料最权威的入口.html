这篇文章整理了 Anthropic 、OpenAI、Google AI  官网公开的 AI 学习资料，帮你熟悉官方文档结构，下次遇到 Agent、模型、工程问题时直接去源头找答案。

我建议大家学 AI，先别急着到处收藏二手资料。

最权威的资料，其实就在模型御三家的官网里。Anthropic，OpenAI，Google。

他们直接研究模型，训练模型，发布模型，还要把这些模型交给应用厂商、开发者、企业团队和千千万万的普通用户使用。

对我来说，我最常看的，是 Claude 官网里的 Engineering 模块。这里是工程团队直接写他们怎么构建 Agent，怎么做 Context Engineering，怎么给 Agent 设计工具，怎么把 Claude Code 这种编码智能体用好。

更重要的是，这些模块一直在更新。

所以这篇文章，我整理了三家公司官网公开的 AI 学习资料。目的是让你熟悉这些文档的结构。

下次你遇到提示词、函数调用、结构化输出、Agent 编排、上下文工程、模型幻觉、工具设计这些问题时，可以直接去源头找答案。

你甚至可以做一个 Agent，专门追踪这些页面的更新。

下面我分别介绍 claude 、openai、google ai 官网的学习资料所在的模块和介绍，以及值得学的文章推荐。文末附所有链接。

Anthropic / Claude

最值得精读的是工程模块

官网 Learn 菜单、教程、用例、工程博客与开发者文档共同组成 Claude 的学习地图。

入口

Anthropic Learn

Claude Tutorials

Anthropic Engineering

Claude Developer Docs

1Anthropic Academy

官方课程平台，偏系统学习。从 Build with Claude，到 Claude Code in action，再到企业协作场景里的 Claude for work，都属于这类内容。刚开始从 API 或工作流角度理解 Claude，可以先看这里。

2Tutorials

面向普通用户和进阶用户的教程库。比如如何选择 Claude 模型，为什么 AI 会幻觉，什么是 sycophancy，也就是模型为了讨好用户而给出不可靠回答的倾向。

3Use cases

这块很适合找灵感。比如按品牌规范审核一整个素材文件夹，把同一页教材改写成不同阅读层级版本，或者在财报后更新财务模型。

★Engineering at Anthropic

这是我最推荐精读的一栏。它把 Agent 从玄学概念拉回工程问题：什么时候用工作流，什么时候才需要更自主的 Agent，如何拆解规划、工具调用、反馈循环。

Building effective agents：Agent 设计模式总纲。

Effective context engineering for AI agents：讲真正复杂的 Agent 如何组织上下文。

Equipping agents with Agent Skills：给 Agent 准备可复用能力包。

Claude Code Best practices：如何把编码任务交给智能体。

Writing effective tools for agents：Agent 能不能干活，很多时候取决于工具是否清晰、可控、可观测。

5Claude Developer Docs

API 和开发文档，重点看 Prompt engineering、Tool use、Extended thinking、Agent SDK、Agent Skills。如果 Engineering 是认知框架，Developer Docs 就是落地手册。

文档最全，Cookbook 最有价值

OpenAI 的开发者资料，更像一套完整工程手册。API、Agents、Cookbook、Codex、Blog 都值得放进资料源。

优先看 Text generation、Prompt engineering、Structured outputs、Function calling、Reasoning best practices。很多应用一到生产环境就不稳定，往往就是这些基础没吃透。

2Agents SDK

重点是多智能体系统，包括 Quickstart、Orchestration、Guardrails、Approvals、Agent Evals。真正做 Agent，不是让模型自由发挥，而是设计任务流、边界、审批机制和评测方法。

OpenAI Cookbook

4Codex Docs

适合所有做 AI 编程的人看。AI 编码不是简单让模型补全代码，而是把工程任务变成可以被智能体理解、执行、验证、交付的工作流。

Codex Overview

学习路线图

问题来了，这么多资料，应该从哪里开始？

我的建议是按目标读。

**想理解 Agent：**先读 Anthropic 的 Building effective agents，再读 Google 的 Agents 白皮书，最后看 OpenAI Agents SDK 的 Orchestration 和 Evals。

**想做 AI 应用：**先读 OpenAI 的 Structured outputs、Function calling、Reasoning best practices，再对应看 Claude 和 Gemini 的 Tool use、Function calling、Long context。

**想提升日常使用能力：**先看 Claude Tutorials 和 Google Prompt Engineering 白皮书。

**想做 AI 编程：**直接看 Claude Code Best practices 和 OpenAI Codex Docs。

特别提醒

不要把官网文档当成一次性资料。

这些页面是活的。模型更新，接口更新，最佳实践也会更新。

今天有效的提示词写法，过几个月可能就不是最优解。今天推荐的 Agent 结构，随着模型能力变化，也可能被重新设计。

所以更好的办法，是做一个自己的资料追踪 Agent。

可以优先追踪这些模块：

Anthropic Engineering

OpenAI Cookbook 和 Developers Blog

OpenAI Agents SDK

Claude Developer Docs

Gemini API Docs

Google Kaggle 白皮书页面

这样你就不用每天刷信息流，而是让信息流来找你。
