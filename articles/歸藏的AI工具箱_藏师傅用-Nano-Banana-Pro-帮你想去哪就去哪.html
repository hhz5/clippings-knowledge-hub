藏师傅用 Nano Banana Pro 帮你想去哪就去哪

歸藏的 AI 工具箱 AINano Banana Pro旅行打卡AI生成图片歸藏 2025-11-26

藏师傅做了个产品用 Nano Banana Pro ，帮你生成任何位置、时间和次元的打卡照，写个使用教程。

原创 歸藏的 AI 工具箱 歸藏的AI工具箱 2025年11月25日 20:57

前几天 Nano Banana Pro 发布之后早上看到了 Deepmind 官方的一个用法，就是给到 Nano Banana Pro 经纬度让他直接生成对应地点的照片。

主要基于 Nano Banana Pro 的实时检索能力，他可以通过经纬度知道这个地点的具体位置。

我试了一下果然可以，而且我还给他生成的照片加上了对应的水印，同时让他检索对应位置的当前时间和天气，让生成的照片更加符合现实场景。

然后我就想 Gemini 3 这么厉害，不行做个水印相机吧，于是就在 AI Studio 里面的 Build 模式里直接一句话错出来了。

之后有个朋友就说可以加个人像的打卡，然后我就加了，加了以后一发不可收拾，就在上面加各种各样好玩的东西。嗯，现在这个想去哪里点哪里的相机已经彻底完工了，给大家介绍一下。

顺便我也为他做了一个官网，（ https://bananacamera.trickle.host/ ）这里有简单的介绍以及各个渠道的使用方式。

你可以通过搜索地址或者在地图上点击对应位置来触发图像生成。

图像生成目前有两个模式，Scenery 风景模式只生成对应位置当前的风景，他会查询当前位置的时间和天气生成符合的风景照片。

比如我这里随便选了一个新加坡的位置，他就基于现在新加坡的时间（20:15）以及当前的天气（晴天）为我生成了一张对应的照片。

同时生成的照片下方也会有当前地理位置、时间、天气和一句当前环境的介绍，你完全可以当一个虚拟谷歌街景来用，瞬间穿越到地球上的任何地方。

说完最基础的，就得说最重要的另一个 Travel Portrait 人像打卡照功能了，切换到这个 Tab 他就会让你上传人像照片，直接给你生成你选择地点的你本人的打卡照。

比如我这里选了罗马，他就会基于罗马现在的时间、天气、温度帮我生成对应的打卡照，而且还会根据当前气温为你选择合适的衣服。

比如我写这个文案的时候罗马是 12:48 而且在下雨，他就帮我穿了一件外套，而且我手上还拿了把伞。

比如这里我测试的时候选了四姑娘山，他就帮我穿上了厚羽绒服以及戴上了帽子，打卡照后面就能看到川西的雪山。

很多朋友问支持合照吗，当然支持，如果你本身上传的是合照，他就会帮你生成合照，这里我随便找了个明星的合照试了一下。

介绍完基础功能就得介绍我们的特色能力了，你会注意到在模式选择下方会有个开关时间机器（Time Machine）。

它可以将你送到当前位置的任何年代以及位面，如果你现在的是 Post Era 这个选项你可以填写过去和未来的任何一个年份，他就会模拟生成这个位置那个时代的打卡照，当然你的装扮也会发生变化。

如果你选择的是 Dimension/Style 他就会将你送到这个地方的任何平行宇宙中去，你可以输入影视作品的名称或者图像风格的名称。

我们来看一下案例我这里选了公元 1000 年的伊斯坦布尔，他就帮我送到了那个时候，建筑风格以及我的穿着风格都发生了变化。

这里我填写了一个黑客帝国的风格，选择罗马，他就生成了有类似黑客帝国数据流的罗马斗兽场打卡照，甚至我自己的服装都换成黑色风衣了，左下角票据风格也发生了变化。

聪明的你肯定看到了另一个开关 Prank Mode 恶搞模式，这个模式会在你的打卡桌上生成各种意想不到的乱入元素。

比如这里我选择了新加坡，又打开了恶搞模式，他直接给我身后塞了个自拍的外星人。

好了，这就是目前的产品功能了。虽然介绍的能力比较少，但是它的潜力非常大。比如说那个时间和风格那个部分，你完全可以自定义提示词，通过各种元素的组合可以得到非常多非常离谱的结果。

太平洋中央或者南极冰盖再或者想要登上珠穆朗玛峰都不再是不可企及的目标。

如果你就是想快速的尝试的话，我们左边这个example的部分有一些预设，会随机挑选地址，点击之后上传你的照片就可以快速生成了。

最后说一下怎么使用。

在官网（ https://bananacamera.trickle.host/ ）下方你可以看到目前这个产品所有渠道的链接。

其中 AI Studio 是效果最好同时功能最全的，但是他需要你有付费版本的 AI Studio API Key ，其实测试几张图需要的钱不多，如果你有多币种信用卡，可以绑了试试。

Poe 的机器人调用的也是 Nano Banana Pro，这个如果你有 Poe 的订阅会员可以用，他会消耗你的 Poe 积分，不过目前他们的 Nano Banana Pro 模型好像出了点问题，一直繁忙，可以过会再试。

Youware 上面的应该是大家最熟悉的平台，这里也会消耗你的 Youware 积分，也支持免费试用，只是目前这里是 Nano Banana 普通模型，中文生成可能会有问题。

你可以选择合适你的渠道进行尝试，后面我也会做一个独立的平台，更新更多的功能。

那有朋友就说了，老师老师这三个平台我都不能用，我怎么办呀？没问题，我们还有 提示词版本 。

你可以去谷歌地图找到你想要去的位置的点，然后点右键就能获取这个位置的经纬度，然后将经纬度替换到提示词里面，找一个支持 Nano Banana Pro 的地方用就行。

创建一幅经纬度位于40.00023661635351, 116.27808154448789并且符合当地当前时间氛围和实时天气的图像，在照片左下角用优美的排版写上当前经纬度以及位置信息和天气图标，并加上一句中文位置介绍文案。
