咖啡的一生

提示词

生成一张中文高密度科普信息图，主题是“从咖啡豆到一杯拿铁”。

画面右侧增加“拿铁配方小卡”：浓缩咖啡 30ml、牛奶 180ml、奶泡 1cm、出杯温度 60-65℃。底部增加“咖啡标签怎么读”小字说明区，包含：产区、海拔、处理法、烘焙日期、风味描述。整体像博物馆科普展板和咖啡课程讲义结合，文字很多但层级清楚，中文必须清晰可读，不要乱码，不要水印。

2提示词写法规律

信息图 prompt

结构通常是：

主题与对象：先说“做什么信息图”，例如咖啡流程、茶叶分类、花卉图谱、地质演化。

中心视觉：指定画面中心的主体，避免模型散掉。

模块清单：列出流程、分类、图表、卡片、说明文字。

版式与风格：网格、流程箭头、自然科普、手账、博物馆展板。

文字字段：每个模块要出现什么标题和说明。

可复用提示词模板：

生成一张[主题]信息图。中心放置[核心主体]；四周按清晰层级排布[模块1]、[模块2]、[模块3]、[流程/分类/图表/说明卡片]。整体采用[风格/配色/材质]，文字需要清晰可读，信息主次明确，可直接用于[科普/教学/品牌内容/文章配图]。

精准改图 prompt

结构通常是：

明确输入图：哪张是原图，哪张是参考。

明确目标对象：只改杯子、衣服、黑板、沙发、包装盒。

明确修改动作：改颜色、换材质、替换文字、新增图案。

明确保持项：人物、背景、光照、构图、其他文字不变。

可复用提示词模板：

只修改图中的[目标对象]，把它改成[新颜色/新材质/新文字/新状态]。保持[人物/背景/光照/构图/其他元素]不变。修改区域要自然融入原图，边缘、阴影、透视和材质要真实，不要改动其他区域。

草图渲染 prompt

结构通常是：

说明草图类型：平面布局、白模构图、建筑体块、分镜站位。

锁定主要结构：哪个物体在哪里，人物站位在哪里。

指定成品风格：室内效果图、电影分镜、建筑渲染、展厅效果。

强调不要改变布局。

可复用提示词模板：

按照草图生成一张[成品类型]。保持草图中的主要布局：[区域/人物/家具/建筑体块/镜头关系]。整体风格为[风格]，加入[材质、光线、环境细节]。不要改变主要结构和位置，不要多余文字，不要水印。

写实影像 prompt

结构通常是：

场景与主体：人物、动物、植物等。

摄影语言：自然光、胶片、静物、街头、低角度、长焦、浅景深。

光影：窗光、反射、逆光、雨后路面、低照度。

材质细节：玻璃、金属、陶瓷、织物、纸张、木头、水珠。

情绪和用途：安静、纪实、商业摄影、电影剧照。

可复用提示词模板：

[主体/场景]，[镜头角度与构图]，[光线条件]，[材质细节]，[情绪风格]。要求主体细节真实，背景与光影自然融合，呈现[静物摄影/街头摄影/商业摄影/电影剧照/建筑摄影]质感。

多语种广告 prompt

结构通常是：

先锁定同一视觉模板。

再列出每个语言版本的标题。

明确哪些语言要注意特殊字符或书写方向。

强调构图、光影和主体一致。

可复用提示词模板：

生成[数量]张同版式[产品/活动]广告海报，主体、构图、色彩和光影保持一致，只替换标题语言：[语言1+标题]、[语言2+标题]、[语言3+标题]。注意[阿拉伯语从右到左/西班牙语重音/法语重音/日韩文字结构]，所有文字清晰，不要乱码，不要水印。

用长提示词控制高级时尚人像的摄影、妆造、构图和材质

这条 prompt 的写法很典型：

人像图别只写“高级、好看”，摄影、妆造、构图、材质、光影，全都写清楚，结果才会更稳定
