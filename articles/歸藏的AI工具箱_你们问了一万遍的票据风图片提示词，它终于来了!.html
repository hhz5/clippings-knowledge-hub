我经常一种票据风格的提示词帮我的内容生成图片，很多朋友一直问啥时候发。

终于腾出手来折腾一下。

把这个风格打包成了一个为你的文章生成配图和封面的 Skills。

这也是我为自己做的内容生产 Skills 系统中的一部分。

所以这篇内容 既有图片提示词也有 Skills ，你可以选择自己喜欢的方式使用。

这个 Skills 具体的功能有：

  • 支持分析当前文件夹下的任何格式文档,批量为每部分生成图片
  • 支持选择图片生成的分辨率 2K、4K
  • 支持选择图片生成的比例(16:9、3:4)
  • 支持选择是否生成总结性质的封面图片
  • 展示归纳结果供你确认,确保所有重要信息都被包含

比如我前几天分享的 Cursor 关于 AI 编程概念的文章配图就是用这个生成的。

简直是发小红书、微信图文、抖音图文的神器!

目前 Skills 里面内置了三套风格： 票据风格、矢量插画风格、渐变玻璃卡片风格。

大家可以按照自己的喜好让模型生成对应风格的图片。

接下来说一下怎么用。

你可以直接打开终端输入这段代码然后回车就行,他会自动安装。

npx skills add https://github.com/op7418/Document-illustrator-skill

安装完成之后你需要跟着 AI 的引导在.env 文件里面填写你的 AI Studio API Key。

这里获取 API Key：aistudio.google.com/api-keys

因为调用的 Nano Banana Pro,所以你的 API 需要开启付费哈。

之后就在 Claude Code 里面跟他聊天就行：

"帮我用 /document-illustrator 这个Skills为 @"文档名称" 这个文档生成配图"

之后他就会让你选择一些选项,确保生成的图片符合你的要求。

在之后等待就行。
