之前分享 Skill 的那几篇文章，评论区问得最多的一类问题是：

其实创作相关的 Skill 我零零散散讲过不少，标题、正文、配图、复盘都有。

但一直没专门按小红书这条线整理过。

所以这篇我把「运营一个小红书号」从头到尾拆成了 定位、选题、写作、视觉、复盘 五个环节。

每个环节做一两个 Skill，再加一个总控把它们串起来，一共 10 个。

下面是这 10 个 Skill 的简介，后面逐个讲功能、实现，配上产出效果。

一、路由总控：space-xhs-buddy

路由 Skill 可以有效解决 Skill 太多，自己和模型都选择困难的问题，有个路由 Skill 做总控，模型会自主的根据用户的描述选择对的 Skill。

你不用记住上面这一堆名字。跟它说一句「帮我做小红书」，它会先问清楚你现在到底卡在哪，再路由到对的 Skill、按对的顺序串起来。

二、账号定位：space-xhs-positioning

它能帮你把「做什么方向、给谁看、靠什么活下去」定下来。

它是一个 引导式咨询 Skill 。通过向你提问，一步步逼近你热爱的领域，你想做的内容，

最后产出赛道选择、定位句、人设三件套（账号名 / 简介 / 视觉）、内容支柱、前 20 篇选题和冷启动路径。

就像下面它对我的提问，让我更清晰我这个号要做什么内容。

三、选题：space-xhs-hotspot

输入你感兴趣的关键词，就能搜索这个领域最热门的笔记。

背后接了三个数据源（红狐 / socialdatax /kuaikei）， 有些是需要配置 API key 的，在使用的时候注意下。

四、写作（标题）：space-xhs-title

只要你输入一个主题、一篇草稿或一条现成标题，就能用这个 Skill 制作 15 种标题方法批量出候选。

每个标题还会给到逐条评分（含搜索词覆盖、人群指向、收藏动机）、标合规风险、按用途分角色推荐，还给 A/B 测试建议

五、写作（正文）：space-xhs-writer

把你的经验和知识翻译成小红书语境里读得下去的正文。

覆盖种草测评、干货教程、个人故事、合集清单、避雷拔草、好物分享、经验复盘 7 种笔记类型 ，产出开头 3 行、分段骨架、结尾互动、标签组合，外加发布前 14 项检测。

六、视觉（封面）：space-xhs-cover

只做首图封面时用它。输入主题、标题，以及可选的人物 / 产品 / 背景素材，生成一张 3:4 封面

调用 Codex 内置生图模型，重点在标题层级、主体识别和移动端可读性。

七、视觉（图文）：xhs-html

把文章、教程、SOP、清单拆成 6 张以上 3:4 图文 ，输出一个可在浏览器里逐页截图的完整 HTML。

支持 62 种设计风格 ，开始前给你风格候选和 6/7/8/9 张页数方案选。

八、视觉（生图）：space-xhs-image

需要模型直接生成位图时。输入内容后生成单图或 6–9 张信息图 ，固定采用白底、紫蓝与青柠绿强调、圆角卡片、线性科技图标的「轻盈 AI 产品信息图」风格。

调用 Codex的内置 `image_gen`能力来制作图片。比如这篇文章的封面图就是调用这个 Skill 制作的。

九、复盘（账号）：space-xhs-account-audit

把小红书博主的主页（自己的或竞品的）交给它，10 分钟给你一份比你自己看主页更清楚的诊断。

从定位清晰度、内容垂直度、封面统一性、标题钩子率、更新节奏、互动率、爆款率、粉丝转化 八个维度打分 ，定位卡点，给可执行改动。

十、复盘（笔记）：space-xhs-note-analytics

把在账号后台的笔记数据下载后，这个 Skill 可以把这堆数字翻译成「卡在哪一层、为什么卡、下一条改什么」。

用 六层漏斗归因 把多篇笔记横向对比找规律。

怎么用

告诉你的 Agent（ Workbuddy/Claude Code / Codex）：

帮我安装这几个 Skill：github.com/SpaceZephyr/creator-buddy/tree/main/xhs-Skills

装完继续说说「帮我做小红书」会自动路由到总控，也可以直接点名某一环，比如「帮我看看这条笔记的数据」。

单个 Skill 能单独用，但真正的价值是串成流水线。™三条标准工作流：

链路 A · 从零起号

positioning → hotspot → writer → title → cover + xhs-html/image → 发布

链路 B · 日常产出

hotspot → writer → title → cover + xhs-html/image

链路 C · 诊断改进

先用 note-analytics 定位卡在漏斗哪一层，再对症下药：

  • 曝光低 → account-audit （标签 / 定位 / 权重）
  • 曝光够、点击率低 → title + cover
  • 点击够、互动低 → writer （开头留人 / 价值兑现）

以上 Skill 除了平台数据查询，其余 Skill 都不需要第三方 API Key。.

这几个 Skill 记忆是 把定位、选题、写作、视觉、复盘这五件事，一件一件做扎实 。

让你在小红书创作路上的每一步都有个搭子，少走点弯路。
