实测LibTV Agent，把100个AI视频工作流重组成Skills后我创意自由了

卡尔的AI沃茨 AILibTV AgentAI视频AI工作流创意自由 2026-07-15

我还手搓了一个做视频Skill的提示语！

AI沃茨 卡尔的AI沃茨 2026年7月14日 17:04

终于让我等到了 LibTV 的 Agent，

但我没想到，它上来就给我整了100多个Skill，还做成了Skill Hub。

我这顺手一拉，发现了好多好玩的skill，从专业影视到商业广告再到短剧漫剧、音乐MV啥类型的skill都有了，而且还细分成了不同的画面风格和叙事风格，

（刷不完根本刷不完）

这我以后还不是想做个啥视频都可以先来这里挑一挑了，果然比起自己一个节点节点的手搓，还是直接用提炼了成熟创作经验的Agent工作流来的更稳定更方便一些啊。

比如我就给了一句想法，

它就嗖嗖嗖给我做出了这样一段剧情连贯又具有视觉冲击力的武侠电影片段，相当得劲儿。

而且整个视频的生成过程非常的丝滑顺手，因为我给的需求比较概括，Agent会先分析我的需求提出几个具体的方向问询让我选择，方便做出更符合我想法的视频。

在Agent对话完成后，我会看到视频的在左侧的画布一步步自动生成，然后各个节点自动串联在一起，形成一张我们平时做视频的完整画布。

画布上的每一个节点都是可以点开看到详细的生成提示语，不满意可以直接手动修改，或者也可以选中这个节点的视频或图片在右侧的Agent直接对话修改。

在生成视频镜头后，LibTV还会有一个自查机制，统一检查一下目前生成的所有镜头是不是都符合要求，有没有什么漏洞，然后进行返修。

我真的很喜欢这个设计，这次测试了好几个视频，其中返修的镜头我都一个个点开看了，确实是存在问题才会触发这个返修。这就又省下了我一个个视频去看去找问题的时间。

（这大头吓我一跳）

还有一个让我觉得LibTV真的站在用户角度做产品的地方是，他们还做了一个故事板的视图，可以契合不同用户的使用习惯，

比如用不惯节点工作流的人就可以直接到故事板中非常清晰的看到图片资产和视频资产，每一个内容依然可以单独点开看到提示语并进行针对性修改。

而且在生成完所有分镜后LibTV会先进行一个初剪，在故事板里可以直接在成片中打开剪辑的时间线进行更加细致的调整，直接一个工具就能完成输出成片，都不用我再手动打开剪辑软件了。

除了这个古装武侠动作电影的Skill之外，我还测试了几个，效果都很不错。

比如我用皮克斯动画广告Skill给一台智能投影仪做了个动画品牌广告片，

做出来的这个动画短片我没调过，直接就拿来用了，整个视频故事剧情流畅，有产品露出，有转场，有音乐起伏，还有结尾的品牌文字释出，成片已经相当完整了。

或者我也可以用爆款复刻Skill，复制一个电商口播视频，把视频中的模特和产品都换成我自己的。

整个视频的节奏和景别以及镜头类型都和原视频一致，连口播内容都相应做出了调整，人物的动作神态都很自然。

如果是想要把这个视频发布到海外平台，我还可以直接让LibTV给我输出一个双语字幕的版本。

或者用新中式美学TVC给奶茶品牌做一个广告短片，

还能用游戏实机PV这个Skill做一个视觉效果非常好的实机游玩演示视频，基本上所有的游玩类型界面都做到了，不得不说这个结算页面是真的帅啊。我觉得比较难得的是，它画面跟画面的衔接都还挺流畅的。切换到第一人称从山城爬起来的时候，我还真觉得是在走过场动画。

除了使用官方提供的这些skill之外，还可以根据需求自己去做Skill，

我一开始的思路是做一个「猫猫邵氏武侠」的无厘头Skill，能把一句很普通的故事，自动做成小体型猫猫和真人同台的无厘头老港武侠短片。

跟一般写skill不太一样的是，写视频Skill的同时还要保证skill本体文字不是特别长，不让模型多轮对话后就全忘了。所以我把它拆成了三个不同分工的文件。

SKILL.md 是主脑，负责告诉LibTV这个Skill做什么、接受什么输入、按照什么流程工作、最终交付出什么。style-bible.md是画风圣经，负责保存角色尺寸、人物形态、灯光、服装、棚景、运镜和声音规则。reference-film-patterns.md 是参考的影片规律，把我们对照的影片拆出来的对白节拍、喜剧结构和剪辑方法存进去。

如果你看完还是不知道怎么下手，也可以把下面这段话直接交给 Codex、Claude Code 或其他能够创建文件的 Agent。

## 视频Skill提示语

创建一个可以上传到LibTV的视频Skill。
这个 Skill 要解决的问题是：
【一句话说明用途】
固定风格包括：
【角色、尺寸、画风、镜头、对白和声音规则】
用户可以改变的内容包括：
【故事、时长、画幅、角色、道具和结局】
我最不能接受的错误包括：
【列出过去生成中出现的问题】
生成：
1. SKILL.md
2. references/style-bible.md
3. references/reference-film-patterns.md

SKILL.md 需要包含触发场景、输入、默认值、工作流程、输出、自检和什么时候询问用户。
风格规则要通用可复用，不要锁死成某一条视频的逐秒分镜。

把括号里的内容替换掉，再让Agent生成就行。

然后上传，测试，发现错误。

再把错误写回Skill，继续再测。

循环几次就搭建完成了。

整个搭建过程真的没有想象中那么难，不需要先学编程，也不用一开始就写出一份完美文档。

你真正需要做的，是对自己想要的效果足够诚实。把你每次看到错误结果时，最想对AI说的那句话写进去。

我当时就一直在纠正这些问题。

猫不能是成人身高，猫不能一会儿到膝盖，一会儿又比人还高。

猫手不能变成人手。

喜剧角色也不能自己解释笑点。

这些规则一条条写进去之后，Skill就开始会有稳定的审美。你会发现，这里面没有什么神秘咒语，全是具体判断。

最后，我觉得比较惊喜的一点是，我居然做出来了粤语配音，我摸出来一个小技巧，只要在出脚本的过程中，让字幕输出粤语字幕，先抽音频等音频出来是粤语之后再配画面，其实就能比较稳定地输出粤语语音了。

讲那么多，其实我觉得LibTV这次做的Skill Hub，意义比单个视频生成能力还要大。

AI 视频发展到现在，把这些经验产品化是现阶段大家都在做的事，更重要的要让创作者们用的顺手。

以前你要做一条片子，要先想 prompt，找参考，写脚本，拆分镜，试画面，配字幕，配音乐。现在你可以先选一个 Skill，让Agent生成一版接近成片的结果。你再进入故事版看看结构，进入节点调调细节，生成后继续让Agent帮你加双语字幕，换人物，调音乐，改镜头。

这才像一个视频 Agent 应该有的样子。

它可以完成从想法到初版成片的第一轮工作，也允许我继续控制细节。

它能提高效率，又没有把创作者完全关在黑盒外面。你可以让它先拍，也可以随时接手。

这点很重要。

LibTV Agent 这次给我的感受，

就是它能明显缩短想法到成片之间的距离。

如果以后Skill Hub继续扩展，更多专业创作者把自己的方法沉淀进去，LibTV 会变成一个很有意思的创作生态。

有人提供 Skill，有人调用 Skill，有人把自己的品牌风格做成 Skill，有人把爆款方法拆成 Skill。

那样以后我们做视频，

就会少一点不必要的消耗，

多一些直接开工的可能。
