视频制作的终极形态，就是你说话，AI干活。

今天晚上我干了一件超级有意思的事——用 Claude Code + Remotion，嘴炮出了一个15秒的可口可乐宣传片。8个场景、Logo爆发、瓶子旋转、液体飞溅、品牌主张，全套专业级动画。

你猜我花了多长时间写代码？

零。

我就跟 Claude 说了句话：

"帮我做个15秒可口可乐宣传片。要有Logo爆发、瓶子360度旋转、液体飞溅效果、瓶子雨、品牌主张、产品展示、行动号召，最后加上署名。用可口可乐的品牌红，要专业、要炸裂。"

然后，Claude 开始疯狂写代码。

不到10分钟，它写出了 540行 React 代码，创建了8个场景、20个粒子效果、5层液体波纹、8个从天而降的可乐瓶。浏览器里自动弹出预览窗口，播放键一按——一个完整的品牌宣传片就在眼前。

以前做视频是体力活，现在做视频是嘴皮子活。

废话不多说先给大家看看效果。（请大家自动忽略没扣干净的白边）

口喷流程拆解

我们来拆解一下这个"口喷流程"到底有多爽。

第一步：搭环境（15分钟）

这是唯一需要动手的部分：

  1. 装个 VS Code、Node.js、Git
  2. 在终端输入 npx skills add remotion-dev/skills
  3. 给 Claude 装上"视频制作技能包"

全程15分钟，跟装游戏一样简单。

第二步：准备素材（5分钟）

  • 把可口可乐的 Logo 和瓶子图片扔进文件夹
  • 如果 Logo 有白色背景，让 Claude 帮你写个 Python 脚本去背景
  • 30秒搞定

第三步：开始"口喷"（20分钟）

这是最爽的环节。视频的底子打好了就可以开始精修了

场景1：Logo爆发（0-2.5秒）

我跟 Claude 说：

"场景1，黑色背景，Logo 从黑暗中爆发出来，要有20个红色粒子从中心向外扩散，Logo 要弹性放大，带红色发光效果。持续2.5秒。"

它立刻写出代码：

  • 用 spring 动画创建弹性效果
  • 用 interpolate 控制粒子扩散
  • 用 filter 添加红色发光
  • 精确控制时长到75帧（2.5秒 @ 30fps）

场景2：瓶子360度旋转（2.5-5秒）

我继续说：

"场景2，白色渐变背景，红色圆形从小到大，可乐瓶360度旋转特写，右上角要有 Logo 角标。"

它继续写：

  • 渐变背景从白到浅灰
  • 红色圆形用 scale 从0放大到1
  • 可乐瓶用 rotation 从0到360度
  • Logo 角标固定在右上角，半透明

当你不再写代码、不再拖时间轴，视频制作就真的民主化了。

场景3-8：一口气"嘴炮"完成

8个场景，我就这样"嘴炮"完了：

场景 时长 描述
场景3：液体飞溅 5-7秒 5层白色圆环从中心扩散，"畅爽"两个巨大文字，红色背景
场景4：瓶子雨 7-9秒 8个可乐瓶从天而降并旋转，白到红渐变背景
场景5：品牌主张 9-11秒 "经典永恒 畅享快乐"文字滑入，两侧半透明可乐瓶
场景6：产品展示 11-13秒 左侧瓶子特写，右侧 Logo +"百年经典·品质传承"
场景7：行动号召 13-14.5秒 白色卡片写着"即刻畅享"，红色背景
场景8：结尾署名 14.5-15秒 Logo + "made by 香君"，底部装饰瓶子

每说一个场景，Claude 就写一段代码。

我不需要懂 React、不需要懂 TypeScript、不需要懂动画函数。

我只需要能描述画面。

技术的进步，就是让复杂的事情变成"说句话"的事。

微调优化（10分钟）

预览不满意怎么办？继续"口喷"。

  • "Logo 爆发的弹性效果太弱，把 damping 参数从15改成10，让它更有冲击力。"
  • "瓶子旋转太快了，从2.5秒延长到3秒。"
  • "液体飞溅的圆环间距太小，从50调整到80。"

每次修改，代码实时更新，预览窗口自动刷新。

你改的是意图，AI 改的是实现。

渲染导出（3分钟）

最后，我说：

"渲染成 1080p 视频。"

Claude 自动执行渲染命令，450帧（15秒 × 30fps）逐帧生成，3分钟后，一个专业级的 MP4 文件就躺在 out 文件夹里了。

这就是口喷时代的视频制作。

⚡ 传统流程 vs 口喷流程

传统流程的痛苦

以前：

  1. 打开 AE
  2. 导入素材
  3. 创建合成
  4. 添加图层
  5. 手动打关键帧
  6. 调缓动曲线
  7. 预渲染，等半小时
  8. 客户说改一个参数？重新来一遍

口喷流程的爽快

现在：

  1. 说句话
  2. 等10分钟
  3. 视频出来了
  4. 客户要改参数？再说一句话

门槛对比

维度 传统流程 口喷流程
技能要求 熟练掌握 AE、Premiere、懂关键帧、懂曲线、懂图层 会说话、有审美、能描述画面
核心能力 操作软件 描述画面
修改成本 高（重新操作） 低（说一句话）
学习曲线 陡峭（数月学习） 平缓（即学即用）

口喷时代的核心能力，不是会操作软件，而是会描述画面。

导演思维

这个能力叫什么？我叫它 导演思维。

你不再是执行者，而是导演。

  • 你只管说我要什么效果
  • AI 负责怎么实现

传统视频制作：你在学软件的语言。

口喷时代：软件在学你的语言。

这才是真正的范式转变。

适合谁？不适合谁？

适合使用的人群

如果你是：

  • 品牌运营：需要快速做宣传片、广告变体
  • 内容创作者：批量生产图文动画、数据可视化
  • 产品经理：想给产品做 Demo 但不会剪辑
  • 独立开发者：需要快速迭代营销素材

那么，Claude Code + Remotion 就是你的口喷神器。

不适合的场景

如果你需要：

  • 复杂的3D建模和渲染
  • 精细的调色和后期
  • 真人拍摄的剪辑和叙事

那传统软件依然不可替代。

但是，如果你的需求是"快速生成、批量迭代、数据驱动"——口喷时代已经到来。

完整时间流程

我做的可口可乐宣传片，完整的技术流程是这样的：

步骤 时长 说明
1️⃣ 装环境 15分钟 安装工具和技能包
2️⃣ 准备素材 5分钟 Logo + 瓶子图片
3️⃣ 口喷场景描述 20分钟 8个场景的语言描述
4️⃣ 微调参数 10分钟 说话调整细节
5️⃣ 渲染视频 3分钟 自动生成 MP4
总计 53分钟 从0到成片

对比传统 AE 流程：保守估计要 3-5小时

而且如果客户说"改一下背景色"：

  • 传统流程：重新来一遍（又是1-2小时）
  • 口喷流程：说一句话，30秒搞定

生产力范式的转变

视频制作的本质，从"手工剪辑"变成了"规则定义"。

你的角色：定义规则和意图

AI 的角色：负责执行和优化

这就是口喷时代的生产力模式。
