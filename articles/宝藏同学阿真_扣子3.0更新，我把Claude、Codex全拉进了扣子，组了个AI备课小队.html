简单来说，首先是桌面端上线，手机和电脑可以同步联动推进项目，电脑上没做完的，手机端继续做。

其次，它支持多人多 Agent 协作。可以把伙伴同事拉进来，也可以同时调度多个 Agent 推进项目，不限于扣子自家 Agent，Claude、Codex、龙虾等本地 Agent 也能直接接入。有项目就拉个群，谁适合干什么就交给谁。

功能一次讲不完，我会用一个案例，和大家先看看这些新能力，也顺便分享一些我的实际体验。

案例尝试

我觉得扣子 3.0 这次最棒的地方是它把项目、同事、多个 Agent、本地工具、手机端创作和资产库放进了同一个工作空间里。以前很多 AI 工具强在单点任务，这次更像是给真实项目搭了一个可以持续推进的 AI 团队。

正好有个朋友找我，她是高中语文老师，下周要讲一节公开课《登高》。问我能不能给有什么工具，把说课稿、PPT、背景动画全做出来。我就用这个走了一遍扣子 3.0 的流程，尝试能不能一个平台把这件事完整做了，后续还有类似场景，很多方面可以直接调用和复用。

首先，安装扣子网页端，现在也不好分享链接了，大家直接搜索和打开扣子的网页端，左下角可以看到，点击就可以下载了。👇

PPT 风格偏好：配色稳重简约，不要花哨动画，不要卡通元素8. 出题偏好：高考真题改编优先于原创题9. 教学难点突破偏好用比较鉴赏法（同题材 / 同作者 / 同时代异作者对比）【格式约束】10. 用编号列表或表格输出，方便我直接复制到 Word / PPT11. 涉及具体文史细节必须能查证（朝代 / 年份 / 篇目名 / 引文原文）12. 不要使用破折号

发完了以后，和它确认一下记忆是不是整理了进去。很多信息会作为长期记忆保留在这个Agent中，后面所有产出都默认按这些偏好走，不用每次提一遍。👇

多任务，并行调度

还记得我们前面是新建了一个项目然后把【小助教】拉进去了吗，接下来在这个项目里，【小助教】就是主力干活的，我们提出任务然后艾特它让它去做。一定注意，在多个Agent的项目里是要通过@来召唤指定Agent的哦，没有@就会没有 Agent 响应。

这个任务是一个扣子 Agent 和三个本地 Agent 同时并行执行完成的，速度嘎嘎快。

多人多 Agent 的价值也在这里显出来了，它的重点在于把任务拆给不同角色，最后仍然回到同一个项目里沉淀结果。一个人可以搭自己的 Agent 小队，团队也可以把真人同事和 Agent 放在同一个项目里，通过 @ 指定谁来处理，协作边界更清楚。

比如可以直接@A Agent 执行某任务的同时@B Agent执行另一项任务，让它们各司其职，或者不同模型执行不同任务。👇

长篇幅，说课稿

接下来就是基于前面的综述推进说课稿了，这里可以继续让小助教按照长期记忆的备课偏好输出说课稿。这里小助教稳稳接住了我的需求，3800字，输出速度很快，同时完成了我要求的字数、环节、教学目标等等交付标准，并附上了自检报告。👇

扣子3.0备课小队-17.png

这一步完成了，有需要的还可以做一份学生反馈与改进计划，以及新课标对齐的自检报告。

很多行业场景的麻烦点在于，每次都要重复解释偏好、格式、风险红线和交付标准。扣子把这些偏好沉淀到 Agent 里，后续同类任务可以直接复用，越用越像一个熟悉我们工作习惯的专业搭档。

PPT课件

说课稿有了，接下来推进PPT设计，【小助教】输出PPT之前，会先给到完整的分页面文档内容，检查无误后推进下一步，如果有问题，可以在右边引用内容提出修改意见👇

@小助教请基于已定稿的说课稿，为我生成完整可用的说课 PPT 内容。【交付标准】1. 共 15 到 18 页，按说课稿八段结构推进2. 每页区块：页标题 / 页面正文（80 到 150 字）3. 在"教学过程 → 意象品读" 那一页和"教学过程 → 情感探究" 那一页明确标注"此处嵌入意境动画 1 / 2"【风格强约束】4. 配色稳重5. 字体建议：标题用思源宋体 Heavy 或方正小标宋，正文用思源黑体 Regular 6. 不要花哨动画、不要卡通插画、不要 3D 立体7. 古诗原文页用书法字或正楷放大，配单色山水水墨小图【知识硬伤红线】8. PPT 上诗句必须与说课稿一字不差9. 年份朝代与说课稿一致10. 末尾另起"PPT 自检清单"。开始写。

动画制作丰富课件

如果王老师突然又了新灵感，吃午饭的时候，突然想给其中四句诗的 PPT 加点意境动画，那么她也可以直接在手机上进行操作。

首先把提示词发给日常常用的Agent，Agent会跳出一个选项，询问是不是要新建视频项目在里边继续聊，点击确认以后，就可以直接通过输入语音或者文字描述想法。👇

请一次生成两段水墨意境动画，每段 8 秒，模型用 Seedance 2.0，比例 16:9。────────【动画 1 · 首联"风急天高猿啸哀，渚清沙白鸟飞回"】画面风格：中国传统水墨写意，墨色为主，淡赭石和淡花青点染，留白大。完全不出现人物。具体内容：开篇高远秋日天空，秋风带枯叶斜向掠过；远处山影朦胧，山雾微微流动暗示猿啸意境；镜头缓缓下移，露出江中小渚，渚上几只水鸟低飞盘旋，沙石浅白，江水墨青。氛围关键词：高远 / 苍凉 / 萧瑟 / 秋意 / 沉郁。不要任何文字标注，不要出现具体诗句字。────────【动画 2 · 颔联"无边落木萧萧下，不尽长江滚滚来"】画面风格：中国传统水墨写意，比上一段更恢弘开阔，墨色厚重，少量淡赭暖色提亮。完全不出现人物。镜头节奏：上下对位，上半部分落叶纷纷下坠，下半部分长江奔流不息。具体内容：画面上方无边落木萧萧而下，叶片散点构图飘落；下方浩荡长江水势汹涌不夸张，"滚滚来" 的连绵感；远景留一线山影锚点。氛围关键词：恢弘 / 苍茫 / 时间无尽 / 空间无垠 / 沉郁顿挫。不要任何文字标注，不要出现具体诗句字。────────两段都用同一套水墨视觉语言，保持风格统一。生成完成后告诉我两段的资产 ID，方便我接下来微调。开始。

小结

如果让我个人给扣子 3.0 这次的更新做个小结，我会放在三个关键词上：协作、接入、持续推进。

协作，是因为它把真人和多个 Agent 放进同一个项目里，任务可以拆开做，结果可以合起来看。接入，是因为扣子原生 Agent、云端 Agent、本地 Agent、行业模板和官方技能包都能进入同一个工作流。持续推进，是桌面端负责资料和本地文件，手机端负责碎片时间创作、修改、审核和分发，项目上下文一直跟着走。

推荐大家用具体场景去尝试。比如一节公开课、一份投研报告、一组小红书选题、一套合同审阅流程、一个视频项目。只要这个任务需要多轮推进、资料沉淀、跨端协作，扣子 3.0 的优势会更加明显。
