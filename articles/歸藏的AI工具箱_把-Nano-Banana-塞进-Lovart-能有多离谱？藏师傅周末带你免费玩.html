大家好我是歸藏 （guizang），今天带来在 Lovart 上使用 Nano Banana 的体验。

在 Nano Banana 上线的第二天 Lovart （ lovart.ai/ ）就上了，这种 Agent 不比一些聚合类应用加个按钮就行，适配新模型还是有些麻烦的，可以说相当迅速了。

今天看到他们还开启了周末免费活动，从今天开始到周日三天， 在 Lovart 上可以免费畅玩 Nano banana ，不会消耗任何积分。

⚠️注意：由于只有 Nano Banana 这一个模型免费，所以为了避免你的任务调用其他模型扣积分，你可以在输入框模型选择这里只勾选 Nano Banana。

其实我这几天也开发出了很多 Nano Banana 和其他模型配合的玩法，图片涂鸦替代提示词的方式跟 Lovart 的画布也非常契合，这次内容就带大家看看 Nano Banana 和自动化的设计 Agent 配合有多强。

首先还记得我说过的 Nano Banana 用涂鸦替代提示词的方式完成对图片的精确修改吗，Lovart 左边的 Magic Canvas 天生就是用来干这个事情的。

Nano Banana 因为有强大的世界知识，所以他是可以看懂地图的。

我们可以从谷歌地图上找一个地点（地标建筑）然后再放到 Magic Canvas 上画个箭头，他就知道这是什么地方。

然后跟点一下下方的评论图标在图片上跟 Lovart 说“Use Nano Banana to draw the photo seen by the red arrow.”

等他回复后我们点击下方的 Run All，等待奇迹就行。

然后他果然帮我们把祈年殿画出来了。

很多朋友也发现 Nano Banana 默认出图的分辨率很低，在 Lovart 你还可以直接点 Upscale 去放大图片，解决这个 Nano Banana 最大的问题。

搞完简单的演示教大家怎么操作之后我们整个难的，Nano Banana 可以实现超多物品在一张图片中的替换和生成，还能保持一致性。

所以我找了 7 件家具图片，然后用 Magic Canvas 画了一个简单的家具位置示意图，让 Nano Banana 把他们放在屋子的指定位置。

以往画示意图这部分你还得找个设计软件，而且还不一定会用，现在直接在 Magic Canvas 左边画框打字就行。

然后用下方评论按钮框选所有用到的图片输入提示词运行就行。

提示词：帮我使用Nano Banana根据左侧图片中标记的位置摆放所有家具，生成一张逼真的家居展示照片。

来看一下 Lovart 给出的结果，相当牛皮了，所有家具的位置都是对的，而且还考虑了空间关系，每个家具都跟原来的细节一致。

这个效果太可怕了。以后大家想要装修自己的屋子的时候只需要拍张照片，在照片上大致写一下家具的名字，再把家具给他，他就能给你家装效果图了。

玩完了 Magic Canvas 之后我们再来看一下结合了 Lovart 中的其他模型一起联动能做出多牛的东西出来。

昨天发了一个用 Nano Banana 改车最后变成完整一镜到底视频的案例，很多朋友问我怎么做，因为涉及到两个模型，有点麻烦，现在在 Lovart 里面两句话就能搞定，先看结果。

首先我们的素材就只是一个白模汽车模型，和一张用来参考配色的图片，这个大家随便搜索都行。

然后输入非常简单的提示词：

帮我用 Nano Banana 分别为这辆车改为第二张图的配色，然后将轮毂改为放射状，然后再在侧面增加黄色拉花，然后将车放在一个有非常好光照的车库中，最后将车变成正在赛道行驶。以上的每次改动都生成一张图片，不要一次完成。

然后我们就获得了 5 张详细度非常高的车辆图片了，分别是加上了蓝白色配色，将五角星轮毂改为放射状、右侧加上了黄色拉花，以及后面的车库视角和赛道视角。

然后我们复制刚才的生成结果加上最开始的白膜图片一起粘贴到提示词框里面。

就能用提示词一键让他将这几个图片用可灵首尾帧模型分别生成视频后，再整合为一个完整的视频，当然还必须让他配上一个应景的音乐。

按照顺序用可灵2.1 首尾帧视频模型分别用前后两张图片当做首帧和尾帧生成视频，最后将段视频整合为一个连贯的完整视频，增加配乐。再用可灵 2.1 首尾帧生成视频的时候，视频生成提示词按照这个要求生成：

你是一位顶尖的创意视频导演和VFX（视觉特效）概念艺术家。你的任务是为AI视频生成模型设计一个从【起始帧】到【结束帧】的转场过程。

你的核心目标是：构思并用一段话清晰、具体地描述这个动态视觉变化。

在构思时，请遵循以下创作框架：

第一步：分析差异 快速判断【起始帧】和【结束帧】的差异程度。

A类 - 关联性强： 主体或场景基本一致，只是状态、风格或环境发生改变（例如，同一个人换了衣服，同一个场景从白天到黑夜）。

B类 - 差异巨大： 主体和场景完全不同（例如，一只猫在客厅 → 一艘飞船在太空）。

第二步：选择转场策略

如果属于 A类，优先采用**“原地演变”的策略。让变化直接发生在主体和环境上，尽量不使用或只使用微弱的摄像机移动。

如果属于 B类，采用“运镜驱动转场”**的策略。必须使用一种明确的摄像机移动（如推、拉、摇、移、旋转）来引导过渡，让镜头运动成为连接两个不相干画面的桥梁。

第三步：构思具体变化（从以下工具箱中选择组合）

主体变化： 主体如何改变？（形态变化、材质替换、服装更替、分解重组、消失或出现）。

环境变化： 背景如何改变？（时间流逝、季节更替、空间切换、从现实变为幻想）。

风格/特效变化： 用什么视觉风格或特效来包装这个过程？（例如，画面逐渐像素化后重组、被火焰/水流吞噬后显现、转变为水彩/油画风格、出现光效粒子）。

输出规则：

将你的最终构思整合为一个连贯的段落。

描述要具体、直接，充满画面感。专注于“我们看到了什么”，而不是“我们感觉到了什么”。

严格遵守你在第二步中选择的摄像机移动策略。

避免使用模糊的比喻和过于文学化的修辞。

现在，请根据我提供的【起始帧】（图片A）和【结束帧】（图片B），生成你的转场描述。

除了这个例子以外，我今天还搞了一个很好玩的例子，就是你随便找些素材的图片，也可以拍一张你冰箱的图片，扔给 Nano Banana 他就会帮你生成一个菜谱图片，告诉你这些菜可以做成什么美食。

当然用 Lovart 也是可以搞定的，你甚至能让他帮你用这些图片做一个动态的视频美食教程出来，非常牛皮，可以直接去做食谱应用或者发视频起号了。

首先我们需要先把用到的食材图片都扔给他，然后输入提示词：

帮我用 Nano Banana 将图片中的食材转为完整的逐步食谱信息图，采用俯视视角。以极简风格呈现在白色背景上。包含带标签的食材照片，使用虚线将代表准备步骤的图标连接起来，并在信息图底部展示装盘完成菜肴的照片。同时，将图片中带背景的食物去除背景，并将食物置于白色背景上。

就能得到一张带有烹饪过程、结果和原料的食谱图片了，而且可以看到原材料的部分都用的是我们给到的图片，一致性保持的非常好。

然后我们继续输入提示词： 帮我用Nano Banana 将这些食材和烹饪成品摆放在餐桌上，制作一张非常漂亮的美食展示图，去除文字。 就获得了用于展示的成品图片。

有了这些之后我们就需要开始做视频了，复制我们所有需要的图片扔到输入框里，然后输入提示词：

用可灵将这三张图片作为首帧生成视频加上可灵一些生成的烹饪过程视频，一起做一个有英文配音和配乐的做菜菜谱视频。

之后他就会任劳任怨的把有图片的用图生视频生成视频，没图片的地方直接文生视频生成视频，最后生成口播的音频和音乐再把所有的素材剪到一起，变成了一个完整的美食教程视频了。

这里 Lovart 有个小问题就是语音是先于视频生成的，所以过长了，视频完事了语音还没播完，跟他们反馈了，后面调整一下顺序。

这个周末免费期最该做的，不是疯狂薅羊毛出图，而是 用 Nano Banana 做一件你原本因为「不会设计」而放弃表达的事 ——可能是给外婆的院子设计个花圃，可能是把十年前写的小说场景可视化。
