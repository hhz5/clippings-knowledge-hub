腾讯设计妙境 Miora

官方说明：是一个由多 AI Agent 协作驱动、会记住你创作方式的多模态创意智能体工作室。 从一份需求开始，它能够理解目标、规划流程，并调度不同的创意 Agent 和专业 Skills，在同一块画布上完成图片、视频、3D、UI 等多模态创作，交付一整套风格统一的创意资产。

地址：https://miora.design/

1. 界面设计

对我个人来说最重要的还是 UI 设计方向，不仅仅是生图，需要完整的流程以及 Agent 来协作达到想要的效果最好。

· 直接上手，在首页选择 网页应用 ，技能添加 APP界面设计Skills「没有显示点击右侧更多里面查找即可」、输入框里 询问执行 、右侧自动里 Max 「要求更多可以在多模态里选择」，进入专属 UI 设计流程，Miora Agent 会引导你一步步从需求到交付。

在写提示前上传一张首页原型图「该项目源自19年一款点餐小程序，不涉及侵权」，来确保功能点清晰。

如果在没有原型图的情况下输入提示：先给我一个线框图，展示首页的信息层级和主要模块位置。然后基于上面的线框，按照刚才说的主题，生成完整的高保真设计稿。

-

同时描述产品需求「描述越清晰，结果越准确」这里有个小知识点：

产品类型：电商、工具、社交、健康等。目标用户：年轻人、中老年、专业人士等。核心功能：列出主要页面/功能模块。设计风格：极简、拟物、卡片式、深色模式等。参考应用：如「参考小红书的信息流风格」

-

提示：请根据我的原型图功能罗列设计一张有关餐饮APP首页，符合年轻人使用习惯，主要核心为预约点餐和排队功能，设计风格卡片式，极简。

由于在刚才设置了 询问执行 主 Agent 根据理解的目标和拆解信息后，会等待你下一步操作是否执行。

以上左侧为原型图、右侧为产出图像。当前问题是审美不符合极简，颜色极其不简洁，需要和 Agent 沟通：目前风格颜色有些过多，请根据我上传的「参考图像」风格参考来呈现视觉。

现在来看还是有些小问题，我们点击 UI 页面上方工具栏的 DOM Select 图标，框选或点选界面中的具体元素「按钮、文本、图片块等」，进入 Edit Element 编辑元素模式。

点击某一位置它分别为对话编辑以及 DOM 编辑 进行优化：像使用 Figma/Framer 一样直接调整前端属性:

Text「文本」：Font Size 字号、Weight 字、Text Color 文字颜色

Appearance「外观」：Background 背景色/透明底 、Opacity 不透明度、Radius 圆角

Border「边框」：Border Width 边框宽度、Border Color 边框颜色

Spacing「间距」：Padding 内边距、Margin 外边距

-

· 以对话的形式进行了优化和修改，最后的结果还是比较满意的，

依次优化路径为从左到右「原型图-初版沟通页面-附上参考图生成页面-对话形式优化的结果页面」，调整满意后点击 Apply 应用修改，或点击 Cancel 撤销「案例结尾有展示」。

-

· 那么 web 页面也是可以的，回到首页选择网页应用，点击下方更多

找到 web-component-generator 这个 Skill，方便后面使用。

· 回到首页新建项目，来复刻一个网页，点击上传要复刻的网页截图或图像。

找到图片反推提示词：根据该网页进行生成相应的提示。

等待提示生成，并打开左侧的 图像生成器 ，选择 Image 2.0 模型，复制刚反推出来的提示词。

可以看到在图像生成器里生成后的优化功能要比画布里直接生成的功能多的多，可以说非常的夯了「下个案例会讲到」～

注意：该图像反推提示skill 不太稳定，最好配合GPT来使用反推效果更好。

-

小知识：UI生成更关注功能逻辑和视觉规范，而不只是画面美感，它是有一个不固定公式的:[产品类型] + [核心页面/模块] + [设计风格] + [配色/字体] + [目标用户]

2. 3D角色设计

以往 3D 设计打开图像生成器并附上提示、生成三视图，再进行下一步的视觉包装，刚好 Miora 有3D生成器，结合在工作流程里面会节省一部分时间。

· 新建项目并打开 图像生成器 ，输入提示词「用图像反推提示，也可以根据自己需求和大模型沟通进行生成，这里只作为演示只讲重要步骤和思路」

基础设置依旧为 Image 2.0 模型、比例3:4、1K画质，附上提示词得到结果。

-

提示：设计一个潮流盲盒风格的3D IP角色，Q版卡通人物设计。角色比例：超大头、小身体，经典Chibi比例，大约头身比 2.5:1，圆润的大脑袋，短小四肢，胖乎乎的玩具感身体，整体像高级设计师潮玩公仔。

角色设定：一个年轻潮流少年角色，浅绿色短发，圆润平滑的发型轮廓，戴大型白色耳罩式电竞耳机，拥有冷淡、傲娇、不耐烦的半眯眼表情，小嘴微微撅起，脸部粉嫩柔和，具有婴儿般皮肤质感。

服装：黑色圆领T恤，胸前有白色X标志，外穿宽松浅绿色连帽夹克，oversize街头潮流服饰，蓬松宽大的袖子，拉链细节，柔软布料褶皱。

下半身：黑色宽松运动裤，白色裤脚装饰，黑色厚底运动鞋，脚下穿橙色轮滑鞋，小型轮子细节。

材质：高级3D玩具材质，柔软PVC塑料质感，轻微磨砂表面，圆润边缘，细腻的材质反射，潮玩收藏级手办效果。

渲染：Octane Render，C4D产品级渲染，柔和棚拍灯光，高清3D建模，真实玩具摄影效果，4K超清，干净白色背景，产品展示图。

构图：角色完整全身展示，正面站立，居中构图，保持玩具比例，无复杂背景。

风格关键词：designer toy, vinyl figure, blind box character, cute but cool, street fashion toy, 3D cartoon character, chibi style, collectible figure, premium toy design.

· 生成好后点击上方栏最右侧图标，里面包含：编辑元素、动作生成「有意思」、重新生成、扩图、裁剪、重新打光、调整视角、反推提示词、矢量化、添加对话、详细信息以及自定义工具栏「如下图」。

用 动作生成 功能，鼠标拖动骨架线来摆放角色姿势，也可以输入提示来确保角色动作生成一致「我这里只用鼠标拖动生成姿势」。

太有意思了hhhh～ 如果我想修改局部的东西，那么就会用到铅笔工具了，直接在图片上 圈画、书写或绘制路径 ，并通过不同颜色区分需要保留、删除、移动或调整的内容。

在左侧输入框里输入提示：删除图像里红色圈出的物体。

Miora 自动调取了 香蕉 2 模型进行了优化删除，并且在执行前对我进行了确认。

小知识：框选并合并标注图层，再通过自然语言说明具体意图，例如：“将黑色圈出的角色人物向左移动，删除红色圈出的物体，蓝线仅作为移动路径参考，最终画面中不要出现。”

-

· 通过上面修改和优化多生成几种姿势，再用 3D 生成器让这个角色更立体，它支持通过文字描述或图片直接生成 3D 模型，并提供交互式预览、多格式导出等能力。无论是产品展示、游戏角色还是电商 3D 展示场景，都能轻松应对。

从页面上选择刚生成的图像附上提示：请把图像生成3D模型，保持图像的一致性。

文生 3D 小知识：在对话框中描述你想要的 3D 模型，AI自动生成对应的 3D 模型文件。你可以指定：尺寸大小-模型的整体比例和大小、旋转方向与角度-模型的初始朝向、风格偏好-写实、卡通、赛博朋克、中世纪等、生成数量-一次生成多个方案供选择。

在 3D 生成器里有相应的下载格式，包括： GLB「非常推荐的格式，通用3D格式，适合网页/AR/游戏引擎」、STL「适合3D打印」、OBJ「通用3D格式，兼容大多数建模软件」、PNG「当前视角的高清渲染截图，透明背景」、JPG「当前视角的压缩渲染截图」、MP4「自动旋转展示视频，适合产品宣传」 格式。

-

· 还可以完善一下，根据这个 IP 形象生成品牌官网，在画布里左侧的菜单栏里最后一个图标，搜索添加上这个技能 skill ，进行对话就行了。

这个技能里包含：三视图、盲盒九宫格、科技场景图、白底壁纸、过度视频、品牌官网。选择品牌官网，然后输入提示词：请根据这张3D角色图像生成品牌官网。

填写基础的要求点击完成按钮等待生成，注意：在生成的时候需要把觉得的背景进行移除，能更好的融合在页面里「我为什么要这样说，因为生成第一张的时候发现这个问题」。

3. 电商设计

在首页点击 品牌视觉全案 ，对话框内输入想法与要求，即可进入专属创作流程「利用品牌视觉来做电商设计效果非常的好」。

基础设置：Agent选择 pro 、多模态选择 Image 2.0 模型并附上提示：帮我设计一款有关 "TabbyFashion" 高端防晒化妆品品牌的视觉识别系统VI。

Agent 会引导你提供必要的品牌信息，支持纯文字描述，也支持上传参考图「可选输入」。描述中最好包含：品牌名称-中文名、英文名或商标、行业与定位-如科技、消费、医疗、教育等、目标受众-面向哪类用户群体、品牌调性与风格-简约、活泼、高端、亲和等、视觉偏好-是否有指定颜色、颜色禁忌或特定的辅助图形倾向。

-

注意：如果你进行「品牌形象重塑」，建议将旧版的视觉资产作为参考图发送给 Al 。

· 有了品牌 Logo，可以告诉 AI 建立完整的视觉识别(VI)基础规范：

品牌色/色板：提取主色「Primary」、辅助色「Secondary」和中性色「Neutral」。

品牌字体与排版：获取适合搭配该品牌的字体风格建议。

辅助图形：基于Logo提取可延展的品牌辅助图形。

· 基础规范建立后，继续将品牌视觉延展到各类实际应用场景中：办公物料：名片、工牌设计、宣传物料：海报、官网首页 Banner、社交媒体封面图、产品包装：包装盒、手提袋效果图、文创周边：马克杯、帆布袋等企业形象周边。

在对话框里输入提示：生成产品生活方式大片，再根据生成的图像生成品牌海报。

注意：根据每个物料只需在对话中简单描述:「基于上面的品牌色，帮我设计一张科技感的产品海报」。

以上海报觉得还行吧，现在要求生成一张化妆品的产品，选择电商 skill 进行设计并附上提示：根据上方的内容生成 TabbyFasahion 品牌的化妆品电商详情页。

整体效果还是可以的。

-

· 你甚至可以查看项目记忆，在日常对话里它会自动捕捉你的身份、偏好、项目背景和创作规则，并在后续的对话和创作中持续记住、主动应用，无需每次重新交代。

记忆分为两类：个人记忆：跟着你的账号走，对你所有项目都生效，比如你的身份、审美偏好、创作习惯。项目记忆：只在当前项目内生效，比如这个项目的品牌资产、风格规范、当前进展。

那么它有什么具体作用呐？

在做设计时每一段对话，它会记住你同一个品牌的资产和风格。避免同样的话重复无数遍，既费时间，产出还容易跑偏。
