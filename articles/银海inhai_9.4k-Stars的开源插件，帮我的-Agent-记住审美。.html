我在小龙虾（OpenClaw）上用了大半年，最头疼的就是生图。

每次让它帮我做封面，我都得重新说一遍：“像素风格，橘黄白色调，标题大字居中偏上”。

更烦的是，每次做新的图，**同样的流程再来一遍，**它不记得我喜欢什么风格，不记得我上次调过哪些细节。

半年下来，光是跟它重复我的审美风格偏好，就浪费了不知道多少时间。

后来 Hermes Agent 火了，记忆能力确实强，我也试了，但它是整套独立系统，我之前已经在龙虾上跑了大半年的工作流、技能、记忆偏好，迁移成本太高。

这个项目是：MemOS，开源，免费，目前已经有 9.4k Stars。

地址是：https://github.com/MemTensor/MemOS。

不用换系统，一行命令就能接进去，装上 MemOS Local Plugin 2.0 这个记忆插件之后，自己一开始没怎么感知，和AI Agent 对话几次之后，打开了记忆面板，竟然发现我和它的聊天内容，自动进化结晶成了一个生图的 Skill。

然后我就直接让它帮我做封面，它直接出了一个：“Claude Code 风格的、教程类的、标题大字居中偏上、3:4”的图片。

我喜欢的风格一次到位。

它记住的不只是「我喜欢扁平风格」这句话，是我整套视觉偏好：配色、构图、字体、尺寸，甚至我过去每次微调的方向。

这是其他 Agent 没有的能力，后续直接对 Agent 说自己的简单需求，Agent 就能通过记忆插件自动检索到了你的个人偏好，就不需要自己再反复调整细节了。

后来才知道，这一版兼容了OpenClaw 和 Hermes Agent 的本地插件 **MemOS Local Plugin 2.0 ，**核心就一句：执行即学习。

怎么理解？以前它只是帮我存聊天记录。现在不一样了，它把整个过程拆成可学习的经验：你做了什么决定、怎么调整、哪些满意、哪些否掉。这些会被记录、评分、归因，下次任务直接调用。

所以慢慢变成了「长期搭档」的感觉。我不用每次重新解释自己，说一句“老样子”，AI Agent 就知道怎么做。

就拿我们开头的这个案例来说，它不只记住了“我喜欢 Claude Code 设计风格”这句话，而是记住了我整个创作偏好，配色、构图、字体、尺寸，甚至我之前每次微调的方向。

这就是执行即学习：它记住的并非是我某一个具体的指令，是我审美需求下的场景感约束。

这个能力远不止封面图。

我让它帮我写一篇推文，配图风格和封面完全一致，让它帮我做几张张社群海报，色调、字体、排版逻辑也是同一套，让它帮我出一组小红书的配图，风格依然统一。

我不需要每次都重新描述我的风格，因为它已经记住了。

我查了一下关于官方的介绍，这背后是 Local Plugin 2.0 的双层反馈机制，自动给「什么方法对这个人有效」打分归因，下次精准调用。

还有个更有意思的事：两个 Agent 之间能通过 MemOS 进行「共享记忆」。

官方叫「一份核心，多Agent共用」。

我之前两个 Agent，一个负责内容创作（OpenClaw），一个负责每日定时任务和数据收集（Hermes Agent），以前它们互不认识。

它从创作Agent的记忆里感知到了，主动做了调整，放在过去换工具，所有长期习惯清零。现在记忆可以脱离工具存在，即便是从换了 OpenClaw 换到了 Hermes Agent ，也不等于重新认识。

现在我把 Skill 设置了多 Agent共享，在 Hermes Agent 进化结晶出来的 Skill，在 Openclaw 也能使用，所以在Openclaw 生成的图片也符合我的需求，直接一键迁移。

再说点最实在的：钱。

OpenClaw 默认每次把所有记忆一股脑塞进上下文，Token 越滚越多。

MemOS的三层按需检索只注入最相关的记忆，还会压缩去重，官方测试：Token消耗降72%，记忆准确率提升33%。

拿个比喻来说：以前是把整个书架搬过来让你自己翻，现在是直接翻到我想要的那一页。

装完 MemOS 之后还有个 Memory Viewer，浏览器里直接看AI记住了什么：我的风格偏好、创作习惯、每条记忆的来源和评分，一目了然。

安装就一行命令，发给你的 OpenClaw 或者 Hermes Agent 几分钟跑起来：

“根据这个文档内容，配置 MemOS 的记忆能力：https://memos-docs.openmem.net/openclaw/hermes\_local\_plugin”

Hermes Agent 和 OpenClaw 用户都能用。

从项目来看，Hermes Agent 能够火起来，说明记忆已经是所有人的共识，但对于小龙虾来说不一定非要推倒重来。

给我的 AI Agent 装上一个「大脑」，可能是成本最低、收益最高的选择。

我现在用了几周，最大的感受就是：终于不用重复自己了。

生图不用再说风格，画图不用再说调性，安慰不用再从头试，它记得我是什么样的人，我要什么样的东西。

开源地址是：https://github.com/MemTensor/MemOS

装不装我自己判断，反正开源免费，十分钟就能装完试试。
