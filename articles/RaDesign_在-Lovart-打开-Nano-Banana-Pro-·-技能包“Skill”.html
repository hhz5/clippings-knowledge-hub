以下视频为我 品牌 Skill 测试视频。

那么大家肯定在很多信息渠道去了解过 Skill 是什么？它对于设计师来说有何优势？以及如何使用 Skill ？

请带着这些疑问跟随我去了解。

Lovart Skill

要想了解 Lovart Skill 是什么，先要了解 Skill 是什么，从直译来看是 “技能”「Agent的技能」，像游戏里的 某种角色技能 类似，比如你是远程法师：技能1 “火球术”、技能2 “冰之炎”、技能3 “陨石岩”等等等。

你的技能1 ”火球术“ 对待不同怪物有不同的 “流程、组合技、什么高级装备发出的、属性”也就等同于[“流程”「说明书」=SKILL.md、“组合技”「引用文档」=references、“高级装备”「放置脚本」=scripts、“属性”「资源目录」=assets] ，以上这些东西打包成一个文件夹，就是一个 Skill 的“技能”包。

一句话总结：带说明书的提示词。

那么 lovart skill 就好理解了，垂直于设计 Agent 的技能包，下方右侧可以直接使用。

1. 电商 · Amazon Listing Images

· 点击右侧电商 Skill 进行使用。

输入框上方有 3 个选项，分别为你设置好了的案例进行使用，我们选择 “完整产品套图”，输入框内修改成自己的内容即可。

上传产品图像「最近空气炸锅比较火，这里作为参考」

提示：设计一套完整的亚马逊产品图，我的产品图是 [空气炸锅图像.jpg]，卖点是：温度可调节，傻瓜操作，安全放心。

记得选择 Nano Banana Pro 模型。

快速且高效，电商 Skill 过程很稳定。

2. 排版 · Marketing Brochure & Print Layouts

· 点击右侧营销宣传册 Skill 进行使用。

提示：广宣物料设计，横向异形牌，[整体造型为自然场景的水生沼泽与环形叶鞘交织的圆润轮廓]。画面右侧主体商品为表皮紫黑光亮、形态扁圆饱满的完整山竹，与一枚去皮后显露雪白脆嫩、水润剔透的球茎切面，局部细节呈现果肉的晶莹无渣与渗出微小汁珠的湿润感。材质与纹理细节强调表皮的滑腻光泽、果肉的极致脆嫩，以及去皮后表面水膜般的透亮质感。左侧主标题文字采用圆润清爽的手写艺术字体，第二行卖点文案为“多汁美味，新鲜可口”，装饰性英文“tabbyfashion”以流畅现代的无衬线体全大写呈现。字体周围点缀一小片细长的枯叶鞘与几滴飞溅的清澈水花。画面风格为清新高饱和度3D插画,色彩倾向为表皮的深紫黑、果肉的雪白与水花透明的纯净对比，突出其水多汁美味，新鲜可口的特质，采用大师级画面排版与构图。

背景有些多余，这里利用“移除背景”功能去掉。

去掉背景后这个不规则的 banner 有些意思。

试试三折页设计，交给该 Skill 技能包。

4. 分镜 · Production Storyboards & Character Sheets

· 点击右侧分镜故事版 Skill 进行使用。

提示：为一个原创动漫角色设计分镜，我的设定是：故事梗概是一位少年重生在异世界，在异世界为史莱姆。剧情：在现代社会少年在加班工位上去世了，再睁开眼是异世界。

第一排第二张人物不统一、史莱姆的手不应该是人手，应该是触手、下个分镜没有嘴，只有眼睛、史莱姆眼睛不统一等，我们进行一一修改。

· 我们先用 Mark 标记进行人物上的统一，提示：请把图像里的角色 「标记1角色」替换掉该图像里的角色「标记2角色」请保持角色的统一性。

· 继续修改史莱姆触手，点击修改图像，附上提示：请保持画面统一，修改手，且只有一只触手。手应该是史莱姆的触手，请避免是人类的手。

· 去掉嘴巴，用 “擦除” 即可，提示：请保持画面统一，修改手，且只有一只触手。手应该是史莱姆的触手，请避免是人类的手。

· 最后两张的眼镜不统一，也用 Mark 标记修改一下，提示：请把这张图像里的眼睛 [标记1眼睛]统一到这张图像里[标记2眼睛]

至此，不统一的地方都已经被修改优化，我们用 可灵O1 模型的首尾帧 生成视频，拼接成完整的故事。
