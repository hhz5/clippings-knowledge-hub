今天给好友@洛小山自己做的一个 AI 产品吆喝一把，好工具值得被传播。洛小山（昵称）是 WPS 的 AI 产品总监，本来就没什么闲暇的闲暇时间还喜欢捣鼓一些对大家有帮助的工具，是我好友中的熬夜冠军和细节控狂魔。

他的产品是一个叫 Alice 的带有可视化的很有温度的 AI 助手 APP，专门用来帮助用户解决日常办公的需求，做到现在是纯公益免费性质，我问了他本人，至少目前他完全没有想赚钱的意思哈哈哈。

简单来说，他做了一个类似 ClaudeCode 但提供完整 GUI 可视化界面的工具，比 Codex 这类工具更多便携快捷方式也更有温度，整个工作流程全部是展现出来的，让大家都能知道它为了完成某个任务做了什么动作。

并且视觉效果很不错👇

使用场景

日常任务，什么生成文档、做网页、数据分析都是手拿把掐的。

数据分析👇

滑动查看所有内容

分析完做个可视化仪表板网页也就是一句话的事👇

除了日常我们的一些简单任务，调用 Skill 和 Cli 的场景也非常方便，只要 Skill 安装好了，Cli 配置好了，除了单个调用，组合拳也很好用，比如我安装好了飞书 Cli、即梦 Cli ，还做了配图的 Skill ，那么我就可以直接给她网址、让她调用飞书 Cli 读取文章，Skill 控制和输出提示词，调用即梦 Cli 输出配图，点击右边可以看到工作区和附件👇

之前还尝试了深度调研的需求。我调用了一个做课件的深度搜索的Skill，说基于公开课资料的需要，让它帮我深度搜索相关的优质视频和说课稿。

下面是我和她的全程对话，从需要深度搜索开始，Alice 的伙伴也闪亮登场了。深度调研的时候陈知远调研员出现了，并且过程中他也可以三项调研同时进行，很有意思。

这里还遇到个问题，当时我电脑没有 md 转 word 文档的工具，它自己写了一个处理好了。👇

虽然我中途阻止，但还是做了 38 页 15000 多字，主要之前我没有特意设置上限，没想到这个调研员这么勤恳的哈哈哈👇

还有个很实用的，还记得我们之前在左下角【渠道】绑定了邮箱吗，绑定好以后，后续可以直接让Alice把结果发到指定邮箱（如果绑定的邮箱不知道怎么获取授权码也可以直接问 Alice 让她一步步教学）👇

上面的右上角那个高亮的【让Alice处理】，点击后就可以让Alice直接读取该邮件了，不管是提炼或是回复都很方便👇

还有很棒的一点是这个过程中所有的执行过程都是可见的。相当于我们直接看到了他可检查的工作证据链，我们也能看到这个我们在用的模型在哪些地方强，哪些地方可能需要人工辅助或者判断👇

好奇还可以看看 Alice 的朋友们是怎样各司其职的，不需要特地去记，触发了场景伙伴自会出现，就像上面出现了设计师周念、调研员陈知远一样（小山做得是真的很细致，光是角色设定都有一个合订本，待我截个图）。👇

Alice的朋友圈

如果有沉迷养女儿快乐的朋友，还可以玩一下这个功能，左上角的爱心图标可以看到情绪状态，左下角的爱心图标可以到 Alice 的朋友圈，点击右上角给她打零花钱，这里的打赏都会用在她的 token 消耗。这里花的并不是等值人民币，就只是 token 额度，但这个养成的感觉还挺有意思的哈哈哈。

收到“打赏”她自己会快乐消费，还会更新朋友圈，生活还挺滋润🤣

没有 token 怎么试玩！

这时候有朋友要问了，如果一点 token 也没有，但是又好奇，有没有什么办法可以先试玩下的？

有的，朋友们有的。来，阿真来教学，选择左下方【设置】，然后在基础设置选【模型供应商】，拉到最下面，有个观猹友情赞助，这个点开，去指引的网页注册帐号，立马获得20yuan的额度。

在【API】密钥创建密钥，然后点击复制👇

回到刚刚模型供应商那块，在【中转/聚合】找到观猹/词元跳动，把复制的密钥贴进去，然后点击旁边的【测试连接】。可以用的模型也都可以看到。可以自己在下方选择相应模型。还可以往下拉，最新的 DeepSeek V4 模型在最下面的位置。

另外看到这个专属 token 还可以填写 ID 和昵称，建议大家也可以填上，在刚刚密钥下面【个人信息】的位置可以找到用户 ID。这个有 30 ，大概3天内会到，加起来有 50 了。
