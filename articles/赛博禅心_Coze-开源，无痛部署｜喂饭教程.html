过程分为几步....

  • • 安装 Docker
  • • 下载并安装 Coze Studio
  • • 启动并访问系统界面
  • • 配置模型（用来运行智能体）
  • • 更换模型（比如切换到 OpenAI 或智谱）

让我们分开来说

一、安装 Docker

第一步，你需要安装一个叫做 Docker 的程序

Docker 是啥？
是一个“运行应用环境”的工具，省的用户来回折腾环境

安装方法：

你可以去 Docker 官网下载：
https://www.docker.com/products/docker-desktop/

也可以使用我提供的下载包
https://ay6exk7fyt.feishu.cn/drive/folder/IccNf2B4JlJOIvd2kWfcpYnRn4l

传到飞书了

二、安装 Coze Studio

首先，打开 Docker Desktop，点击右下角“终端 Terminal”，输入：

git clone https://github.com/coze-dev/coze-studio.git

含义是：
从 GitHub 下载 Coze Studio 的官方代码

右下角有个 Terminal，点一下

按下回车，东西就被拉取下来了

第二步，输入：

cd coze-studio/docker

意思是：进入 Coze 的 docker 配置文件夹

cd 的意思是 Change Directory，更改目录

更改目录到项目位置

第三步，输入：

cp .env.example .env

这句话的意思是，把环境配置模板，复制为实际配置

其中， cp ：是 copy（复制） 的缩写，用于复制文件或目录。然后将当前目录下的 .env.example 文件复制一份，并命名为 .env

复制环境

最后，输入：

docker compose --profile '*' up -d

这个指令的意思是，安装所有配置，然后 Coze Studio 需要的所有服务

docker compose ：使用 Docker Compose 运行服务

--profile '*' ：启用所有 profile 配置， * 代表所有

up ：启动服务（没有就创建容器，有就重启）。

-d ：detached 模式，即后台运行

启动项目

首次部署，需要构建本地镜像，这可能需要一些时间，请耐心等待

要一点时间，取决于网络

很好，一切部署完成，打开浏览器，访问:

http://localhost:8888/

localhost:8888 是打开本地运行的项目，然后监听的 8888 端口

于是，你就可以看到 Coze Studio 的首页了

随便输入点啥

三、配置模型服务

这时候虽然可访问 UI，但没有模型无法创建智能体或工作流

1、在 terminal 里输入：

open ../backend/conf/model/

如果你是 windows，则输入

start ../backend/conf/model/

意思是，打开上级目录中的 backend/conf/model/ 文件夹

其中 .. 指的是「上级目录」

当然，你也可以手动打开文件夹

2、这里，我们以配置豆包模型为例，打开文件 ark_doubao-seed-1.6.yaml

修改其中的 model 和 api_key

meta:
  conn_config:
    api_key: "你的密钥"
    model: "doubao-seed-1.6"

这里有很多配置可以更改

有朋友可能会问：
Api Key 在哪里获取？

答：各 API 平台都行

比如豆包的 API Key，来自火山（字节的云服务平台）
https://console.volcengine.com/ark/region:ark+cn-beijing/apiKey?apikey=%7B%7D

在这里新建即可

点一下新建

3、保存后，需要重启 Coze 服务生效

docker compose --profile "*" restart coze-server

大概需要 10 秒

四、重启后体验 Coze

打开浏览器访问：

http://localhost:8888

此时，你就能完整地体验 Coze Studio 了，可以创建智能体、组合工作流

啊～熟悉的页面

五、如果想更换模型？

1、重新打开 model 配置文件夹，打开 template 文件夹：

open ../backend/conf/model/

2、打开 template 文件夹，找到一个模板，然后复制到上一级目录

里面有很多模板

3、比如说，我想使用智谱的模型，就复制 model_template_basic 到上一层文件夹，改名 glm.yaml （名字不影响）

随便复制一个，改不改名都行

4、修改里面的各种简介， url 、 model 、 api_key 等各种信息，然后保存

当作是个.txt，用笔记本就能改

5、重启 coze-server 服务生效：

docker compose --profile "*" restart coze-server

6、再次访问 Coze，就可以选择新模型了

你可以配置 logo，以及其他信息

一些 FAQ

部署是不是很麻烦？
参考上文，有手就行

听说没完全开源，是不是只能看不能用？
最核心部分，也是大家所理解的Coze，已经全部开源

扣子是「Apache 2.0 开源」，啥意思？
Apache 2.0 是常见开源协议中 最开放的 ：

  • • 可商用：可商业使用，无附加条款
  • • 专利授权： 明确授权，无后顾之忧

对于常见的开源协议，这里做了一个对比

不同开源协议的差异

是不是只能用火山/豆包的模型？
你想用啥都行

插件没开源，是不是有限制？
插件是第三方服务，你可以在../backend/conf/plugin 中定义任何插件

Agent 平台的绝对老大，开源了自己的业务...掀桌子了
